一、项目完成说明
1.1 当前阶段项目目标
本项目目前处于大学生创新创业比赛前期准备阶段，学校尚未正式审核项目方案，因此暑假阶段的开发目标不是完成一个完整商业化产品，而是完成一个具有核心功能、能够进行项目展示的Demo版本，用于开学后的项目申报以及后续比赛展示。
由于项目是否能够通过学校审核、是否进入正式比赛流程目前无法确定，因此团队现阶段不进行过度扩展，而是围绕项目核心价值完成约60%的基础版本。核心目标是证明“AI能够帮助计算机专业大学生分析自身就业竞争力，并提供职业规划和简历优化建议”这一方向具备可行性。
暑假结束前，需要完成一个完整闭环：
用户填写大学阶段经历 → AI分析个人能力 → 生成就业画像 → 推荐适合岗位 → 优化简历 → 提供能力提升建议。
通过这个流程，让评委能够直观看到项目解决的问题以及AI技术带来的实际价值。

二、项目技术路线
2.1 整体技术架构
项目采用前后端分离架构：
React + Next.js 前端->FastAPI 后端->DeepSeek大语言模型->MySQL数据库
JSON岗位知识库->RAG检索增强
整体技术路线围绕“AI应用开发”展开，而不是传统管理系统开发。
前端负责：
基本网页的实现（直接去抄或者js反向爬虫一个好看的网页去改就完事、但是AI很蠢很难做到想要的效果）、用户信息、各种功能展示等前端要渲染出来的内容实现（不涉及核心功能，其余基础功能全由前端去搞，比如注册登录、设置页）
后端负责：
核心功能的实现（有现成做好的可以直接去问AI如何实现、再进行不断的调整优化）、优化核心功能、不用拓展子功能、保证项目能基本运行就行。
知识库部分负责：
去找相关资料做好RAG的实现（B站上有课但是看不懂、这个资料大部分要AI生成，但是要审查是否真实，还要去知网上去找相关参考文献 、资料确保真实性）准备一些文档要用的材料比如流程图、E-R图、数据流图啥、相关文献收集方便以后文档编写。

主要负责：
•	用户数据处理； 
•	AI模型调用； 
•	岗位匹配； 
•	简历生成。

保存用户数据。
例如：

•	技能； 
•	项目经历； 
•	AI分析结果。

________________________________________
AI技术：DeepSeek + LangChain + RAG
DeepSeek：
负责理解学生经历并生成分析结果。
LangChain：
负责组织AI任务流程。
例如：
学生经历分析 → 岗位匹配 → 简历优化 → 成长规划。
RAG：
通过岗位知识库增强AI结果准确性。
避免AI只凭自身知识回答，而是结合真实岗位要求进行分析。

三、核心功能定义与描述
3.1 AI就业画像分析
功能定义
AI就业画像分析是本项目的核心入口功能，主要针对计算机专业大学生在大学期间积累的大量经历无法有效转化为就业优势的问题。系统通过收集学生的专业背景、技术技能、课程学习情况、项目经历、竞赛经历、实习经历等信息，利用大语言模型对用户经历进行结构化分析，将学生原本零散的经历转换为企业招聘视角下的能力画像，帮助学生发现自身隐藏优势，明确当前就业竞争力。
解决问题
目前很多计算机专业学生存在“学了很多技术，但是不知道自己的价值在哪里”的问题。例如一个学生可能学习过Java、Vue、数据库，完成过几个课程项目，也参加过比赛，但是无法判断自己更适合后端开发、前端开发、测试开发还是AI应用方向。同时，学生通常只关注技术名称，而不了解企业招聘更关注的是技术背后的能力，例如“完成SpringBoot项目”实际上代表后端开发能力，“参与算法比赛”代表算法基础和问题解决能力。因此，该功能帮助学生将大学经历转换为职业能力。
功能实现
用户输入：
•	专业方向； 
•	掌握技术栈； 
•	项目经历； 
•	比赛经历； 
•	实习经历； 
•	自我评价。 
AI分析内容：
•	技术能力分析； 
•	项目实践能力分析； 
•	工程开发能力分析； 
•	学习能力分析； 
•	职业方向判断。
最终输出：
用户就业画像（一个对用户的就业定位）
用户倾向的技术方向：
后端开发能力较强
用户的就业核心优势：
1. 掌握Java开发体系
2. 具备SpringBoot项目经验
3. 有数据库设计经验
用户的当前水平：
具备初级后端开发岗位竞争力
用户的推荐方向：
1.Java后端开发工程师
2.全栈开发工程师
用户需要提升地方：
Redis、微服务、企业级项目经验

3.2 AI岗位方向匹配
功能定义
AI岗位方向匹配功能主要解决计算机专业学生“知道学习技术，但是不知道未来应该进入什么岗位”的问题。系统根据学生当前技术能力、项目经验以及岗位要求数据库，对用户进行职业方向推荐，帮助学生找到与自身能力更加匹配的发展方向。
该功能不是简单的招聘信息搜索，而是通过分析学生当前能力和企业岗位要求之间的差距，告诉学生“为什么推荐这个岗位”和“距离这个岗位还缺少什么能力”。
解决问题
目前计算机专业就业方向较多：
•	Java后端开发； 
•	前端开发； 
•	AI应用开发； 
•	算法工程师； 
•	测试开发； 
•	数据分析。 
很多学生面对大量岗位不知道如何选择。例如：
学生：
Java + SpringBoot + MySQL + Vue
传统方式：
学生自己搜索岗位。
本项目：
AI分析：
该技术组合更符合Java后端开发岗位要求，因此推荐后端方向。
功能实现
系统流程：
学生能力数据
↓
提取技术标签
↓
匹配岗位知识库
↓
分析岗位匹配程度
↓
生成推荐结果
输出示例：
推荐岗位：
Java后端开发工程师
匹配度：
86%
推荐原因：
1. 掌握Java语言
2. 熟悉SpringBoot开发
3. 具有数据库项目经验
岗位要求：
Java
SpringBoot
MySQL
Redis
当前差距：
缺少：
Redis缓存应用经验
微服务架构经验
提升建议：
完成一个企业级后端项目
学习Spring Cloud

3.3 AI简历优化助手
功能定义
AI简历优化助手主要解决计算机学生“有项目经历，但是不会写简历”的问题。系统根据用户目标岗位要求，对学生已有项目经历、技能描述以及个人优势进行AI优化，使其从学生视角描述转换为企业招聘视角描述，提高简历内容专业度。
该功能不是简单修改文字，而是结合目标岗位要求，对项目经历进行重新包装，使简历更加突出技术能力和实际贡献。
解决问题
很多学生简历存在以下问题：
第一，只描述做了什么，没有体现技术价值。
例如：
普通描述：
完成校园管理系统开发。
企业视角：
不知道使用什么技术，不知道学生承担什么工作。
AI优化：
基于SpringBoot + Vue构建校园管理系统，负责用户权限管理、数据库设计以及后端接口开发，实现学生信息管理和业务流程优化。
第二，不知道如何突出个人能力。
例如：
学生：
“参加过程序设计比赛。”
AI优化：
“参与程序设计竞赛，提升算法设计能力和复杂问题分析能力。”
功能实现
用户输入：
•	原始简历内容； 
•	目标岗位。 
AI分析：
岗位要求
↓
匹配项目经历
↓
优化描述方式
↓
生成岗位化简历内容
输出：
原始：
开发一个商城系统。
优化：
基于SpringBoot开发在线商城系统，
完成用户管理、商品管理、订单处理等核心模块，
设计MySQL数据库结构，实现前后端数据交互。

3.4 AI成长提升规划
功能定义
AI成长提升规划功能根据学生当前就业画像和目标岗位要求，分析学生目前存在的能力差距，并生成个性化学习路线，帮助学生明确未来需要学习什么技术、完成什么项目以及达到什么就业水平。
该功能相当于一个针对计算机学生的AI职业导师。
解决问题
很多学生的问题不是不努力，而是不知道学习方向。
例如：
学生学习：
Java基础、Vue、数据库。
但是不知道：
•	是否需要学习Redis； 
•	是否需要学习微服务； 
•	是否应该转AI方向。 
系统通过分析：
当前能力 → 目标岗位要求 → 能力差距 → 学习计划。
功能实现
输入：
目标岗位：
AI应用工程师。
当前能力：
Python基础。
AI生成：
当前情况：
具备Python基础，可以进行简单开发。
能力差距：
缺少：
机器学习基础
大模型应用经验
RAG开发经验
提升路线：
阶段一：
学习机器学习基础知识。
阶段二：
学习LangChain、大模型API调用。
阶段三：
完成AI应用项目。
最终目标：
达到AI应用开发岗位要求。

项目最终定位总结
本项目不是一个普通招聘平台，也不是简单的AI聊天工具，而是一个面向计算机专业大学生的AI就业竞争力提升助手。
核心流程：
分析大学经历 → 发现个人优势 → 推荐就业方向 → 优化求职材料 → 指导能力提升。
