## 业务与权限

| 能力 | 结果 |
|---|---|
| 注册角色与登录 | 注册默认学生，可选招聘者；服务端身份返回角色；登录/刷新按角色进入工作台 |
| 旧账号迁移 | 新增 `accounts.role`，旧行默认为 student，重复迁移不重复改表，旧数据保留 |
| 学生/招聘者隔离 | 学生调用招聘管理接口返回 403；招聘者调用学生私有档案、匹配、简历、外部投递等接口返回 403 |
| 招聘者内容归属 | 招聘者 A 无法读取、修改、发布、下架或删除 B 的岗位，不能查看或更新 B 收到的投递 |
| 企业资料 | 发布前需要企业名称、联系人和有效联系邮箱；页面明确资料由招聘者填写 |
| 岗位管理 | 草稿、招聘中、已下架；发布校验完整字段；在线编辑被拒绝；有投递的岗位不可删除 |
| 检索 | 关键词覆盖标题、企业、职责、要求和技能标签；可按分类、城市筛选并分页 |
| 投递校验 | 只能投递本人简历；数据库唯一约束防重复；下架或账号禁用的岗位不可浏览或投递 |
| 简历快照 | 只分享已选技能/项目/竞赛/实习、基本信息和概要；保留已采纳的项目表达；后续修改简历不改变已投递内容 |
| 处理状态 | 已投递、筛选中、面试中、已录用、未通过、已撤回；终态不可重新打开，投递状态采用条件更新防止覆盖不同的新状态 |
| 学生反馈 | 招聘反馈保存后学生可以在站内查看；未结束投递可撤回，撤回后不能重复投递同一岗位 |
| 异常与空态 | 空库显示真实空态，失败可重试；发布失败保留草稿与输入并展示缺失字段，未保存离开有提示 |
