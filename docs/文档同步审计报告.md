## 1. 当前项目实际架构与技术栈

### 1.1 技术栈（以依赖清单为准）

| 层级 | 实际技术 | 依据 |
|------|---------|------|
| 前端框架 | **React 19.2**（非 Vue3） | `frontend/package.json` dependencies：`react ^19.2.0`、`react-dom ^19.2.0` |
| 3D 渲染 | Three.js 0.182 + @react-three/fiber 9.4 + drei 10.7 + postprocessing | `frontend/package.json`、`frontend/src/App.jsx` |
| 动画 | GSAP 3.14 + @gsap/react | `frontend/package.json`、`GalleryRoom.jsx` |
| HTTP | Axios 1.7（`baseURL:"/api"`，30s 超时，X-Request-ID 注入，`ApiError` 业务错误） | `frontend/src/api/index.ts` |
| 构建 | Vite 7.2 + TypeScript 5.5 + Sass（**无 vue-tsc**） | `frontend/package.json` scripts、`frontend/vite.config.ts` |
| 代理 | Vite dev server `/api → http://localhost:8000` **已启用**（未注释） | `frontend/vite.config.ts` |
| 后端 | FastAPI + Uvicorn（Python ≥3.10） | `backend/main.py`、`backend/requirements.txt` |
| ORM/校验 | SQLAlchemy 2.0（Mapped 写法）+ Pydantic v2 | `backend/app/models/`、`backend/app/schemas/` |
| 数据库 | SQLite（开发默认）/ MySQL 8（生产，pymysql） | `backend/app/config.py` |
| AI | DeepSeek API（OpenAI 兼容 SDK），未配 Key 自动 Mock | `backend/app/ai/deepseek_client.py` |
| 知识库 | Markdown + 内存关键词倒排索引（纯 Python） | `knowledge/` + `backend/app/knowledge/` |

前端**不存在** Vue、Pinia、Vue Router、`views/`、`router/`、`store/`、`layouts/` 等旧文档所述内容（`frontend/src/` 下无任何 `.vue` 文件）。

### 1.2 前端实际结构（沉浸式 3D 多房间架构）

- 入口链：`main.jsx` → `App.jsx`（Provider 栈：Performance → Achievements → User → JobMatch → Audio/Scene）→ `Canvas`（R3F）→ `Experience`（懒加载）
- 功能房间（4 个，`NavigationUI.jsx` ROOMS 与 `RoomInterior.jsx` 导入一一对应）：**About（就业画像）、Gallery（岗位匹配房间）、Studio（AI 工作台）、Contact（联系我们）**；入口（EntranceDoors/EmptyCorridor）与走廊（Corridor/InfiniteCorridorManager/传送门）为公共场景/导航空间，不计入功能房间数量
- 全局 UI：`NavigationUI`、`GlobalOverlay`（纸张卡片弹层，承载岗位详情/表单）、`JobMatchPanel`（房间内入口）、`ProfileOverlay`（档案编辑）、`ScreenReaderOverlay`、`Preloader`
- Context：`UserContext`（档案 + 画像分析）、`JobMatchContext`（岗位浏览/匹配）、`SceneContext`、`AudioManager`、`PerformanceContext`、`AchievementsContext`
- API 封装：`src/api/{index,user,analysis,jobMatch,resume,growth,system,types}.ts` + `src/adapters/{profile,jobMatch}.ts`
- SSE 工具：`src/utils/sse.ts`（`streamSSE`，fetch + ReadableStream）
