## 第二轮视觉差异（只读对比）

对比基准：`portfolio-itom-main/.../Gallery/GalleryRoom.jsx`（参考版 **1367 行**）  
当前实现：`frontend/src/components/canvas/rooms/Gallery/GalleryRoom.jsx`（优化前 **477 行**）

| 维度 | 参考版 | 优化前当前版 | 差距 |
|------|--------|--------------|------|
| **卡片数量** | `PROJECT_COUNT = 10` 固定 | `MIN_CARD_COUNT = 3`，动态 3~8 张 | 视觉密度不足、滚动环不完整 |
| **GAP / 滚动** | `GAP = 2.5`，`totalWidth = PROJECT_COUNT * GAP` | 随 `cardCount` 变化 | 无限循环算法与参考不一致 |
| **openCard / closeCard** | ProjectCard 内完整 GSAP 时间线（~200 行） | JobCard 简化版（压缩单行 timeline） | 翻面节奏、缓动、中间态不同 |
| **useFrame** | 分块处理 text / button / details / techStack 四组弯曲；`PROJECT_COUNT * GAP` 定位 | 合并 helper、缺少 techStack 组级弯曲；`cardCount * gap` | 文字贴纸与风摆不同步 |
| **空数据** | 4 个项目循环填满 10 卡 | 3 张「加载中/暂无岗位」文字卡 | 破坏参考构图 |
| **面板** | 无居中 HTML 面板 | `JobMatchPanel` 顶部居中宽面板（520px） | 遮挡云层与天空 |

### JobCard vs ProjectCard 动画差异

| 项目 | 参考 ProjectCard | 优化前 JobCard |
|------|------------------|----------------|
| closeCard | 6 段 timeline，含 scale 复位 | 结构相似但写法压缩 |
| openCard | scrollToIndex 回调内 8 段 + 独立 uProgress | 同结构但缺少 techStackGroup 级 Z 弯曲 |
| 正面文字 | 仅 `textRef`，`fillOpacity=0` + paint 揭示 | 额外 `categoryRef`、tags 正面可见 |
| 背面 | details @ Y=-0.5，techStack @ Y=0.30 | details @ -0.35，tags 组 fillOpacity 恒为 1 | 正反面文字叠显 |
| 按钮 | `OPEN PROJECT` + window.open | `查看详情`（业务正确） |

### JobMatchPanel 构图遮挡

- 优化前：`position: fixed; top: 1rem; left: 50%; width: min(92vw, 520px)` — 永久居中白底面板，遮挡晾绳上方云层。
- 参考版：无此类 HTML 遮罩，场景全屏可见。

### `/api/jobs` 实测（2026-09-11）

| 测试 | 结果 |
|------|------|
| 后端进程 | 本地需 `uvicorn main:app --port 8000`；未启动时 Vite 代理返回 **HTTP 500/连接失败**（非业务逻辑 bug） |
| `GET /api/jobs?page=1&page_size=8` | **200**，`code: 0`，`total: 54`，8 条 items |
| 知识库直调 `JobMatchService.search_jobs` | 54 篇岗位可加载 |
| `category=前端` | **200**，含「前端开发工程师」 |
| `keyword=前端` | 可检索前端相关岗位 |

**结论**：截图中的 HTTP 500 原因为**后端未运行**；知识库与接口逻辑正常，前端不应伪造数据。

## 第二轮改动清单

1. 恢复 `PROJECT_COUNT=10`、`GAP=2.5` 与参考版无限滚动。
2. JobCard 按参考 ProjectCard 动画骨架重写；业务字段替换为中文岗位信息；中性 `tylkartki` 纸张。
3. JobMatchPanel 改为右下角「岗位搜索」小入口 + GlobalOverlay `job_match_panel` 表单。
4. API 失败时 10 张空白纸卡 + 轻量 toast，不在卡片上写错误文案。
5. NavigationUI / GlobalOverlay 等用户可见英文改为中文。
