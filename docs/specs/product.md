# 需求规范 (Product Specification)

> **功能名称：** 按接口文档补全并固化后端接口
> **版本：** v1.0
> **状态：** 已批准
> **作者：** AI Architect + Human Engineer
> **最后更新：** 2026-09-10

## 1. 概述

依据 `docs/02-API接口文档.md`，使后端对外提供文档列出的系统、用户、岗位匹配、画像分析、简历优化、成长规划和 SSE 接口，并保证统一响应、参数校验、资源不存在处理及 Mock 模式行为可验证。现有路由已覆盖文档列出的 27 个接口，本次重点是补齐实现与契约之间的行为缺口，并建立可重复的最小回归验证。

## 2. 用户故事与验收标准

### US-001: 系统与资源接口可用

**作为**前端调用方，**我希望**系统接口和资源查询接口返回文档约定的数据结构，**以便**完成页面加载和岗位浏览。

- **AC-001.1:** GIVEN 后端启动，WHEN 请求 `/`、`/api/health`、`/api/usage`，THEN 返回 HTTP 200、`code=0`，且数据包含文档要求字段。
- **AC-001.2:** GIVEN 知识库可读，WHEN 请求岗位列表、岗位详情，THEN 返回分页/详情结构；不存在岗位返回 HTTP 404 和统一错误结构。

### US-002: 学生资料和经历可维护

**作为**学生，**我希望**创建、更新和整组替换个人经历，**以便**后续 AI 功能使用最新资料。

- **AC-002.1:** GIVEN 合法资料，WHEN 调用用户创建、基本资料更新和上下文接口，THEN 返回完整用户聚合及四组经历。
- **AC-002.2:** GIVEN 用户存在，WHEN 调用技能、项目、竞赛、实习替换接口，THEN 未提交的旧条目被删除，空数组可清空整组。
- **AC-002.3:** GIVEN 用户或请求参数无效，WHEN 调用对应接口，THEN 分别返回 404 或 HTTP 422、业务码 1001/3001，不产生部分写入。

### US-003: AI 同步、历史和流式接口可用

**作为**学生，**我希望**完成岗位匹配、画像分析、简历优化和成长规划，并能查询历史或使用 SSE，**以便**获得连续的就业提升反馈。

- **AC-003.1:** GIVEN 合法请求且 Mock 模式，WHEN 调用三个同步 AI接口或岗位匹配，THEN 返回符合 Schema 的结果；AI 同步结果包含 `is_mock=true`，匹配结果可落库并返回 `record_id`。
- **AC-003.2:** GIVEN 已生成记录，WHEN 查询详情或用户历史列表，THEN 返回文档要求的字段、排序和统一响应结构；不存在记录返回 404。
- **AC-003.3:** GIVEN 合法流式请求，WHEN 调用三个 `/api/stream/*` 端点，THEN 返回 `text/event-stream`，至少发送 start、chunk、complete 或 error 事件，且不落库。

## 3. 非功能性需求

| ID | 类别 | 描述 | 目标指标 |
|:---|:---|:---|:---|
| NFR-001 | 兼容性 | 保持 API 文档 V2.1 的路径、方法、字段和统一三段式响应 | 27/27 路由可发现 |
| NFR-002 | 正确性 | 所有请求体使用现有 Pydantic Schema 校验，错误结构稳定 | 定向契约测试通过 |
| NFR-003 | 数据一致性 | 经历整组替换在单次事务中完成 | 失败时无半更新 |
| NFR-004 | 可测试性 | 测试使用隔离 SQLite，不依赖外部 AI Key 或运行中服务 | 本地可重复执行 |

## 4. 约束与假设

### 约束
- `docs/02-API接口文档.md` 是唯一接口契约；不新增认证、自动投递或生产系统集成。
- 复用现有 FastAPI、SQLAlchemy、Pydantic、知识库和 DeepSeek Mock 实现，不引入新运行时依赖。
- 保留当前错误码兼容行为：资源不存在使用现有 `3001`，参数校验使用 `1001`。

### 假设
- 当前任务在开发环境执行，所有接口无需认证。
- AI Key 未配置时以 Mock 模式作为验收基线。
- 用户允许将现有后端测试扩展为契约测试；不要求本次实现 JWT、限流或向量检索。

## 5. 超出范围 (Out of Scope)

- Embedding 向量检索、知识库内容重写。
- 前端页面改造及接口文档本身的版本升级。
