## 2. 已连通的流程

1. 首页或资源中心查看动态，保留原始来源与发布日期。
2. 就业画像查看岗位样本需求，以及个人档案中的对应记录。
3. 岗位列表直接比较技能差距，进入岗位简历或创建成长任务。
4. 简历按目标岗位优化，用户逐项核对 AI 表达后保存正式版本。
5. 在简历内准备投递材料、打开招聘页面尝试预填，由用户确认最终发送。
6. 在投递记录补充状态与反馈，并可将待改进事项加入成长任务。
7. 完成任务时提交产物或复盘，刷新后仍能查看任务与完成证据。
8. 用户可补充档案事实并重新匹配岗位；本次没有把勾选完成直接转换成技能评分上涨。

## 3. 登录、隔离与自动化

- 失效登录凭证触发 401 时，清除对应旧凭证并进入登录页，保留原访问路径。
- 旧请求的迟到 401 不会清除后来登录得到的新凭证；登录、注册、找回密码页不重复跳转。
- 资源页面仍要求登录。401 是身份校验结果，不能通过取消鉴权来“修复”。
- 任务、资源交互、简历版本和投递记录按账号隔离，拒绝跨账号读取或更新。
- 成长任务按账号和来源去重；同一简历版本与岗位链接复用已有投递记录。
- 已有投递结果的记录不能直接再次启动预填。
- 预填仅接受 HTTPS 的 BOSS 域名链接，不接受账号信息、自定义端口或首页链接；跳转后再次检查地址。
- 仅尝试识别明确的沟通输入框，不向任意文本框填入开场白；无法识别时提示手动填写。
- 不绕过验证码，不点击最终发送，不进行无人确认的批量投递。

## 4. 数据与真实性

### 资讯

- 当前接入 GitHub、Python 官方博客的 RSS 白名单。
- 保留原始发布日期、原文链接、来源名称与抓取时间。
- 只展示最近 30 天的有效日期内容；过滤未来、无日期、过期及非来源域名链接。
- 限制响应体大小，拒绝 XML DTD/实体输入，去除摘要中的 HTML。
- 按需抓取并使用进程内缓存：正常结果缓存 15 分钟，完全无结果时短暂缓存后可重试。
- 单个来源不可用时，仍展示其他可用来源；全部不可用时不生成替代新闻。
- 当前不是定时采集、数据库持久化资讯或跨进程共享缓存，也不提供“全网最热”排名。

### 岗位与简历

- 技能对照使用现有技能同义词归一化，修复 Java 与 JavaScript 的子串误匹配。
- 同一岗位中的重复技能不重复计入覆盖度或样本频率。
- AI 可补充解释和建议，不能覆盖确定性计算的技能覆盖分及缺口列表。
- 简历改写回指用户经历原文与记录 ID；目标 JD 只提供岗位要求，不能作为用户已具备成果的证据。
- 检出来源中不存在的新数字时回退到原文并提示；个人介绍同样接受新增数字检查。
- 未经用户确认的 AI 改写不会静默覆盖正式简历。

### 持久化

- 新增成长任务与资源交互表，收藏、已读、不相关以及任务状态均按账号保存。
- 新增出生日期兼容迁移，旧账号可保留空值；新增表由现有数据库初始化流程创建。
- 测试固定使用隔离 SQLite，避免认证测试夹具对实际配置数据库进行建表/删表操作。
- 已有数据库仍应在正式部署前备份，并按实际数据库类型执行迁移验证。

### 测试边界

业务页面浏览器测试使用明确标识的接口夹具，验证布局、交互与前端刷新流程，不写入真实业务数据。浏览器测试中的注册页与失效凭证跳转使用实际运行的应用；账号隔离、持久化、去重、迁移与校验由隔离数据库的后端测试验证。

真实 RSS 抓取曾返回有效内容，并观察到部分来源不可用，已验证部分降级行为；这不是对所有来源持续可用性的保证。

## 6. 尚未完成的方案项

以下项目仍需后续开发，不能视为已通过完整方案验收：

1. **资讯运营底座**：持久化资讯与来源表、定时采集、来源管理和审核、内容过期归档。
2. **岗位市场统计**：接入更多授权国内岗位来源，提供带统计周期的城市、学历、企业类型及技能趋势；现有样本频率不能替代市场趋势。
3. **完整证据模型**：经历的成果摘要、关联技能、核验状态、可用于简历标记及独立证据管理；当前主要复用已有技能、项目与完成产物。
4. **硬条件判定与分层评分**：毕业时间、学历、专业、城市、实习时间等结构化校验，以及项目场景、偏好、证据可信度的分项评分和人工校准。
5. **简历质量评测**：四维评分、语义级事实一致性校验、质量评测集及批量回归；当前防新增数字与逐项确认不能完全阻止模型虚构。
6. **成长深度反馈**：独立面试答题及 AI 批改、技能与匹配度历史快照、连续学习统计、任务期限及核验流程。
7. **反馈分析**：推荐效果、成长任务完成率、投递漏斗和结果分析；目前保存反馈和任务，不自动训练或调整匹配模型。
8. **部署级验收**：实际生产数据库迁移、长期运行、资讯源稳定性、真实招聘网站登录/验证码/页面变更兼容测试。
