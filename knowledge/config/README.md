# config/ — 配置文件

## 目录职责
集中管理知识库的所有配置参数。

## 配置文件清单
| 文件 | 说明 |
|------|------|
| `knowledge_config.json` | 全局路径、分类、加载策略 |
| `retrieval_config.json` | 检索策略（keyword/embedding/hybrid）|
| `embedding_config.json` | Embedding 模型候选配置 |
| `llm_config.json` | DeepSeek API 调用参数 |
| `chunk_config.json` | 文本切块配置 |
