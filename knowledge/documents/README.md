# documents/ — Markdown 知识文档

## 目录职责

存放所有结构化的 Markdown 知识文档，是知识库的核心数据层。每个 `.md` 文件代表一个独立的知识条目。

知识库目标：打造一个可用于 **Keyword Retrieval（关键词检索）**，未来可无缝升级为 **Embedding + FAISS + Hybrid Retrieval** 的高质量企业级 RAG 知识库。

## 文档规范

每个 `.md` 文件必须包含：

### Front Matter（YAML 头信息）

```yaml
---
title: 文档标题
category: 分类（岗位/技能/企业/面试题/项目/路线/简历/市场/竞赛/政策）
tags: [标签1, 标签2, 标签3]
source: [来源1, 来源2]
last_update: YYYY-MM-DD
---
```

### 正文结构

- 使用 `#` 一级标题做章节划分
- 每篇 9-14 个一级章节
- 丰富的二级/三级子标题
- 末尾必须包含 `Reference`（不少于 3 个来源，标注发布时间和访问时间）
