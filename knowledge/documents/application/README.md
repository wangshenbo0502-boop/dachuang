# AI 可信求职投递知识库

本目录用于支撑项目的核心特色：**以职业能力数字孪生为事实底座，以人机协同方式完成岗位理解、材料生成、表单预填、投递确认和结果复盘**。

知识链分为八个环节：

1. 岗位 JD 结构化解析与硬条件识别；
2. 大学生职业能力证据卡建设；
3. 事实受控的岗位定制简历；
4. AI 可信投递助手的能力边界；
5. 招聘表单预填与人工确认；
6. 投递状态、材料版本与回执验证；
7. 投递结果和面试反馈复盘；
8. 求职隐私、个人信息与浏览器扩展安全。

这些文档面向知识检索和问答使用，不把“猜测”包装成事实，不提供绕过验证码、登录、双因素认证或招聘平台限制的方法。涉及政策、平台规则和技术规范的内容应结合访问日期定期复核。
