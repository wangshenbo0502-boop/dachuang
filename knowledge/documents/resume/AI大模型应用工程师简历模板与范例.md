### 项目经历

#### 企业级 RAG 知识库问答系统（实验室项目） | 2025.03 - 2025.09

> **项目链接**：github.com/lisi-ai/enterprise-rag-system

- **背景**：为某制造企业搭建基于大模型的内部知识库问答系统，解决员工查询技术文档效率低的问题。
- **架构设计**：采用 LangChain + Milvus + Qwen-7B 技术栈，设计文档解析、向量检索、重排序、答案生成四级流水线。
- **核心优化**：针对企业技术文档特点，设计基于章节的语义分块策略（chunk size 512 + overlap 128），引入 BGE-Reranker 进行二阶段重排序，结合 Self-Reflection 机制自动校验答案准确性。
- **效果量化**：在内部测试集上，问答准确率从基线的 65% 提升至 88%，召回率从 72% 提升至 93%，平均响应时间控制在 3 秒以内。系统已在企业内部部署，服务 200+ 研发人员。

#### 多 Agent 协作数据分析平台（个人项目） | 2025.10 - 2025.12

> **项目链接**：github.com/lisi-ai/multi-agent-data-analyst

- **背景**：探索多 Agent 协作在数据分析场景的应用，实现自然语言到可视化图表的自动化生成。
- **实现方案**：基于 LangGraph 设计 Planner → Coder → Reviewer 三 Agent 协作模式，Planner 拆解分析任务，Coder 生成 Python 分析代码，Reviewer 校验结果合理性。支持表格数据自动 EDA、统计检验、趋势预测等功能。
- **技术亮点**：实现工具调用的错误自动重试机制（最多 3 次），集成 ECharts 生成交互式图表，支持上下文记忆和多轮追问。
- **开源成果**：项目 GitHub 获得 200+ Star，被收录进 Awesome-LLM-Agents 列表。

## 三、AI岗位简历特殊要点

### 3.1 突出量化效果

> AI岗位面试官最看重的就是**你做的东西到底有没有用、提升了多少**。

| 常见空洞描述 | 推荐量化写法 |
|--------------|--------------|
| 优化了模型效果 | 通过引入重排序模块，RAG 问答准确率从 65% 提升至 88% |
| 提升了推理速度 | 使用 vLLM 部署 + 量化，推理吞吐量提升 4 倍，延迟降低 60% |
| 做了模型微调 | 基于 LoRA 微调 7B 模型，1000 条数据训练后，领域任务 F1 提升 18 个百分点 |
| 开发了一个 Agent | 设计三 Agent 协作框架，任务完成率从单 Agent 的 55% 提升至 82% |

### 3.2 GitHub 和开源贡献很重要

- AI岗位面试官几乎都会看你的 GitHub
- 至少有 2-3 个 AI 相关项目，每个都要有完整的 README 和代码
- commit 记录要连续，不要一次性全提交
- 能给知名开源项目（LangChain、Transformers 等）提 PR 是很大的加分项

### 3.3 论文比竞赛更有分量

- 顶会论文（NeurIPS/ICML/ACL/EMNLP 等）一作 > 任何竞赛金牌
- 没有顶会也没关系，可以把 workshop、arxiv 预印本、在投论文写上
- 论文要写清楚：你的贡献是什么、用了什么方法、达到了什么效果

### 3.4 突出对大模型的理解深度

- 不要只写"会调用 OpenAI API"，要体现你对底层原理的理解
- 可以写：Transformer 架构细节、Attention 机制、位置编码、各种微调方法的区别与适用场景
- 项目中体现你做过消融实验、对比过不同方案的优劣

## 四、常见AI简历误区

| # | 误区 | 为什么不行 | 正确做法 |
|---|------|------------|----------|
| 1 | 只会调 API 没有深度 | 面试官会觉得你只是个 API 调用工程师，技术门槛太低 | 至少深入了解一个模型的训练/微调过程，理解底层原理 |
| 2 | 项目太简单没有技术含量 | "基于 GPT 做了个聊天机器人" 这种项目人人都能做 | 要有自己的创新点和优化，比如特定领域的 RAG 优化、多 Agent 协作 |
| 3 | 夸大经验一问就露馅 | AI 圈子很小，面试官很容易识破夸大的简历 | 诚实写你真正做过的东西，每个技术点都要能讲清楚 |
| 4 | 只罗列模型名称 | "用过 GPT-4、Claude、Llama、Qwen" 不代表你懂大模型 | 写清楚你用这些模型做了什么、解决了什么问题、效果如何 |
| 5 | 数学基础薄弱却投算法岗 | 算法岗面试必考机器学习/深度学习基础 | 如果数学和算法基础一般，优先投大模型应用/工程岗 |
| 6 | 项目没有量化指标 | 没有数据支撑的"效果很好"等于没说 | 每个项目都要有准确率/召回率/性能提升等可量化的数据 |
