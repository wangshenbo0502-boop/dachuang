# 前端开发工程师简历模板与范例

## 一、推荐简历结构

> 前端岗位简历的核心是**作品说话**，在线 Demo 链接和 GitHub 活跃度至关重要。

| 序号 | 模块 | 重要性 | 建议篇幅 |
|------|------|--------|----------|
| 1 | 基本信息 | 必备（附作品集/在线Demo链接） | 1-2 行 |
| 2 | 教育背景 | 必备 | 3-5 行 |
| 3 | 技术能力 | 核心 | 10-15 行 |
| 4 | 项目经历 | 核心（最重要） | 简历的 50% 以上 |
| 5 | 实习经历 | 加分项（有则优先放项目前） | 5-8 行/段 |
| 6 | 开源/博客/设计作品 | 加分项 | 3-5 行 |

> **模块排序建议**：有知名公司实习经历，放在项目经历之前；有非常亮眼的开源项目或作品集，可提前到教育背景之后。

## 三、前端简历特殊要点

### 3.1 一定要有在线 Demo 链接

> 面试官一定会点你的项目链接，**打不开的项目等于没做过**。

- 每个项目都要有在线预览地址，推荐部署在 Vercel / Netlify / GitHub Pages
- 部署要稳定，不要面试当天打不开
- 项目打开速度要快，最好做过首屏优化
- 移动端项目可以放二维码，扫码即可预览

### 3.2 GitHub 要活跃，有绿点

- 保持稳定的 commit 频率，每天有几个绿点比一次性提交一堆代码好
- 仓库要有清晰的 README，包含项目介绍、技术栈、功能截图、在线预览
- 至少有 2-3 个质量较高的前端项目，不要全是 demo 级别的小练习
- 项目命名要专业，不要叫 `test`、`demo1` 这种名字

### 3.3 突出工程化能力和性能优化经验

| 常见普通描述 | 加分写法 |
|--------------|----------|
| 会用 Vue/React | 深入理解 Vue3 响应式原理，阅读过源码并输出技术博客 |
| 用过 Webpack | 熟悉 Webpack/Vite 构建原理，有项目构建优化经验，构建时间缩短 60% |
| 做过性能优化 | 通过懒加载、代码分割、缓存策略等手段，首屏加载时间从 3.2s 优化至 1.1s |
| 会写组件 | 封装过 20+ 通用业务组件，有组件库设计经验，支持按需引入和主题定制 |

### 3.4 设计能力是加分项

- 有设计基础（Figma / Sketch）的前端很受欢迎
- 如果有设计作品，可以放作品集链接
- 简历本身的排版和配色也能体现你的设计审美（因为你是前端）

### 3.5 简历本身的排版设计也很重要

> 前端工程师的简历，**简历本身就是你的第一个作品**。

- 排版要干净、美观、有设计感
- 配色要协调，不要花里胡哨
- 字体选择要专业，字号层级清晰
- 可以适当用图标点缀，但不要影响 ATS 解析

## 五、简历投递注意事项

- **作品集优先**：投递时附上个人作品集链接，放在简历最显眼的位置
- **文件命名**：`姓名-学校-前端开发-简历.pdf`，如 `王五-XX大学-前端开发-简历.pdf`
- **PDF 格式**：导出为 PDF，确保排版不乱；**千万不要用 Word 格式**
- **项目自查**：所有在线链接自己先点一遍，确保能正常访问且加载速度不慢
- **简历适配**：根据目标岗位 JD 调整技术栈顺序和项目描述的侧重点
- **面试准备**：前端面试通常包含手写代码（JS 基础/算法）+ 框架原理 + 项目深挖 + 手撕 CSS
