# 简历投递与面试邀约全攻略

## 一、投递渠道大全

> 渠道选得好，Offer 来得早。不同渠道的通过率差异巨大。

### 1.1 校招渠道

| 渠道 | 特点 | 通过率 | 适合人群 |
|------|------|--------|----------|
| 官网网申 | 最正规，所有校招岗位都有 | 低（竞争大） | 所有人 |
| 校园宣讲会 | 现场投简历，有机会直接面试 | 中 | 目标院校学生 |
| 校园招聘会 | 集中多家公司，一次投多家 | 中低 | 本地高校学生 |
| 校企合作/定向招聘 | 学校和企业合作，名额有限 | 高 | 合作院校学生 |

**提示**：官网网申是必走渠道，但不要只靠这一个。多渠道并行才能提高效率。

### 1.2 招聘平台

| 平台 | 特点 | 推荐指数 |
|------|------|----------|
| 牛客网 | 技术岗为主，有题库+面经+内推 | ★★★★★ |
| BOSS 直聘 | 直接和 HR/老板聊，反馈快 | ★★★★☆ |
| 智联招聘 | 综合类，岗位多，质量参差不齐 | ★★★☆☆ |
| 前程无忧（51job） | 老牌平台，传统企业多 | ★★★☆☆ |
| 猎聘 | 中高端岗位为主，应届生岗位少 | ★★☆☆☆ |
| 实习僧 | 实习岗位为主，也有校招 | ★★★☆☆ |

### 1.3 内推渠道

| 渠道 | 特点 | 推荐指数 |
|------|------|----------|
| 学长学姐内推 | 最靠谱，知根知底 | ★★★★★ |
| 牛客内推 | 技术岗内推信息集中 | ★★★★☆ |
| 脉脉 | 职场社交，找在职员工内推 | ★★★☆☆ |
| LinkedIn | 外企/大厂员工多，适合找内推 | ★★★☆☆ |
| GitHub 内推 | 技术牛人的项目页面留内推方式 | ★★☆☆☆ |

### 1.4 其他渠道

- **技术社区**：掘金、知乎、V2EX 上有很多招聘帖和内推信息
- **技术博客**：关注目标公司技术团队的博客，常有招聘信息
- **开源社区**：参与知名开源项目，有机会被核心成员内推
- **微信群/QQ群**：加入校招交流群，信息更新快

## 二、内推完全指南

> 内推是提升面试邀约率最有效的方式，没有之一。

### 2.1 为什么内推通过率更高

- 内推简历会被**优先筛选**，不会淹没在简历海里
- 有些公司内推可以**免笔试**或**直通面试**
- 内推人可以帮你**跟进进度**，及时反馈
- 内推简历默认有"熟人背书"，HR 信任度更高

> 数据表明：内推的面试邀约率比普通网申高 **3-5 倍**。

### 2.2 怎么找内推人

**优先级排序**：

1. **直系学长学姐**（同校同专业，成功率最高）
2. **实验室/社团认识的人**（有过交集，愿意帮忙）
3. **牛客网/脉脉 上主动联系**（礼貌私信，附上简历）
4. **LinkedIn 搜索目标公司员工**（发邀请时说明来意）

**找内推的话术模板**：

> 学长/学姐您好，我是 XX 大学 XX 专业的 XXX，今年校招想投贵公司的 XX 岗位。我做过 XX 项目（一句话亮点），看到您在贵公司工作，想麻烦问一下能不能帮忙内推？我的简历附在后面，谢谢您！

### 2.3 内推邮件怎么写

**邮件标题**：`内推-姓名-学校-应聘岗位-来源`

**邮件正文模板**：

```
XX 哥/姐您好，

我叫 XXX，是 XX 大学 XX 专业 XX 级学生，想申请贵公司 XX 岗位。
了解到您在贵公司 XX 部门工作，冒昧打扰，希望能获得您的内推机会。

【个人亮点】
- 有 XX 公司 XX 岗位实习经历，负责 XX，取得了 XX 成果
- 独立完成 XX 项目，使用 XX 技术栈，实现了 XX（量化数据）
- GitHub：xxx  博客：xxx

简历已附在附件中，感谢您的时间和帮助！

此致
敬礼
XXX
联系电话：XXX
邮箱：XXX
```

### 2.4 内推注意事项

- **不要海投同一家**：同一个公司只找一个人内推，重复内推会被标记
- **不要同时找多个人内推同一家公司**：会让对方尴尬，也可能都不帮你推
- **简历要先打磨好再发**：不要拿半成品去麻烦别人
- **及时感谢**：不管结果如何，都要跟内推人道谢
- **不要催进度**：内推人也很忙，等一周没消息可以礼貌问一下

## 三、投递策略

### 3.1 海投 vs 精准投递

| 维度 | 海投 | 精准投递 |
|------|------|----------|
| 投递数量 | 一天几十份 | 一天 3-5 份 |
| 简历匹配度 | 低，一份投所有 | 高，每份都针对性修改 |
| 面试邀约率 | 低（1%-3%） | 高（10%-20%） |
| 精力消耗 | 低，机械操作 | 高，需要研究 JD 和公司 |
| 面试质量 | 参差不齐 | 都是目标公司 |

**建议策略**：**精准投递为主，海投为辅**
- 目标公司（20-30 家）：精心准备，针对性修改简历
- 保底公司（20-30 家）：适度修改，保证匹配度
- 海投（可选）：精力有余时，批量投一些还不错的公司

### 3.2 投递时间

**校招黄金期**：
- **秋招**：金九银十（9 月最黄金，10 月还能捡漏）
- **春招**：金三银四（3 月补招高峰，4 月逐渐减少）

**周度最佳时间**：
- **周一到周五上午 9:00-11:00** 投递效果最好
- HR 刚上班，会优先处理新收到的简历
- 周末投递的简历容易被周一的新简历淹没

**提前批很重要**：
- 大厂通常 7-8 月就开始提前批
- 提前批竞争小，名额多，一定要抓住
- 即使提前批没过，正式批还可以再投

### 3.3 投递节奏

**推荐节奏**：每天投 **5-10 份**，不要一天投几十份。

原因：
- 每份简历都需要针对性修改，太快了质量下降
- 太多面试邀约应付不过来，反而影响发挥
- 细水长流，保持求职状态的连续性

**分阶段安排**：

| 阶段 | 时间 | 重点 |
|------|------|------|
| 提前批 | 7-8 月 | 冲大厂提前批，练手 |
| 秋招高峰 | 9 月 | 主攻目标公司，密集投递 |
| 查漏补缺 | 10-11 月 | 补投 + 等结果 + 面试 |
| 春招补招 | 2-4 月 | 没拿到满意 Offer 的再战 |

### 3.4 投递记录管理

> 一定要做投递记录！不然投了多少家、哪些有回复、哪些面试到哪一步，全都会乱。

**推荐用 Excel/飞书表格管理**，字段如下：

| 字段 | 说明 |
|------|------|
| 公司名称 | 全称 |
| 岗位名称 | 具体岗位 |
| 投递渠道 | 官网/BOSS/内推/宣讲会 |
| 内推人 | 如有 |
| 投递日期 | 哪天投的 |
| 当前状态 | 待笔试/待面试/已过/已挂 |
| 面试进度 | 一面/二面/HR面 |
| 备注 | 特殊情况、JD 链接等 |

## 四、简历筛选机制揭秘

> 了解筛选流程，才能有的放矢。

### 4.1 第一层：ATS 系统筛选

**ATS（Applicant Tracking System）** 是企业用来自动化筛选简历的系统。

**工作原理**：
- 解析简历内容，提取关键词
- 和岗位 JD 的要求做匹配度计算
- 匹配度低于阈值的直接淘汰

**大厂 ATS 淘汰率**：**70% 以上**的简历在这一步就被刷掉了。

**过关要点**：
- 关键技能词要**直接出现在文本**中，不要藏在图片里
- 从 JD 中提取高频关键词，确保简历中都有
- 使用标准字体和格式，不要用艺术字、图片、图标
- 文件格式用 PDF，但有些系统对 Word 解析更好

### 4.2 第二层：HR 初筛

**HR 看一份简历多久？—— 平均 30 秒。**

**HR 重点看什么**：
1. **学校/学历**：是不是目标院校，学历够不够
2. **实习经历**：有没有相关实习，公司知名度
3. **项目关键词**：有没有岗位需要的技术栈
4. **整体感觉**：排版、内容完整性、有没有明显硬伤

**过关要点**：
- 学校好的话，教育背景放在前面
- 有实习的话，实习经历突出写
- 关键词要醒目，让 HR 一眼看到
- 排版清爽，不要密密麻麻

### 4.3 第三层：技术负责人复筛

通过 HR 初筛后，简历会送到用人部门技术负责人那里。

**技术负责人重点看什么**：
1. **项目深度**：项目有没有技术含量，是不是真的做过
2. **技术匹配度**：技术栈和团队用的对不对口
3. **技术思考**：有没有体现出对技术的理解和思考
4. **潜力**：学习能力怎么样，能不能快速上手

**过关要点**：
- 项目描述要有技术细节，不能太浅
- 突出和岗位匹配的项目，放在最前面
- 展示技术选型的思考和优化过程
- 量化成果，用数据说话

## 五、提升面试邀约率的技巧

### 技巧 1：针对每一个 JD 修改简历关键词

- 把 JD 里的技能要求逐条对照简历
- 缺少的关键词，有相关经验就加进去
- 项目描述中尽量使用 JD 里的术语
- 关键词在简历中出现 2-3 次效果最好

### 技巧 2：找内推

- 内推通过率比网申高 3-5 倍
- 优先找认识的人，其次是校友
- 内推时附上一句话亮点，提高成功率
- 内推后面试进度可以找内推人跟进

### 技巧 3：在招聘平台保持活跃

- BOSS 直聘每天刷新简历，提升曝光率
- 完善个人资料，技能标签都填上
- 主动给 HR 发消息，不要只等别人找你
- 头像用正式一点的照片，增加信任感

### 技巧 4：完善技术社区和 GitHub

- GitHub 有连续的 commit 记录
- 有 2-3 个高质量的开源项目
- 掘金/知乎有技术文章输出
- 这些链接放在简历上，是加分项

### 技巧 5：直接给 HR 发消息（BOSS 直聘）

**话术模板**：

> HR 您好，我是 XX 大学 XX 专业的应届生，想应聘贵公司的 XX 岗位。我有 XX 项目经验，使用 XX 技术栈，实现了 XX（数据）。我的简历和项目链接都在主页，期待能有面试机会，谢谢！

**要点**：
- 一句话说清你的亮点
- 不要发"在吗""招人吗"这种没营养的话
- 直接说你是谁、你会什么、你想干什么

## 六、投递后多久没消息算凉了

**一般情况**：**7-14 天**没消息基本就凉了。

**不同阶段的时间参考**：

| 阶段 | 正常等待时间 | 超过多久算凉 |
|------|-------------|-------------|
| 网申后 | 3-7 天 | 14 天 |
| 笔试后 | 3-5 天 | 10 天 |
| 面试后 | 3-7 天 | 14 天 |
| HR 面后 | 3-5 天 | 10 天 |

**怎么办**：
- 不要干等，继续投其他公司
- 超过 2 周可以礼貌地发邮件问一下结果
- 没收到拒信不代表没过，可能在池子里泡着
- 保持好心态，多拿几个 offer 才有选择权
