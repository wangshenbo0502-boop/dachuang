# 简历撰写综合指南

## 一、推荐简历结构

应届生推荐模块顺序：

1. **基本信息**
2. **求职意向**
3. **教育背景**
4. **技术能力**
5. **项目经历**
6. **实习/工作经历**
7. **竞赛与证书**
8. **自我评价**

> 每个模块都是可选的，但项目经历和技术能力是核心。

---

## 二、各模块写法规范

### 2.1 基本信息

| 必须包含 | 可选 |
|----------|------|
| 姓名 | 年龄 |
| 手机号 | 政治面貌 |
| 邮箱 | 照片 |
| GitHub/技术博客链接 | |

**规则**：
- 手机号和邮箱必须准确无误
- 不要写 QQ 邮箱（建议用 Gmail / Outlook / 163）
- GitHub 链接必须有效且有内容（绿点/项目）
- 有技术博客（掘金/知乎专栏/个人博客）是加分项

### 2.2 求职意向

| 必须包含 | 可选 |
|----------|------|
| 期望岗位 | 期望薪资 |
| 期望城市 | |
| 到岗时间 | |

**规则**：
- 岗位名称必须与招聘 JD 一致（不要写"软件相关"这种模糊描述）
- 只写一个岗位意向（不要写"前端/后端/测试"多个方向）
- 薪资应届生建议写"面议"

### 2.3 教育背景

| 必须包含 | 可选 |
|----------|------|
| 学校名称 | GPA（如果 > 3.5/4.0 或专业前 20%） |
| 专业 | 主修课程（写 5-8 门与岗位最相关的） |
| 学历 | |
| 入学-毕业年份 | |

**规则**：
- 从最高学历开始写
- GPA 不高就不要写
- 主修课程只写与岗位相关的，不要堆砌

### 2.4 技术能力

**推荐分组**：编程语言 → 框架/库 → 数据库 → 工具/平台

**熟练度标注**：建议用词语描述代替数字，如"精通 > 熟练 > 熟悉 > 了解"，不要超过 2 个"精通"。

**核心规则**：
- 严禁使用进度条或百分比（"Java 80%" 毫无意义且会引发质疑）
- 不会的技能绝对不要写（面试一定会被问到）
- 技能要按类别分组，不要堆成一段

### 2.5 项目经历（最重要！）

> 应届生简历中最重要的板块，HR 和面试官会花 60% 以上的时间看这部分。

**STAR 法则**：

| 步骤 | 含义 | 写法 |
|------|------|------|
| **S** (Situation) | 项目背景 | 1 句话 |
| **T** (Task) | 你负责什么 | 1 句话 |
| **A** (Action) | 你做了什么 | 2-3 句话，技术细节 |
| **R** (Result) | 结果如何 | 1 句话，尽量量化 |

**规则**：
- 每个项目写 3-5 个要点
- 突出你个人做了什么，而不是团队做了什么
- 用动词开头：设计/实现/优化/重构/搭建/集成
- 有数据就要写数据："响应时间从 2s 降到 200ms" > "优化了系统性能"
- 不要写课程大作业（除非确实有技术含量）
- 项目链接（GitHub/线上地址）必须可访问

**优秀示例**：
> 设计并实现了一个基于 Spring Boot 的权限管理系统，支持 RBAC 动态权限控制。接入 Redis 缓存后，权限校验响应时间从 300ms 降至 20ms。项目已部署在阿里云，GitHub 获得 50+ Star。

**反面示例**：
> 参与开发了某管理系统，负责后端开发工作。使用了 Spring Boot 框架和 MySQL 数据库。

### 2.6 实习/工作经历

> 有实习经历会显著提升简历通过率。

**规则**：
- 没有实习可以写实验室项目、开源贡献、校园工作室
- 工作内容同样用 STAR 法则描述

## 三、ATS 优化技巧

> ATS（Applicant Tracking System）是企业用来初筛简历的自动化系统。大厂收到的简历 70% 以上会被 ATS 淘汰。

### 关键要点

1. **字体**：使用标准字体（微软雅黑/宋体/Calibri），不要用艺术字体
2. **格式**：不要用表格、图片、图标（ATS 无法解析）
3. **页眉页脚**：不要在其中放重要信息（ATS 可能漏读）
4. **文件格式**：首选 PDF（排版不会乱），但有些公司要求 Word
5. **关键词**：关键技能词要直接出现在文本中（ATS 按关键词匹配）
6. **JD 对齐**：从企业 JD 中提取高频技能词，确保在简历中出现
7. **页数**：一页为佳（应届生超过一页会被扣分）
8. **自我评价**：不要用模板的占位文字（"本人性格开朗..."ATS 明显识别为模板）

## 四、常见错误及修正

| # | 错误 | 修正方法 |
|---|------|----------|
| 1 | 简历超过一页 | 删掉无关内容、合并重复描述、缩减课程列表 |
| 2 | 项目只写"参与开发"不说做了什么 | 用 STAR 法则重写，明确你的角色和贡献 |
| 3 | 列了一堆课程名 | 只写 5-8 门与岗位最相关的课程 |
| 4 | 自我评价写"吃苦耐劳、勤奋好学" | 改为技术特长总结，如"熟悉 Java 并发编程，有 JVM 调优经验" |
| 5 | 手机号/邮箱错误 | 发出去前自己给自己发一封测试邮件/打一次电话 |
| 6 | GitHub 链接是空的或只有 fork 的仓库 | 至少放 2-3 个自己的项目，commit 记录连续 |
| 7 | 罗列技术栈但不标熟练度 | 按熟练度分级，面试官会围绕你的"熟练"技能提问 |
| 8 | 用 Word 格式投递 | 导出为 PDF，文件命名规范：姓名-学校-岗位.pdf |

## 五、按岗位的针对性建议

### 前端开发工程师

**必须展示**：
- JS/TS 基础扎实
- 至少一个主流框架（Vue/React）的完整项目
- CSS 布局和响应式能力
- Git 版本控制

**差异化亮点**：
- TypeScript 经验
- 组件库封装经验
- 性能优化实践
- Node.js 了解

**推荐技术栈**：`Vue3 + TypeScript + Pinia + Vite`

---

### Java后端开发工程师

**必须展示**：
- Java 基础（集合/多线程/JVM）
- Spring Boot + MyBatis
- MySQL + Redis
- 至少一个完整后端项目

**差异化亮点**：
- Spring Cloud/微服务经验
- 消息队列（RabbitMQ/Kafka）
- 系统设计能力
- JVM 调优经验

**推荐技术栈**：`Java + Spring Boot + MySQL + Redis + Docker`

---

### Python数据分析师

**必须展示**：
- Python + Pandas + NumPy
- SQL 熟练
- 数据可视化（ECharts/Matplotlib）
- 至少一个完整的数据分析项目

**差异化亮点**：
- 机器学习基础
- Tableau/PowerBI
- A/B测试经验
- 业务理解能力

**推荐技术栈**：`Python + Pandas + SQL + ECharts + Scikit-learn`

---

### AI算法工程师

**必须展示**：
- Python + PyTorch/TensorFlow
- 机器学习/深度学习理论
- 至少一个完整的模型训练+部署项目
- 数学基础（线代/概率论）

**差异化亮点**：
- 顶会论文/竞赛成绩
- 模型优化经验
- 分布式训练
- ONNX/TensorRT 部署

**推荐技术栈**：`Python + PyTorch + Transformers + Docker`

---

### 全栈开发工程师

**必须展示**：
- 前端框架（React/Vue）
- 后端语言（Node.js/Java/Python）
- 数据库（SQL + NoSQL）
- 至少一个前后端完整的全栈项目

**差异化亮点**：
- Docker/CI/CD
- 云服务经验（阿里云/AWS）
- TypeScript 全栈
- 系统设计能力

**推荐技术栈**：`React/Vue3 + TypeScript + Node.js/Python + MySQL + Docker`
