## 文档规范

每篇技能文档遵循以下结构：

1. **Front Matter**：title、category、tags、source、last_update
2. **技能简介**：一句话定位 + 就业影响 + 前置技能 + 关联系能
3. **阶段 1 — 了解**：学习主题、学习资源、练习项目、评估方式
4. **阶段 2 — 熟悉**：同上结构
5. **阶段 3 — 掌握**：同上结构
6. **学习建议与进阶路径**（高质量文档标配）

## 熟练度等级定义

| 等级 | 含义 | 能力描述 |
|------|------|---------|
| 了解 | 知道是什么 | 理解基本概念、能看懂代码、能做简单修改 |
| 熟悉 | 能上手干活 | 独立完成常规任务、排查常见问题、阅读文档学习 |
| 掌握 | 能独立负责 | 深入理解原理、解决复杂问题、优化性能、指导他人 |
| 精通 | 领域专家 | 源码级理解、架构设计、技术选型、行业影响力 |
