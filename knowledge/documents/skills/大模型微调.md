# 大模型微调

> 让通用大模型适配特定领域与业务场景的核心技术，通过参数高效微调（LoRA/QLoRA）在单张GPU上即可完成7B-70B模型的定制化训练。2026年企业级大模型落地中，80%以上的场景需要经过微调适配，微调工程师成为AI团队刚需岗位，薪资较通用算法工程师高出20%-30%。

- **就业影响**: 高（企业大模型落地核心能力，80%场景需微调适配）
- **前置技能**: Python, PyTorch, 深度学习, 大模型基础
- **关联系能**: HuggingFace, vLLM, LangChain, 向量数据库, 强化学习

---

## 阶段 1 — 目标：了解（预估 2 周）

**学习主题：**
- 大模型微调基础概念：为什么要微调、微调 vs Prompt Engineering vs RAG 的适用边界
- 全参数微调 vs 参数高效微调（PEFT）：算力成本对比、效果差异、选型指南
- LoRA 原理与实现：低秩适配思想、秩的选择、注意力层注入、参数规模估算
- QLoRA 量化微调：4bit/8bit 量化原理、NF4 数据类型、双量化技术、显存优化
- 微调数据准备与清洗：数据格式（JSONL/ShareGPT）、去重、质量过滤、长度分布统计
- 指令微调（Instruction Tuning）：指令数据集构建、模板设计、 Alpaca 格式详解
- HuggingFace Transformers/PEFT 库入门：模型加载、Tokenizer 使用、Trainer API
- 第一个 LoRA 微调实验：用 LLaMA-Factory 在 7B 模型上跑通指令微调全流程
- 微调超参数基础：学习率、Batch Size、Epoch、Warmup、权重衰减的作用与调优
- 微调结果验证：loss 曲线解读、生成效果对比、检查点保存与加载

**学习资源：**
- [HuggingFace PEFT 官方文档](https://huggingface.co/docs/peft) — 官方文档 · 免费 · 入门 · 英文
- [LLaMA-Factory 官方教程](https://github.com/hiyouga/LLaMA-Factory) — 开源项目 · 免费 · 入门 · 中文
- [知乎 - 大模型微调入门专栏](https://www.zhihu.com/column) — 技术博客 · 免费 · 入门 · 中文

**练习项目：**
- 使用 LLaMA-Factory 在 Qwen2-7B 上跑通第一个 LoRA 指令微调实验
- 构建 500 条自定义指令数据集（Alpaca 格式），完成数据清洗与格式转换
- 对比全参微调与 LoRA 微调的显存占用、训练速度与最终效果差异
- 实现一个基于 PEFT 库的最简 LoRA 微调脚本，手动配置训练流程

**评估方式：**
- 实操验证 — 独立完成端到端 LoRA 微调实验，loss 正常收敛，生成效果有明显提升
- 数据能力 — 能独立构建并清洗指令微调数据集，掌握数据质量评估方法
- 工具掌握 — 熟练使用 LLaMA-Factory 和 PEFT 库进行基础微调实验

## 阶段 2 — 目标：熟悉（预估 3 周）

**学习主题：**
- 多轮对话微调（SFT）：ShareGPT 格式、多轮对话构建、系统提示词设计、角色设定
- DPO 人类偏好对齐：直接偏好优化原理、偏好数据集构建、DPO vs PPO 对比
- RLHF 基础流程：SFT -> 奖励模型 -> PPO 强化学习三阶段框架与实践
- 数据配比与采样策略：领域数据混合比例、困难样本挖掘、上采样/下采样策略
- 微调评估指标与方法：BLEU/ROUGE/Perplexity 自动指标、人工评估规范、Elo 评分
- 长上下文微调：位置编码扩展（RoPE scaling）、LongQLoRA、长文本训练技巧
- 多语言微调：中英双语数据配比、跨语言迁移、代码混合训练策略
- 微调模型合并与部署：LoRA 权重合并、AWQ/GPTQ 量化部署、vLLM 推理加速
- 微调成本估算与优化：GPU 选型、训练时长估算、Checkpoint 策略、梯度累积技巧
- 常见问题排查：梯度消失/爆炸、loss 不收敛、过拟合、灾难性遗忘的识别与解决

**学习资源：**
- [HuggingFace TRL 官方文档](https://huggingface.co/docs/trl) — 官方文档 · 免费 · 进阶 · 英文
- [vLLM 官方部署文档](https://docs.vllm.ai/) — 官方文档 · 免费 · 进阶 · 英文
- [B站 - 陈巍大模型微调实战课程](https://www.bilibili.com/) — 视频课程 · 付费 · 进阶 · 中文

**练习项目：**
- 使用 ShareGPT 格式数据完成 Qwen2-7B 的多轮对话 SFT 微调
- 构建 1000 条偏好数据，完成 DPO 对齐训练并对比 SFT 模型的回答偏好差异
- 实现长上下文微调（32K -> 128K），验证长文档理解能力的提升
- 用 vLLM 部署微调后的模型，实现 OpenAI 兼容的 API 接口服务
- 设计并执行一次完整的微调评估实验，输出包含自动指标与人工评估的对比报告

**评估方式：**
- 项目评审 — 独立完成多轮对话 SFT + DPO 全流程微调，模型在目标任务上表现达标
- 部署能力 — 熟练完成模型量化、合并与 vLLM 部署，推理性能满足业务要求
- 问题排查 — 能独立定位并解决微调过程中的常见问题（loss 异常、过拟合等）

## 阶段 3 — 目标：掌握（预估 4 周）

**学习主题：**
- RLHF 深入：PPO 算法细节、奖励模型训练技巧、KL 散度控制、价值函数初始化
- 拒绝采样微调（Rejection Sampling）：候选生成、排序筛选、迭代优化策略
- MoE 模型微调：Mixtral/Qwen2-MoE 架构、专家选择策略、稀疏训练优化技巧
- 多模态大模型微调：LLaVA 架构、Qwen-VL 微调、图文对数据构建、视觉编码器冻结策略
- 持续学习与灾难性遗忘：弹性权重巩固（EWC）、渐进式网络、回放缓冲区、领域增量学习
- 领域自适应微调：医疗/法律/金融等垂直领域数据构建、专业术语注入、领域评估基准
- 模型蒸馏与小模型微调：知识蒸馏原理、教师-学生架构、大模型蒸馏到 1B-3B 小模型实践
- 量化感知训练（QAT）：量化训练原理、4bit 量化感知微调、精度-速度权衡优化
- 分布式训练与 ZeRO 优化：DeepSpeed ZeRO-1/2/3、FSDP、多机多卡训练配置
- 企业级微调流水线：数据管理平台、实验追踪（W&B/MLflow）、A/B 测试、版本管理

**练习项目：**

## 学习建议与进阶路径

- **动手优先**：微调是工程性极强的技术，务必跑通完整流程，在真实数据上反复实验积累经验
- **数据为王**：微调效果 80% 取决于数据质量，重视数据构建、清洗与配比，建立数据飞轮
- **评估驱动**：建立完善的评估体系（自动指标 + 人工评估 + 业务指标），用数据指导优化方向
- **成本意识**：熟练掌握 QLoRA、梯度检查点、ZeRO 等显存优化技术，用有限算力撬动更大模型
- **关注前沿**：跟踪 DPO 变体（ORPO/KTO/IPO）、多模态微调、MoE 微调等新兴技术方向
- **工程落地**：结合 vLLM 部署、模型量化、A/B 测试，形成从训练到上线的全链路能力
