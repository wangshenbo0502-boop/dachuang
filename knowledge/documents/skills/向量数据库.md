# 向量数据库

> AI时代的核心基础设施，存储和检索高维向量数据，是RAG和语义搜索的技术底座。向量数据库在AI应用中的地位类似互联网时代的MySQL，2026年企业AI落地浪潮推动向量数据库需求爆发式增长，是AI应用开发必备的基础设施知识。

- **就业影响**: 高（AI应用开发必备基础设施知识）
- **前置技能**: 数据库基础, Python
- **关联系能**: RAG, Embedding, Milvus, LangChain

---

## 阶段 1 — 目标：了解（预估 2 周）

**学习主题：**
- 向量数据库基本原理：向量、Embedding、相似度搜索、近似最近邻（ANN）
- Embedding 概念与模型：文本向量、图像向量、多模态向量的生成原理
- Milvus 入门：安装、架构、核心概念（Collection / Partition / Field / Index）
- Chroma / FAISS 轻量级向量库入门、特点对比与适用场景
- 基本增删改查操作：插入、查询、更新、删除、批量操作
- 相似度度量方式：余弦相似度、欧氏距离、内积（IP）的区别与选型
- 向量数据库 vs 传统数据库：技术差异、适用场景、互补关系
- 向量数据库典型应用场景：RAG、推荐系统、图像搜索、去重、聚类

**学习资源：**
- [Milvus 官方文档](https://milvus.io/docs) — 官方文档 · 免费 · 入门 · 英文
- [腾讯云向量数据库教程](https://cloud.tencent.com/document/product/1709) — 官方文档 · 免费 · 入门 · 中文
- [Chroma 官方文档](https://docs.trychroma.com/) — 官方文档 · 免费 · 入门 · 英文

**练习项目：**
- 使用 Docker 搭建本地 Milvus 服务，完成 Hello Milvus 示例
- 构建一个 10 万条文本向量的语义搜索 Demo，支持关键词与语义混合查询
- 对比 Chroma / FAISS / Milvus 在相同数据集上的检索性能与功能差异
- 使用向量数据库实现一个简单的图片搜索功能（基于图像 Embedding）
- 完成向量数据库的基本 CRUD 操作练习，验证数据一致性

**评估方式：**
- 实操 — 独立完成向量数据库的部署与基本操作，实现一个可用的语义搜索功能
- 概念理解 — 准确阐述向量数据库的核心原理与适用场景
- 功能验证 — 检索结果相关度达标，基本增删改查操作正确无误

## 阶段 2 — 目标：熟悉（预估 3 周）

**学习主题：**
- 索引算法原理与对比：HNSW、IVF_FLAT、IVF_PQ、IVF_SQ8、DiskANN
- 索引选型与性能调优：召回率 vs 速度 vs 内存的权衡策略
- 过滤与混合检索：标量过滤（Scalar Filter）、向量 + 标量混合查询
- 多向量与多模态：一张表多个向量字段、图文混合检索、跨模态搜索
- 数据分片与扩容：分布式架构、水平扩展、数据一致性
- 数据导入优化：批量插入、索引构建时机、并发控制、数据迁移
- 向量数据库与 RAG 系统集成实践：检索层设计与优化
- 查询优化：查询参数调优、Top-K 选择、搜索精度配置
- 向量数据库的 Python SDK 使用：Milvus SDK、LangChain 集成
- 监控与运维：基本指标监控、日志查看、常见问题排查

**学习资源：**
- [Milvus 索引指南](https://milvus.io/docs/index.md) — 官方文档 · 免费 · 进阶 · 英文
- [Pinecone 学习中心](https://www.pinecone.io/learn/) — 技术博客 · 免费 · 进阶 · 英文
- [腾讯云向量数据库最佳实践](https://cloud.tencent.com/document/product/1709) — 官方文档 · 免费 · 进阶 · 中文

**练习项目：**
- 为 100 万条向量数据集选择并优化索引，达到指定召回率（95%+）与延迟目标（<100ms）
- 实现一个带标量过滤的混合检索系统（如按时间范围 + 分类标签 + 语义检索）
- 使用 Milvus + LangChain 构建一个生产级 RAG 的检索层，支持多文档管理
- 完成向量数据库的性能调优实验：对比不同索引类型在相同数据集上的 QPS 与召回率
- 设计并实现一个多模态检索系统，支持图文双向搜索

**评估方式：**
- 性能测试 — 向量检索系统在百万级数据集上满足延迟与召回率指标
- 功能评审 — 混合检索功能正确，过滤条件生效，多模态检索效果达标
- 代码审查 — SDK 使用规范，错误处理完善，具备连接管理与资源释放

## 学习建议与进阶路径

- **夯实基础**：深入理解向量检索算法原理（HNSW、IVF 等），知其然更知其所以然
- **动手实践**：在不同规模数据集上进行性能测试，积累调优经验
- **关注生态**：向量数据库技术迭代迅速，定期关注新版本与新特性
- **全栈视角**：结合 RAG、Embedding 模型、大模型推理，形成端到端优化能力
- **关注前沿**：跟踪 DiskANN、SPANN、多模态检索等前沿技术发展趋势
