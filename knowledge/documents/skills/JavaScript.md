# JavaScript

> Web 开发核心语言，全栈开发的基础。从浏览器交互到 Node.js 服务端，几乎所有现代 Web 技术都基于 JS。

- **就业影响**: 高
- **前置技能**: HTML, CSS
- **关联系能**: TypeScript, Vue.js, React, Node.js

---

## 阶段 1 — 目标：了解（预估 3 周）

**学习主题：**
- 变量与数据类型
- 运算符与表达式
- 条件判断与循环
- 函数(声明/表达式/箭头)
- 数组与对象操作
- DOM 操作与事件
- JSON 数据格式

**学习资源：**
- [现代 JavaScript 教程](https://zh.javascript.info/) — 在线课程 · 免费 · 入门 · 中文
- [MDN JavaScript 指南](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Guide) — 官方文档 · 免费 · 入门 · 中文

**练习项目：**
- 写一个 Todo List（增删改查+本地存储）
- 写一个轮播图组件

**评估方式：** 独立完成 — Todo List 功能完整，数据能存到 localStorage 并刷新后不丢失

---

## 阶段 2 — 目标：熟悉（预估 3 周）

**学习主题：**
- ES6+新特性(解构/展开/模板字符串)
- Promise/async-await
- 模块化(ESM/CommonJS)
- 闭包与作用域链
- 原型链与 this
- 事件循环(Event Loop)
- Fetch API / Axios

**学习资源：**
- [《JavaScript 高级程序设计（第4版）》](https://book.douban.com/subject/35175321/) — 书籍 · 付费 · 进阶 · 中文
- [《你不知道的 JavaScript》上中下](https://book.douban.com/subject/26351021/) — 书籍 · 付费 · 进阶 · 中文

**练习项目：**
- 写一个支持搜索和筛选的电影列表页（调用公开电影 API）
- 用原生 JS 实现一个简单的 SPA 路由

**评估方式：** 代码审查+面试模拟 — 能解释清楚 this 指向、事件循环机制、Promise 链式调用

---

## 阶段 3 — 目标：掌握（预估 4 周）

**学习主题：**
- 设计模式在 JS 中的应用
- 函数式编程
- Web Workers
- WebSocket
- 性能优化(节流/防抖/懒加载/虚拟列表)
- TypeScript 入门
- 单元测试(Jest)

**学习资源：**
- [《JavaScript 设计模式与开发实践》](https://book.douban.com/subject/26382780/) — 书籍 · 付费 · 高级 · 中文
- [Jest 官方文档](https://jestjs.io/zh-Hans/docs/getting-started) — 官方文档 · 免费 · 进阶 · 中文

**练习项目：**
- 用原生 JS 实现一个表格组件（排序/筛选/分页/虚拟滚动）
- 为之前的 Todo List 写单元测试

**评估方式：** 代码审查 — 代码模块化清晰，有测试覆盖，虚拟滚动列表流畅支持万级数据
