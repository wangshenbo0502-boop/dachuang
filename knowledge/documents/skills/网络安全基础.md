# 网络安全基础

> 网络安全是数字时代的基础保障技能，涵盖网络协议、系统安全、Web安全等核心领域，是构建可信数字世界的基石。

- **就业影响**: 高（网络安全人才缺口超320万，2026年招聘岗位同比增长37%，薪资水平比普通IT岗位高约30%）
- **前置技能**: 计算机网络, Linux基础
- **关联系能**: 渗透测试, 网络安全工程师, Linux, 云安全
- **学习总周期**: 约 12 周（可根据基础调整）
- **推荐学习方式**: 理论学习 + 靶场实操 + CTF 比赛 + 社区交流

## 阶段 1 — 目标：了解（预估 3 周）

**学习主题：**
- 网络基础协议（TCP/IP 四层模型、三次握手与四次挥手、UDP 协议特性、端口与套接字）
- HTTP/HTTPS 协议深度解析（请求方法 GET/POST/PUT/DELETE、状态码 2xx/3xx/4xx/5xx、Header 字段、Cookie/Session 机制、TLS 握手过程）
- Linux 系统安全基础（用户与组管理、文件权限 rwx、SUID/SGID/Sticky Bit、sudo 配置、SSH 密钥登录、防火墙 firewalld/iptables）
- 常见攻击原理概述（DDoS 攻击类型与防护、SYN Flood、UDP Flood、SQL 注入基础原理、XSS 跨站脚本反射型/存储型/ DOM 型）
- 安全工具入门（Nmap 端口扫描原理与常用参数、Wireshark 过滤器语法与抓包分析、Netcat 网络瑞士军刀、Dirb/Dirbuster 目录扫描）
- OWASP Top 10 2025 概览（注入、认证失效、敏感信息泄露、XML 外部实体、访问控制失效、安全配置错误、跨站脚本、不安全的反序列化、使用含有已知漏洞的组件、日志与监控不足）
- 信息收集方法论（Whois 查询、子域名枚举、端口扫描、指纹识别、Google Hacking 语法）

**学习资源：**
- [FreeBuf 网络安全入门专栏](https://www.freebuf.com/) — 技术社区 · 免费 · 入门 · 中文
- [奇安信网络安全学院](https://www.qianxin.com/) — 在线课程 · 部分免费 · 入门 · 中文
- [Wireshark 官方文档](https://www.wireshark.org/docs/) — 官方文档 · 免费 · 入门 · 英文
- [OWASP Top 10 官方文档](https://owasp.org/www-project-top-ten/) — 官方文档 · 免费 · 入门 · 英文
- [《图解HTTP》](https://book.douban.com/subject/25863515/) — 技术书籍 · 付费 · 入门 · 中文

**练习项目：**
- 用 Wireshark 抓取并分析一次完整的 HTTP 请求与响应流程，标记出 TCP 三次握手与四次挥手
- 用 Nmap 扫描本地网络，识别存活主机、开放端口、服务版本与操作系统指纹
- 在本地搭建 DVWA 靶场环境，完成低难度 SQL 注入、反射型 XSS、命令注入等 5 类漏洞练习
- 配置一台 Linux 服务器的基础安全策略（禁用 root 远程登录、密钥登录、修改 SSH 端口、配置防火墙规则、关闭不必要的服务）
- 使用 Google Hacking 语法对指定目标进行信息收集，整理出可利用的敏感信息清单

**评估方式：** 实操 + 理论 — 能独立完成端口扫描与抓包分析，准确描述 OWASP Top 10 中至少 5 类漏洞的原理与危害，DVWA 低难度全部通关，信息收集报告内容完整度达 80% 以上

## 阶段 2 — 目标：熟悉（预估 4 周）

**学习主题：**
- Web 安全深入（文件上传漏洞类型与绕过、CSRF 跨站请求伪造原理与防御、SSRF 服务端请求伪造利用方式、反序列化漏洞 PHP/Java、XXE XML 外部实体注入）
- 漏洞利用基础（常见 CMS 漏洞复现 WordPress/Discuz/DedeCMS、EXP 编写入门、Payload 构造与 WAF 绕过、编码与混淆技巧）
- 安全加固策略（Web 应用防火墙 WAF 原理与规则、服务器安全配置基线、代码审计入门思路、输入验证与输出编码、CSP 内容安全策略）
- 日志分析与应急响应（Web 日志分析 Nginx/Apache、入侵检测系统 IDS/IPS、应急响应流程 PDCER、溯源分析方法、病毒木马查杀）
- 密码学基础（对称加密 AES/DES、非对称加密 RSA/ECC、哈希算法 MD5/SHA-256、数字签名与证书 PKI、HTTPS 完整链路）
- 中间件安全（Nginx/Apache 安全配置、Tomcat 常见漏洞、Redis 未授权访问、Jenkins 远程代码执行、Fastjson 反序列化）
- 业务安全（验证码绕过、短信轰炸、支付漏洞、越权访问水平/垂直、逻辑漏洞挖掘思路）

**学习资源：**
- [FreeBuf Web 安全专题](https://www.freebuf.com/articles/web) — 技术文章 · 免费 · 进阶 · 中文
- [启明星辰安全研究](https://www.venustech.com.cn/) — 安全研究 · 免费 · 进阶 · 中文
- [PortSwigger Web Security Academy](https://portswigger.net/web-security) — 在线实验室 · 免费 · 进阶 · 英文
- [《Web安全深度剖析》](https://book.douban.com/subject/26777058/) — 技术书籍 · 付费 · 进阶 · 中文
- [先知社区](https://xz.aliyun.com/) — 技术社区 · 免费 · 进阶 · 中文

**练习项目：**
- 在 DVWA 中完成中高难度的文件上传、CSRF、SSRF、SQL 注入等全部漏洞利用练习
- 复现 3 个经典 CVE 漏洞（如 Log4j2、Spring Boot Actuator 泄露、Redis 未授权访问 GetShell）
- 对一个真实 CMS 系统进行基础安全加固，包括 WAF 规则配置、权限最小化、敏感路径防护、错误信息隐藏
- 模拟一次应急响应：从 Web 日志中发现攻击痕迹，还原攻击路径，定位攻击者手法，提出修复方案并输出报告
- 挖掘 1-2 个业务逻辑漏洞（如越权、支付、验证码），编写漏洞报告与修复建议

**评估方式：** 实操 — 能独立完成中高级 Web 漏洞利用，复现至少 3 个 CVE 漏洞，独立完成一次完整的应急响应分析报告，具备业务逻辑漏洞挖掘能力

## 常见面试题

1. **基础类**：简述 TCP 三次握手和四次挥手的过程，为什么需要三次握手？
2. **Web 安全类**：SQL 注入有哪些类型？如何防御 SQL 注入？PreparedStatement 为什么能防注入？
3. **渗透测试类**：一次完整的渗透测试流程是什么？PTES 标准包含哪些阶段？
4. **内网安全类**：什么是哈希传递攻击（PTH）？如何防御？
5. **协议安全类**：HTTPS 的工作原理是什么？TLS 握手过程是怎样的？
6. **工具类**：Nmap 的常用参数有哪些？-sS 和 -sT 的区别是什么？
7. **漏洞原理类**：XSS 有哪几种类型？各自的危害和利用场景有什么不同？
8. **安全加固类**：Linux 系统安全加固有哪些常用措施？从哪些维度进行加固？
9. **应急响应类**：服务器被入侵后，应急响应的流程是什么？如何溯源？
10. **职业规划类**：网络安全方向有哪些细分岗位？各自的能力要求是什么？

## 学习路径建议

- **入门阶段（0-3个月）**：以打基础为主，掌握计算机网络、操作系统、Linux 基础、一门编程语言，同时开始接触 Web 安全基础概念，完成 DVWA 低难度全部靶场。
- **进阶阶段（3-8个月）**：深入学习 Web 安全、漏洞利用、安全工具，复现 30+ 经典 CVE 漏洞，参与 CTF 比赛提升实战能力，尝试提交第一个 CVE 或 Bug Bounty。
- **深入阶段（8-15个月）**：选择一个方向深耕（Web 渗透/内网渗透/安全开发/云安全），完成 1-2 个完整的实战项目，考取行业认证（CISP-PTE/OSCP/CISSP），积累项目经验。
- **职业发展**：乙方安全公司（渗透测试/安全服务）→ 甲方企业安全团队（安全运营/安全架构）→ 安全研究员/安全专家/CTO 路线，薪资随经验和能力呈阶梯式增长。
- **持续学习**：订阅 FreeBuf、先知社区、安全客等技术社区，关注 CVE 新漏洞披露，参加 CTF 比赛和安全会议，保持对新技术和新威胁的敏感度。
