# Prompt Engineering提示工程

> 与大模型高效交互的核心技能，通过优化提示词提升模型输出质量。是所有 AI 应用从业者的必备基础能力，直接决定大模型应用的最终效果上限，掌握提示工程能显著提升 AI 工具的使用效率与产出质量。

- **就业影响**: 中高（AI应用从业者必备基础能力）
- **前置技能**: 大模型基础
- **关联系能**: RAG, Agent, 大模型应用

---

## 阶段 1 — 目标：了解（预估 1 周）

**学习主题：**
- 基础提示词技巧：Zero-shot、Few-shot、Chain-of-Thought 入门
- 角色设定（Persona）：为模型分配专业身份与行为模式
- 格式控制：Markdown、列表、表格、代码块等输出格式规范
- 指令清晰度原则：具体、明确、分步、约束完整
- 上下文管理：信息组织与优先级排序、关键信息突出
- 常见错误与避免方法：模糊指令、遗漏约束、逻辑冲突、负面提示
- 大模型能力边界认知：擅长领域、局限性、幻觉问题
- 主流大模型特性对比：GPT、Claude、DeepSeek、Qwen 的提示风格差异

**学习资源：**
- [OpenAI Prompt Engineering Guide](https://platform.openai.com/docs/guides/prompt-engineering) — 官方文档 · 免费 · 入门 · 英文
- [DeepLearning.AI 提示工程课程](https://www.deeplearning.ai/short-courses/chatgpt-prompt-engineering-for-developers/) — 在线课程 · 免费 · 入门 · 英文
- [腾讯云开发者社区 - 提示工程入门](https://cloud.tencent.com/developer) — 技术博客 · 免费 · 入门 · 中文

**练习项目：**
- 为 5 个不同职业角色（律师 / 医生 / 教师 / 程序员 / 产品经理）设计专业的 System Prompt
- 使用 Few-shot 方法优化一个文本分类任务，对比 Zero-shot 的准确率提升
- 对比 3 种不同提示词风格（简洁 / 详细 / 结构化）对同一任务输出质量的影响
- 设计一个格式化输出提示词，要求模型输出严格符合 JSON Schema
- 识别并修正 5 个典型的"坏提示"案例，说明问题并给出优化版本

**评估方式：**
- 实操 — 能够针对给定任务设计出结构清晰、效果稳定的提示词
- 功能验证 — 输出符合预期格式与内容要求，模型遵循指令率 > 90%
- 案例分析 — 能够准确识别常见提示词问题并给出优化建议

## 阶段 2 — 目标：熟悉（预估 2 周）

**学习主题：**
- 思维链（Chain-of-Thought）：逐步推理、解释要求、复杂问题拆解
- 自一致性（Self-Consistency）：多路径采样、投票策略、答案聚合
- 思维树（Tree of Thoughts）：多分支探索、回溯、广度/深度优先搜索
- 结构化输出：JSON Schema、Function Calling 输出约束、Pydantic 模型
- 提示词调试与迭代方法论：A/B 测试、失败案例分析、渐进式优化
- 提示词模式库：总结、翻译、分类、提取、生成、改写、推理等常用模式
- 长文本处理：分块摘要、渐进式总结、Map-Reduce 模式
- 多轮对话提示设计：上下文维护、状态追踪、角色一致性
- 提示词模板化：变量设计、动态组装、条件分支
- 跨模型适配：不同模型的提示词差异与迁移技巧

**学习资源：**
- [Prompt Engineering Guide](https://www.promptingguide.ai/) — 在线教程 · 免费 · 进阶 · 英文
- [腾讯云开发者社区 - 提示工程进阶专栏](https://cloud.tencent.com/developer) — 技术博客 · 免费 · 进阶 · 中文
- [Learn Prompting 教程](https://learnprompting.org/) — 在线课程 · 免费 · 进阶 · 英文

**练习项目：**
- 使用 CoT + Self-Consistency 提升数学推理题的正确率，对比单一 CoT 的效果
- 设计一套结构化数据提取的提示词方案（JSON 输出），支持嵌套结构与字段校验
- 为一个客服对话场景设计多轮对话提示词系统，包含身份设定、知识库引用、情绪识别
- 实现一个长文档渐进式摘要工具，支持万字长文的分层摘要
- 建立个人提示词模板库，覆盖 10 种以上常用场景，支持参数化调用

**评估方式：**
- 项目评审 — 提示词方案在测试集上表现稳定，输出格式规范，能处理边界情况
- 效果评估 — 在复杂推理任务上准确率显著提升，结构化输出字段完整率 > 95%
- 方法论 — 具备系统的提示词迭代优化方法，能持续改进效果

## 阶段 3 — 目标：掌握（预估 3 周）

**学习主题：**
- 提示词工程方法论：系统设计框架、最佳实践、质量标准
- 复杂任务拆解：大任务 -> 子任务 -> 提示词链 -> 结果整合
- 自动化提示词优化：DSPy、Promptfoo、AutoPrompt 等框架
- 提示词评估体系：质量指标、测试集构建、回归测试、A/B 实验平台
- 领域专用提示词设计：法律、医疗、金融、代码、教育等垂直领域深度优化
- 提示词安全：Prompt Injection 防护、越权操作防范、内容安全、越狱检测
- 模型差异适配：不同模型（GPT / Claude / DeepSeek / Qwen）的提示策略差异
- 提示词资产管理：版本管理、A/B 测试、效果监控、知识库沉淀
- 提示词与 RAG/Agent 的协同设计：系统提示、工具提示、反思提示的组合
- 前沿技术：提示词压缩、软提示（Soft Prompt）、连续提示学习

**学习资源：**
- [DSPy 官方文档](https://dspy-docs.vercel.app/) — 官方文档 · 免费 · 高级 · 英文
- [OpenAI 安全最佳实践](https://platform.openai.com/docs/guides/safety-best-practices) — 官方文档 · 免费 · 高级 · 英文
- [Promptfoo 提示词测试框架](https://www.promptfoo.dev/) — 开源工具 · 免费 · 高级 · 英文

**练习项目：**
- 使用 DSPy 框架构建一个自动化提示词优化流水线，自动调优指定任务的提示词
- 设计一套完整的提示词评估方案，包含测试集构建、评估指标、自动化评测流程
- 为一个垂直领域（如法律 / 医疗 / 金融）设计专业提示词系统，并进行安全加固
- 搭建企业级提示词管理平台，支持版本管理、A/B 测试、效果监控与回滚
- 设计 Prompt Injection 防护方案，实现多层检测与防御机制，通过 20+ 种攻击测试

**评估方式：**
- 方案设计 — 能够独立设计企业级提示词工程方案，涵盖开发、测试、部署、监控全流程
- 技术深度 — 深入理解提示词原理与优化方法论，能解决复杂场景的提示工程问题
- 安全意识 — 具备完善的提示词安全防护意识与能力，能设计有效的防御方案

## 学习建议与进阶路径

- **大量练习**：提示工程是实践驱动的技能，需在各类任务中反复打磨优化
- **建立模板库**：积累各场景的高质量提示词模板，形成个人知识库
- **理解模型差异**：不同模型的特性差异显著，需针对性调整提示策略
- **关注安全**：Prompt Injection 等安全问题是企业落地的重要挑战，需持续研究
- **自动化思维**：逐步从手动写提示词转向利用工具实现自动化优化与评估
