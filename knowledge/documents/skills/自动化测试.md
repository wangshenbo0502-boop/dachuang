# 自动化测试

> 通过代码和工具自动执行测试，提升测试效率和质量，是测试开发工程师的核心技能，也是企业质量保障体系的关键组成部分。

- **就业影响**: 中高（测试开发/质量保障岗位必备，测试开发工程师是大厂校招高性价比岗位，竞争烈度低于纯开发）
- **前置技能**: Python/Java编程基础
- **关联系能**: 测试开发工程师, Python, DevOps, CI/CD
- **学习总周期**: 约 9 周（可根据基础调整）
- **推荐学习方式**: 理论学习 + 框架搭建 + 项目实战 + 工具链集成

## 阶段 1 — 目标：了解（预估 2 周）

**学习主题：**
- 测试基础理论（软件测试分类功能/性能/安全/兼容、黑盒测试与白盒测试、灰盒测试、测试金字塔模型单元/接口/UI、测试 V 模型与 W 模型）
- 单元测试框架（JUnit 5 架构与注解@Test/@BeforeEach/@DisplayName、TestNG 高级特性、Pytest fixture/参数化/标记、断言 assertThat/assert、测试覆盖率概念）
- 接口测试基础（HTTP/HTTPS 协议回顾、RESTful API 设计规范、Postman 使用 Collections/Environments/Tests、接口断言状态码/响应体/响应时间、接口文档 Swagger/Postman Doc）
- Selenium WebDriver 入门（浏览器驱动配置 ChromeDriver/GeckoDriver、元素定位 8 大法 id/name/class/tag/link/css/xpath、基本操作点击/输入/清空/获取文本、等待机制显式等待/隐式等待/流畅等待）
- 测试用例设计（等价类划分有效/无效、边界值分析上点/离点/内点、场景法基本流/备选流、错误推测法、因果图法、判定表法、测试用例模板编写）
- 缺陷管理（Bug 生命周期新建/打开/修复/验证/关闭、缺陷报告编写标题/复现步骤/预期结果/实际结果/附件、Jira/禅道/TestLink 使用、缺陷严重度与优先级定义）
- 测试文档编写（测试计划范围/资源/进度/风险、测试方案策略/环境/工具、测试用例、测试报告总结/覆盖率/缺陷分析、上线 Checklist）
- 测试环境搭建（测试环境与生产环境差异、环境配置管理、数据准备、环境隔离策略、Docker 搭建测试环境）

**学习资源：**
- [测试之家 TesterHome](https://testerhome.com/) — 技术社区 · 免费 · 入门 · 中文
- [Selenium 官方文档（入门篇）](https://www.selenium.dev/documentation/) — 官方文档 · 免费 · 入门 · 英文
- [Postman 官方学习中心](https://learning.postman.com/) — 官方教程 · 免费 · 入门 · 英文
- [菜鸟教程 - 软件测试教程](https://www.runoob.com/) — 在线教程 · 免费 · 入门 · 中文
- [51Testing 软件测试网](http://www.51testing.com/) — 测试门户 · 免费 · 入门 · 中文

**练习项目：**
- 为一个简单的计算器程序（加减乘除、开方、取模）编写单元测试，覆盖正常路径与边界情况，代码覆盖率达到 90% 以上
- 使用 Postman 对一套公开 API（如豆瓣图书 API、天气 API）进行完整的接口测试，编写断言脚本，创建 Collection 并生成测试报告
- 使用 Selenium 编写一个简单的 UI 自动化脚本，实现登录网站、浏览商品、加入购物车、结算等一次完整的业务流程操作
- 为一个电商购物车功能设计完整的测试用例（至少 50 条），包含功能测试、边界测试、异常场景、兼容性测试、性能测试点
- 在本地搭建禅道/Jira 环境，模拟一次完整的缺陷提交、分配、修复、验证、关闭流程，编写规范的缺陷报告
- 设计一份完整的测试计划文档模板，包含测试范围、测试策略、资源安排、进度计划、风险评估等模块
- 使用 Docker 快速搭建一套测试环境（Nginx + MySQL + 应用服务），练习环境配置与数据初始化

**评估方式：** 实操 + 理论 — 能独立编写单元测试与接口测试用例，熟练使用 Selenium 基础操作，设计的测试用例覆盖度达 80% 以上，能规范编写缺陷报告与测试文档，理解测试金字塔模型与测试基础理论

## 常见面试题

1. **基础类**：什么是测试金字塔模型？为什么单元测试在最底层，UI 测试在最顶层？
2. **自动化策略**：什么样的测试适合自动化？如何评估自动化测试的 ROI？自动化覆盖率越高越好吗？
3. **UI 自动化**：Page Object 模式的核心思想是什么？它解决了什么问题？有哪些优缺点？
4. **接口测试**：接口自动化测试中，如何处理接口依赖（如需要登录 Token）？如何进行数据驱动测试？
5. **性能测试**：性能测试的核心指标有哪些？TPS、响应时间、并发数之间是什么关系？如何定位性能瓶颈？
6. **CI/CD 集成**：如何将自动化测试集成到 CI/CD 流水线中？测试失败时如何处理？质量门禁如何设计？
7. **测试框架**：设计一个自动化测试框架需要考虑哪些方面？分层架构的每一层职责是什么？
8. **Flaky Test**：什么是不稳定测试（Flaky Test）？产生的原因有哪些？如何治理和预防？
9. **测试左移**：什么是测试左移？具体有哪些实践方式？如何推动开发团队重视质量？
10. **职业发展**：测试开发工程师的职业发展路径有哪些？如何从功能测试转型测试开发？测试架构师需要具备什么能力？

## 学习路径建议

- **入门阶段（1-2个月）**：掌握测试基础理论、测试用例设计方法、缺陷管理流程，学习一门编程语言（Python/Java），掌握单元测试和接口测试基础工具（Pytest/JUnit/Postman），能独立完成功能测试和简单的自动化测试。
- **进阶阶段（2-5个月）**：深入学习 UI 自动化框架设计（Selenium + PO 模式）、接口自动化框架（Requests/RestAssured + Allure）、性能测试（JMeter/Locust）、CI/CD 集成，能独立设计和实现自动化测试框架，达到中级测试开发工程师水平。
- **深入阶段（5-12个月）**：学习测试平台开发、性能调优、测试左移、AI 辅助测试、质量保障体系建设，能独立开发测试平台、主导性能优化项目、推动质量体系落地，达到高级测试开发工程师或测试架构师水平。
- **职业发展**：功能测试 → 自动化测试工程师 → 测试开发工程师 → 高级测试开发/测试架构师 → 质量经理/技术专家，测试开发工程师是大厂校招高性价比岗位，竞争烈度低于纯开发，薪资却接近开发水平。
- **持续学习**：关注测试之家 TesterHome、51Testing、思否测试专区等社区，学习 AI 测试、混沌工程、云原生测试等前沿技术，持续提升技术深度和广度，建立个人技术影响力。
