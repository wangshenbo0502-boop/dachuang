# 劳动合同签订与试用期权益指南

## 一、核心要点

### 1.1 劳动合同基本知识

劳动合同是劳动者与用人单位确立劳动关系、明确双方权利义务的协议。**入职之日起30日内，用人单位必须与劳动者签订书面劳动合同**。逾期未签订的，劳动者可主张每月支付二倍工资，最长不超过11个月。

劳动合同应当具备以下必备条款：
- 用人单位名称、住所和法定代表人或主要负责人
- 劳动者姓名、住址和居民身份证号码
- 劳动合同期限
- 工作内容和工作地点
- 工作时间和休息休假
- 劳动报酬
- 社会保险
- 劳动保护、劳动条件和职业危害防护

### 1.2 试用期法定规范

试用期是用人单位与劳动者相互了解、选择的考察期，但**试用期包含在劳动合同期限内**，并非独立于合同之外。

| 劳动合同期限 | 试用期上限 |
|------------|----------|
| 3个月以上不满1年 | ≤1个月 |
| 1年以上不满3年 | ≤2个月 |
| 3年以上固定期限/无固定期限 | ≤6个月 |

关键规则：
- **同一用人单位与同一劳动者只能约定一次试用期**
- 试用期工资≥转正工资的80%，且≥当地最低工资标准
- 试用期内必须依法缴纳五险一金
- 不存在"试岗期无工资"的说法，提供劳动即应获得报酬

### 1.3 常见无效条款

以下条款因违反法律强制性规定而**自始无效**：

| 无效条款 | 违法原因 |
|--------|--------|
| "自愿放弃社保" | 社保是国家强制保险，不能自愿放弃 |
| "试用期无薪资" | 提供劳动必须支付报酬 |
| "离职需赔付高额违约金" | 除培训服务期和竞业限制外，不得约定违约金 |
| "合同期内不得结婚/生育" | 侵犯婚姻自由和生育权 |
| "无偿加班" | 加班应依法支付加班费或安排调休 |
| 收取押金/扣押证件 | 用人单位不得要求劳动者提供担保或扣押证件 |

## 二、法律依据

1. **《中华人民共和国劳动合同法》第十条**：建立劳动关系，应当订立书面劳动合同。已建立劳动关系，未同时订立书面劳动合同的，应当自用工之日起一个月内订立书面劳动合同。

2. **《中华人民共和国劳动合同法》第十九条**：劳动合同期限三个月以上不满一年的，试用期不得超过一个月；劳动合同期限一年以上不满三年的，试用期不得超过二个月；三年以上固定期限和无固定期限的劳动合同，试用期不得超过六个月。

3. **《中华人民共和国劳动合同法》第二十条**：劳动者在试用期的工资不得低于本单位相同岗位最低档工资或者劳动合同约定工资的百分之八十，并不得低于用人单位所在地的最低工资标准。

4. **《中华人民共和国劳动合同法》第八十二条**：用人单位自用工之日起超过一个月不满一年未与劳动者订立书面劳动合同的，应当向劳动者每月支付二倍的工资。

5. **《中华人民共和国社会保险法》第五十八条**：用人单位应当自用工之日起三十日内为其职工向社会保险经办机构申请办理社会保险登记。

## 三、常见坑点

### 3.1 签约陷阱

- **空白合同**：用人单位让劳动者在空白合同上签字，后续自行填写不利条款。务必拒绝签署空白合同。
- **阴阳合同**：一份用于备案（工资低），一份实际履行（工资高）。发生争议时劳动者举证困难。
- **口头承诺**：HR口头承诺的薪资、福利、晋升等，如未写入合同，事后难以兑现。
- **模糊条款**：工作内容写"相关工作"、工作地点写"全国"、薪资写"按公司规定"，为用人单位随意调岗降薪留空间。

### 3.2 试用期陷阱

- **重复约定试用期**：换岗或续约后再次约定试用期，违法。
- **试用期不缴社保**：以"转正后再缴"为由拖延缴纳社保，违法。
- **延长试用期**：以"表现一般"为由延长试用期，超出法定上限的部分无效。
- **试用期随意辞退**：试用期辞退需证明劳动者"不符合录用条件"，不能仅凭主观判断。

### 3.3 证件与押金

- 用人单位不得扣押劳动者身份证、毕业证等证件
- 不得以任何名义收取押金、保证金、服装费、培训费等
- 遇到此类要求，应坚决拒绝并向劳动监察部门举报

## 四、签约注意事项与维权方式

### 4.1 签约注意事项

1. **逐条阅读**：仔细阅读合同全部条款，特别是工作内容、工作地点、薪资结构、工时制度
2. **落实书面**：所有口头承诺必须写入合同正文或补充协议
3. **薪资明确**：明确基本工资、绩效工资、补贴的构成和发放方式
4. **保留原件**：自己保留一份合同原件，拍照备份也可作为辅助证据
5. **谨慎签字**：确认所有条款无误后再签字，不要在空白页或空白合同上签字

### 4.2 维权方式

- **协商**：发现问题先与用人单位协商，要求补正或赔偿
- **投诉**：向用人单位所在地的劳动保障监察大队投诉
- **仲裁**：协商不成，向劳动争议仲裁委员会申请劳动仲裁
- **诉讼**：对仲裁裁决不服的，可向人民法院提起诉讼

## 五、典型案例

### 案例一：未签劳动合同主张双倍工资

**案情**：张某于2024年3月入职某科技公司，公司一直未与其签订书面劳动合同。2025年1月张某离职后申请劳动仲裁，要求支付2024年4月至2025年1月期间的双倍工资差额。

**结果**：仲裁委支持了张某的请求，裁决公司支付10个月的双倍工资差额共计8万余元。

**提示**：双倍工资的仲裁时效为一年，从知道或应当知道权利被侵害之日起计算，建议及时维权。

### 案例二：试用期超长被判违法

**案情**：李某与公司签订了期限为2年的劳动合同，约定试用期3个月，试用期工资为转正工资的70%。李某转正后申请仲裁，要求补发试用期工资差额。

**结果**：仲裁委认定2年合同试用期不得超过2个月，且试用期工资不得低于转正工资的80%，裁决公司补发李某第3个月工资差额及试用期工资差额。

**提示**：试用期期限和工资标准均有法律强制性规定，低于法定标准的约定无效。

### 案例三："自愿放弃社保"协议被判无效

**案情**：王某入职时应公司要求签署了"自愿放弃缴纳社保"的声明。工作一年后王某以公司未缴社保为由提出解除劳动合同，并要求经济补偿。

**结果**：法院认定放弃社保的声明违反法律强制性规定，属无效约定，判决公司支付经济补偿金并补缴社保。

**提示**：社保是国家强制保险，任何形式的"自愿放弃"均无效。
