# 加班费、调岗与辞退赔偿详解

## 一、核心要点

### 1.1 加班费

加班费是劳动者超出正常工作时间提供劳动所应获得的额外报酬，实行不同的倍率标准：

| 加班类型 | 工资倍率 | 能否调休替代 |
|--------|--------|------------|
| 工作日延长工作时间 | 1.5倍 | 不能，必须支付加班费 |
| 休息日加班 | 2倍 | 可以，优先安排调休，不能调休的支付2倍工资 |
| 法定节假日加班 | 3倍 | 不能，必须支付加班费 |

**加班工资计算基数**：劳动合同有约定的按约定，无约定的按正常出勤月工资的70%确定，但不得低于当地最低工资标准。

**举证要点**：
- 加班通知截图、加班审批记录
- 考勤记录（打卡截图、考勤系统导出）
- 工作群消息、邮件往来
- 打车记录（加班后打车报销）
- 工作产出记录（提交时间戳）

> 注意："自愿加班"举证难度大，建议保留用人单位安排加班的证据。考勤记录由用人单位掌握管理，用人单位不提供的，应当承担不利后果。

### 1.2 调岗降薪

调岗降薪属于**劳动合同变更**，根据《劳动合同法》第三十五条，必须**用人单位与劳动者协商一致**，并采用书面形式。

**公司不能单方面随意调岗降薪**，合法调岗仅限以下情形：
1. 劳动者患病或非因工负伤，医疗期满后不能从事原工作
2. 劳动者不能胜任工作（需有明确考核标准和证据）
3. 劳动合同订立时所依据的客观情况发生重大变化，致使合同无法履行

> 重要提示："末位淘汰"不能作为辞退理由，单纯的排名末位不等于"不能胜任工作"，以此解除劳动合同属违法。

### 1.3 辞退与经济补偿

| 辞退类型 | 适用情形 | 补偿标准 |
|--------|--------|--------|
| 过失性辞退 | 严重违纪、严重失职、被追究刑事责任等 | 0（无补偿） |
| 无过失性辞退 | 不胜任工作/医疗期满/客观情况变化 | N+1（或提前30天通知） |
| 经济性裁员 | 依照企业破产法重整、生产经营严重困难等 | N |
| 违法辞退 | 不符合法定条件和程序解除劳动合同 | 2N（赔偿金） |

**补偿计算**：
- **N = 工作年限 × 月工资**
- 工作不满6个月按0.5计算，满6个月不满1年按1计算
- 月工资按离职前12个月平均应发工资计算
- 月工资高于当地社平工资3倍的，按3倍封顶，年限不超过12年

> 试用期辞退：需要证明劳动者"不符合录用条件"，且录用条件需已明确告知劳动者，不能随意辞退。

### 1.4 离职规范

- 试用期内：提前**3天**通知用人单位
- 转正后：提前**30天**以**书面形式**通知用人单位
- 劳动者解除劳动合同是"**通知**"而非"申请"，不需要用人单位批准
- 用人单位应在解除或终止劳动合同时**一次性结清工资**，并在15日内办理社保转移和档案转移手续

## 二、法律依据

1. **《中华人民共和国劳动法》第四十四条**：有下列情形之一的，用人单位应当按照下列标准支付高于劳动者正常工作时间工资的工资报酬：（一）安排劳动者延长工作时间的，支付不低于工资的百分之一百五十的工资报酬；（二）休息日安排劳动者工作又不能安排补休的，支付不低于工资的百分之二百的工资报酬；（三）法定休假日安排劳动者工作的，支付不低于工资的百分之三百的工资报酬。

2. **《中华人民共和国劳动合同法》第三十五条**：用人单位与劳动者协商一致，可以变更劳动合同约定的内容。变更劳动合同，应当采用书面形式。

3. **《中华人民共和国劳动合同法》第三十九条**：劳动者有下列情形之一的，用人单位可以解除劳动合同：（一）在试用期间被证明不符合录用条件的；（二）严重违反用人单位的规章制度的...

4. **《中华人民共和国劳动合同法》第四十条**：有下列情形之一的，用人单位提前三十日以书面形式通知劳动者本人或者额外支付劳动者一个月工资后，可以解除劳动合同：（一）劳动者患病或者非因工负伤，在规定的医疗期满后不能从事原工作，也不能从事由用人单位另行安排的工作的；（二）劳动者不能胜任工作，经过培训或者调整工作岗位，仍不能胜任工作的；（三）劳动合同订立时所依据的客观情况发生重大变化，致使劳动合同无法履行，经用人单位与劳动者协商，未能就变更劳动合同内容达成协议的。

5. **《中华人民共和国劳动合同法》第八十七条**：用人单位违反本法规定解除或者终止劳动合同的，应当依照本法第四十七条规定的经济补偿标准的二倍向劳动者支付赔偿金。

## 三、常见坑点

### 3.1 加班费陷阱

- **"包薪制"规避加班费**：合同约定"工资已包含加班费"，如实际加班时长超出合理范围，约定无效
- **"自愿加班"不付加班费**：只要有证据证明是用人单位安排或默许的加班，仍应支付加班费
- **以调休代替法定节假日加班费**：法定节假日加班必须支付3倍工资，不能用调休冲抵
- **按最低工资计算加班费**：应以实际正常工资为基数，不能一律按最低工资计算

### 3.2 调岗降薪陷阱

- **"根据公司需要"条款**：合同中宽泛约定公司有权调岗，不等于可以任意调岗，仍需合理
- **变相逼迫离职**：通过调岗到不合理地点、降职降薪等方式逼迫员工主动辞职，以规避补偿
- **"竞聘上岗"末位调岗**：内部竞聘不能作为单方调岗降薪的合法依据
- **以"不胜任"为由调岗**：需有明确的岗位职责、考核标准和不胜任的客观证据

### 3.3 辞退赔偿陷阱

- **让员工签"自愿离职申请"**：以补偿为条件要求员工签署自愿离职书，签署后可能丧失维权依据
- **"劝退"变"主动辞职"**：口头协商辞退，让员工走主动辞职流程，规避经济补偿
- **试用期随意辞退**：以"试用期不合格"为由随意辞退，无具体考核标准和证据
- **经济补偿金按基本工资计算**：应按离职前12个月平均应发工资（含奖金、补贴等）计算

## 四、维权方式

### 4.1 加班费维权

1. **收集证据**：考勤记录、加班通知、工作群记录、工资条等
2. **内部协商**：向HR或部门负责人提出加班费支付请求
3. **劳动监察投诉**：向劳动保障监察大队投诉，要求责令支付
4. **劳动仲裁**：申请仲裁要求支付加班费及25%的经济补偿金
5. **注意时效**：劳动关系存续期间不受1年时效限制，离职后1年内主张

### 4.2 调岗降薪维权

1. **书面异议**：收到调岗通知后，及时以书面形式提出异议（保留证据）
2. **拒绝到岗**：如调岗不合法不合理，可拒绝到新岗位报到
3. **继续上班**：坚持在原岗位正常出勤，避免被认定为旷工
4. **申请仲裁**：要求恢复原岗位原待遇，或解除合同并主张经济补偿

### 4.3 辞退赔偿维权

1. **获取书面通知**：要求用人单位出具书面辞退通知，载明辞退理由
2. **不要乱签字**：不要轻易签署"自愿离职书""放弃权益承诺书"等文件
3. **收集证据**：劳动合同、工资流水、辞退通知、谈话录音等
4. **申请仲裁**：主张违法解除劳动合同的赔偿金（2N）或经济补偿金

## 五、典型案例

### 案例一："末位淘汰"被判违法解除

**案情**：某销售公司实行月度排名制度，连续3个月排名末位的员工予以辞退。员工赵某连续3个月排名末位被辞退后申请仲裁，要求支付违法解除赔偿金。

**结果**：仲裁委和法院均认为，"末位"不等于"不能胜任工作"，公司以末位淘汰为由解除劳动合同缺乏法律依据，属违法解除，判决支付2N赔偿金。

**提示**：考核排名末位仅说明员工相对业绩靠后，不能直接等同于不胜任工作。不胜任需有明确的客观标准且经培训或调岗后仍不胜任。

### 案例二：法定节假日加班不得以调休抵加班费

**案情**：张某在国庆期间加班3天，公司事后安排3天调休但未支付加班费。张某申请仲裁要求支付3倍加班费。

**结果**：仲裁委支持了张某的请求，裁决公司支付法定节假日3倍工资。依据《劳动法》第四十四条，法定休假日安排劳动者工作的，必须支付不低于工资300%的工资报酬，不能以调休替代。

**提示**：只有休息日加班可以安排调休，工作日延时加班和法定节假日加班必须支付加班费。

### 案例三：单方调岗降薪被判恢复原待遇

**案情**：某公司未经协商，将研发部经理刘某调至行政部任专员，工资降为原工资的60%。刘某拒绝到岗并申请仲裁。

**结果**：法院认为，调岗降薪属于劳动合同变更，应双方协商一致。公司单方调岗既无合同依据也无法律依据，判决恢复刘某原岗位和原工资待遇。

**提示**：面对不合理调岗，应及时书面提出异议并保留证据，不要主动辞职，否则可能丧失经济补偿权利。
