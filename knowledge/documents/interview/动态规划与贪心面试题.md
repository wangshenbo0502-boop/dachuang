# 动态规划与贪心面试题（20题）

动态规划（DP）和贪心算法是算法面试中的重点和难点，也是区分候选人算法功底的关键题型。动态规划考察状态定义、状态转移方程的推导能力；贪心算法考察能否找到最优子结构和贪心选择性质。本篇整理了20道最高频的DP与贪心面试题。

## Q1: 爬楼梯

**题目描述**: 假设你正在爬楼梯。需要 n 阶你才能到达楼顶。每次你可以爬 1 或 2 个台阶。你有多少种不同的方法可以爬到楼顶呢？

**考察点**: 动态规划、斐波那契数列

**难度**: 简单

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

这是动态规划的入门题，本质就是斐波那契数列。

**思路分析**：
- 到达第n阶的方法数 = 到达第n-1阶的方法数（再爬1步）+ 到达第n-2阶的方法数（再爬2步）
- 即：dp[n] = dp[n-1] + dp[n-2]
- 初始条件：dp[1] = 1（1阶只有1种），dp[2] = 2（2阶有2种）

**空间优化**：
- 不需要数组，只需要两个变量记录前两个状态
- 时间O(n)，空间O(1)

**参考代码**（Java）:
```java
// 动态规划（空间优化版）
public int climbStairs(int n) {
    if (n == 1) return 1;
    if (n == 2) return 2;
    
    int prev1 = 1; // dp[n-2]
    int prev2 = 2; // dp[n-1]
    
    for (int i = 3; i <= n; i++) {
        int curr = prev1 + prev2;
        prev1 = prev2;
        prev2 = curr;
    }
    return prev2;
}

// 递归+记忆化（自顶向下）
public int climbStairs(int n) {
    int[] memo = new int[n + 1];
    return climbStairsHelper(n, memo);
}

private int climbStairsHelper(int n, int[] memo) {
    if (n == 1) return 1;
    if (n == 2) return 2;
    if (memo[n] != 0) return memo[n];
    
    memo[n] = climbStairsHelper(n - 1, memo) + climbStairsHelper(n - 2, memo);
    return memo[n];
}
```

**复杂度分析**:
- 时间复杂度：O(n)，迭代n-2次
- 空间复杂度：O(1)，只使用两个变量

**扩展问题**:
- 如果每次可以爬1、2、3步？（递推式变成dp[n] = dp[n-1] + dp[n-2] + dp[n-3]）
- 最小花费爬楼梯？
- 斐波那契数列的矩阵快速幂优化（O(logn)）？

## Q2: 斐波那契数列

**题目描述**: 写一个函数，输入 n ，求斐波那契（Fibonacci）数列的第 n 项（即 F(N)）。斐波那契数列的定义如下：F(0) = 0, F(1) = 1；F(N) = F(N - 1) + F(N - 2), 其中 N > 1。答案需要取模 1e9+7（1000000007）。

**考察点**: 动态规划、递推、矩阵快速幂

**难度**: 简单

**频率**: ⭐⭐⭐⭐

**解题思路**:

斐波那契数列是最基础的递推问题，有多种解法：

**方法一：递归（暴力，不推荐）**
- 直接按定义递归，时间O(2^n)，会有大量重复计算

**方法二：记忆化递归（自顶向下）**
- 用数组或哈希表缓存计算结果，避免重复计算
- 时间O(n)，空间O(n)

**方法三：动态规划（自底向上，最优）**
- 从底向上迭代计算
- 空间优化：只需要两个变量
- 时间O(n)，空间O(1)

**方法四：矩阵快速幂（进阶）**
- 利用矩阵快速幂，时间O(logn)
- 面试中一般不会要求，但知道是加分项

**参考代码**（Java）:
```java
// 动态规划（空间优化）
public int fib(int n) {
    if (n == 0) return 0;
    if (n == 1) return 1;
    
    int MOD = 1000000007;
    int prev1 = 0; // F(n-2)
    int prev2 = 1; // F(n-1)
    
    for (int i = 2; i <= n; i++) {
        int curr = (prev1 + prev2) % MOD;
        prev1 = prev2;
        prev2 = curr;
    }
    return prev2;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，迭代n-1次
- 空间复杂度：O(1)，只使用两个变量

**扩展问题**:
- 青蛙跳台阶问题（就是爬楼梯）？
- 矩形覆盖问题（2xn的矩形用2x1的小矩形覆盖，有多少种方法）？
- 矩阵快速幂如何实现O(logn)的斐波那契计算？

## Q3: 零钱兑换

**题目描述**: 给你一个整数数组 coins ，表示不同面额的硬币；以及一个整数 amount ，表示总金额。计算并返回可以凑成总金额所需的最少的硬币个数。如果没有任何一种硬币组合能组成总金额，返回 -1。你可以认为每种硬币的数量是无限的。

**考察点**: 动态规划、完全背包

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

这是一道经典的完全背包问题（每个物品可以选无限次）。

**DP定义**：
- dp[i] 表示凑成金额 i 所需的最少硬币数
- 目标：求 dp[amount]

**状态转移**：
- 对于每个硬币 coin，如果 coin <= i：
  dp[i] = min(dp[i], dp[i - coin] + 1)
- 即尝试使用这枚硬币，硬币数+1

**初始化**：
- dp[0] = 0（金额为0需要0枚硬币）
- 其他位置初始化为一个大数（如amount+1），表示无法凑成
- 最后判断 dp[amount] 是否大于 amount，是则返回-1

**参考代码**（Java）:
```java
public int coinChange(int[] coins, int amount) {
    int[] dp = new int[amount + 1];
    // 初始化为一个大数（最多需要amount枚1元硬币）
    Arrays.fill(dp, amount + 1);
    dp[0] = 0;
    
    // 遍历每个金额
    for (int i = 1; i <= amount; i++) {
        // 尝试每种硬币
        for (int coin : coins) {
            if (coin <= i) {
                dp[i] = Math.min(dp[i], dp[i - coin] + 1);
            }
        }
    }
    
    return dp[amount] > amount ? -1 : dp[amount];
}
```

**复杂度分析**:
- 时间复杂度：O(amount × k)，k是硬币种类数
- 空间复杂度：O(amount)，DP数组大小

**扩展问题**:
- 零钱兑换II（求组合数，不是最少硬币数）？
- 完全背包和01背包的区别？
- 如果硬币数量有限制（多重背包）？

## Q4: 打家劫舍

**题目描述**: 你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警。给定一个代表每个房屋存放金额的非负整数数组，计算你不触动警报装置的情况下，一夜之内能够偷窃到的最高金额。

**考察点**: 动态规划、状态压缩

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

经典的一维DP问题。

**DP定义**：
- dp[i] 表示前 i 间房屋能偷窃到的最高金额

**状态转移**：
- 对于第 i 间房，有两种选择：
  - 偷：则第 i-1 间不能偷，dp[i] = dp[i-2] + nums[i]
  - 不偷：dp[i] = dp[i-1]
- dp[i] = max(dp[i-1], dp[i-2] + nums[i])

**初始化**：
- dp[0] = nums[0]（只有一间房）
- dp[1] = max(nums[0], nums[1])（两间房偷金额大的）

**空间优化**：
- 只需要前两个状态，用两个变量即可
- 时间O(n)，空间O(1)

**参考代码**（Java）:
```java
// 标准DP
public int rob(int[] nums) {
    if (nums == null || nums.length == 0) return 0;
    if (nums.length == 1) return nums[0];
    
    int n = nums.length;
    int[] dp = new int[n];
    dp[0] = nums[0];
    dp[1] = Math.max(nums[0], nums[1]);
    
    for (int i = 2; i < n; i++) {
        dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[i]);
    }
    return dp[n - 1];
}

// 空间优化版
public int rob(int[] nums) {
    if (nums == null || nums.length == 0) return 0;
    
    int prev1 = 0; // dp[i-2]
    int prev2 = 0; // dp[i-1]
    
    for (int num : nums) {
        int curr = Math.max(prev2, prev1 + num);
        prev1 = prev2;
        prev2 = curr;
    }
    return prev2;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，遍历一次数组
- 空间复杂度：O(1)，只使用两个变量

**扩展问题**:
- 打家劫舍II（房屋围成一圈）？
- 打家劫舍III（二叉树结构的房屋）？
- 按摩师（和打家劫舍完全一样的题）？

## Q5: 打家劫舍II

**题目描述**: 你是一个专业的小偷，计划偷窃沿街的房屋，每间房内都藏有一定的现金。这个地方所有的房屋都围成一圈，这意味着第一个房屋和最后一个房屋是紧挨着的。同时，相邻的房屋装有相互连通的防盗系统，如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警。给定一个代表每个房屋存放金额的非负整数数组，计算你在不触动警报装置的情况下，今晚能够偷窃到的最高金额。

**考察点**: 动态规划、环形数组处理

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

这道题是打家劫舍的进阶版，房屋围成了一圈。关键是：第一间和最后一间不能同时偷。

**思路**：
- 将环形问题拆解成两个线性问题：
  1. 不偷第一间房：求 nums[1..n-1] 的最大金额
  2. 不偷最后一间房：求 nums[0..n-2] 的最大金额
- 答案就是两者的较大值

这种"拆解问题"的思路在环形问题中很常见。

**参考代码**（Java）:
```java
public int rob(int[] nums) {
    if (nums == null || nums.length == 0) return 0;
    if (nums.length == 1) return nums[0];
    
    // 不偷第一间 vs 不偷最后一间
    return Math.max(robRange(nums, 1, nums.length - 1),
                    robRange(nums, 0, nums.length - 2));
}

// 打家劫舍I的解法，指定范围
private int robRange(int[] nums, int start, int end) {
    int prev1 = 0; // dp[i-2]
    int prev2 = 0; // dp[i-1]
    
    for (int i = start; i <= end; i++) {
        int curr = Math.max(prev2, prev1 + nums[i]);
        prev1 = prev2;
        prev2 = curr;
    }
    return prev2;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，两次线性扫描
- 空间复杂度：O(1)，只使用常数额外空间

**扩展问题**:
- 打家劫舍III（树形DP）？
- 环形数组的其他问题（环形数组的最大子数组和）？
- 删除与获得点数（类似打家劫舍）？

## Q6: 最大子序和（Kadane算法）

**题目描述**: 给你一个整数数组 nums ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。子数组是数组中的一个连续部分。

**考察点**: 动态规划、Kadane算法、分治

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

**Kadane算法**（动态规划的空间优化版）：

**DP定义**：
- dp[i] 表示以 nums[i] 结尾的最大子数组和
- 注意：必须以 nums[i] 结尾，这样才能保证连续性

**状态转移**：
- dp[i] = max(dp[i-1] + nums[i], nums[i])
- 即：要么和前面连起来，要么从自己重新开始

**结果**：
- max(dp[0], dp[1], ..., dp[n-1])

**空间优化**：
- 只需要前一个状态，用一个变量即可
- 时间O(n)，空间O(1)

**分治法**（了解即可）：
- 最大子数组和 = max(左半边最大和, 右半边最大和, 跨越中间的最大和)
- 时间O(nlogn)

**参考代码**（Java）:
```java
// Kadane算法（空间优化DP）
public int maxSubArray(int[] nums) {
    int maxSum = nums[0]; // 全局最大和
    int currSum = nums[0]; // 以当前位置结尾的最大和
    
    for (int i = 1; i < nums.length; i++) {
        // 要么从当前重新开始，要么和前面连起来
        currSum = Math.max(nums[i], currSum + nums[i]);
        maxSum = Math.max(maxSum, currSum);
    }
    return maxSum;
}

// 标准DP写法
public int maxSubArray(int[] nums) {
    int n = nums.length;
    int[] dp = new int[n];
    dp[0] = nums[0];
    int maxSum = nums[0];
    
    for (int i = 1; i < n; i++) {
        dp[i] = Math.max(nums[i], dp[i - 1] + nums[i]);
        maxSum = Math.max(maxSum, dp[i]);
    }
    return maxSum;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，遍历一次数组
- 空间复杂度：O(1)，只使用两个变量

**扩展问题**:
- 最大子数组的起始和结束下标？
- 环形数组的最大子数组和？
- 乘积最大子数组？

## Q7: 最长上升子序列

**题目描述**: 给你一个整数数组 nums ，找到其中最长严格递增子序列的长度。子序列是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，[3,6,2,7] 是数组 [0,3,1,6,2,2,7] 的子序列。

**考察点**: 动态规划、二分查找优化

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

**方法一：动态规划（O(n²)）**

**DP定义**：
- dp[i] 表示以 nums[i] 结尾的最长上升子序列长度

**状态转移**：
- dp[i] = max(dp[j] + 1)，其中 j < i 且 nums[j] < nums[i]
- 即：在 i 前面找一个比 nums[i] 小的数，接在它后面

**结果**：
- max(dp[0], dp[1], ..., dp[n-1])

**方法二：贪心 + 二分查找（O(nlogn)，进阶）**
- 维护一个数组 tails，tails[i] 表示长度为 i+1 的上升子序列的最小末尾值
- 遍历每个数，如果大于tails末尾就追加
- 否则用二分查找找到第一个 >= 当前数的位置，替换它
- 最后 tails 的长度就是LIS长度

**参考代码**（Java）:
```java
// 方法一：动态规划 O(n²)
public int lengthOfLIS(int[] nums) {
    int n = nums.length;
    int[] dp = new int[n];
    Arrays.fill(dp, 1); // 每个元素自身长度为1
    int maxLen = 1;
    
    for (int i = 1; i < n; i++) {
        for (int j = 0; j < i; j++) {
            if (nums[j] < nums[i]) {
                dp[i] = Math.max(dp[i], dp[j] + 1);
            }
        }
        maxLen = Math.max(maxLen, dp[i]);
    }
    return maxLen;
}

// 方法二：贪心+二分 O(nlogn)
public int lengthOfLIS(int[] nums) {
    List<Integer> tails = new ArrayList<>();
    
    for (int num : nums) {
        // 二分查找第一个 >= num 的位置
        int left = 0, right = tails.size();
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (tails.get(mid) < num) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        
        if (left == tails.size()) {
            tails.add(num); // 比所有都大，追加
        } else {
            tails.set(left, num); // 替换
        }
    }
    return tails.size();
}
```

**复杂度分析**:
- DP法：时间O(n²)，空间O(n)
- 贪心+二分：时间O(nlogn)，空间O(n)

**扩展问题**:
- 最长连续递增序列（更简单，双指针）？
- 最长递增子序列的个数？
- 俄罗斯套娃信封问题（二维LIS）？

## Q8: 最长公共子序列

**题目描述**: 给定两个字符串 text1 和 text2，返回这两个字符串的最长公共子序列的长度。如果不存在公共子序列，返回 0。一个字符串的子序列是指这样一个新的字符串：它是由原字符串在不改变字符的相对顺序的情况下删除某些字符（也可以不删除任何字符）后组成的新字符串。两个字符串的公共子序列是这两个字符串所共同拥有的子序列。

**考察点**: 动态规划、二维DP

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

二维DP的经典题。

**DP定义**：
- dp[i][j] 表示 text1 前 i 个字符和 text2 前 j 个字符的最长公共子序列长度

**状态转移**：
- 如果 text1[i-1] == text2[j-1]（注意下标）：
  dp[i][j] = dp[i-1][j-1] + 1
- 如果不相等：
  dp[i][j] = max(dp[i-1][j], dp[i][j-1])
  （即：不选text1第i个，或不选text2第j个，取较大的）

**初始化**：
- dp[0][j] = 0，dp[i][0] = 0（空串的LCS为0）

时间O(m×n)，空间O(m×n)，可以优化到O(min(m,n))。

**参考代码**（Java）:
```java
public int longestCommonSubsequence(String text1, String text2) {
    int m = text1.length();
    int n = text2.length();
    
    int[][] dp = new int[m + 1][n + 1];
    
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }
    return dp[m][n];
}
```

**复杂度分析**:
- 时间复杂度：O(m×n)，双重循环
- 空间复杂度：O(m×n)，二维DP数组

**扩展问题**:
- 最长公共子串（连续的，状态转移不同）？
- 两个字符串的删除操作（LCS的变形）？
- 如何输出最长公共子序列（不仅是长度）？

## Q9: 编辑距离

**题目描述**: 给你两个单词 word1 和 word2，请你计算出将 word1 转换成 word2 所使用的最少操作数。你可以对一个单词进行如下三种操作：插入一个字符、删除一个字符、替换一个字符。

**考察点**: 动态规划、二维DP

**难度**: 困难

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

编辑距离（Levenshtein距离）是DP的经典难题。

**DP定义**：
- dp[i][j] 表示 word1 前 i 个字符转换成 word2 前 j 个字符所需的最少操作数

**状态转移**：
- 如果 word1[i-1] == word2[j-1]：
  dp[i][j] = dp[i-1][j-1]（字符相同，不需要操作）
- 如果不相等，有三种操作：
  1. 替换：dp[i-1][j-1] + 1（把word1第i个字符替换成word2第j个）
  2. 删除：dp[i-1][j] + 1（删除word1第i个字符）
  3. 插入：dp[i][j-1] + 1（在word1第i个位置插入word2第j个字符）
  dp[i][j] = min(三种操作) + 1

**初始化**：
- dp[i][0] = i（word1前i个字符转成空串，需要i次删除）
- dp[0][j] = j（空串转成word2前j个字符，需要j次插入）

**参考代码**（Java）:
```java
public int minDistance(String word1, String word2) {
    int m = word1.length();
    int n = word2.length();
    
    int[][] dp = new int[m + 1][n + 1];
    
    // 初始化
    for (int i = 0; i <= m; i++) {
        dp[i][0] = i;
    }
    for (int j = 0; j <= n; j++) {
        dp[0][j] = j;
    }
    
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1];
            } else {
                // 替换、删除、插入 三种操作取最小
                dp[i][j] = Math.min(Math.min(dp[i - 1][j - 1], dp[i - 1][j]), 
                                    dp[i][j - 1]) + 1;
            }
        }
    }
    return dp[m][n];
}
```

**复杂度分析**:
- 时间复杂度：O(m×n)，双重循环
- 空间复杂度：O(m×n)，二维DP数组（可优化到O(n)）

**扩展问题**:
- 只有删除操作的情况？（就是LCS的变形）
- 两个字符串的最小ASCII删除和？
- 编辑距离的具体操作序列怎么输出？

## Q10: 单词拆分

**题目描述**: 给你一个字符串 s 和一个字符串列表 wordDict 作为字典。请你判断是否可以利用字典中出现的单词拼接出 s 。注意：不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。

**考察点**: 动态规划、完全背包

**难度**: 中等

**频率**: ⭐⭐⭐⭐

**解题思路**:

这道题可以看作是完全背包的变形：字典中的单词是物品，字符串s是背包容量，问能否装满背包。

**DP定义**：
- dp[i] 表示字符串 s 的前 i 个字符能否被拆分

**状态转移**：
- dp[i] = OR(dp[j] && s[j..i-1] 在字典中)，其中 j < i
- 即：尝试所有可能的分割点 j，如果前 j 个能拆分，且 j 到 i 的子串在字典中，则 dp[i] 为 true

**初始化**：
- dp[0] = true（空串可以被拆分）

**优化**：
- 遍历 j 时，可以只遍历字典中最长单词长度范围内的 j
- 用HashSet存储字典，O(1)查找

**参考代码**（Java）:
```java
public boolean wordBreak(String s, List<String> wordDict) {
    Set<String> wordSet = new HashSet<>(wordDict);
    int n = s.length();
    boolean[] dp = new boolean[n + 1];
    dp[0] = true; // 空串可以被拆分
    
    // 计算字典中最长单词长度，优化内层循环
    int maxLen = 0;
    for (String word : wordDict) {
        maxLen = Math.max(maxLen, word.length());
    }
    
    for (int i = 1; i <= n; i++) {
        // j从i-maxLen开始，不用从0开始
        for (int j = Math.max(0, i - maxLen); j < i; j++) {
            if (dp[j] && wordSet.contains(s.substring(j, i))) {
                dp[i] = true;
                break;
            }
        }
    }
    return dp[n];
}
```

**复杂度分析**:
- 时间复杂度：O(n × L)，n是字符串长度，L是字典中最长单词长度
- 空间复杂度：O(n + k)，k是字典单词数

**扩展问题**:
- 单词拆分II（返回所有可能的拆分方式）？
- 完全背包的排列数和组合数区别？
- 最长单词链？

## Q11: 不同路径

**题目描述**: 一个机器人位于一个 m x n 网格的左上角。机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角。问总共有多少条不同的路径？

**考察点**: 动态规划、二维DP、组合数学

**难度**: 中等

**频率**: ⭐⭐⭐⭐

**解题思路**:

**方法一：动态规划**

**DP定义**：
- dp[i][j] 表示从左上角到 (i,j) 位置的不同路径数

**状态转移**：
- dp[i][j] = dp[i-1][j] + dp[i][j-1]
- （只能从上面或左边来）

**初始化**：
- dp[0][j] = 1（第一行，只能一直向右）
- dp[i][0] = 1（第一列，只能一直向下）

时间O(m×n)，空间O(m×n)，可优化到O(n)。

**方法二：组合数学**
- 从左上角到右下角需要走 (m-1)+(n-1) 步
- 其中 m-1 步向下，n-1 步向右
- 答案 = C(m+n-2, m-1) = C(m+n-2, n-1)
- 时间O(min(m,n))，空间O(1)

**参考代码**（Java）:
```java
// 动态规划
public int uniquePaths(int m, int n) {
    int[][] dp = new int[m][n];
    
    // 初始化第一行和第一列
    for (int i = 0; i < m; i++) dp[i][0] = 1;
    for (int j = 0; j < n; j++) dp[0][j] = 1;
    
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
        }
    }
    return dp[m - 1][n - 1];
}

// 空间优化（滚动数组）
public int uniquePaths(int m, int n) {
    int[] dp = new int[n];
    Arrays.fill(dp, 1);
    
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            dp[j] = dp[j] + dp[j - 1];
        }
    }
    return dp[n - 1];
}
```

**复杂度分析**:
- 时间复杂度：O(m×n)，双重循环
- 空间复杂度：O(n)，滚动数组优化后

## Q12: 最小路径和

**题目描述**: 给定一个包含非负整数的 m x n 网格 grid ，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。说明：每次只能向下或者向右移动一步。

**考察点**: 动态规划、二维DP

**难度**: 中等

**频率**: ⭐⭐⭐⭐

**解题思路**:

和不同路径类似，只是求的是最小和而不是路径数。

**DP定义**：
- dp[i][j] 表示从左上角到 (i,j) 的最小路径和

**状态转移**：
- dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]
- 从上面或左边来，取较小的那个，加上当前格的值

**初始化**：
- dp[0][j] = dp[0][j-1] + grid[0][j]（第一行，只能从左边来）
- dp[i][0] = dp[i-1][0] + grid[i][0]（第一列，只能从上面来）

可以直接在原数组上修改，空间优化到O(1)。

**参考代码**（Java）:
```java
public int minPathSum(int[][] grid) {
    int m = grid.length;
    int n = grid[0].length;
    
    // 直接在原数组上修改
    // 初始化第一行
    for (int j = 1; j < n; j++) {
        grid[0][j] += grid[0][j - 1];
    }
    // 初始化第一列
    for (int i = 1; i < m; i++) {
        grid[i][0] += grid[i - 1][0];
    }
    
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            grid[i][j] += Math.min(grid[i - 1][j], grid[i][j - 1]);
        }
    }
    return grid[m - 1][n - 1];
}
```

**复杂度分析**:
- 时间复杂度：O(m×n)，双重循环
- 空间复杂度：O(1)，原地修改（如果允许修改原数组）

**扩展问题**:
- 不同路径II（有障碍物）？
- 三角形最小路径和？
- 下降路径最小和？

**难度**: 简单

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

**方法一：暴力法**
- 枚举所有买入卖出对，找最大差值
- 时间O(n²)，会超时

**方法二：一次遍历（最优）**
- 遍历数组，维护两个变量：
  - minPrice：到当前天为止的最低价格
  - maxProfit：到当前天为止的最大利润
- 对于每一天，计算如果今天卖出能获得的利润 = 当前价格 - minPrice
- 更新最大利润，同时更新最低价格
- 时间O(n)，空间O(1)

**参考代码**（Java）:
```java
public int maxProfit(int[] prices) {
    int minPrice = Integer.MAX_VALUE;
    int maxProfit = 0;
    
    for (int price : prices) {
        if (price < minPrice) {
            minPrice = price;
        } else if (price - minPrice > maxProfit) {
            maxProfit = price - minPrice;
        }
    }
    return maxProfit;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(1)，只使用两个变量

## Q14: 买卖股票的最佳时机II

**考察点**: 贪心算法、动态规划

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

**方法一：贪心算法**
- 只要后一天价格比前一天高，就前一天买后一天卖，赚取差价
- 这等价于在最低点买入，最高点卖出
- 因为所有上涨区间的利润之和 = 最高点 - 最低点
- 时间O(n)，空间O(1)

**方法二：动态规划**
- dp[i][0] 表示第i天不持有股票的最大利润
- dp[i][1] 表示第i天持有股票的最大利润
- dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i])
- dp[i][1] = max(dp[i-1][1], dp[i-1][0] - prices[i])
- 时间O(n)，空间O(n)，可优化到O(1)

**参考代码**（Java）:
```java
// 贪心法
public int maxProfit(int[] prices) {
    int maxProfit = 0;
    for (int i = 1; i < prices.length; i++) {
        if (prices[i] > prices[i - 1]) {
            maxProfit += prices[i] - prices[i - 1];
        }
    }
    return maxProfit;
}

// 动态规划（空间优化）
public int maxProfit(int[] prices) {
    int dp0 = 0; // 不持有
    int dp1 = -prices[0]; // 持有
    
    for (int i = 1; i < prices.length; i++) {
        int newDp0 = Math.max(dp0, dp1 + prices[i]);
        int newDp1 = Math.max(dp1, dp0 - prices[i]);
        dp0 = newDp0;
        dp1 = newDp1;
    }
    return dp0;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(1)，只使用常数变量

- 买卖股票含手续费？

## Q15: 分割等和子集

**题目描述**: 给你一个只包含正整数的非空数组 nums 。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

**考察点**: 动态规划、01背包

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

这道题可以转化为01背包问题：能否从数组中选出一些数，使得它们的和等于总和的一半。

**转化思路**：
- 先计算数组总和 sum
- 如果 sum 是奇数，直接返回 false
- 问题转化为：能否选出一些数，和为 sum/2
- 这就是经典的01背包问题

**DP定义**：
- dp[j] 表示能否凑出金额 j
- 这是01背包的"能不能"问题，不是"最大价值"问题

**状态转移**：
- dp[j] = dp[j] || dp[j - nums[i]]
- （不选第i个数 或者 选第i个数）

**初始化**：
- dp[0] = true（和为0总是可以的）

注意：01背包要从后往前遍历，避免重复使用。

**参考代码**（Java）:
```java
public boolean canPartition(int[] nums) {
    int sum = 0;
    for (int num : nums) {
        sum += num;
    }
    // 和为奇数，不可能分割
    if (sum % 2 != 0) return false;
    
    int target = sum / 2;
    boolean[] dp = new boolean[target + 1];
    dp[0] = true;
    
    for (int num : nums) {
        // 01背包：从后往前遍历
        for (int j = target; j >= num; j--) {
            dp[j] = dp[j] || dp[j - num];
        }
    }
    return dp[target];
}
```

**复杂度分析**:
- 时间复杂度：O(n × target)，target = sum/2
- 空间复杂度：O(target)，一维DP数组

- 最后一块石头的重量II（01背包变形）？
- 目标和（01背包变形）？
- 一和零（二维01背包）？

## Q16: 最长回文子串

**题目描述**: 给你一个字符串 s，找到 s 中最长的回文子串。

**考察点**: 动态规划、中心扩展、Manacher算法

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

**方法一：动态规划**

**DP定义**：
- dp[i][j] 表示子串 s[i..j] 是否是回文串

**状态转移**：
- 如果 s[i] == s[j] 且 (j - i <= 2 或 dp[i+1][j-1])：
  dp[i][j] = true
- 即：两端字符相等，且中间也是回文（或者长度<=2）

**初始化**：
- dp[i][i] = true（单个字符是回文）

时间O(n²)，空间O(n²)。

**方法二：中心扩展法（更优）**
- 枚举每个回文中心，向两边扩展
- 回文串有两种：奇数长度（中心是一个字符）、偶数长度（中心是两个字符之间）
- 时间O(n²)，空间O(1)

**方法三：Manacher算法**（了解即可）
- 时间O(n)，但实现复杂，面试一般不要求

**参考代码**（Java）:
```java
// 中心扩展法
public String longestPalindrome(String s) {
    if (s == null || s.length() == 0) return "";
    
    int start = 0, maxLen = 0;
    
    for (int i = 0; i < s.length(); i++) {
        // 奇数长度回文
        int len1 = expandAroundCenter(s, i, i);
        // 偶数长度回文
        int len2 = expandAroundCenter(s, i, i + 1);
        
        int len = Math.max(len1, len2);
        if (len > maxLen) {
            maxLen = len;
            start = i - (len - 1) / 2;
        }
    }
    return s.substring(start, start + maxLen);
}

private int expandAroundCenter(String s, int left, int right) {
    while (left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)) {
        left--;
        right++;
    }
    return right - left - 1;
}

// 动态规划
public String longestPalindrome(String s) {
    int n = s.length();
    if (n < 2) return s;
    
    boolean[][] dp = new boolean[n][n];
    int maxLen = 1;
    int start = 0;
    
    // 初始化：长度为1的都是回文
    for (int i = 0; i < n; i++) {
        dp[i][i] = true;
    }
    
    // 按子串长度递推
    for (int len = 2; len <= n; len++) {
        for (int i = 0; i + len <= n; i++) {
            int j = i + len - 1;
            if (s.charAt(i) == s.charAt(j)) {
                if (len == 2 || dp[i + 1][j - 1]) {
                    dp[i][j] = true;
                    if (len > maxLen) {
                        maxLen = len;
                        start = i;
                    }
                }
            }
        }
    }
    return s.substring(start, start + maxLen);
}
```

**复杂度分析**:
- 中心扩展：时间O(n²)，空间O(1)
- 动态规划：时间O(n²)，空间O(n²)

- 回文子串的数量？
- 最长回文子序列？

## Q17: 跳跃游戏

**题目描述**: 给定一个非负整数数组 nums ，你最初位于数组的第一个下标。数组中的每个元素代表你在该位置可以跳跃的最大长度。判断你是否能够到达最后一个下标。

**考察点**: 贪心算法、动态规划

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

**方法一：贪心算法（最优）**
- 维护一个变量 farthest，表示当前能到达的最远位置
- 遍历数组，对于每个位置 i：
  - 如果 i > farthest，说明到不了这个位置，返回false
  - 更新 farthest = max(farthest, i + nums[i])
  - 如果 farthest >= n-1，说明能到达终点，返回true
- 时间O(n)，空间O(1)

**方法二：动态规划**
- dp[i] 表示能否到达位置 i
- dp[i] = OR(dp[j] && j + nums[j] >= i)，其中 j < i
- 时间O(n²)，会超时

**参考代码**（Java）:
```java
// 贪心法
public boolean canJump(int[] nums) {
    int farthest = 0;
    int n = nums.length;
    
    for (int i = 0; i < n; i++) {
        if (i > farthest) {
            return false; // 到不了当前位置
        }
        farthest = Math.max(farthest, i + nums[i]);
        if (farthest >= n - 1) {
            return true; // 已经能到达终点
        }
    }
    return false;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(1)，只使用一个变量

**扩展问题**:

## Q18: 区间合并

**题目描述**: 以数组 intervals 表示若干个区间的集合，其中单个区间为 intervals[i] = [starti, endi]。请你合并所有重叠的区间，并返回一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间。

**考察点**: 排序、贪心

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

**思路**：
1. 按区间的起始位置排序
2. 遍历排序后的区间：
   - 如果当前区间的起始位置 <= 结果中最后一个区间的结束位置，说明有重叠，合并（更新结束位置为较大值）
   - 否则，将当前区间加入结果

时间O(nlogn)（排序），空间O(logn)（排序的栈空间）。

这道题本质是贪心：按起始位置排序后，每次尽可能合并更多区间。

**参考代码**（Java）:
```java
public int[][] merge(int[][] intervals) {
    if (intervals == null || intervals.length == 0) {
        return new int[0][2];
    }
    
    // 按起始位置排序
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);
    
    List<int[]> result = new ArrayList<>();
    result.add(intervals[0]);
    
    for (int i = 1; i < intervals.length; i++) {
        int[] last = result.get(result.size() - 1);
        int[] curr = intervals[i];
        
        if (curr[0] <= last[1]) {
            // 有重叠，合并
            last[1] = Math.max(last[1], curr[1]);
        } else {
            // 无重叠，加入结果
            result.add(curr);
        }
    }
    
    return result.toArray(new int[result.size()][2]);
}
```

**复杂度分析**:
- 时间复杂度：O(nlogn)，排序O(nlogn) + 遍历O(n)
- 空间复杂度：O(logn)，排序所需的栈空间

- 插入区间？
- 区间列表的交集？
- 无重叠区间（求最少删除多少个区间使剩下的不重叠）？

## Q19: 分发饼干（贪心）

**题目描述**: 假设你是一位很棒的家长，想要给你的孩子们一些小饼干。但是，每个孩子最多只能给一块饼干。对每个孩子 i，都有一个胃口值 g[i]，这是能让孩子们满足胃口的饼干的最小尺寸；并且每块饼干 j，都有一个尺寸 s[j]。如果 s[j] >= g[i]，我们可以将这个饼干 j 分配给孩子 i，这个孩子会得到满足。你的目标是尽可能满足越多数量的孩子，并输出这个最大数值。

**考察点**: 贪心算法、排序、双指针

**难度**: 简单

**频率**: ⭐⭐⭐

**解题思路**:

这是一道典型的贪心入门题。

**贪心策略**：
- 把最小的饼干给胃口最小的孩子（这样大饼干可以留给胃口大的孩子）
- 这样能最大化满足的孩子数量

**思路**：
1. 对孩子胃口数组 g 排序
2. 对饼干尺寸数组 s 排序
3. 双指针：i 指向孩子，j 指向饼干
4. 如果 s[j] >= g[i]，说明可以满足，孩子数+1，i++，j++
5. 否则 j++（这块饼干太小，换下一块）

时间O(nlogn + mlogm)（排序），空间O(logn + logm)。

**参考代码**（Java）:
```java
public int findContentChildren(int[] g, int[] s) {
    Arrays.sort(g);
    Arrays.sort(s);
    
    int i = 0; // 孩子指针
    int j = 0; // 饼干指针
    int count = 0;
    
    while (i < g.length && j < s.length) {
        if (s[j] >= g[i]) {
            // 这块饼干可以满足这个孩子
            count++;
            i++;
            j++;
        } else {
            // 饼干太小，换下一块
            j++;
        }
    }
    return count;
}
```

**复杂度分析**:
- 时间复杂度：O(nlogn + mlogm)，排序为主
- 空间复杂度：O(logn + logm)，排序的栈空间

**扩展问题**:
- 无重叠区间（经典贪心区间调度）？
- 用最少数量的箭引爆气球？
- 柠檬水找零？

## Q20: 无重叠区间（贪心）

**题目描述**: 给定一个区间的集合 intervals ，其中 intervals[i] = [starti, endi]。返回需要移除区间的最小数量，使剩余区间互不重叠。

**考察点**: 贪心算法、区间调度

**难度**: 中等

**频率**: ⭐⭐⭐⭐

**解题思路**:

这是经典的区间调度问题：求最多有多少个不重叠的区间。答案 = 总区间数 - 最多不重叠区间数。

**贪心策略**：
- 按区间的结束位置排序
- 每次选择结束最早的区间，这样留给后面的空间最大
- 这是经典的"活动选择问题"的贪心解法

**思路**：
1. 按结束位置从小到大排序
2. 维护变量 end 表示上一个选中区间的结束位置
3. 遍历每个区间：
   - 如果当前区间起始 >= end，说明不重叠，选中它，更新 end，计数+1
   - 否则跳过（需要移除）
4. 答案 = 总区间数 - 不重叠区间数

为什么按结束位置排序是正确的？可以用交换论证法证明：任何最优解都可以通过交换变成"每次选最早结束"的形式，且不会变差。

**参考代码**（Java）:
```java
public int eraseOverlapIntervals(int[][] intervals) {
    if (intervals == null || intervals.length == 0) return 0;
    
    // 按结束位置排序
    Arrays.sort(intervals, (a, b) -> a[1] - b[1]);
    
    int count = 1; // 不重叠区间数，至少有1个
    int end = intervals[0][1];
    
    for (int i = 1; i < intervals.length; i++) {
        if (intervals[i][0] >= end) {
            // 不重叠，选中
            count++;
            end = intervals[i][1];
        }
    }
    
    return intervals.length - count;
}
```

**复杂度分析**:
- 时间复杂度：O(nlogn)，排序O(nlogn) + 遍历O(n)
- 空间复杂度：O(logn)，排序的栈空间

- 用最少数量的箭引爆气球（类似思路）？
- 合并区间？
- 会议室II（求最少需要多少会议室）？
