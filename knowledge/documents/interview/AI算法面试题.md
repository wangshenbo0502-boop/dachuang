## 高频面试题

### Q1: 过拟合的原因和解决方案？

- **类别**: 机器学习
- **难度**: 基础
- **频率**: 极高

<details>
<summary>答题要点</summary>

**原因**：
- 模型过于复杂（参数过多）
- 训练数据太少
- 数据噪声大
- 训练时间过长

**解决方案**：
1. **正则化**：L1（稀疏解）/ L2（权重衰减）
2. **Dropout**：训练时随机丢弃神经元
3. **Early Stopping**：验证集 loss 不再下降时停止
4. **数据增强**：旋转、翻转、裁剪、加噪声（CV）；近义词替换、回译（NLP）
5. **Batch Normalization**：正则化效果 + 加速训练
6. **减小模型复杂度**：减少层数/参数量
7. **集成学习**：Bagging、Boosting

</details>

### Q2: Transformer 的 Self-Attention 机制详细讲解？

- **类别**: 深度学习
- **难度**: 困难
- **频率**: 极高

<details>
<summary>答题要点</summary>

**Self-Attention 核心公式**：

```
Attention(Q, K, V) = softmax(QK^T / √d_k) V
```

**步骤**：
1. 输入 X 通过三个线性变换得到 Q（Query）、K（Key）、V（Value）
2. Q 与 K 的转置做点积得到相似度矩阵
3. 除以 √d_k（缩放因子，防止点积过大导致 softmax 梯度消失）
4. Softmax 归一化得到注意力权重
5. 权重乘以 V 得到加权输出

**为什么除以 √d_k？** 当 d_k 较大时，点积结果方差变大，softmax 趋近于 one-hot（梯度接近 0），缩放后保持方差稳定。

**Multi-Head Attention**：并行计算多组 Attention，每组关注不同的表示子空间，最后拼接 → 线性变换。

**位置编码**：Transformer 没有循环/卷积结构，需要显式加入位置信息（正弦位置编码或可学习位置编码）。

</details>

### Q3: 梯度下降、随机梯度下降、Mini-Batch 的区别？

- **类别**: 优化
- **难度**: 基础
- **频率**: 高

<details>
<summary>答题要点</summary>

| 方法 | 每次更新使用的样本数 | 优点 | 缺点 |
|------|---------------------|------|------|
| **GD** | 全量数据 | 稳定收敛 | 计算慢，内存大 |
| **SGD** | 1 个 | 快，可在线学习 | 不稳定，震荡大 |
| **Mini-Batch SGD** | 批大小（如 32/64/128） | 兼顾速度和稳定性 | 需要调 batch size |

**其他优化器**：
- Momentum：累积历史的梯度方向，加速收敛
- Adam：结合 Momentum + RMSProp，自适应学习率，最常用

</details>

### Q4: BatchNorm 和 LayerNorm 的区别和适用场景？

- **类别**: 深度学习
- **难度**: 中等
- **频率**: 高

<details>
<summary>答题要点</summary>

| 维度 | BatchNorm | LayerNorm |
|------|-----------|-----------|
| 归一化维度 | 对 batch 内同一 channel 归一化 | 对单个样本的所有 feature 归一化 |
| 依赖 batch size | 是（batch 太小不稳定） | 否 |
| 适用场景 | CNN / 图像 | RNN / Transformer（NLP） |
| 训练/推理差异 | 推理时用全局统计量 | 训练推理一致 |

**为什么 Transformer 用 LayerNorm？**
- NLP 中句子长度不一，batch 内统计不稳定
- 序列模型中 batch 维度归一化不自然
- LayerNorm 每个样本独立归一化，不受 batch size 影响

</details>

### Q5: 什么是迁移学习？你在项目中如何使用？

- **类别**: 方法论
- **难度**: 中等
- **频率**: 高

<details>
<summary>答题要点</summary>

**定义**：将在源任务/源域上学到的知识迁移到目标任务/目标域。

**常见方式**：
1. **Fine-tuning**（微调）：在预训练模型基础上用目标数据继续训练
   - 冻结底层（通用特征），只训练顶层（任务特定）
   - 全部微调（数据充足时）
2. **特征提取**：预训练模型作为特征提取器，只训练下游分类器

**实际应用**：
- CV：ImageNet 预训练的 ResNet / ViT 微调到自己的分类任务
- NLP：BERT / GPT 预训练模型微调到文本分类/命名实体识别/问答

**好处**：减少数据需求、加速训练、提升效果（尤其小数据集）

</details>

### Q6: 精确率和召回率的权衡？F1 Score 的计算？

- **类别**: 评估指标
- **难度**: 基础
- **频率**: 高

<details>
<summary>答题要点</summary>

**混淆矩阵**：

|  | 预测正 | 预测负 |
|--|--------|--------|
| 实际正 | TP | FN |
| 实际负 | FP | TN |

- **精确率（Precision）** = TP / (TP + FP) — 预测为正中有多少是真正的正
- **召回率（Recall）** = TP / (TP + FN) — 真正的正中有多少被预测出来
- **F1 Score** = 2 × P × R / (P + R) — 精确率与召回率的调和平均

**权衡**：
- 医疗诊断、反欺诈 → 高召回（宁可错杀也不放过）
- 搜索引擎、推荐系统 → 高精确率（推荐质量优先）

</details>

### Q7: 如何处理样本不平衡问题？

- **类别**: 数据问题
- **难度**: 中等
- **频率**: 中

<details>
<summary>答题要点</summary>

**数据层面**：
- 过采样（Oversampling）：SMOTE 合成少数类样本
- 欠采样（Undersampling）：随机丢弃多数类样本
- 数据增强：对少数类做增强

**算法层面**：
- 类别权重（Class Weight）：增大少数类的 loss 权重
- Focal Loss：降低易分类样本的权重，关注难样本
- 集成方法：EasyEnsemble、BalanceCascade

**评估层面**：
- 不用 Accuracy，改用 Precision/Recall/F1/AUC/PR-AUC

</details>

### Q8: 介绍你最熟悉的一个模型，从原理到优化过程

- **类别**: 项目深挖
- **难度**: 中等
- **频率**: 极高

<details>
<summary>答题要点</summary>

这是面试中最常见的开放题，考察深度和表达能力。

**回答结构**：
1. **项目背景**：什么场景、什么数据、解决什么问题
2. **为什么选这个模型**：与其他模型的对比
3. **模型原理**：核心结构、关键技术点
4. **训练过程**：数据预处理、超参数选择、训练技巧
5. **优化过程**：遇到了什么问题 → 如何分析 → 如何解决
6. **效果对比**：优化前后的指标变化
7. **反思**：如果重新做，有哪些改进空间

**加分项**：能说出论文名称、GitHub 上有实现、提到部署相关经验。

</details>
