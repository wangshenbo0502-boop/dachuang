## Q1: 两数之和

**题目描述**: 给定一个整数数组 nums 和一个整数目标值 target，请你在该数组中找出和为目标值 target 的那两个整数，并返回它们的数组下标。你可以假设每种输入只会对应一个答案。但是，数组中同一个元素在答案里不能重复出现。你可以按任意顺序返回答案。

**考察点**: 哈希表、数组遍历

**难度**: 简单

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

这道题是LeetCode第一题，也是面试中最常考的入门题。最直观的思路是暴力枚举，两层循环遍历所有可能的数对，时间复杂度O(n²)，空间复杂度O(1)。但这种方法在数组较大时效率很低。

更优的解法是使用哈希表（HashMap）。我们遍历数组时，对于每个元素 nums[i]，我们需要找到另一个数 target - nums[i]。如果这个数已经在哈希表中存在，说明我们找到了答案；如果不存在，就把当前元素和它的下标存入哈希表，继续遍历。

这种方法只需一次遍历，时间复杂度O(n)，空间复杂度O(n)，用空间换时间。

**参考代码**（Java）:
```java
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i];
        if (map.containsKey(complement)) {
            return new int[]{map.get(complement), i};
        }
        map.put(nums[i], i);
    }
    return new int[]{-1, -1};
}
```

**复杂度分析**:
- 时间复杂度：O(n)，只遍历了一次数组，每个元素的哈希表操作都是O(1)
- 空间复杂度：O(n)，哈希表最多存储n个键值对

**扩展问题**:
- 如果数组是有序的，如何优化？（双指针法，空间O(1)）
- 如果要求返回所有满足条件的数对，如何处理？
- 三数之和、四数之和怎么解决？

## Q2: 三数之和

**题目描述**: 给你一个整数数组 nums ，判断是否存在三元组 [nums[i], nums[j], nums[k]] 满足 i != j、i != k 且 j != k ，同时还满足 nums[i] + nums[j] + nums[k] == 0 。请你返回所有和为 0 且不重复的三元组。注意：答案中不可以包含重复的三元组。

**考察点**: 排序、双指针、去重

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

三数之和是两数之和的进阶版，但解法思路完全不同。因为要求返回所有不重复的三元组，暴力法时间复杂度O(n³)会超时，而且去重也是个问题。

标准解法是**排序 + 双指针**：
1. 先对数组排序，时间O(nlogn)
2. 固定第一个数 nums[i]，然后在 i 后面的子数组中用双指针找两数之和等于 -nums[i]
3. 左指针 left = i + 1，右指针 right = n - 1
4. 如果 nums[left] + nums[right] < target，左指针右移；如果 > target，右指针左移；如果 == target，记录结果并同时移动两个指针
5. 关键是去重：nums[i] 如果和 nums[i-1] 相同则跳过；找到解后，left 和 right 也要跳过重复值

时间复杂度O(n²)，空间复杂度O(logn)（排序的栈空间）。

**参考代码**（Java）:
```java
public List<List<Integer>> threeSum(int[] nums) {
    List<List<Integer>> result = new ArrayList<>();
    Arrays.sort(nums);
    int n = nums.length;
    
    for (int i = 0; i < n - 2; i++) {
        if (nums[i] > 0) break; // 第一个数大于0，后面不可能有解
        if (i > 0 && nums[i] == nums[i - 1]) continue; // 去重
        
        int left = i + 1, right = n - 1;
        int target = -nums[i];
        
        while (left < right) {
            int sum = nums[left] + nums[right];
            if (sum == target) {
                result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                // 去重
                while (left < right && nums[left] == nums[left + 1]) left++;
                while (left < right && nums[right] == nums[right - 1]) right--;
                left++;
                right--;
            } else if (sum < target) {
                left++;
            } else {
                right--;
            }
        }
    }
    return result;
}
```

**复杂度分析**:
- 时间复杂度：O(n²)，排序O(nlogn) + 双重循环O(n²)
- 空间复杂度：O(logn)，排序所需的栈空间

**扩展问题**:
- 四数之和怎么解？（在三数之和基础上再加一层循环）
- 最接近的三数之和？
- 如果数组很大无法全部加载到内存，怎么办？

## Q3: 移动零

**题目描述**: 给定一个数组 nums，编写一个函数将所有 0 移动到数组的末尾，同时保持非零元素的相对顺序。请注意，必须在不复制数组的情况下原地对数组进行操作。

**考察点**: 双指针、原地修改

**难度**: 简单

**频率**: ⭐⭐⭐⭐

**解题思路**:

这道题要求原地操作，不能使用额外数组。核心思路是用双指针：
- 慢指针 slow 指向当前非零元素应该放置的位置
- 快指针 fast 遍历数组
- 当 fast 遇到非零元素时，将 nums[fast] 赋值给 nums[slow]，slow 前移
- 遍历完后，slow 及之后的位置全部设为 0

另一种更简洁的写法是交换法：遇到非零元素就和 slow 位置交换，slow 前移。这样不需要最后再补零。

**参考代码**（Java）:
```java
public void moveZeroes(int[] nums) {
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != 0) {
            // 交换非零元素到slow位置
            int temp = nums[slow];
            nums[slow] = nums[fast];
            nums[fast] = temp;
            slow++;
        }
    }
}
```

**复杂度分析**:
- 时间复杂度：O(n)，只遍历一次数组
- 空间复杂度：O(1)，原地操作，只使用常数额外空间

**扩展问题**:
- 移动零到数组头部？
- 保持非零元素相对顺序的前提下，最少交换次数是多少？
- 如果数组中除了0还有其他需要移动的特殊值？

## Q4: 盛最多水的容器

**题目描述**: 给定一个长度为 n 的整数数组 height 。有 n 条垂线，第 i 条线的两个端点是 (i, 0) 和 (i, height[i]) 。找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。返回容器可以储存的最大水量。

**考察点**: 双指针、贪心

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

这道题的经典解法是双指针法，也是一道经典的贪心算法题。

暴力法是枚举所有可能的两条线，计算面积，时间O(n²)会超时。

双指针法的思路是：初始时左指针在最左边，右指针在最右边。容器的面积 = 左右指针间距 × 左右指针对应高度的较小值。

关键问题：为什么移动较矮的那个指针是正确的？
- 假设左边高度 h[l] < 右边高度 h[r]
- 如果移动右指针，间距减小，且高度最多只能是 h[l]（因为h[l]更矮），所以面积一定减小
- 如果移动左指针，间距减小，但高度有可能增大，所以面积有可能增大
- 因此，每次应该移动较矮的那个指针，才有机会找到更大的面积

时间复杂度O(n)，空间复杂度O(1)。

**参考代码**（Java）:
```java
public int maxArea(int[] height) {
    int left = 0, right = height.length - 1;
    int maxArea = 0;
    
    while (left < right) {
        int area = Math.min(height[left], height[right]) * (right - left);
        maxArea = Math.max(maxArea, area);
        
        if (height[left] < height[right]) {
            left++;
        } else {
            right--;
        }
    }
    return maxArea;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，双指针最多移动n次
- 空间复杂度：O(1)，只使用常数额外空间

**扩展问题**:
- 如果可以选择三条线组成容器，怎么解？
- 接雨水问题和这道题的区别与联系？
- 证明双指针法的正确性？

## Q5: 接雨水

**题目描述**: 给定 n 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

**考察点**: 双指针、单调栈、动态规划

**难度**: 困难

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

接雨水是一道非常经典的困难题，有多种解法。

**方法一：动态规划**
- 对于每个位置 i，能接的雨水量 = min(左边最高高度, 右边最高高度) - height[i]
- 预处理两个数组：leftMax[i] 表示 i 左边最高的柱子高度，rightMax[i] 表示 i 右边最高的柱子高度
- 时间O(n)，空间O(n)

**方法二：双指针（最优）**
- 左指针 left 从左往右，右指针 right 从右往左
- 维护 leftMax 和 rightMax 两个变量
- 如果 leftMax < rightMax，说明左边决定了当前位置的水量，处理 left 位置，left++
- 否则处理 right 位置，right--
- 时间O(n)，空间O(1)

**方法三：单调栈**
- 维护一个单调递减栈，栈中存储下标
- 遇到比栈顶高的柱子时，说明可能形成凹槽，可以接雨水
- 弹出栈顶作为凹槽底部，新的栈顶是左边界，当前位置是右边界
- 时间O(n)，空间O(n)

这里给出双指针法的代码。

**参考代码**（Java）:
```java
public int trap(int[] height) {
    int left = 0, right = height.length - 1;
    int leftMax = 0, rightMax = 0;
    int result = 0;
    
    while (left < right) {
        if (height[left] < height[right]) {
            if (height[left] >= leftMax) {
                leftMax = height[left];
            } else {
                result += leftMax - height[left];
            }
            left++;
        } else {
            if (height[right] >= rightMax) {
                rightMax = height[right];
            } else {
                result += rightMax - height[right];
            }
            right--;
        }
    }
    return result;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，双指针遍历一次数组
- 空间复杂度：O(1)，只使用常数额外空间

**扩展问题**:
- 二维接雨水（矩阵中接雨水）怎么解？
- 如果柱子宽度不是1，怎么计算？
- 用单调栈怎么实现？

## Q6: 合并两个有序数组

**题目描述**: 给你两个按非递减顺序排列的整数数组 nums1 和 nums2，另有两个整数 m 和 n ，分别表示 nums1 和 nums2 中的元素数目。请你合并 nums2 到 nums1 中，使合并后的数组同样按非递减顺序排列。注意：最终，合并后数组不应由函数返回，而是存储在数组 nums1 中。nums1 的初始长度为 m + n，其中前 m 个元素表示应合并的元素，后 n 个元素为 0 ，应忽略。nums2 的长度为 n 。

**考察点**: 双指针、从后往前遍历

**难度**: 简单

**频率**: ⭐⭐⭐⭐

**解题思路**:

这道题的巧妙之处在于从后往前合并。因为 nums1 的尾部有足够空间，如果从前往后合并会覆盖 nums1 中未处理的元素。

从后往前的思路：
- 三个指针：p1 指向 nums1 的第 m-1 位（有效元素末尾），p2 指向 nums2 的第 n-1 位，p 指向 nums1 的第 m+n-1 位（合并后末尾）
- 比较 nums1[p1] 和 nums2[p2]，将较大的放到 nums1[p]，对应指针前移
- 如果 nums2 先遍历完，nums1 前面的元素已经在正确位置，无需处理
- 如果 nums1 先遍历完，需要把 nums2 剩余元素复制到 nums1 前面

**参考代码**（Java）:
```java
public void merge(int[] nums1, int m, int[] nums2, int n) {
    int p1 = m - 1;
    int p2 = n - 1;
    int p = m + n - 1;
    
    while (p1 >= 0 && p2 >= 0) {
        if (nums1[p1] > nums2[p2]) {
            nums1[p] = nums1[p1];
            p1--;
        } else {
            nums1[p] = nums2[p2];
            p2--;
        }
        p--;
    }
    // nums2还有剩余元素，复制到nums1前面
    while (p2 >= 0) {
        nums1[p] = nums2[p2];
        p--;
        p2--;
    }
}
```

**复杂度分析**:
- 时间复杂度：O(m + n)，最多遍历两个数组各一次
- 空间复杂度：O(1)，原地合并

**扩展问题**:
- 合并K个有序数组？
- 如果两个数组长度相差很大，有什么优化策略？
- 合并两个有序链表？

## Q7: 加一

**题目描述**: 给定一个由整数组成的非空数组所表示的非负整数，在该数的基础上加一。最高位数字存放在数组的首位，数组中每个元素只存储单个数字。你可以假设除了整数 0 之外，这个整数不会以零开头。

**考察点**: 数组遍历、进位处理

**难度**: 简单

**频率**: ⭐⭐⭐

**解题思路**:

这道题看似简单，但需要考虑各种进位情况：
1. 末尾没有进位：直接末尾加一返回
2. 末尾有进位但中间停止：从后往前遍历，遇到9设为0，直到遇到非9数字加一
3. 全部都是9：需要新建一个长度+1的数组，首位置1

从后往前遍历，如果当前位是9，设为0继续；否则加一直接返回。如果遍历完还没返回，说明全是9，新建数组首位置1。

**参考代码**（Java）:
```java
public int[] plusOne(int[] digits) {
    int n = digits.length;
    for (int i = n - 1; i >= 0; i--) {
        if (digits[i] < 9) {
            digits[i]++;
            return digits;
        }
        digits[i] = 0;
    }
    // 所有位都是9的情况
    int[] result = new int[n + 1];
    result[0] = 1;
    return result;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，最坏情况遍历整个数组
- 空间复杂度：O(1)或O(n)，一般情况原地修改，全9时需要O(n)新数组

**扩展问题**:
- 两个数组表示的数相加？
- 字符串表示的大数相乘？
- 二进制加一？

## Q8: 删除有序数组中的重复项

**题目描述**: 给你一个非严格递增排列的数组 nums ，请你原地删除重复出现的元素，使每个元素只出现一次，返回删除后数组的新长度。元素的相对顺序应该保持一致。然后返回 nums 中唯一元素的个数。考虑 nums 的唯一元素的数量为 k ，你需要做以下事情确保你的题解可以被通过：更改数组 nums ，使 nums 的前 k 个元素以初始顺序包含唯一元素。nums 中其余的元素与 nums 的大小不重要。返回 k 。

**考察点**: 双指针、快慢指针

**难度**: 简单

**频率**: ⭐⭐⭐⭐

**解题思路**:

经典的快慢指针题目：
- 慢指针 slow 指向当前唯一元素序列的末尾位置
- 快指针 fast 遍历数组
- 如果 nums[fast] != nums[slow]，说明遇到新元素，slow 前移，nums[slow] = nums[fast]
- 最后返回 slow + 1（因为slow是下标，长度是下标+1）

这道题的进阶版是"删除有序数组中的重复项II"，允许每个元素最多出现两次，思路类似，只是比较的是 nums[fast] 和 nums[slow-1]。

**参考代码**（Java）:
```java
public int removeDuplicates(int[] nums) {
    if (nums.length == 0) return 0;
    
    int slow = 0;
    for (int fast = 1; fast < nums.length; fast++) {
        if (nums[fast] != nums[slow]) {
            slow++;
            nums[slow] = nums[fast];
        }
    }
    return slow + 1;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，遍历一次数组
- 空间复杂度：O(1)，原地操作

**扩展问题**:
- 如果允许每个元素最多出现k次，怎么写通用代码？
- 删除无序数组中的重复元素？（用哈希表）
- 移除元素（给一个val，删除所有等于val的元素）？

## Q9: 旋转数组

**题目描述**: 给定一个整数数组 nums，将数组中的元素向右轮转 k 个位置，其中 k 是非负数。你可以使用空间复杂度为 O(1) 的原地算法解决这个问题吗？

**考察点**: 数组翻转、原地算法

**难度**: 中等

**频率**: ⭐⭐⭐⭐

**解题思路**:

这道题有多种解法：

**方法一：使用额外数组**
- 新数组中位置 (i + k) % n 存放原数组位置 i 的元素
- 时间O(n)，空间O(n)

**方法二：环状替换**
- 从位置0开始，将元素放到 (0 + k) % n 的位置
- 再把被替换位置的元素放到它应该去的位置
- 像环一样遍历，直到回到起点
- 然后从下一个未访问的位置继续
- 时间O(n)，空间O(1)

**方法三：三次翻转（最经典）**
- 翻转整个数组
- 翻转前 k 个元素
- 翻转后 n-k 个元素
- 例如：[1,2,3,4,5,6,7], k=3
  - 整体翻转：[7,6,5,4,3,2,1]
  - 翻转前3个：[5,6,7,4,3,2,1]
  - 翻转后4个：[5,6,7,1,2,3,4]
- 时间O(n)，空间O(1)

**参考代码**（Java）:
```java
public void rotate(int[] nums, int k) {
    int n = nums.length;
    k = k % n; // k可能大于n
    
    reverse(nums, 0, n - 1);
    reverse(nums, 0, k - 1);
    reverse(nums, k, n - 1);
}

private void reverse(int[] nums, int start, int end) {
    while (start < end) {
        int temp = nums[start];
        nums[start] = nums[end];
        nums[end] = temp;
        start++;
        end--;
    }
}
```

**复杂度分析**:
- 时间复杂度：O(n)，总共翻转了n个元素
- 空间复杂度：O(1)，原地操作

**扩展问题**:
- 向左旋转怎么实现？
- 旋转字符串？

## Q10: 螺旋矩阵

**题目描述**: 给你一个 m 行 n 列的矩阵 matrix ，请按照顺时针螺旋顺序，返回矩阵中的所有元素。

**考察点**: 模拟、边界指针

**难度**: 中等

**频率**: ⭐⭐⭐⭐

**解题思路**:

螺旋矩阵是一道经典的模拟题，没有特别的算法技巧，主要考察边界处理能力。

思路是设置四个边界：上(top)、下(bottom)、左(left)、右(right)。然后按顺时针方向遍历：
1. 从左到右遍历顶部行，遍历完top++
2. 从上到下遍历右列，遍历完right--
3. 从右到左遍历底部行，遍历完bottom--
4. 从下到上遍历左列，遍历完left++
5. 重复以上步骤，直到 top > bottom 或 left > right

注意：每次遍历完一条边后，要检查是否还需要继续遍历（避免单行或单列时重复遍历）。

**参考代码**（Java）:
```java
public List<Integer> spiralOrder(int[][] matrix) {
    List<Integer> result = new ArrayList<>();
    if (matrix == null || matrix.length == 0) return result;
    
    int top = 0, bottom = matrix.length - 1;
    int left = 0, right = matrix[0].length - 1;
    
    while (top <= bottom && left <= right) {
        // 从左到右
        for (int i = left; i <= right; i++) {
            result.add(matrix[top][i]);
        }
        top++;
        
        // 从上到下
        for (int i = top; i <= bottom; i++) {
            result.add(matrix[i][right]);
        }
        right--;
        
        // 从右到左（需要检查是否还有行）
        if (top <= bottom) {
            for (int i = right; i >= left; i--) {
                result.add(matrix[bottom][i]);
            }
            bottom--;
        }
        
        // 从下到上（需要检查是否还有列）
        if (left <= right) {
            for (int i = bottom; i >= top; i--) {
                result.add(matrix[i][left]);
            }
            left++;
        }
    }
    return result;
}
```

**复杂度分析**:
- 时间复杂度：O(m×n)，每个元素遍历一次
- 空间复杂度：O(1)，除结果外只使用常数空间

- 逆时针螺旋？
- 按对角线遍历矩阵？

## Q11: 最长公共前缀

**题目描述**: 编写一个函数来查找字符串数组中的最长公共前缀。如果不存在公共前缀，返回空字符串 ""。

**考察点**: 字符串遍历、纵向扫描

**难度**: 简单

**频率**: ⭐⭐⭐

**解题思路**:

最长公共前缀有几种常见解法：

**方法一：纵向扫描**
- 以第一个字符串为基准，逐列比较所有字符串的对应位置字符
- 如果某一列有字符不同或某个字符串已到末尾，返回当前已匹配的前缀
- 时间O(m×n)，m是字符串平均长度，n是字符串数量

**方法二：横向扫描**
- 依次比较相邻两个字符串的公共前缀，更新当前公共前缀
- 如果公共前缀变为空，提前返回
- 时间O(m×n)

**方法三：分治法**
- 将字符串数组分成左右两部分
- 分别求左右两部分的LCP，再求两个LCP的LCP
- 时间O(m×n)，空间O(mlogn)

这里给出最直观的纵向扫描法。

**参考代码**（Java）:
```java
public String longestCommonPrefix(String[] strs) {
    if (strs == null || strs.length == 0) return "";
    
    // 以第一个字符串为基准
    for (int i = 0; i < strs[0].length(); i++) {
        char c = strs[0].charAt(i);
        // 检查其他字符串的第i位
        for (int j = 1; j < strs.length; j++) {
            if (i == strs[j].length() || strs[j].charAt(i) != c) {
                return strs[0].substring(0, i);
            }
        }
    }
    return strs[0];
}
```

**复杂度分析**:
- 时间复杂度：O(m×n)，m是字符串平均长度，n是字符串数量
- 空间复杂度：O(1)，只使用常数额外空间

## Q12: 无重复字符的最长子串

**题目描述**: 给定一个字符串 s ，请你找出其中不含有重复字符的最长子串的长度。

**考察点**: 滑动窗口、哈希表

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

这是滑动窗口的经典入门题。

**暴力法**：枚举所有子串，检查是否有重复字符，时间O(n³)。

**滑动窗口**：
- 维护一个窗口 [left, right]，窗口内的字符都不重复
- right 不断向右扩展
- 当遇到重复字符时，将 left 移动到重复字符上一次出现位置的右边
- 用哈希表记录每个字符最后一次出现的位置
- 注意：left 只能往前走，不能后退（比如 "abba" 的情况）

时间复杂度O(n)，空间复杂度O(min(m, n))，m是字符集大小。

**参考代码**（Java）:
```java
public int lengthOfLongestSubstring(String s) {
    Map<Character, Integer> map = new HashMap<>();
    int left = 0;
    int maxLen = 0;
    
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (map.containsKey(c)) {
            // left只能往前走，不能后退
            left = Math.max(left, map.get(c) + 1);
        }
        map.put(c, right);
        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，right指针遍历整个字符串一次
- 空间复杂度：O(min(m, n))，m是字符集大小（如ASCII是128）

## Q13: 字符串转整数（atoi）

**题目描述**: 请你来实现一个 myAtoi(string s) 函数，使其能将字符串转换成一个 32 位有符号整数（类似 C/C++ 中的 atoi 函数）。函数 myAtoi(string s) 的算法如下：1. 读入字符串并丢弃无用的前导空格；2. 检查下一个字符（假设还未到字符末尾）为正还是负号，读取该字符（如果有）。确定最终结果是负数还是正数。如果两者都不存在，则假定结果为正；3. 读入下一个字符，直到到达下一个非数字字符或到达输入的结尾。字符串的其余部分将被忽略；4. 将前面步骤读入的这些数字转换为整数（即，"123" -> 123，"0032" -> 32）。如果没有读入数字，则整数为 0。必要时更改符号（从步骤2开始）；5. 如果整数数超过 32 位有符号整数范围 [−2³¹, 2³¹ − 1] ，需要截断这个整数，使其保持在这个范围内。具体来说，小于 −2³¹ 的整数应该被固定为 −2³¹ ，大于 2³¹ − 1 的整数应该被固定为 2³¹ − 1；6. 返回整数作为最终结果。

**考察点**: 字符串处理、边界条件、溢出判断

**难度**: 中等

**频率**: ⭐⭐⭐⭐

**解题思路**:

这道题没有什么算法技巧，主要考察细心程度和边界条件处理。需要考虑的情况：
1. 前导空格
2. 正负号
3. 数字转换
4. 溢出判断（重点和难点）
5. 非数字字符提前终止

溢出判断技巧：在结果乘10加新数字之前判断：
- 如果 result > Integer.MAX_VALUE / 10，一定会溢出
- 如果 result == Integer.MAX_VALUE / 10 且 digit > 7，正数溢出（MAX_VALUE最后一位是7）
- 如果 result == Integer.MAX_VALUE / 10 且 digit > 8，负数溢出（MIN_VALUE最后一位是8）

也可以用 long 类型暂存结果，最后再判断范围，但这在某些面试中可能不被允许。

**参考代码**（Java）:
```java
public int myAtoi(String s) {
    if (s == null || s.length() == 0) return 0;
    
    int index = 0;
    int sign = 1;
    int result = 0;
    int n = s.length();
    
    // 1. 跳过前导空格
    while (index < n && s.charAt(index) == ' ') {
        index++;
    }
    
    // 2. 处理符号
    if (index < n && (s.charAt(index) == '+' || s.charAt(index) == '-')) {
        sign = s.charAt(index) == '+' ? 1 : -1;
        index++;
    }
    
    // 3. 转换数字
    while (index < n && Character.isDigit(s.charAt(index))) {
        int digit = s.charAt(index) - '0';
        
        // 4. 溢出判断
        if (result > Integer.MAX_VALUE / 10 || 
            (result == Integer.MAX_VALUE / 10 && digit > 7)) {
            return sign == 1 ? Integer.MAX_VALUE : Integer.MIN_VALUE;
        }
        
        result = result * 10 + digit;
        index++;
    }
    
    return result * sign;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，最多遍历整个字符串一次
- 空间复杂度：O(1)，只使用常数额外空间

**扩展问题**:
- 字符串转浮点数？
- 大数相加/相乘（用字符串表示）？
- 罗马数字转整数？

**频率**: ⭐⭐⭐⭐

**解题思路**:

经典的双指针题目：
- 左指针从左往右，右指针从右往左
- 跳过非字母数字字符
- 比较两个指针指向的字符（忽略大小写）
- 如果不相等返回false，都相等返回true

也可以先预处理字符串，过滤掉非字母数字字符并转成小写，然后判断是否是回文。但双指针法更高效，不需要额外空间。

**参考代码**（Java）:
```java
public boolean isPalindrome(String s) {
    int left = 0, right = s.length() - 1;
    
    while (left < right) {
        // 跳过左边非字母数字字符
        while (left < right && !Character.isLetterOrDigit(s.charAt(left))) {
            left++;
        }
        // 跳过右边非字母数字字符
        while (left < right && !Character.isLetterOrDigit(s.charAt(right))) {
            right--;
        }
        // 比较（忽略大小写）
        if (Character.toLowerCase(s.charAt(left)) != Character.toLowerCase(s.charAt(right))) {
            return false;
        }
        left++;
        right--;
    }
    return true;
}
```

- 时间复杂度：O(n)，双指针最多遍历半个字符串

public boolean isAnagram(String s, String t) {

## Q16: 字符串相乘

**题目描述**: 给定两个以字符串形式表示的非负整数 num1 和 num2，返回 num1 和 num2 的乘积，它们的乘积也表示为字符串形式。注意：不能使用任何内置的 BigInteger 库或直接将输入转换为整数。

**考察点**: 字符串、模拟乘法

**难度**: 中等

**频率**: ⭐⭐⭐⭐

**解题思路**:

这道题模拟手工乘法的过程。

关键观察：长度为m的数和长度为n的数相乘，结果长度最多为m+n。

模拟乘法步骤：
1. 创建一个长度为 m+n 的数组存储结果
2. 从右往左遍历 num1 的每一位（下标i），再从右往左遍历 num2 的每一位（下标j）
3. 乘积结果的个位放在位置 i+j+1，进位放在位置 i+j
4. 即：num1[i] × num2[j] 的结果累加到 res[i+j+1]
5. 处理完所有乘法后，统一处理进位
6. 最后将数组转为字符串，注意去掉前导零

**参考代码**（Java）:
```java
public String multiply(String num1, String num2) {
    if (num1.equals("0") || num2.equals("0")) return "0";
    
    int m = num1.length(), n = num2.length();
    int[] res = new int[m + n];
    
    // 从右往左逐位相乘
    for (int i = m - 1; i >= 0; i--) {
        int digit1 = num1.charAt(i) - '0';
        for (int j = n - 1; j >= 0; j--) {
            int digit2 = num2.charAt(j) - '0';
            int product = digit1 * digit2;
            // 乘积加到对应位置
            int sum = res[i + j + 1] + product;
            res[i + j + 1] = sum % 10;
            res[i + j] += sum / 10;
        }
    }
    
    // 转为字符串，跳过前导零
    StringBuilder sb = new StringBuilder();
    for (int i = 0; i < res.length; i++) {
        if (i == 0 && res[i] == 0) continue; // 跳过前导零
        sb.append(res[i]);
    }
    return sb.toString();
}
```

**复杂度分析**:
- 时间复杂度：O(m×n)，双重循环逐位相乘
- 空间复杂度：O(m+n)，存储结果的数组

**扩展问题**:
- 字符串相加？
- 字符串相除？
- 大整数加减乘除的完整实现？

## Q18: 反转字符串中的单词

**题目描述**: 给你一个字符串 s ，请你反转字符串中单词的顺序。单词是由非空格字符组成的字符串。s 中使用至少一个空格将字符串中的单词分隔开。返回单词顺序颠倒且单词之间用单个空格连接的结果字符串。注意：输入字符串 s中可能会存在前导空格、尾随空格或者单词间的多个空格。返回的结果字符串中，单词间应当仅用单个空格分隔，且不包含任何额外的空格。

**考察点**: 字符串、双指针、反转

**难度**: 中等

**频率**: ⭐⭐⭐⭐

**解题思路**:

这道题有多种解法：

**方法一：使用语言特性**
- 用 split 分割字符串，过滤空字符串
- 反转单词列表，用空格连接
- 简单但可能不被面试官认可（太取巧）

**方法二：双端队列**
- 遍历字符串，用双端队列存储每个单词
- 最后从队列头部依次弹出拼接

**方法三：先整体反转，再逐个反转单词（最经典）**
1. 先去除多余空格（前导、尾随、中间多个空格）
2. 反转整个字符串
3. 逐个反转每个单词

这种方法不需要额外空间（如果是可变字符串的话），最能体现算法功底。

**参考代码**（Java）:
```java
public String reverseWords(String s) {
    // 1. 去除多余空格
    StringBuilder sb = trimSpaces(s);
    
    // 2. 反转整个字符串
    reverse(sb, 0, sb.length() - 1);
    
    // 3. 反转每个单词
    reverseEachWord(sb);
    
    return sb.toString();
}

private StringBuilder trimSpaces(String s) {
    int left = 0, right = s.length() - 1;
    while (left <= right && s.charAt(left) == ' ') left++;
    while (left <= right && s.charAt(right) == ' ') right--;
    
    StringBuilder sb = new StringBuilder();
    while (left <= right) {
        char c = s.charAt(left);
        if (c != ' ' || sb.charAt(sb.length() - 1) != ' ') {
            sb.append(c);
        }
        left++;
    }
    return sb;
}

private void reverse(StringBuilder sb, int left, int right) {
    while (left < right) {
        char temp = sb.charAt(left);
        sb.setCharAt(left, sb.charAt(right));
        sb.setCharAt(right, temp);
        left++;
        right--;
    }
}

private void reverseEachWord(StringBuilder sb) {
    int n = sb.length();
    int start = 0, end = 0;
    while (start < n) {
        while (end < n && sb.charAt(end) != ' ') end++;
        reverse(sb, start, end - 1);
        start = end + 1;
        end++;
    }
}
```

**复杂度分析**:
- 时间复杂度：O(n)，遍历字符串多次，每次都是O(n)
- 空间复杂度：O(n)，Java中String不可变，需要StringBuilder

- 反转字符串中的元音字母？

## Q19: 找到所有数组中消失的数字

**题目描述**: 给你一个含 n 个整数的数组 nums ，其中 nums[i] 在区间 [1, n] 内。请你找出所有在 [1, n] 范围内但没有出现在 nums 中的数字，并以数组的形式返回结果。你能在不使用额外空间且时间复杂度为 O(n) 的情况下解决这个问题吗? 你可以假定返回的数组不算在额外空间内。

**考察点**: 原地哈希、数组技巧

**难度**: 简单

**频率**: ⭐⭐⭐⭐

**解题思路**:

这道题的精妙之处在于利用"数组元素值在[1,n]范围内"这个条件，用数组本身作为哈希表。

**方法一：使用额外哈希表**
- 遍历数组，将所有元素存入HashSet
- 再从1到n遍历，找出不在Set中的数字
- 时间O(n)，空间O(n)

**方法二：原地修改（最优）**
- 利用数组下标和值的对应关系
- 遍历每个数字 nums[i]，将 |nums[i]| - 1 位置的数字变成负数（标记这个数字出现过）
- 遍历完后，再遍历数组，如果位置 i 的数字还是正数，说明 i+1 这个数没出现过
- 时间O(n)，空间O(1)

核心思想：用符号作为标记，不丢失原始数值（取绝对值仍可得到原值）。

**参考代码**（Java）:
```java
public List<Integer> findDisappearedNumbers(int[] nums) {
    List<Integer> result = new ArrayList<>();
    int n = nums.length;
    
    // 第一次遍历：标记出现过的数字
    for (int i = 0; i < n; i++) {
        int index = Math.abs(nums[i]) - 1;
        if (nums[index] > 0) {
            nums[index] = -nums[index];
        }
    }
    
    // 第二次遍历：找出未出现的数字
    for (int i = 0; i < n; i++) {
        if (nums[i] > 0) {
            result.add(i + 1);
        }
    }
    
    return result;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，两次遍历数组
- 空间复杂度：O(1)，原地修改，返回值不计入

**扩展问题**:
- 数组中重复的数据（找所有重复出现的数）？
- 寻找重复数（只有一个重复数，1到n之间）？
- 缺失的第一个正数？

## Q20: 除自身以外数组的乘积

**题目描述**: 给你一个整数数组 nums，返回数组 answer ，其中 answer[i] 等于 nums 中除 nums[i] 之外其余各元素的乘积。题目数据保证数组 nums 之中任意元素的全部前缀元素和后缀的乘积都在32位整数范围内。请不要使用除法，且在 O(n) 时间复杂度内完成此题。你可以在 O(1) 的额外空间复杂度内完成这个题目吗？（出于对空间复杂度分析的目的，输出数组不被视为额外空间。）

**考察点**: 前缀积、后缀积、空间优化

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

这道题的关键是不能用除法（而且有0的时候除法也不行）。

**方法一：左右乘积数组**
- 定义 left[i] 表示位置 i 左边所有元素的乘积（不包含i）
- 定义 right[i] 表示位置 i 右边所有元素的乘积（不包含i）
- answer[i] = left[i] × right[i]
- 时间O(n)，空间O(n)

**方法二：空间优化（输出数组不算额外空间）**
- 先用输出数组存储左边乘积
- 再用一个变量从右往左遍历，记录右边乘积，同时更新输出数组
- answer[i] = 左边乘积（已存在answer中）× 右边乘积（变量R）
- 时间O(n)，空间O(1)（输出数组不计）

**参考代码**（Java）:
```java
public int[] productExceptSelf(int[] nums) {
    int n = nums.length;
    int[] answer = new int[n];
    
    // answer[i] 先存i左边所有元素的乘积
    answer[0] = 1;
    for (int i = 1; i < n; i++) {
        answer[i] = answer[i - 1] * nums[i - 1];
    }
    
    // R 表示右边所有元素的乘积
    int R = 1;
    for (int i = n - 1; i >= 0; i--) {
        // answer[i] = 左边乘积 × 右边乘积
        answer[i] = answer[i] * R;
        // 更新右边乘积
        R *= nums[i];
    }
    
    return answer;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，两次线性遍历
- 空间复杂度：O(1)，输出数组不计入额外空间

**扩展问题**:
- 除自身以外数组的和？（前缀和，更简单）
- 数组的乘积除自身以外的最大/最小值？
- 如果允许用除法，需要注意什么问题？（0的处理）
