## Q1: 二叉树的最大深度

**题目描述**: 给定一个二叉树，找出其最大深度。二叉树的深度为根节点到最远叶子节点的最长路径上的节点数。说明：叶子节点是指没有子节点的节点。

**考察点**: 递归、深度优先搜索

**难度**: 简单

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

**递归法**：
- 树的最大深度 = max(左子树深度, 右子树深度) + 1
- 终止条件：节点为空时返回0
- 这是最直观的解法，时间O(n)，空间O(height)

**迭代法（BFS层序遍历）**：
- 用队列进行层序遍历，每遍历一层深度+1
- 时间O(n)，空间O(n)

**参考代码**（Java）:
```java
// 递归法
public int maxDepth(TreeNode root) {
    if (root == null) return 0;
    int leftDepth = maxDepth(root.left);
    int rightDepth = maxDepth(root.right);
    return Math.max(leftDepth, rightDepth) + 1;
}

// 迭代法（BFS）
public int maxDepth(TreeNode root) {
    if (root == null) return 0;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    int depth = 0;
    
    while (!queue.isEmpty()) {
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        depth++;
    }
    return depth;
}
```

**复杂度分析**:
- 递归法：时间O(n)，空间O(height)，最坏O(n)
- BFS法：时间O(n)，空间O(n)

**扩展问题**:
- 二叉树的最小深度？
- N叉树的最大深度？
- 平衡二叉树判断？

## Q2: 二叉树的最小深度

**题目描述**: 给定一个二叉树，找出其最小深度。最小深度是从根节点到最近叶子节点的最短路径上的节点数量。说明：叶子节点是指没有子节点的节点。

**考察点**: 递归、BFS

**难度**: 简单

**频率**: ⭐⭐⭐⭐

**解题思路**:

这道题和最大深度类似，但有个坑：不能直接写成min(left, right) + 1。因为如果一个节点只有左子树或只有右子树，那么它的最小深度不是1，而是非空子树的深度+1。

**递归法**：
- 如果左右子树都为空，返回1（叶子节点）
- 如果只有左子树，返回左子树深度+1
- 如果只有右子树，返回右子树深度+1
- 如果都有，返回min(left, right) + 1

**BFS法**（更优，因为找到第一个叶子节点就可以返回）：
- 层序遍历，遇到第一个叶子节点时返回当前深度
- 时间O(n)，但平均情况比DFS快

**参考代码**（Java）:
```java
// 递归法
public int minDepth(TreeNode root) {
    if (root == null) return 0;
    
    if (root.left == null && root.right == null) {
        return 1;
    }
    
    int leftDepth = minDepth(root.left);
    int rightDepth = minDepth(root.right);
    
    // 只有左子树或只有右子树
    if (root.left == null) return rightDepth + 1;
    if (root.right == null) return leftDepth + 1;
    
    return Math.min(leftDepth, rightDepth) + 1;
}

// BFS法
public int minDepth(TreeNode root) {
    if (root == null) return 0;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    int depth = 1;
    
    while (!queue.isEmpty()) {
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            // 遇到叶子节点，直接返回深度
            if (node.left == null && node.right == null) {
                return depth;
            }
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        depth++;
    }
    return depth;
}
```

**复杂度分析**:
- 递归法：时间O(n)，空间O(height)
- BFS法：时间O(n)，空间O(n)，但最佳情况是O(1)

**扩展问题**:
- 二叉树的直径？
- 求根到叶子的最短路径和？
- 完全二叉树的节点个数？

## Q3: 翻转二叉树

**题目描述**: 给你一棵二叉树的根节点 root ，翻转这棵二叉树，并返回其根节点。

**考察点**: 递归、二叉树遍历

**难度**: 简单

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

翻转二叉树的经典题，传说中Google面试Homebrew作者被拒的那道题。

**递归法**：
- 翻转当前节点的左右子节点
- 递归翻转左子树
- 递归翻转右子树
- 时间O(n)，空间O(height)

**迭代法（BFS或DFS）**：
- 用队列或栈遍历每个节点
- 每个节点交换左右子节点
- 时间O(n)，空间O(n)

**参考代码**（Java）:
```java
// 递归法
public TreeNode invertTree(TreeNode root) {
    if (root == null) return null;
    
    // 交换左右子节点
    TreeNode temp = root.left;
    root.left = root.right;
    root.right = temp;
    
    // 递归翻转
    invertTree(root.left);
    invertTree(root.right);
    
    return root;
}

// 迭代法（BFS）
public TreeNode invertTree(TreeNode root) {
    if (root == null) return null;
    
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    
    while (!queue.isEmpty()) {
        TreeNode node = queue.poll();
        // 交换
        TreeNode temp = node.left;
        node.left = node.right;
        node.right = temp;
        
        if (node.left != null) queue.offer(node.left);
        if (node.right != null) queue.offer(node.right);
    }
    return root;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：递归O(height)，迭代O(n)

**扩展问题**:
- 对称二叉树判断？
- 相同的树？
- N叉树的翻转？

## Q4: 对称二叉树

**题目描述**: 给你一个二叉树的根节点 root ，检查它是否轴对称。

**考察点**: 递归、双指针

**难度**: 简单

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

对称二叉树 = 左子树和右子树互为镜像。

**递归法**：
- 定义一个辅助函数，判断两个树是否互为镜像
- 镜像条件：根节点值相同，左树的左子树和右树的右子树镜像，左树的右子树和右树的左子树镜像
- 时间O(n)，空间O(height)

**迭代法**：
- 用队列，每次成对入队和出队比较
- 入队顺序：左树左节点、右树右节点、左树右节点、右树左节点
- 时间O(n)，空间O(n)

**参考代码**（Java）:
```java
// 递归法
public boolean isSymmetric(TreeNode root) {
    if (root == null) return true;
    return isMirror(root.left, root.right);
}

private boolean isMirror(TreeNode left, TreeNode right) {
    if (left == null && right == null) return true;
    if (left == null || right == null) return false;
    
    return left.val == right.val 
        && isMirror(left.left, right.right) 
        && isMirror(left.right, right.left);
}

// 迭代法
public boolean isSymmetric(TreeNode root) {
    if (root == null) return true;
    
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root.left);
    queue.offer(root.right);
    
    while (!queue.isEmpty()) {
        TreeNode left = queue.poll();
        TreeNode right = queue.poll();
        
        if (left == null && right == null) continue;
        if (left == null || right == null) return false;
        if (left.val != right.val) return false;
        
        // 成对入队
        queue.offer(left.left);
        queue.offer(right.right);
        queue.offer(left.right);
        queue.offer(right.left);
    }
    return true;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：递归O(height)，迭代O(n)

**扩展问题**:
- 相同的树？
- 翻转二叉树？
- 另一个树的子树？

## Q5: 二叉树的层序遍历

**题目描述**: 给你二叉树的根节点 root ，返回其节点值的层序遍历。（即逐层地，从左到右访问所有节点）。

**考察点**: BFS、队列

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

层序遍历是BFS的经典应用，也是很多树题的基础。

**BFS法**：
- 使用队列存储当前层的所有节点
- 每次遍历一层，先记录当前层的节点数size
- 遍历size个节点，将它们的值加入结果，同时将子节点入队
- 时间O(n)，空间O(n)

**DFS法**（前序遍历+层数）：
- 递归时传入当前层数level
- 如果level等于结果列表的长度，说明是该层第一个节点，新建一个列表
- 将节点值加入对应层的列表
- 时间O(n)，空间O(height)

**参考代码**（Java）:
```java
// BFS法
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;
    
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    
    while (!queue.isEmpty()) {
        int size = queue.size();
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        result.add(level);
    }
    return result;
}

// DFS法
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    dfs(root, 0, result);
    return result;
}

private void dfs(TreeNode node, int level, List<List<Integer>> result) {
    if (node == null) return;
    
    // 该层第一个节点
    if (level == result.size()) {
        result.add(new ArrayList<>());
    }
    result.get(level).add(node.val);
    
    dfs(node.left, level + 1, result);
    dfs(node.right, level + 1, result);
}
```

**复杂度分析**:
- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：BFS O(n)，DFS O(height)

**扩展问题**:
- 二叉树的锯齿形层序遍历（之字形）？
- 二叉树的层序遍历II（从底向上）？
- N叉树的层序遍历？

## Q6: 二叉树的前/中/后序遍历（递归+迭代）

**题目描述**: 给你二叉树的根节点 root ，分别返回它节点值的前序遍历、中序遍历、后序遍历。请分别用递归和迭代的方式实现。

**考察点**: 递归、栈、Morris遍历

**难度**: 简单（递归）/ 中等（迭代）

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

二叉树的三种遍历是基础中的基础，必须掌握递归和迭代两种写法。

**前序遍历**：根-左-右
**中序遍历**：左-根-右
**后序遍历**：左-右-根

**递归法**：非常直观，按照遍历顺序递归即可。

**迭代法**：使用栈模拟递归过程。
- 前序：先压入根，弹出后压右再压左（因为栈是后入先出）
- 中序：先一路向左走到底，边走边入栈；到底后弹出，处理，然后走右子树
- 后序：可以用"根-右-左"的前序遍历然后反转，或者用双栈/标记法

**参考代码**（Java）:
```java
// ========== 前序遍历 ==========
// 递归
public List<Integer> preorderTraversal(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    preorder(root, res);
    return res;
}
private void preorder(TreeNode node, List<Integer> res) {
    if (node == null) return;
    res.add(node.val);
    preorder(node.left, res);
    preorder(node.right, res);
}
// 迭代
public List<Integer> preorderTraversal(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    if (root == null) return res;
    Stack<TreeNode> stack = new Stack<>();
    stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        res.add(node.val);
        if (node.right != null) stack.push(node.right);
        if (node.left != null) stack.push(node.left);
    }
    return res;
}

// ========== 中序遍历 ==========
// 递归
public List<Integer> inorderTraversal(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    inorder(root, res);
    return res;
}
private void inorder(TreeNode node, List<Integer> res) {
    if (node == null) return;
    inorder(node.left, res);
    res.add(node.val);
    inorder(node.right, res);
}
// 迭代
public List<Integer> inorderTraversal(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    Stack<TreeNode> stack = new Stack<>();
    TreeNode curr = root;
    while (curr != null || !stack.isEmpty()) {
        // 一路向左走到底
        while (curr != null) {
            stack.push(curr);
            curr = curr.left;
        }
        curr = stack.pop();
        res.add(curr.val);
        curr = curr.right;
    }
    return res;
}

// ========== 后序遍历 ==========
// 递归
public List<Integer> postorderTraversal(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    postorder(root, res);
    return res;
}
private void postorder(TreeNode node, List<Integer> res) {
    if (node == null) return;
    postorder(node.left, res);
    postorder(node.right, res);
    res.add(node.val);
}
// 迭代（前序翻转法）
public List<Integer> postorderTraversal(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    if (root == null) return res;
    Stack<TreeNode> stack = new Stack<>();
    stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        res.add(node.val);
        if (node.left != null) stack.push(node.left);
        if (node.right != null) stack.push(node.right);
    }
    Collections.reverse(res); // 反转得到后序
    return res;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(n)，最坏情况栈存储所有节点

**扩展问题**:
- Morris遍历（空间O(1)）？
- 根据前序和中序遍历构造二叉树？
- 二叉树的序列化与反序列化？

## Q7: 二叉树的最近公共祖先

**题目描述**: 给定一个二叉树，找到该树中两个指定节点的最近公共祖先。百度百科中最近公共祖先的定义为："对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（一个节点也可以是它自己的祖先）。"

**考察点**: 递归、后序遍历

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

这道题是二叉树递归的经典应用。

**递归思路**：
- 定义函数的含义：在以root为根的树中找p和q的最近公共祖先
- 如果root是null、p或q，直接返回root
- 递归查找左子树和右子树
- 如果左右都不为空，说明p和q分别在左右子树，root就是LCA
- 如果只有左边不为空，说明都在左子树，返回左边结果
- 如果只有右边不为空，说明都在右子树，返回右边结果

**哈希表法**：
- 遍历树，用哈希表记录每个节点的父节点
- 然后从p往上走，记录路径
- 再从q往上走，第一个在路径中的就是LCA

**参考代码**（Java）:
```java
// 递归法
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    // 终止条件：root为空，或root是p/q
    if (root == null || root == p || root == q) {
        return root;
    }
    
    TreeNode left = lowestCommonAncestor(root.left, p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);
    
    // 左右都不为空，说明p和q分别在左右子树
    if (left != null && right != null) {
        return root;
    }
    // 只有左边不为空
    if (left != null) return left;
    // 只有右边不为空，或都为空
    return right;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，最坏情况遍历所有节点
- 空间复杂度：O(n)，递归栈最坏情况

**扩展问题**:
- 二叉搜索树的最近公共祖先？（更简单，利用BST性质）
- N叉树的最近公共祖先？
- 二叉树的两个节点之间的距离？

## Q8: 验证二叉搜索树

**题目描述**: 给你一个二叉树的根节点 root ，判断其是否是一个有效的二叉搜索树。有效二叉搜索树定义如下：节点的左子树只包含小于当前节点的数；节点的右子树只包含大于当前节点的数；所有左子树和右子树自身必须也是二叉搜索树。

**考察点**: 中序遍历、递归

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

**方法一：中序遍历**
- BST的中序遍历结果是严格递增的
- 用中序遍历，记录前一个节点的值
- 如果当前节点值 <= 前一个节点值，返回false
- 时间O(n)，空间O(n)

**方法二：递归（带范围）**
- 每个节点的值有一个范围：(min, max)
- 左子树的范围是(min, root.val)
- 右子树的范围是(root.val, max)
- 初始范围是(Long.MIN_VALUE, Long.MAX_VALUE)
- 时间O(n)，空间O(height)

注意要用long，因为节点值可能是Integer.MIN_VALUE或Integer.MAX_VALUE。

**参考代码**（Java）:
```java
// 方法一：中序遍历（迭代）
public boolean isValidBST(TreeNode root) {
    Stack<TreeNode> stack = new Stack<>();
    TreeNode curr = root;
    long prev = Long.MIN_VALUE;
    
    while (curr != null || !stack.isEmpty()) {
        while (curr != null) {
            stack.push(curr);
            curr = curr.left;
        }
        curr = stack.pop();
        if (curr.val <= prev) return false;
        prev = curr.val;
        curr = curr.right;
    }
    return true;
}

// 方法二：递归（带范围）
public boolean isValidBST(TreeNode root) {
    return isValid(root, Long.MIN_VALUE, Long.MAX_VALUE);
}

private boolean isValid(TreeNode node, long min, long max) {
    if (node == null) return true;
    
    if (node.val <= min || node.val >= max) {
        return false;
    }
    
    return isValid(node.left, min, node.val) 
        && isValid(node.right, node.val, max);
}
```

**复杂度分析**:
- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(n)，栈或递归栈

**扩展问题**:
- 二叉搜索树的第k小元素？

## Q9: 二叉搜索树的第k大节点

**题目描述**: 给定一棵二叉搜索树，请找出其中第 k 大的节点的值。

**考察点**: 中序遍历、逆中序

**难度**: 简单

**频率**: ⭐⭐⭐⭐

**解题思路**:

BST的中序遍历是升序的，那么**右-根-左**的遍历（逆中序）就是降序的，第k个就是第k大。

**方法一：逆中序遍历**
- 先遍历右子树，再访问根，最后遍历左子树
- 用一个计数器，每访问一个节点计数器+1
- 计数器等于k时，返回当前节点值
- 时间O(n)，空间O(n)

**方法二：中序遍历 + 列表**
- 中序遍历得到升序列表
- 返回列表倒数第k个元素
- 时间O(n)，空间O(n)

**参考代码**（Java）:
```java
// 逆中序遍历（最优）
public int kthLargest(TreeNode root, int k) {
    Stack<TreeNode> stack = new Stack<>();
    TreeNode curr = root;
    int count = 0;
    
    while (curr != null || !stack.isEmpty()) {
        // 先一路向右
        while (curr != null) {
            stack.push(curr);
            curr = curr.right;
        }
        curr = stack.pop();
        count++;
        if (count == k) {
            return curr.val;
        }
        curr = curr.left;
    }
    return -1;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，最坏情况遍历所有节点
- 空间复杂度：O(n)，栈的大小

## Q10: 二叉树的直径

**题目描述**: 给你一棵二叉树的根节点，返回该树的直径。二叉树的直径是指树中任意两个节点之间最长路径的长度。这条路径可能经过也可能不经过根节点。两节点之间路径的长度由它们之间边数表示。

**考察点**: 后序遍历、递归

**难度**: 简单

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

这道题的关键是理解：直径 = 某个节点的左子树深度 + 右子树深度。

不一定经过根节点，所以需要遍历所有节点，计算每个节点的左右子树深度之和，取最大值。

**思路**：
- 定义一个全局变量maxDiameter记录最大直径
- 写一个函数计算以某个节点为根的树的深度
- 在计算深度的过程中，顺便计算该节点的直径（左深度+右深度），更新maxDiameter
- 时间O(n)，空间O(height)

**参考代码**（Java）:
```java
class Solution {
    int maxDiameter = 0;
    
    public int diameterOfBinaryTree(TreeNode root) {
        depth(root);
        return maxDiameter;
    }
    
    private int depth(TreeNode node) {
        if (node == null) return 0;
        
        int leftDepth = depth(node.left);
        int rightDepth = depth(node.right);
        
        // 更新最大直径
        maxDiameter = Math.max(maxDiameter, leftDepth + rightDepth);
        
        // 返回以该节点为根的树的深度
        return Math.max(leftDepth, rightDepth) + 1;
    }
}
```

**复杂度分析**:
- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(n)，递归栈最坏情况

## Q11: 平衡二叉树

**题目描述**: 给定一个二叉树，判断它是否是高度平衡的二叉树。本题中，一棵高度平衡二叉树定义为：一个二叉树每个节点的左右两个子树的高度差的绝对值不超过 1。

**考察点**: 后序遍历、递归

**难度**: 简单

**频率**: ⭐⭐⭐⭐

**解题思路**:

**方法一：自顶向下（暴力）**
- 对每个节点，计算左右子树的高度，判断高度差是否<=1
- 然后递归判断左右子树是否平衡
- 时间O(n²)，因为每个节点的高度都被重复计算了
- 空间O(n)

**方法二：自底向上（最优）**
- 后序遍历，先判断左右子树是否平衡，再判断当前节点
- 如果子树不平衡，直接返回-1（用-1表示不平衡）
- 如果平衡，返回当前树的高度
- 时间O(n)，每个节点只访问一次
- 空间O(n)

**参考代码**（Java）:
```java
// 自底向上
public boolean isBalanced(TreeNode root) {
    return height(root) != -1;
}

private int height(TreeNode node) {
    if (node == null) return 0;
    
    int leftHeight = height(node.left);
    if (leftHeight == -1) return -1; // 左子树不平衡
    
    int rightHeight = height(node.right);
    if (rightHeight == -1) return -1; // 右子树不平衡
    
    if (Math.abs(leftHeight - rightHeight) > 1) {
        return -1; // 当前节点不平衡
    }
    
    return Math.max(leftHeight, rightHeight) + 1;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，每个节点只遍历一次
- 空间复杂度：O(n)，递归调用栈

## Q12: 路径总和

**题目描述**: 给你二叉树的根节点 root 和一个表示目标和的整数 targetSum 。判断该树中是否存在根节点到叶子节点的路径，这条路径上所有节点值相加等于目标和 targetSum 。如果存在，返回 true ；否则，返回 false 。叶子节点是指没有子节点的节点。进阶：路径总和II，找出所有从根节点到叶子节点路径总和等于给定目标和的路径。

**考察点**: DFS、递归、回溯

**难度**: 简单 / 中等（进阶版）

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

**路径总和I（判断是否存在）**：
- 递归：如果是叶子节点，判断sum是否等于当前节点值
- 否则递归判断左右子树，sum减去当前节点值
- 时间O(n)，空间O(height)

**路径总和II（找出所有路径）**：
- DFS + 回溯
- 用一个列表记录当前路径
- 到达叶子节点且sum等于target时，将路径加入结果
- 回溯：返回前移除当前节点
- 时间O(n²)，因为每条路径需要O(n)复制

**参考代码**（Java）:
```java
// 路径总和I
public boolean hasPathSum(TreeNode root, int targetSum) {
    if (root == null) return false;
    
    // 叶子节点
    if (root.left == null && root.right == null) {
        return root.val == targetSum;
    }
    
    return hasPathSum(root.left, targetSum - root.val) 
        || hasPathSum(root.right, targetSum - root.val);
}

// 路径总和II
public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
    List<List<Integer>> result = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    dfs(root, targetSum, path, result);
    return result;
}

private void dfs(TreeNode node, int targetSum, List<Integer> path, List<List<Integer>> result) {
    if (node == null) return;
    
    path.add(node.val);
    
    // 叶子节点
    if (node.left == null && node.right == null) {
        if (targetSum == node.val) {
            result.add(new ArrayList<>(path));
        }
    } else {
        dfs(node.left, targetSum - node.val, path, result);
        dfs(node.right, targetSum - node.val, path, result);
    }
    
    path.remove(path.size() - 1); // 回溯
}
```

**复杂度分析**:
- 路径总和I：时间O(n)，空间O(height)
- 路径总和II：时间O(n²)，空间O(n)

## Q13: 从前序与中序遍历构造二叉树

**题目描述**: 给定两个整数数组 preorder 和 inorder ，其中 preorder 是二叉树的先序遍历， inorder 是同一棵树的中序遍历，请构造二叉树并返回其根节点。

**考察点**: 递归、分治、哈希表优化

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

前序遍历的第一个元素是根节点。在中序遍历中，根节点左边是左子树，右边是右子树。

**递归思路**：
1. 前序第一个元素是根
2. 在中序中找到根的位置，左边是左子树，右边是右子树
3. 递归构造左子树和右子树

为了快速找到根在中序中的位置，用哈希表预处理中序遍历的值->下标的映射。

关键参数：
- 前序的左边界preLeft、右边界preRight
- 中序的左边界inLeft、右边界inRight
- 左子树大小 = rootIndex - inLeft
- 左子树前序范围：[preLeft+1, preLeft+leftSize]
- 右子树前序范围：[preLeft+leftSize+1, preRight]

**参考代码**（Java）:
```java
public TreeNode buildTree(int[] preorder, int[] inorder) {
    // 预处理中序遍历的值->下标映射
    Map<Integer, Integer> inorderMap = new HashMap<>();
    for (int i = 0; i < inorder.length; i++) {
        inorderMap.put(inorder[i], i);
    }
    
    return build(preorder, 0, preorder.length - 1, inorderMap, 0, inorder.length - 1);
}

private TreeNode build(int[] preorder, int preLeft, int preRight,
                       Map<Integer, Integer> inorderMap, int inLeft, int inRight) {
    if (preLeft > preRight) return null;
    
    // 前序第一个是根
    int rootVal = preorder[preLeft];
    TreeNode root = new TreeNode(rootVal);
    
    // 在中序中找根的位置
    int rootIndex = inorderMap.get(rootVal);
    int leftSize = rootIndex - inLeft; // 左子树大小
    
    // 递归构造左右子树
    root.left = build(preorder, preLeft + 1, preLeft + leftSize,
                      inorderMap, inLeft, rootIndex - 1);
    root.right = build(preorder, preLeft + leftSize + 1, preRight,
                       inorderMap, rootIndex + 1, inRight);
    
    return root;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，每个节点构造一次，哈希表查找O(1)
- 空间复杂度：O(n)，哈希表+递归栈

## Q14: 二叉树的右视图

**题目描述**: 给定一个二叉树的根节点 root ，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

**考察点**: BFS、DFS

**难度**: 中等

**频率**: ⭐⭐⭐⭐

**解题思路**:

**方法一：BFS层序遍历**
- 每层的最后一个节点就是右视图能看到的节点
- 时间O(n)，空间O(n)

**方法二：DFS（根-右-左）**
- 按照"根-右-左"的顺序遍历
- 每一层第一次访问到的节点就是最右边的节点
- 用一个变量记录当前深度，如果深度等于结果列表长度，说明是该层第一个节点
- 时间O(n)，空间O(n)

**参考代码**（Java）:
```java
// BFS法
public List<Integer> rightSideView(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    if (root == null) return result;
    
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    
    while (!queue.isEmpty()) {
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            // 每层最后一个节点
            if (i == size - 1) {
                result.add(node.val);
            }
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
    }
    return result;
}

// DFS法
public List<Integer> rightSideView(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    dfs(root, 0, result);
    return result;
}

private void dfs(TreeNode node, int depth, List<Integer> result) {
    if (node == null) return;
    
    // 该层第一个访问到的节点（因为先右后左）
    if (depth == result.size()) {
        result.add(node.val);
    }
    
    dfs(node.right, depth + 1, result); // 先右
    dfs(node.left, depth + 1, result);  // 后左
}
```

**复杂度分析**:
- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(n)

## Q15: 完全二叉树的节点个数

**题目描述**: 给你一棵完全二叉树的根节点 root ，求出该树的节点个数。完全二叉树的定义如下：在完全二叉树中，除了最底层节点可能没填满外，其余每层节点数都达到最大值，并且最下面一层的节点都集中在该层最左边的若干位置。若最底层为第 h 层，则该层包含 1~ 2ʰ 个节点。

**考察点**: 二分查找、完全二叉树性质

**难度**: 中等

**频率**: ⭐⭐⭐⭐

**解题思路**:

**暴力法**：遍历所有节点计数，时间O(n)，但没有利用完全二叉树的性质。

**利用完全二叉树性质**：
- 完全二叉树中，如果左子树高度等于右子树高度，说明左子树是满二叉树
- 如果左子树高度大于右子树高度，说明右子树是满二叉树
- 满二叉树的节点数 = 2^h - 1

**思路**：
1. 分别计算左子树的左高度和右子树的右高度（其实就是根节点的左右两侧高度）
2. 如果相等，说明是满二叉树，节点数 = 2^h - 1
3. 如果不等，递归计算左子树节点数 + 右子树节点数 + 1

更准确的做法：
- 计算左子树的左高度（leftH）和右子树的左高度（rightH）
- 如果leftH == rightH，说明左子树是满的，节点数 = 2^leftH + countNodes(right)
- 如果leftH > rightH，说明右子树是满的，节点数 = countNodes(left) + 2^rightH

时间复杂度O(log²n)，每次递归减少一半，每次计算高度O(logn)。

**参考代码**（Java）:
```java
public int countNodes(TreeNode root) {
    if (root == null) return 0;
    
    int leftHeight = getLeftHeight(root.left);
    int rightHeight = getLeftHeight(root.right);
    
    if (leftHeight == rightHeight) {
        // 左子树是满二叉树，节点数 = 2^leftHeight - 1 + 1(根) + 右子树节点数
        return (1 << leftHeight) + countNodes(root.right);
    } else {
        // 右子树是满二叉树
        return countNodes(root.left) + (1 << rightHeight);
    }
}

// 计算左高度（一直往左走）
private int getLeftHeight(TreeNode node) {
    int height = 0;
    while (node != null) {
        height++;
        node = node.left;
    }
    return height;
}
```

**复杂度分析**:
- 时间复杂度：O(log²n)，递归深度O(logn)，每次计算高度O(logn)
- 空间复杂度：O(logn)，递归栈

**扩展问题**:

- 完全二叉树的最后一个节点？
- 满二叉树和完全二叉树的区别？

## Q16: 图的深度优先搜索(DFS)

**题目描述**: 给你一个有 n 个节点的图，节点编号从 0 到 n - 1。同时给你一个数组 graph ，其中 graph[i] 是一个数组，由所有从节点 i 出发能到达的节点组成。请实现图的深度优先搜索（DFS），从节点 0 开始，返回访问顺序。

**考察点**: DFS、递归、栈、邻接表

**难度**: 简单

**频率**: ⭐⭐⭐⭐

**解题思路**:

图的DFS和树的DFS类似，但图可能有环，所以需要用visited数组记录已访问的节点。

**递归法**：
- 从起始节点开始，标记为已访问
- 遍历当前节点的所有邻居
- 如果邻居未访问，递归访问邻居
- 时间O(V+E)，空间O(V)

**迭代法（栈）**：
- 用栈模拟递归过程
- 注意：栈的弹出顺序和递归的顺序相反
- 时间O(V+E)，空间O(V)

图的表示方法：
- 邻接矩阵：适合稠密图
- 邻接表：适合稀疏图（本题用的是邻接表）

**参考代码**（Java）:
```java
// 递归DFS
public List<Integer> dfs(int n, List<List<Integer>> graph) {
    List<Integer> result = new ArrayList<>();
    boolean[] visited = new boolean[n];
    dfsHelper(0, graph, visited, result);
    return result;
}

private void dfsHelper(int node, List<List<Integer>> graph, boolean[] visited, List<Integer> result) {
    visited[node] = true;
    result.add(node);
    
    for (int neighbor : graph.get(node)) {
        if (!visited[neighbor]) {
            dfsHelper(neighbor, graph, visited, result);
        }
    }
}

// 迭代DFS
public List<Integer> dfsIterative(int n, List<List<Integer>> graph) {
    List<Integer> result = new ArrayList<>();
    boolean[] visited = new boolean[n];
    Stack<Integer> stack = new Stack<>();
    
    stack.push(0);
    
    while (!stack.isEmpty()) {
        int node = stack.pop();
        if (visited[node]) continue;
        
        visited[node] = true;
        result.add(node);
        
        // 注意：为了和递归顺序一致，需要逆序入栈
        List<Integer> neighbors = graph.get(node);
        for (int i = neighbors.size() - 1; i >= 0; i--) {
            int neighbor = neighbors.get(i);
            if (!visited[neighbor]) {
                stack.push(neighbor);
            }
        }
    }
    return result;
}
```

**复杂度分析**:
- 时间复杂度：O(V+E)，V是节点数，E是边数
- 空间复杂度：O(V)，visited数组+递归栈/栈

**扩展问题**:
- 图的BFS？
- 图的连通分量？
- 图中是否有环？

## Q17: 图的广度优先搜索(BFS)

**题目描述**: 给你一个有 n 个节点的图，节点编号从 0 到 n - 1。同时给你一个数组 graph ，其中 graph[i] 是一个数组，由所有从节点 i 出发能到达的节点组成。请实现图的广度优先搜索（BFS），从节点 0 开始，返回访问顺序。

**考察点**: BFS、队列、邻接表

**难度**: 简单

**频率**: ⭐⭐⭐⭐

**解题思路**:

BFS使用队列实现，一层一层向外扩展。

**步骤**：
1. 创建队列，将起始节点入队，标记为已访问
2. 当队列不为空时：
   - 出队一个节点，加入结果
   - 遍历该节点的所有邻居
   - 如果邻居未访问，标记为已访问并入队

注意：必须在入队时标记为已访问，而不是出队时，否则可能重复入队。

BFS的应用场景：
- 层序遍历
- 最短路径（无权图）
- 连通性判断

**参考代码**（Java）:
```java
public List<Integer> bfs(int n, List<List<Integer>> graph) {
    List<Integer> result = new ArrayList<>();
    boolean[] visited = new boolean[n];
    Queue<Integer> queue = new LinkedList<>();
    
    queue.offer(0);
    visited[0] = true; // 入队时标记为已访问
    
    while (!queue.isEmpty()) {
        int node = queue.poll();
        result.add(node);
        
        for (int neighbor : graph.get(node)) {
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                queue.offer(neighbor);
            }
        }
    }
    return result;
}

// 层序BFS（知道每一层有哪些节点）
public List<List<Integer>> bfsLevel(int n, List<List<Integer>> graph) {
    List<List<Integer>> result = new ArrayList<>();
    boolean[] visited = new boolean[n];
    Queue<Integer> queue = new LinkedList<>();
    
    queue.offer(0);
    visited[0] = true;
    
    while (!queue.isEmpty()) {
        int size = queue.size();
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {
            int node = queue.poll();
            level.add(node);
            for (int neighbor : graph.get(node)) {
                if (!visited[neighbor]) {
                    visited[neighbor] = true;
                    queue.offer(neighbor);
                }
            }
        }
        result.add(level);
    }
    return result;
}
```

**复杂度分析**:
- 时间复杂度：O(V+E)，每个节点和每条边各访问一次
- 空间复杂度：O(V)，队列和visited数组

## Q18: 岛屿数量

**题目描述**: 给你一个由 '1'（陆地）和 '0'（水）组成的的二维网格，请你计算网格中岛屿的数量。岛屿总是被水包围，并且每座岛屿只能由水平方向和/或竖直方向上相邻的陆地连接形成。此外，你可以假设该网格的四条边均被水包围。

**考察点**: DFS、BFS、并查集

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

这是一道经典的网格DFS/BFS题。

**思路**：
- 遍历网格中的每个单元格
- 如果是陆地('1')，说明发现一个新岛屿，岛屿数+1
- 然后用DFS或BFS把这个岛屿的所有陆地都标记为已访问（改成'0'）
- 继续遍历

**DFS**：
- 当前位置是陆地，标记为水（或用visited数组）
- 递归访问上下左右四个方向

**BFS**：
- 当前位置是陆地，入队
- 出队时标记，邻居陆地入队

时间O(m×n)，空间O(m×n)。

**参考代码**（Java）:
```java
// DFS法
public int numIslands(char[][] grid) {
    if (grid == null || grid.length == 0) return 0;
    
    int count = 0;
    int m = grid.length, n = grid[0].length;
    
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (grid[i][j] == '1') {
                count++;
                dfs(grid, i, j);
            }
        }
    }
    return count;
}

private void dfs(char[][] grid, int i, int j) {
    int m = grid.length, n = grid[0].length;
    // 边界判断
    if (i < 0 || i >= m || j < 0 || j >= n || grid[i][j] == '0') {
        return;
    }
    
    grid[i][j] = '0'; // 标记为已访问
    
    // 上下左右
    dfs(grid, i - 1, j);
    dfs(grid, i + 1, j);
    dfs(grid, i, j - 1);
    dfs(grid, i, j + 1);
}

// BFS法
public int numIslands(char[][] grid) {
    if (grid == null || grid.length == 0) return 0;
    
    int count = 0;
    int m = grid.length, n = grid[0].length;
    int[][] dirs = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};
    
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (grid[i][j] == '1') {
                count++;
                Queue<int[]> queue = new LinkedList<>();
                queue.offer(new int[]{i, j});
                grid[i][j] = '0';
                
                while (!queue.isEmpty()) {
                    int[] curr = queue.poll();
                    for (int[] dir : dirs) {
                        int x = curr[0] + dir[0];
                        int y = curr[1] + dir[1];
                        if (x >= 0 && x < m && y >= 0 && y < n && grid[x][y] == '1') {
                            grid[x][y] = '0';
                            queue.offer(new int[]{x, y});
                        }
                    }
                }
            }
        }
    }
    return count;
}
```

**复杂度分析**:
- 时间复杂度：O(m×n)，每个单元格最多访问一次
- 空间复杂度：O(m×n)，最坏情况全是陆地，DFS栈或BFS队列

**扩展问题**:
- 岛屿的最大面积？
- 朋友圈/省份数量（并查集经典题）？
- 被围绕的区域？

## Q19: 课程表（拓扑排序）

**题目描述**: 你这个学期必须选修 numCourses 门课程，记为 0 到 numCourses - 1。在选修某些课程之前需要一些先修课程。先修课程按数组 prerequisites 给出，其中 prerequisites[i] = [ai, bi] ，表示如果要学习课程 ai 则必须先学习课程 bi。请你判断是否可能完成所有课程的学习？如果可以，返回 true ；否则，返回 false 。进阶：返回你为了学完所有课程所安排的学习顺序。可能会有多个正确的顺序，你只要返回任意一种就可以了。如果不可能完成所有课程，返回一个空数组。

**考察点**: 拓扑排序、BFS、入度表

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

这道题本质是判断有向图是否有环，如果无环则输出拓扑排序。

**拓扑排序（Kahn算法 - BFS）**：
1. 统计每个节点的入度
2. 将所有入度为0的节点入队
3. 出队一个节点，加入结果
4. 遍历该节点的所有邻居，将邻居的入度-1
5. 如果邻居入度变为0，入队
6. 最后判断结果数量是否等于节点数
   - 相等：无环，返回结果
   - 不等：有环，返回空/false

时间O(V+E)，空间O(V+E)。

也可以用DFS判断环，但Kahn算法更直观。

**参考代码**（Java）:
```java
// 课程表I：判断是否能完成
public boolean canFinish(int numCourses, int[][] prerequisites) {
    // 构建邻接表和入度表
    List<List<Integer>> graph = new ArrayList<>();
    int[] inDegree = new int[numCourses];
    
    for (int i = 0; i < numCourses; i++) {
        graph.add(new ArrayList<>());
    }
    
    for (int[] pre : prerequisites) {
        int course = pre[0];
        int prerequisite = pre[1];
        graph.get(prerequisite).add(course); // 先修课指向当前课
        inDegree[course]++;
    }
    
    // BFS拓扑排序
    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < numCourses; i++) {
        if (inDegree[i] == 0) {
            queue.offer(i);
        }
    }
    
    int count = 0;
    while (!queue.isEmpty()) {
        int course = queue.poll();
        count++;
        for (int next : graph.get(course)) {
            inDegree[next]--;
            if (inDegree[next] == 0) {
                queue.offer(next);
            }
        }
    }
    
    return count == numCourses;
}

// 课程表II：返回学习顺序
public int[] findOrder(int numCourses, int[][] prerequisites) {
    List<List<Integer>> graph = new ArrayList<>();
    int[] inDegree = new int[numCourses];
    
    for (int i = 0; i < numCourses; i++) {
        graph.add(new ArrayList<>());
    }
    
    for (int[] pre : prerequisites) {
        graph.get(pre[1]).add(pre[0]);
        inDegree[pre[0]]++;
    }
    
    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < numCourses; i++) {
        if (inDegree[i] == 0) {
            queue.offer(i);
        }
    }
    
    int[] result = new int[numCourses];
    int index = 0;
    
    while (!queue.isEmpty()) {
        int course = queue.poll();
        result[index++] = course;
        for (int next : graph.get(course)) {
            inDegree[next]--;
            if (inDegree[next] == 0) {
                queue.offer(next);
            }
        }
    }
    
    return index == numCourses ? result : new int[0];
}
```

**复杂度分析**:
- 时间复杂度：O(V+E)，V是课程数，E是先修关系数
- 空间复杂度：O(V+E)，邻接表+入度表+队列

- 有向图中是否有环？
- 最小高度树？
- 拓扑排序的其他应用？

## Q20: 克隆图

**题目描述**: 给你无向连通图中一个节点的引用，请你返回该图的深拷贝（克隆）。图中的每个节点都包含它的值 val（int）和其邻居的列表（list[Node]）。

**考察点**: DFS、BFS、哈希表

**难度**: 中等

**频率**: ⭐⭐⭐⭐

**解题思路**:

这道题和"复制带随机指针的链表"思想类似，用哈希表存储原节点到克隆节点的映射。

**DFS法**：
- 如果节点已克隆（在map中），直接返回克隆节点
- 否则创建克隆节点，存入map
- 递归克隆所有邻居，加入克隆节点的邻居列表
- 返回克隆节点

**BFS法**：
- 原节点入队，创建克隆节点存入map
- 出队一个原节点，遍历其邻居
- 如果邻居未克隆，创建并入队
- 将克隆邻居加入克隆节点的邻居列表

时间O(V+E)，空间O(V)。

**参考代码**（Java）:
```java
class Node {
    public int val;
    public List<Node> neighbors;
}

// DFS法
class Solution {
    Map<Node, Node> map = new HashMap<>();
    
    public Node cloneGraph(Node node) {
        if (node == null) return null;
        
        // 已经克隆过了
        if (map.containsKey(node)) {
            return map.get(node);
        }
        
        // 创建克隆节点
        Node cloneNode = new Node(node.val, new ArrayList<>());
        map.put(node, cloneNode);
        
        // 克隆邻居
        for (Node neighbor : node.neighbors) {
            cloneNode.neighbors.add(cloneGraph(neighbor));
        }
        
        return cloneNode;
    }
}

// BFS法
public Node cloneGraph(Node node) {
    if (node == null) return null;
    
    Map<Node, Node> map = new HashMap<>();
    Queue<Node> queue = new LinkedList<>();
    
    // 克隆起始节点
    Node cloneNode = new Node(node.val, new ArrayList<>());
    map.put(node, cloneNode);
    queue.offer(node);
    
    while (!queue.isEmpty()) {
        Node curr = queue.poll();
        
        for (Node neighbor : curr.neighbors) {
            if (!map.containsKey(neighbor)) {
                // 克隆邻居节点
                map.put(neighbor, new Node(neighbor.val, new ArrayList<>()));
                queue.offer(neighbor);
            }
            // 将克隆邻居加入当前克隆节点的邻居列表
            map.get(curr).neighbors.add(map.get(neighbor));
        }
    }
    return cloneNode;
}
```

**复杂度分析**:
- 时间复杂度：O(V+E)，每个节点和每条边各处理一次
- 空间复杂度：O(V)，哈希表+递归栈/队列
