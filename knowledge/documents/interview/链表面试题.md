## Q1: 反转链表

**题目描述**: 给你单链表的头节点 head ，请你反转链表，并返回反转后的链表。

**考察点**: 链表遍历、指针操作、递归

**难度**: 简单

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

反转链表是链表题的基础中的基础，必须掌握迭代和递归两种写法。

**迭代法**：
- 维护三个指针：prev（前一个节点）、curr（当前节点）、next（下一个节点）
- 遍历链表，每次将 curr.next 指向 prev
- 然后 prev 和 curr 分别前移
- 时间O(n)，空间O(1)

**递归法**：
- 递归到链表末尾，返回新的头节点
- 然后逐层返回，在回溯时反转指针
- 即 head.next.next = head; head.next = null;
- 时间O(n)，空间O(n)（递归栈）

**参考代码**（Java）:
```java
// 迭代法
public ListNode reverseList(ListNode head) {
    ListNode prev = null;
    ListNode curr = head;
    
    while (curr != null) {
        ListNode next = curr.next; // 保存下一个节点
        curr.next = prev;          // 反转当前节点指针
        prev = curr;               // prev前移
        curr = next;               // curr前移
    }
    return prev; // prev最终指向新的头节点
}

// 递归法
public ListNode reverseList(ListNode head) {
    if (head == null || head.next == null) {
        return head;
    }
    ListNode newHead = reverseList(head.next);
    head.next.next = head;
    head.next = null;
    return newHead;
}
```

**复杂度分析**:
- 迭代法：时间O(n)，空间O(1)
- 递归法：时间O(n)，空间O(n)（递归调用栈）

**扩展问题**:
- 反转链表的前N个节点？
- 反转链表的第m到第n个节点？
- K个一组翻转链表？

## Q2: 合并两个有序链表

**题目描述**: 将两个升序链表合并为一个新的升序链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

**考察点**: 链表遍历、递归、虚拟头节点

**难度**: 简单

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

**迭代法**：
- 使用虚拟头节点（dummy）简化边界处理
- 用一个指针 curr 遍历，比较两个链表当前节点的值
- 将较小的节点接到 curr 后面，对应链表指针前移
- 最后将剩余的非空链表直接接上
- 时间O(n+m)，空间O(1)

**递归法**：
- 比较两个链表头节点，较小的那个的 next 等于递归合并剩余部分
- 时间O(n+m)，空间O(n+m)（递归栈）

**参考代码**（Java）:
```java
// 迭代法
public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
    ListNode dummy = new ListNode(-1);
    ListNode curr = dummy;
    
    while (list1 != null && list2 != null) {
        if (list1.val < list2.val) {
            curr.next = list1;
            list1 = list1.next;
        } else {
            curr.next = list2;
            list2 = list2.next;
        }
        curr = curr.next;
    }
    // 接上剩余部分
    curr.next = list1 != null ? list1 : list2;
    
    return dummy.next;
}

// 递归法
public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
    if (list1 == null) return list2;
    if (list2 == null) return list1;
    
    if (list1.val < list2.val) {
        list1.next = mergeTwoLists(list1.next, list2);
        return list1;
    } else {
        list2.next = mergeTwoLists(list1, list2.next);
        return list2;
    }
}
```

**复杂度分析**:
- 迭代法：时间O(n+m)，空间O(1)
- 递归法：时间O(n+m)，空间O(n+m)

**扩展问题**:
- 合并K个升序链表？
- 合并两个有序数组？
- 排序链表（归并排序思路）？

## Q3: 链表的中间节点

**题目描述**: 给定一个头结点为 head 的非空单链表，返回链表的中间结点。如果有两个中间结点，则返回第二个中间结点。

**考察点**: 快慢指针

**难度**: 简单

**频率**: ⭐⭐⭐⭐

**解题思路**:

这是快慢指针的经典应用。

**暴力法**：先遍历一次统计长度，再遍历一半找到中间节点。时间O(n)，但要遍历两次。

**快慢指针法**：
- 慢指针每次走一步，快指针每次走两步
- 当快指针到达末尾时，慢指针正好在中间
- 如果链表长度为偶数，慢指针指向第二个中间节点（正好符合题意）
- 时间O(n)，只遍历一次，空间O(1)

**参考代码**（Java）:
```java
public ListNode middleNode(ListNode head) {
    ListNode slow = head;
    ListNode fast = head;
    
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，快指针遍历完整个链表
- 空间复杂度：O(1)，只使用两个指针

**扩展问题**:
- 如果要返回第一个中间节点，怎么改？（fast从head.next开始）
- 判断链表是否有环（快慢指针的另一个应用）？
- 找到链表的倒数第k个节点？

## Q4: 判断链表是否有环

**题目描述**: 给你一个链表的头节点 head ，判断链表中是否有环。如果链表中有某个节点，可以通过连续跟踪 next 指针再次到达，则链表中存在环。为了表示给定链表中的环，评测系统内部使用整数 pos 来表示链表尾连接到链表中的位置（索引从 0 开始）。注意：pos 不作为参数进行传递。如果链表中存在环，则返回 true 。否则，返回 false 。

**考察点**: 快慢指针、哈希表

**难度**: 简单

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

**方法一：哈希表**
- 遍历链表，每个节点存入HashSet
- 如果遇到已经在Set中的节点，说明有环
- 时间O(n)，空间O(n)

**方法二：快慢指针（Floyd判圈算法）**
- 慢指针每次走一步，快指针每次走两步
- 如果有环，快指针一定会追上慢指针（套圈）
- 如果没环，快指针会先到达null
- 时间O(n)，空间O(1)

为什么快指针每次走两步一定能相遇？可以用数学归纳法证明：进入环后，假设快慢指针距离为d，每走一步距离减少1，所以一定会相遇。

**参考代码**（Java）:
```java
public boolean hasCycle(ListNode head) {
    if (head == null || head.next == null) return false;
    
    ListNode slow = head;
    ListNode fast = head;
    
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) {
            return true;
        }
    }
    return false;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，有环时最多走n步相遇
- 空间复杂度：O(1)，只使用两个指针

**扩展问题**:
- 环形链表II（找到环的入口节点）？
- 环的长度怎么求？
- 如何判断两个链表是否相交？

## Q5: 环形链表II（找入口）

**题目描述**: 给定一个链表的头节点 head ，返回链表开始入环的第一个节点。如果链表无环，则返回 null。如果链表中有某个节点，可以通过连续跟踪 next 指针再次到达，则链表中存在环。不允许修改链表。

**考察点**: 快慢指针、数学推导

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

这是上一题的进阶版，需要找到环的入口节点。

**方法一：哈希表**
- 遍历链表，遇到的第一个重复节点就是入口
- 时间O(n)，空间O(n)

**方法二：快慢指针 + 数学推导**
- 先用快慢指针找到相遇点
- 设头节点到入口距离为a，入口到相遇点距离为b，相遇点回到入口距离为c
- 慢指针走了 a+b，快指针走了 a+b+k(b+c)（k圈）
- 快指针路程是慢指针两倍：2(a+b) = a+b+k(b+c)
- 化简得：a = (k-1)(b+c) + c
- 即从头节点到入口的距离 = 从相遇点走k-1圈再加c
- 所以相遇后，让一个指针从头开始，两个指针都每次走一步，相遇点就是入口

**参考代码**（Java）:
```java
public ListNode detectCycle(ListNode head) {
    ListNode slow = head;
    ListNode fast = head;
    
    // 找相遇点
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) {
            break;
        }
    }
    
    // 无环
    if (fast == null || fast.next == null) {
        return null;
    }
    
    // 一个指针从头开始，每次走一步
    slow = head;
    while (slow != fast) {
        slow = slow.next;
        fast = fast.next;
    }
    return slow;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，两轮遍历都是线性的
- 空间复杂度：O(1)，只使用常数额外空间

**扩展问题**:
- 求环的长度？（相遇后继续走，再次相遇时慢指针走的步数）
- 快乐数（判断是否进入循环）？
- 寻找重复数（链表思想的应用）？

## Q6: 相交链表

**题目描述**: 给你两个单链表的头节点 headA 和 headB ，请你找出并返回两个单链表相交的起始节点。如果两个链表不存在相交节点，返回 null 。题目数据保证整个链式结构中不存在环。注意，函数返回结果后，链表必须保持其原始结构。

**考察点**: 双指针、链表拼接

**难度**: 简单

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

**方法一：哈希表**
- 遍历链表A，所有节点存入HashSet
- 遍历链表B，第一个在Set中存在的节点就是交点
- 时间O(m+n)，空间O(m)或O(n)

**方法二：双指针（浪漫解法）**
- 指针A从headA开始遍历，遍历完A后从headB开始
- 指针B从headB开始遍历，遍历完B后从headA开始
- 如果有交点，两个指针会在交点相遇（走的路程相同：a+b+c = b+a+c）
- 如果没有交点，两个指针会同时到达null
- 时间O(m+n)，空间O(1)

**参考代码**（Java）:
```java
public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
    if (headA == null || headB == null) return null;
    
    ListNode pA = headA;
    ListNode pB = headB;
    
    while (pA != pB) {
        pA = (pA == null) ? headB : pA.next;
        pB = (pB == null) ? headA : pB.next;
    }
    return pA; // 有交点返回交点，无交点返回null
}
```

**复杂度分析**:
- 时间复杂度：O(m+n)，最多遍历两个链表各两次
- 空间复杂度：O(1)，只使用两个指针

**扩展问题**:
- 如果链表可能有环，怎么判断相交？
- 三个链表的交点？
- 求两个相交链表的交点之前的长度？

## Q7: 删除链表的倒数第N个节点

**题目描述**: 给你一个链表，删除链表的倒数第 n 个结点，并且返回链表的头结点。你能尝试使用一趟扫描实现吗？

**考察点**: 快慢指针、虚拟头节点

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

**方法一：两次遍历**
- 第一次遍历统计链表长度
- 第二次遍历找到正数第 L-n+1 个节点删除
- 时间O(n)，但要遍历两次

**方法二：快慢指针（一次遍历）**
- 快指针先走n步
- 然后快慢指针一起走，直到快指针到达末尾
- 此时慢指针的下一个节点就是要删除的节点
- 使用虚拟头节点处理删除头节点的情况
- 时间O(n)，空间O(1)

**参考代码**（Java）:
```java
public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(-1);
    dummy.next = head;
    
    ListNode fast = dummy;
    ListNode slow = dummy;
    
    // 快指针先走n步
    for (int i = 0; i < n; i++) {
        fast = fast.next;
    }
    
    // 快慢指针一起走
    while (fast.next != null) {
        slow = slow.next;
        fast = fast.next;
    }
    
    // 删除slow的下一个节点
    slow.next = slow.next.next;
    
    return dummy.next;
}
```

**复杂度分析**:
- 时间复杂度：O(L)，L为链表长度，只遍历一次
- 空间复杂度：O(1)，只使用常数额外空间

**扩展问题**:
- 删除链表的中间节点？
- 删除排序链表中的重复元素？
- 找到链表的倒数第k个节点？

## Q8: 两两交换链表中的节点

**题目描述**: 给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。你必须在不修改节点内部的值的情况下完成本题（即，只能进行节点交换）。

**考察点**: 递归、迭代、指针操作

**难度**: 中等

**频率**: ⭐⭐⭐⭐

**解题思路**:

**递归法**：
- 递归终止条件：链表为空或只有一个节点
- 每次交换前两个节点，然后递归处理后面的链表
- 时间O(n)，空间O(n)

**迭代法**：
- 使用虚拟头节点
- 三个指针：prev、first、second
- 每次交换 first 和 second，prev 指向交换后的第二个节点
- 时间O(n)，空间O(1)

**参考代码**（Java）:
```java
// 递归法
public ListNode swapPairs(ListNode head) {
    if (head == null || head.next == null) {
        return head;
    }
    ListNode first = head;
    ListNode second = head.next;
    
    first.next = swapPairs(second.next);
    second.next = first;
    
    return second;
}

// 迭代法
public ListNode swapPairs(ListNode head) {
    ListNode dummy = new ListNode(-1);
    dummy.next = head;
    ListNode prev = dummy;
    
    while (prev.next != null && prev.next.next != null) {
        ListNode first = prev.next;
        ListNode second = prev.next.next;
        
        // 交换
        first.next = second.next;
        second.next = first;
        prev.next = second;
        
        prev = first; // prev移到下一组的前一个位置
    }
    return dummy.next;
}
```

**复杂度分析**:
- 递归法：时间O(n)，空间O(n)
- 迭代法：时间O(n)，空间O(1)

**扩展问题**:
- K个一组翻转链表？
- 反转链表II（反转指定区间）？
- 奇偶链表？

## Q9: 回文链表

**题目描述**: 给你一个单链表的头节点 head ，请你判断该链表是否为回文链表。如果是，返回 true ；否则，返回 false 。你能否用 O(n) 时间复杂度和 O(1) 空间复杂度解决此题？

**考察点**: 快慢指针、反转链表

**难度**: 简单

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

**方法一：数组 + 双指针**
- 将链表值存入数组，然后用双指针判断回文
- 时间O(n)，空间O(n)

**方法二：递归**
- 利用递归的反向遍历特性
- 维护一个全局指针从前往后，递归从后往前
- 时间O(n)，空间O(n)

**方法三：快慢指针 + 反转后半段（最优）**
- 快慢指针找到中间节点
- 反转后半段链表
- 比较前半段和反转后的后半段是否相同
- 最后恢复链表（可选，面试中最好提一下）
- 时间O(n)，空间O(1)

**参考代码**（Java）:
```java
public boolean isPalindrome(ListNode head) {
    if (head == null || head.next == null) return true;
    
    // 快慢指针找中点
    ListNode slow = head;
    ListNode fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    
    // 反转后半段
    ListNode secondHalf = reverseList(slow);
    
    // 比较前后两段
    ListNode p1 = head;
    ListNode p2 = secondHalf;
    while (p2 != null) {
        if (p1.val != p2.val) {
            return false;
        }
        p1 = p1.next;
        p2 = p2.next;
    }
    return true;
}

private ListNode reverseList(ListNode head) {
    ListNode prev = null;
    ListNode curr = head;
    while (curr != null) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，找中点O(n) + 反转O(n/2) + 比较O(n/2)
- 空间复杂度：O(1)，原地操作

**扩展问题**:
- 回文数？
- 最长回文子串？
- 如何用O(1)空间且不修改原链表？

## Q10: K个一组翻转链表

**题目描述**: 给你链表的头节点 head ，每 k 个节点一组进行翻转，请你返回修改后的链表。k 是一个正整数，它的值小于或等于链表的长度。如果节点总数不是 k 的整数倍，那么请将最后剩余的节点保持原有顺序。你不能只是单纯的改变节点内部的值，而是需要实际进行节点交换。

**考察点**: 递归、链表反转、分组处理

**难度**: 困难

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

这道题是链表操作的集大成者，综合了反转链表和分组思想。

**递归法**：
- 检查剩余节点是否够k个，不够直接返回head
- 反转前k个节点
- 递归处理剩下的链表，接在反转后的尾部
- 时间O(n)，空间O(n/k)（递归栈深度）

**迭代法**：
- 使用虚拟头节点
- 每组需要找到k个节点的头尾
- 反转子链表，接到前面
- 时间O(n)，空间O(1)

关键点：反转子链表时要保存子链表的头和尾，以及前后的连接点。

**参考代码**（Java）:
```java
public ListNode reverseKGroup(ListNode head, int k) {
    ListNode dummy = new ListNode(-1);
    dummy.next = head;
    ListNode prev = dummy; // 每组的前一个节点
    
    while (true) {
        // 检查剩余节点是否够k个
        ListNode end = prev;
        for (int i = 0; i < k; i++) {
            end = end.next;
            if (end == null) {
                return dummy.next; // 不够k个，结束
            }
        }
        
        ListNode start = prev.next; // 每组的第一个节点
        ListNode nextGroup = end.next; // 下一组的第一个节点
        
        // 反转start到end之间的k个节点
        reverse(start, end);
        
        // 连接前后
        prev.next = end;
        start.next = nextGroup;
        
        prev = start; // prev移到下一组的前一个位置
    }
}

// 反转从start到end的链表，返回反转后的头（即原来的end）
private void reverse(ListNode start, ListNode end) {
    ListNode prev = null;
    ListNode curr = start;
    ListNode stop = end.next; // 反转到end为止
    
    while (curr != stop) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
}
```

**复杂度分析**:
- 时间复杂度：O(n)，每个节点最多被访问两次（检查+反转）
- 空间复杂度：O(1)，只使用常数额外空间

- 从后往前K个一组翻转？
- 不足k个也翻转？

## Q11: 复制带随机指针的链表

**题目描述**: 给你一个长度为 n 的链表，每个节点包含一个额外增加的随机指针 random ，该指针可以指向链表中的任何节点或空节点。构造这个链表的深拷贝。深拷贝应该正好由 n 个全新节点组成，其中每个新节点的值都设为其对应的原节点的值。新节点的 next 指针和 random 指针也都应指向复制链表中的新节点，并使原链表和复制链表中的这些指针能够表示相同的链表状态。复制链表中的指针都不应指向原链表中的节点。

**考察点**: 哈希表、链表拼接与拆分

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

这道题的难点在于random指针的复制，因为random指针可能指向后面还没创建的节点。

**方法一：哈希表**
- 遍历原链表，用HashMap存储 原节点 -> 新节点 的映射
- 再遍历一次，根据原节点的next和random，设置新节点的next和random
- 时间O(n)，空间O(n)

**方法二：拼接 + 拆分（空间优化）**
- 第一步：在每个原节点后面插入一个复制节点（A->A'->B->B'->...）
- 第二步：设置复制节点的random指针：A'.random = A.random.next
- 第三步：将两个链表拆分开
- 时间O(n)，空间O(1)（忽略返回值的空间）

**参考代码**（Java）:
```java
// 方法一：哈希表
public Node copyRandomList(Node head) {
    if (head == null) return null;
    
    Map<Node, Node> map = new HashMap<>();
    
    // 第一次遍历：创建所有新节点
    Node curr = head;
    while (curr != null) {
        map.put(curr, new Node(curr.val));
        curr = curr.next;
    }
    
    // 第二次遍历：设置next和random
    curr = head;
    while (curr != null) {
        map.get(curr).next = map.get(curr.next);
        map.get(curr).random = map.get(curr.random);
        curr = curr.next;
    }
    
    return map.get(head);
}

// 方法二：拼接+拆分
public Node copyRandomList(Node head) {
    if (head == null) return null;
    
    // 第一步：拼接
    Node curr = head;
    while (curr != null) {
        Node copy = new Node(curr.val);
        copy.next = curr.next;
        curr.next = copy;
        curr = copy.next;
    }
    
    // 第二步：设置random
    curr = head;
    while (curr != null) {
        if (curr.random != null) {
            curr.next.random = curr.random.next;
        }
        curr = curr.next.next;
    }
    
    // 第三步：拆分
    curr = head;
    Node newHead = head.next;
    while (curr != null) {
        Node copy = curr.next;
        curr.next = copy.next;
        if (copy.next != null) {
            copy.next = copy.next.next;
        }
        curr = curr.next;
    }
    
    return newHead;
}
```

**复杂度分析**:
- 哈希表法：时间O(n)，空间O(n)
- 拼接拆分法：时间O(n)，空间O(1)

- 克隆图（类似思想，DFS/BFS + 哈希表）？
- 复杂链表的其他变种？
- 为什么拼接法的random可以直接取next？

## Q12: 排序链表

**题目描述**: 给你链表的头结点 head ，请将其按升序排列并返回排序后的链表。你可以在 O(n log n) 时间复杂度和常数级空间复杂度下，对链表进行排序吗？

**考察点**: 归并排序、快慢指针、链表合并

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

链表排序的最优解法是归并排序，因为：
- 数组排序最快O(nlogn)的是快排，但链表不支持随机访问，快排很难高效实现
- 归并排序天然适合链表，因为合并两个有序链表不需要额外空间

**归并排序思路**：
1. 用快慢指针找到链表中点
2. 递归排序左右两半
3. 合并两个有序链表
4. 时间O(nlogn)，空间O(logn)（递归栈）

如果要求O(1)空间，需要用迭代版的归并排序（bottom-up），从长度为1的子链表开始，两两合并，直到整个链表有序。

**参考代码**（Java）:
```java
public ListNode sortList(ListNode head) {
    if (head == null || head.next == null) {
        return head;
    }
    
    // 快慢指针找中点
    ListNode slow = head;
    ListNode fast = head.next;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    
    ListNode rightHead = slow.next;
    slow.next = null; // 断开
    
    // 递归排序左右两半
    ListNode left = sortList(head);
    ListNode right = sortList(rightHead);
    
    // 合并两个有序链表
    return merge(left, right);
}

private ListNode merge(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(-1);
    ListNode curr = dummy;
    
    while (l1 != null && l2 != null) {
        if (l1.val < l2.val) {
            curr.next = l1;
            l1 = l1.next;
        } else {
            curr.next = l2;
            l2 = l2.next;
        }
        curr = curr.next;
    }
    curr.next = (l1 != null) ? l1 : l2;
    
    return dummy.next;
}
```

**复杂度分析**:
- 时间复杂度：O(nlogn)，归并排序标准时间复杂度
- 空间复杂度：O(logn)，递归调用栈深度

**扩展问题**:
- 插入排序链表？
- 合并K个升序链表？
- 数组的归并排序和链表的归并排序有什么区别？

## Q13: LRU缓存机制

**题目描述**: 请你设计并实现一个满足 LRU (最近最少使用) 缓存约束的数据结构。实现 LRUCache 类：LRUCache(int capacity) 以正整数作为容量 capacity 初始化 LRU 缓存；int get(int key) 如果关键字 key 存在于缓存中，则返回关键字的值，否则返回 -1；void put(int key, int value) 如果关键字 key 已经存在，则变更其数据值 value；如果不存在，则向缓存中插入该组 key-value。如果插入操作导致关键字数量超过 capacity，则应该逐出最久未使用的关键字。函数 get 和 put 必须以 O(1) 的平均时间复杂度运行。

**考察点**: 哈希表 + 双向链表、数据结构设计

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

LRU是面试中超高频的设计题。核心要求是get和put都是O(1)。

**数据结构选型**：
- 哈希表：O(1)查找，但无法维护使用顺序
- 链表：可以维护顺序，但查找O(n)
- 两者结合：哈希表存 key -> 节点 的映射，双向链表维护使用顺序

**设计思路**：
- 双向链表头部是最近使用的，尾部是最久未使用的
- get操作：通过哈希表找到节点，将节点移到链表头部
- put操作：
  - key已存在：更新value，移到头部
  - key不存在：创建新节点加到头部，加入哈希表；如果超出容量，删除尾部节点并从哈希表移除
- 使用虚拟头节点和虚拟尾节点，简化边界操作

**参考代码**（Java）:
```java
class LRUCache {
    class DLinkedNode {
        int key;
        int value;
        DLinkedNode prev;
        DLinkedNode next;
        public DLinkedNode() {}
        public DLinkedNode(int key, int value) {
            this.key = key;
            this.value = value;
        }
    }
    
    private Map<Integer, DLinkedNode> cache = new HashMap<>();
    private int size;
    private int capacity;
    private DLinkedNode head, tail;
    
    public LRUCache(int capacity) {
        this.size = 0;
        this.capacity = capacity;
        // 虚拟头节点和尾节点
        head = new DLinkedNode();
        tail = new DLinkedNode();
        head.next = tail;
        tail.prev = head;
    }
    
    public int get(int key) {
        DLinkedNode node = cache.get(key);
        if (node == null) return -1;
        // 移到头部
        moveToHead(node);
        return node.value;
    }
    
    public void put(int key, int value) {
        DLinkedNode node = cache.get(key);
        if (node == null) {
            // 新节点
            DLinkedNode newNode = new DLinkedNode(key, value);
            cache.put(key, newNode);
            addToHead(newNode);
            size++;
            if (size > capacity) {
                // 删除尾部
                DLinkedNode tail = removeTail();
                cache.remove(tail.key);
                size--;
            }
        } else {
            // 更新值并移到头部
            node.value = value;
            moveToHead(node);
        }
    }
    
    private void addToHead(DLinkedNode node) {
        node.prev = head;
        node.next = head.next;
        head.next.prev = node;
        head.next = node;
    }
    
    private void removeNode(DLinkedNode node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }
    
    private void moveToHead(DLinkedNode node) {
        removeNode(node);
        addToHead(node);
    }
    
    private DLinkedNode removeTail() {
        DLinkedNode res = tail.prev;
        removeNode(res);
        return res;
    }
}
```

**复杂度分析**:
- 时间复杂度：get和put都是O(1)
- 空间复杂度：O(capacity)

**扩展问题**:
- LFU缓存（最不经常使用）？
- 为什么用双向链表而不是单向链表？
- LinkedHashMap如何实现LRU？

## Q14: 重排链表

**题目描述**: 给定一个单链表 L 的头节点 head ，单链表 L 表示为：L0 → L1 → … → Ln - 1 → Ln。请将其重新排列后变为：L0 → Ln → L1 → Ln - 1 → L2 → Ln - 2 → …。不能只是单纯的改变节点内部的值，而是需要实际的进行节点交换。

**考察点**: 快慢指针、链表反转、链表合并

**难度**: 中等

**频率**: ⭐⭐⭐⭐

**解题思路**:

这道题是多个链表操作的综合应用，可以拆分成三步：

1. **找中点**：用快慢指针找到链表中点
2. **反转后半段**：将后半段链表反转
3. **交替合并**：将前半段和反转后的后半段交替合并

每一步都是一个经典的链表操作，组合起来就是这道题的解法。

**参考代码**（Java）:
```java
public void reorderList(ListNode head) {
    if (head == null || head.next == null) return;
    
    // 第一步：快慢指针找中点
    ListNode slow = head;
    ListNode fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    
    // 第二步：反转后半段
    ListNode secondHalf = reverse(slow.next);
    slow.next = null; // 断开前后两段
    
    // 第三步：交替合并
    ListNode p1 = head;
    ListNode p2 = secondHalf;
    while (p2 != null) {
        ListNode next1 = p1.next;
        ListNode next2 = p2.next;
        p1.next = p2;
        p2.next = next1;
        p1 = next1;
        p2 = next2;
    }
}

private ListNode reverse(ListNode head) {
    ListNode prev = null;
    ListNode curr = head;
    while (curr != null) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，找中点O(n) + 反转O(n/2) + 合并O(n/2)
- 空间复杂度：O(1)，原地操作

**扩展问题**:
- 回文链表（类似的三步法）？
- 奇偶链表？
- 链表的其他重排方式？

## Q15: 链表相加（两数相加）

**题目描述**: 给你两个非空的链表，表示两个非负的整数。它们每位数字都是按照逆序的方式存储的，并且每个节点只能存储一位数字。请你将两个数相加，并以相同形式返回一个表示和的链表。你可以假设除了数字 0 之外，这两个数都不会以 0 开头。

**考察点**: 链表遍历、进位处理

**难度**: 中等

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

这道题模拟手工加法的过程。因为链表是逆序存储的（个位在头部），所以可以直接从头开始相加。

**思路**：
- 同时遍历两个链表，对应位相加，加上进位
- 新节点的值 = sum % 10，进位 = sum / 10
- 当一个链表遍历完后，只遍历另一个链表（加0）
- 最后还要检查进位，如果进位不为0，还要加一个节点
- 使用虚拟头节点简化操作

进阶题：如果链表是正序存储的（高位在前），怎么办？可以先反转链表，或者用栈。

**参考代码**（Java）:
```java
public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(-1);
    ListNode curr = dummy;
    int carry = 0; // 进位
    
    while (l1 != null || l2 != null || carry != 0) {
        int sum = carry;
        if (l1 != null) {
            sum += l1.val;
            l1 = l1.next;
        }
        if (l2 != null) {
            sum += l2.val;
            l2 = l2.next;
        }
        
        curr.next = new ListNode(sum % 10);
        carry = sum / 10;
        curr = curr.next;
    }
    
    return dummy.next;
}
```

**复杂度分析**:
- 时间复杂度：O(max(m,n))，遍历较长的链表
- 空间复杂度：O(max(m,n))，结果链表的长度

- 两数相加II（正序存储）？

## Q16: 分隔链表

**题目描述**: 给你一个链表的头节点 head 和一个特定值 x ，请你对链表进行分隔，使得所有小于 x 的节点都出现在大于或等于 x 的节点之前。你应当保留两个分区中每个节点的初始相对位置。

**考察点**: 双指针、链表拼接

**难度**: 中等

**频率**: ⭐⭐⭐

**解题思路**:

这道题用两个虚拟头节点的思路非常简洁：

- 创建两个虚拟头节点：smallHead（小于x的链表）和largeHead（大于等于x的链表）
- 遍历原链表，根据节点值分别接到small或large链表后面
- 最后将small链表的尾部接到large链表的头部
- large链表的尾部要置null，否则可能形成环

时间O(n)，空间O(1)。

**参考代码**（Java）:
```java
public ListNode partition(ListNode head, int x) {
    ListNode smallHead = new ListNode(-1);
    ListNode largeHead = new ListNode(-1);
    ListNode small = smallHead;
    ListNode large = largeHead;
    
    while (head != null) {
        if (head.val < x) {
            small.next = head;
            small = small.next;
        } else {
            large.next = head;
            large = large.next;
        }
        head = head.next;
    }
    
    // 连接两个链表
    small.next = largeHead.next;
    large.next = null; // 重要：最后一个节点的next要置空
    
    return smallHead.next;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，遍历一次链表
- 空间复杂度：O(1)，只使用了常数个额外节点

## Q17: 旋转链表

**题目描述**: 给你一个链表的头节点 head ，旋转链表，将链表每个节点向右移动 k 个位置。

**考察点**: 链表成环、找断点

**难度**: 中等

**频率**: ⭐⭐⭐

**解题思路**:

旋转链表的本质是找到新的头节点和尾节点。

**思路**：
1. 先统计链表长度n，并找到尾节点
2. k = k % n（k可能大于n）
3. 如果k == 0，直接返回head
4. 将尾节点连到头节点，形成环
5. 找到新的尾节点（第 n-k 个节点），新的头节点就是尾节点的next
6. 断开尾节点的next

或者更简单：找到第 n-k 个节点，从这里断开，将后半段接到前面。

**参考代码**（Java）:
```java
public ListNode rotateRight(ListNode head, int k) {
    if (head == null || head.next == null || k == 0) {
        return head;
    }
    
    // 统计长度并找到尾节点
    int n = 1;
    ListNode tail = head;
    while (tail.next != null) {
        tail = tail.next;
        n++;
    }
    
    k = k % n;
    if (k == 0) return head;
    
    // 找到新的尾节点（第 n-k 个节点）
    ListNode newTail = head;
    for (int i = 0; i < n - k - 1; i++) {
        newTail = newTail.next;
    }
    
    ListNode newHead = newTail.next;
    newTail.next = null; // 断开
    tail.next = head;    // 原尾连到原头
    
    return newHead;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，最多遍历两次链表
- 空间复杂度：O(1)，只使用常数额外空间

**扩展问题**:
- 旋转数组（三次翻转法）？
- 旋转字符串？
- 向左旋转k个位置？

## Q18: 奇偶链表

**题目描述**: 给定单链表的头节点 head ，将所有索引为奇数的节点和索引为偶数的节点分别组合在一起，然后返回重新排序的列表。第一个节点的索引被认为是奇数，第二个节点的索引为偶数，以此类推。请注意，偶数组和奇数组内部的相对顺序应该与输入时保持一致。你必须在 O(1) 的额外空间复杂度和 O(n) 的时间复杂度下解决这个问题。

**考察点**: 双指针、链表拼接

**难度**: 中等

**频率**: ⭐⭐⭐

**解题思路**:

和分隔链表类似，用两个指针分别串联奇数位置和偶数位置的节点。

**思路**：
- odd指针串联奇数位置节点，even指针串联偶数位置节点
- 用evenHead记录偶数链表的头节点
- 遍历完后，将odd的next指向evenHead
- 注意even的next要置空，防止出现环

**参考代码**（Java）:
```java
public ListNode oddEvenList(ListNode head) {
    if (head == null || head.next == null) {
        return head;
    }
    
    ListNode odd = head;
    ListNode even = head.next;
    ListNode evenHead = even; // 保存偶数链表头
    
    while (even != null && even.next != null) {
        odd.next = even.next;
        odd = odd.next;
        even.next = odd.next;
        even = even.next;
    }
    
    odd.next = evenHead; // 奇数链表尾部连到偶数链表头部
    
    return head;
}
```

**复杂度分析**:
- 时间复杂度：O(n)，遍历一次链表
- 空间复杂度：O(1)，只使用常数额外空间

**扩展问题**:
- 重排链表？
- 分隔链表（按值分隔）？
- 按其他规则重排链表？

## Q19: 合并K个升序链表

**题目描述**: 给你一个链表数组，每个链表都已经按升序排列。请你将所有链表合并到一个升序链表中，返回合并后的链表。

**考察点**: 优先队列、归并、分治

**难度**: 困难

**频率**: ⭐⭐⭐⭐⭐

**解题思路**:

**方法一：优先队列（最小堆）**
- 将每个链表的头节点放入最小堆
- 每次取出堆顶节点（最小值），加入结果
- 如果该节点有next，将next加入堆
- 时间O(n×logk)，n是总节点数，k是链表数
- 空间O(k)

**方法二：分治归并**
- 将k个链表两两合并
- 类似归并排序的思路
- 时间O(n×logk)，空间O(logk)（递归栈）

**方法三：顺序合并**
- 逐个合并，时间O(kn)，效率最低

**参考代码**（Java）:
```java
// 方法一：优先队列
public ListNode mergeKLists(ListNode[] lists) {
    if (lists == null || lists.length == 0) return null;
    
    PriorityQueue<ListNode> pq = new PriorityQueue<>((a, b) -> a.val - b.val);
    
    // 将每个链表的头节点加入堆
    for (ListNode node : lists) {
        if (node != null) {
            pq.offer(node);
        }
    }
    
    ListNode dummy = new ListNode(-1);
    ListNode curr = dummy;
    
    while (!pq.isEmpty()) {
        ListNode minNode = pq.poll();
        curr.next = minNode;
        curr = curr.next;
        if (minNode.next != null) {
            pq.offer(minNode.next);
        }
    }
    
    return dummy.next;
}

// 方法二：分治归并
public ListNode mergeKLists(ListNode[] lists) {
    if (lists == null || lists.length == 0) return null;
    return merge(lists, 0, lists.length - 1);
}

private ListNode merge(ListNode[] lists, int left, int right) {
    if (left == right) return lists[left];
    int mid = left + (right - left) / 2;
    ListNode l1 = merge(lists, left, mid);
    ListNode l2 = merge(lists, mid + 1, right);
    return mergeTwoLists(l1, l2);
}

private ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(-1);
    ListNode curr = dummy;
    while (l1 != null && l2 != null) {
        if (l1.val < l2.val) {
            curr.next = l1;
            l1 = l1.next;
        } else {
            curr.next = l2;
            l2 = l2.next;
        }
        curr = curr.next;
    }
    curr.next = l1 != null ? l1 : l2;
    return dummy.next;
}
```

**复杂度分析**:
- 优先队列：时间O(n×logk)，空间O(k)
- 分治归并：时间O(n×logk)，空间O(logk)

**扩展问题**:
- 合并K个有序数组？
- 丑数II（优先队列的应用）？
- 第K小的元素（多种数据结构）？

## Q20: 删除排序链表中的重复元素

**题目描述**: 给定一个已排序的链表的头 head ，删除所有重复的元素，使每个元素只出现一次。返回已排序的链表。进阶：给定一个已排序的链表的头 head ，删除原始链表中所有重复数字的节点，只留下不同的数字。返回已排序的链表。

**考察点**: 链表遍历、快慢指针

**难度**: 简单 / 中等（进阶版）

**频率**: ⭐⭐⭐⭐

**解题思路**:

**基础版（保留一个）**：
- 因为链表已排序，重复元素是相邻的
- 遍历链表，如果当前节点和下一个节点值相同，跳过下一个节点
- 时间O(n)，空间O(1)

**进阶版（全部删除）**：
- 重复元素一个都不留，难度稍大
- 使用虚拟头节点（因为头节点可能被删除）
- 用prev指针指向已确定不重复的最后一个节点
- 当发现重复元素时，prev.next跳过所有重复节点
- 时间O(n)，空间O(1)

**参考代码**（Java）:
```java
// 基础版：保留一个重复元素
public ListNode deleteDuplicates(ListNode head) {
    if (head == null) return null;
    
    ListNode curr = head;
    while (curr.next != null) {
        if (curr.val == curr.next.val) {
            curr.next = curr.next.next; // 跳过重复节点
        } else {
            curr = curr.next;
        }
    }
    return head;
}

// 进阶版：删除所有重复元素
public ListNode deleteDuplicates(ListNode head) {
    if (head == null) return null;
    
    ListNode dummy = new ListNode(-1);
    dummy.next = head;
    ListNode prev = dummy;
    
    while (prev.next != null && prev.next.next != null) {
        if (prev.next.val == prev.next.next.val) {
            int val = prev.next.val;
            // 跳过所有等于val的节点
            while (prev.next != null && prev.next.val == val) {
                prev.next = prev.next.next;
            }
        } else {
            prev = prev.next;
        }
    }
    return dummy.next;
}
```

**复杂度分析**:
- 基础版：时间O(n)，空间O(1)
- 进阶版：时间O(n)，空间O(1)

- 删除有序数组中的重复项？
- 移除链表元素（删除所有等于val的节点）？
- 删除链表中的节点（只给要删除的节点指针）？
