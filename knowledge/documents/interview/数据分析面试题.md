### Q1: Pandas 如何处理缺失值？fillna 和 dropna 的区别？

- **类别**: Python数据
- **难度**: 基础
- **频率**: 极高

<details>
<summary>答题要点</summary>

**检测缺失值**：
- `df.isnull()` / `df.isna()`：返回布尔 DataFrame
- `df.isnull().sum()`：统计每列缺失值数量

**处理缺失值**：
- `df.dropna()`：删除含缺失值的行或列
  - `axis=0`（默认）：删除行
  - `axis=1`：删除列
  - `how='any'`（默认）：有任何缺失就删
  - `how='all'`：全部缺失才删
  - `thresh=n`：至少 n 个非空值才保留

- `df.fillna(value)`：填充缺失值
  - 固定值：`df.fillna(0)`
  - 前向/后向填充：`method='ffill'` / `method='bfill'`
  - 均值/中位数/众数：`df.fillna(df.mean())`

**选择策略**：
- 缺失率 < 5%：可用均值/中位数填充
- 缺失率 5%-20%：插值或建模预测
- 缺失率 > 20%：考虑删除该列

</details>

### Q2: 写一条SQL：查询每门课成绩都大于80分的学生姓名

- **类别**: SQL
- **难度**: 中等
- **频率**: 极高

<details>
<summary>答题要点</summary>

```sql
-- 方法一：HAVING + MIN
SELECT student_name
FROM scores
GROUP BY student_name
HAVING MIN(score) > 80;

-- 方法二：NOT EXISTS
SELECT DISTINCT student_name
FROM scores s1
WHERE NOT EXISTS (
    SELECT 1 FROM scores s2
    WHERE s2.student_name = s1.student_name
    AND s2.score <= 80
);
```

**考察点**：
- GROUP BY + HAVING 对分组后结果的条件过滤
- HAVING 与 WHERE 的区别：WHERE 过滤原始行，HAVING 过滤分组结果
- 聚合函数 MIN 的使用

</details>

### Q3: 你如何判断一个数据分析结果是否有效？（假设检验）

- **类别**: 统计
- **难度**: 中等
- **频率**: 高

<details>
<summary>答题要点</summary>

**假设检验步骤**：
1. 提出 H0（原假设）和 H1（备择假设）
2. 选择显著性水平 α（通常 0.05）
3. 选择检验方法（t 检验/卡方检验/方差分析等）
4. 计算 p-value
5. p < α → 拒绝 H0，结果显著

**常见检验方法**：
- **t 检验**：比较两组均值（AB 测试常用）
- **卡方检验**：分类变量的关联性
- **ANOVA**：多组均值比较

**注意事项**：
- p-value 小 ≠ 效果大（效应量也很重要）
- 多重比较要修正（Bonferroni 校正）
- 相关 ≠ 因果

</details>

### Q4: 解释一下 A/B 测试的流程和注意事项？

- **类别**: 数据实验
- **难度**: 中等
- **频率**: 高

<details>
<summary>答题要点</summary>

**流程**：
1. 确定目标和指标（核心指标 + 护栏指标）
2. 确定样本量（功效分析 → 在线计算器）
3. 随机分流（AA 测试验证分流均匀性）
4. 实验运行（通常 1-2 周，覆盖完整的用户行为周期）
5. 统计分析（t 检验 / 卡方检验）
6. 结论与决策

**注意事项**：
- 样本量不足 → 结果不可靠
- 实验时间太短 → 未捕捉周期性
- 新奇效应（Novelty Effect）：用户对新功能的好奇导致短期数据虚高
- 辛普森悖论：分组看和总体看趋势相反
- 不要同时跑多个互相影响的实验

</details>

### Q5: 如果你的数据分析结论和产品经理的直觉相反，你怎么处理？

- **类别**: 沟通
- **难度**: 中等
- **频率**: 中

<details>
<summary>答题要点</summary>

2. **多角度交叉验证**：用不同的方法/数据源验证结论
3. **深入挖掘**：从数据中寻找与直觉矛盾的客观原因

</details>

### Q6: SQL 中 WHERE 和 HAVING 的区别？

- **类别**: SQL
- **难度**: 基础
- **频率**: 高

<details>
<summary>答题要点</summary>

| 维度 | WHERE | HAVING |
|------|-------|--------|
| 过滤对象 | 原始行数据 | 分组后的聚合结果 |
| 能否用聚合函数 | 不能 | 能（AVG/SUM/COUNT 等） |
| 执行顺序 | 先于 GROUP BY | 后于 GROUP BY |
| 性能 | 通常更快（减少分组数据量） | 在分组后过滤 |

**示例**：
```sql
-- 正确：WHERE 过滤行，HAVING 过滤分组
SELECT dept, AVG(salary)
FROM employees
WHERE hire_date > '2020-01-01'   -- 过滤行
GROUP BY dept
HAVING AVG(salary) > 10000;      -- 过滤分组

-- 错误：WHERE 中不能使用聚合函数
-- WHERE AVG(salary) > 10000  ❌
```

</details>

### Q7: 解释一下相关系数和因果关系？

- **类别**: 统计
- **难度**: 基础
- **频率**: 中

<details>
<summary>答题要点</summary>

**相关系数**：
- 衡量两个变量之间的线性关系强度和方向
- Pearson 相关系数 r ∈ [-1, 1]
  - r > 0：正相关；r < 0：负相关；r ≈ 0：不相关
- 只反映线性关系，不反映非线性关系

**相关 ≠ 因果**：
- 存在混杂变量（Confounder）：冰淇淋销量和溺水人数都随气温升高
- 反向因果：城市警察数量越多犯罪率越高？其实是高犯罪率导致增加警力
- 伪相关：纯属巧合（如某年某生日和股票涨跌）

**建立因果关系**：
- 随机对照实验（RCT）
- A/B 测试
- 工具变量
- 断点回归
</details>

### Q8: 如何对一份从未见过的数据进行探索性分析？

- **类别**: 方法论
- **难度**: 中等
- **频率**: 高

<details>
<summary>答题要点</summary>

**EDA（Exploratory Data Analysis）步骤**：

1. **数据概览**：
   - `df.shape`：行数列数
   - `df.info()`：数据类型、缺失情况
   - `df.describe()`：数值列统计

2. **数据质量检查**：
   - 缺失值比例和模式
   - 重复值
   - 异常值（箱线图、Z-score、IQR）
   - 数据类型是否正确

3. **单变量分析**：
   - 数值型：分布（直方图、KDE）、集中趋势、离散程度
   - 类别型：频数统计、柱状图

4. **多变量分析**：
   - 相关性矩阵（热力图）
   - 分组聚合（GROUP BY + 统计）
   - 交叉表/透视表
   - 散点图矩阵

5. **提出假设**：
   - 基于探索发现，形成分析假设
   - 确定后续深入分析方向

</details>
