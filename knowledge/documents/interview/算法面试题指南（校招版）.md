## 高频题型分类与模板

### 1. 数组与双指针

**核心思想**：用两个指针同向或相向遍历，将 O(n²) 优化为 O(n)。

**代表题目**：
- 两数之和（LeetCode 1）- 哈希表 / 双指针
- 盛最多水的容器（LeetCode 11）- 左右指针
- 移动零（LeetCode 283）- 快慢指针
- 无重复字符的最长子串（LeetCode 3）- 滑动窗口
- 三数之和（LeetCode 15）- 排序 + 双指针

<details>
<summary>答题要点</summary>

**快慢指针模板**（原地修改数组）：
```
慢指针 slow = 0
快指针 fast 遍历数组：
    if nums[fast] 满足条件：
        nums[slow] = nums[fast]
        slow++
返回 slow
```

**滑动窗口模板**（子串/子数组问题）：
```
left = 0, right = 0
while right < n:
    扩大窗口，加入 nums[right]
    while 窗口不满足条件：
        缩小窗口，移出 nums[left]
        left++
    更新答案
    right++
```

**左右指针模板**（有序数组 / 字符串首尾）：
```
left = 0, right = n - 1
while left < right:
    if 满足条件：
        更新答案
        left++ / right--
    else if 需要增大：
        left++
    else:
        right--
```

</details>

### 2. 链表

**核心思想**：操作指针指向，注意空指针和环的判断。

**代表题目**：
- 反转链表（LeetCode 206）- 迭代 / 递归
- 合并两个有序链表（LeetCode 21）- 归并
- 环形链表（LeetCode 141）- 快慢指针
- 相交链表（LeetCode 160）- 双指针浪漫相遇
- 删除链表的倒数第 N 个节点（LeetCode 19）- 快慢指针 + 哑节点

<details>
<summary>答题要点</summary>

**反转链表迭代模板**：
```
prev = null, curr = head
while curr:
    next = curr.next   // 保存下一个
    curr.next = prev   // 反转指向
    prev = curr        // prev 前进
    curr = next        // curr 前进
return prev
```

**环形链表判断**：快慢指针相遇则有环；相遇后慢指针回到起点，同速前进再次相遇即为入环点。

**常用技巧**：
- 哑节点（dummy）：避免处理头节点特殊情况
- 快慢指针：找中点、判环、倒数第 k 个
- 递归：反转链表、合并链表

</details>

### 3. 树与递归

**核心思想**：树的问题优先考虑递归，明确每个节点要做什么。

**代表题目**：
- 二叉树的最大深度（LeetCode 104）- DFS 递归
- 二叉树的层序遍历（LeetCode 102）- BFS 队列
- 翻转二叉树（LeetCode 226）- 递归交换
- 验证二叉搜索树（LeetCode 98）- 中序遍历有序
- 二叉树的最近公共祖先（LeetCode 236）- 后序遍历

<details>
<summary>答题要点</summary>

**前/中/后序遍历（递归）**：
```
前序：根 → 左 → 右
中序：左 → 根 → 右
后序：左 → 右 → 根
```

**BFS 层序遍历模板**：
```
queue = [root]
while queue not empty:
    level = []
    size = len(queue)
    for i in range(size):
        node = queue.popleft()
        level.append(node.val)
        if node.left: queue.append(node.left)
        if node.right: queue.append(node.right)
    result.append(level)
```

**BST 性质**：中序遍历结果为升序数组，常用此性质验证 BST 或找第 k 小元素。

</details>

### 4. 动态规划

**核心思想**：将大问题分解为子问题，存储子问题的解避免重复计算。

**代表题目**：
- 爬楼梯（LeetCode 70）- 一维 DP
- 最长递增子序列（LeetCode 300）- 一维 DP + 二分优化
- 最长公共子序列（LeetCode 1143）- 二维 DP
- 零钱兑换（LeetCode 322）- 完全背包
- 买卖股票最佳时机（LeetCode 121）- 一维 DP / 贪心

<details>
<summary>答题要点</summary>

**DP 五步法**：
1. 确定 dp 数组及下标的含义
2. 确定递推公式（状态转移方程）
3. dp 数组如何初始化
4. 确定遍历顺序
5. 举例推导 dp 数组

**背包问题分类**：
| 类型 | 特点 | 递推方向 |
|------|------|----------|
| 01 背包 | 每个物品只能选一次 | 背包容量倒序遍历 |
| 完全背包 | 每个物品可选多次 | 背包容量正序遍历 |
| 多重背包 | 每个物品有数量限制 | 二进制优化 / 单调队列 |

**子序列问题**：
- 连续子数组：dp[i] 以 i 结尾的最值
- 不连续子序列：dp[i] 考虑前 i 个元素的最值

</details>

### 5. 字符串

**核心思想**：双指针、滑动窗口、KMP 算法。

**代表题目**：
- 最长回文子串（LeetCode 5）- 中心扩展 / 动态规划
- 字符串相加（LeetCode 415）- 模拟竖式
- 无重复字符的最长子串（LeetCode 3）- 滑动窗口
- 有效的字母异位词（LeetCode 242）- 哈希计数
- 实现 strStr()（LeetCode 28）- KMP / 滑动窗口

<details>
<summary>答题要点</summary>

**回文中心扩展模板**：
```
def expand(s, l, r):
    while l >= 0 and r < len(s) and s[l] == s[r]:
        l--; r++
    return s[l+1:r]  // 最长回文
```

**KMP 算法**：
- next 数组：每个位置之前的子串的最长相等前后缀长度
- 匹配失败时，模式串指针回退到 next[j-1]，避免主串指针回溯
- 时间复杂度 O(n+m)

</details>

### 6. 排序与查找

**核心思想**：掌握快排、归并、二分查找的实现和变形。

**代表题目**：
- 排序数组（LeetCode 912）- 快排 / 归并
- 搜索插入位置（LeetCode 35）- 二分查找
- 在排序数组中查找元素的第一个和最后一个位置（LeetCode 34）- 二分左右边界
- 数组中的第 K 个最大元素（LeetCode 215）- 快速选择 / 堆
- 寻找两个正序数组的中位数（LeetCode 4）- 二分 / 划分数组

<details>
<summary>答题要点</summary>

**二分查找模板**：
```
// 基本二分
left, right = 0, n-1
while left <= right:
    mid = left + (right - left) / 2
    if nums[mid] == target: return mid
    elif nums[mid] < target: left = mid + 1
    else: right = mid - 1

// 左边界
while left < right:
    mid = (left + right) / 2
    if nums[mid] < target: left = mid + 1
    else: right = mid

// 右边界
while left < right:
    mid = (left + right + 1) / 2
    if nums[mid] <= target: left = mid
    else: right = mid - 1
```

**快速排序**：选 pivot → 分区 → 递归左右，平均 O(n log n)，最坏 O(n²)。

</details>

### 7. 图论

**核心思想**：BFS / DFS 遍历，拓扑排序，最短路径。

**代表题目**：
- 岛屿数量（LeetCode 200）- DFS / BFS
- 课程表（LeetCode 207）- 拓扑排序
- 克隆图（LeetCode 133）- DFS / BFS + 哈希
- 腐烂的橘子（LeetCode 994）- 多源 BFS
- 最小基因变化（LeetCode 433）- BFS 最短路径

<details>
<summary>答题要点</summary>

**DFS 模板**：
```
def dfs(grid, i, j):
    if 越界 or 不满足条件: return
    标记已访问
    dfs(grid, i+1, j)
    dfs(grid, i-1, j)
    dfs(grid, i, j+1)
    dfs(grid, i, j-1)
```

**BFS 模板（最短路径）**：
```
queue = [start]
visited = set()
step = 0
while queue not empty:
    size = len(queue)
    for i in range(size):
        node = queue.popleft()
        if node == target: return step
        for neighbor in node.neighbors:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
    step++
```

**拓扑排序**：Kahn 算法（入度表 + 队列），每次取出度为 0 的节点。

</details>

### 8. 回溯与贪心

**核心思想**：回溯 = 暴力枚举 + 剪枝；贪心 = 每步最优 → 全局最优。

**代表题目**：
- 全排列（LeetCode 46）- 回溯
- 组合总和（LeetCode 39）- 回溯 + 剪枝
- 子集（LeetCode 78）- 回溯
- 跳跃游戏（LeetCode 55）- 贪心
- 分发饼干（LeetCode 455）- 贪心

<details>
<summary>答题要点</summary>

**回溯模板**：
```
result = []
def backtrack(路径, 选择列表):
    if 满足结束条件:
        result.append(路径.copy())
        return
    for 选择 in 选择列表:
        if 剪枝条件: continue
        做选择
        backtrack(路径, 选择列表)
        撤销选择
```

**贪心算法**：
- 适用条件：贪心选择性质 + 最优子结构
- 证明方法：反证法、数学归纳法
- 常见场景：区间调度、哈夫曼编码、最小生成树

</details>

## 刷题策略与时间规划

### 入门阶段（1-2 个月）

- **目标**：熟悉基础数据结构和常见题型
- **题量**：100-150 道
- **方法**：
  - 按题型分类刷，每个类型先刷 5-10 道简单题建立感觉
  - 不会的题直接看题解，理解思路后自己写一遍

- **目标**：掌握中等题，形成解题模板
- **题量**：200-300 道
- **方法**：
  - 主攻中等题，重点攻克动态规划、图论、回溯
  - 每道题限时 30 分钟，超时看题解
  - 总结题型模板，建立自己的解题框架
  - 开始参加周赛，锻炼抗压和临场思维
- **建议节奏**：每天 3-5 题，每周 1 场周赛

### 冲刺阶段（1 个月）

- **目标**：适应面试节奏，查漏补缺
- **方法**：
  - 刷 HOT 100 / 剑指 Offer，高频题反复练
  - 模拟面试：给自己限时，口头讲思路 + 写代码
  - 复习错题本，总结常见易错点
  - 按公司分类刷目标公司的高频题
- **建议节奏**：每天 3-5 道中等 + 1 道困难，每周 2-3 次模拟

## 面试算法题答题技巧

### 四步法

**第一步：澄清题意（2-3 分钟）**
- 确认输入输出格式和范围
- 询问数据规模（决定算法复杂度选择）
- 举几个例子确认理解正确
- 询问是否有空间/时间复杂度要求

**第二步：说思路（3-5 分钟）**
- 先说最直观的暴力解法（哪怕 O(n²)）
- 然后说优化思路，为什么能优化
- 说出时间和空间复杂度
- 与面试官确认思路方向是否正确

**第三步：写代码（10-15 分钟）**
- 先写函数签名和注释
- 变量名清晰，逻辑分层
- 边写边解释关键步骤
- 注意边界条件和异常处理

**第四步：测边界（2-3 分钟）**
- 用样例数据走一遍代码
- 测试空输入、单元素、最大值等边界
- 分析时间空间复杂度
- 主动说可能的优化方向

## 常见算法面试题 Top10

### 1. 两数之和（LeetCode 1）

- **类别**: 数组/哈希表
- **难度**: 简单
- **频率**: 极高

<details>
<summary>答题要点</summary>

**思路**：
- 暴力：两层循环 O(n²)，空间 O(1)
- **最优**：哈希表一次遍历，key 存数值，value 存下标
- 遍历数组，检查 `target - nums[i]` 是否已在哈希表中
- 时间 O(n)，空间 O(n)

**注意点**：
- 返回的是下标，不是值
- 同一个元素不能重复使用
- 无序数组不能用双指针（需排序打乱下标）

</details>

---

### 2. 反转链表（LeetCode 206）

- **类别**: 链表
- **难度**: 简单
- **频率**: 极高

<details>
<summary>答题要点</summary>

**迭代法**：
- 三个指针：prev、curr、next
- 每次反转 curr.next = prev，然后三个指针前进
- 时间 O(n)，空间 O(1)

**递归法**：
- 递归到最后一个节点，逐层返回反转后的头节点
- `head.next.next = head; head.next = null`
- 时间 O(n)，空间 O(n)（递归栈）

</details>

---

### 3. 二叉树层序遍历（LeetCode 102）

- **类别**: 树/BFS
- **难度**: 中等
- **频率**: 极高

<details>
<summary>答题要点</summary>

**BFS 队列实现**：
- 队列存当前层节点
- 每层开始时记录队列 size，循环 size 次处理当前层
- 每处理一个节点，将其左右子节点入队
- 时间 O(n)，空间 O(n)

**DFS 递归实现**：
- 前序遍历，传入当前层级 level
- result[level].append(node.val)
- 时间 O(n)，空间 O(h)（递归栈）

</details>

### 4. 最长回文子串（LeetCode 5）

- **类别**: 字符串/动态规划
- **难度**: 中等
- **频率**: 高

<details>
<summary>答题要点</summary>

**中心扩展法**：
- 枚举每个中心点（奇数长度中心为字符，偶数为两字符之间）
- 向左右扩展直到不相等，记录最长
- 时间 O(n²)，空间 O(1)

**动态规划**：
- `dp[i][j]` 表示 s[i..j] 是否为回文
- `dp[i][j] = (s[i] == s[j]) && dp[i+1][j-1]`
- 时间 O(n²)，空间 O(n²)

**Manacher 算法**：O(n) 时间，但面试一般不要求写出，知道即可。

</details>

### 5. 买卖股票最佳时机（LeetCode 121）

- **类别**: 动态规划/贪心
- **难度**: 简单
- **频率**: 极高

<details>
<summary>答题要点</summary>

**贪心 / 一次遍历**：
- 记录遍历到当前位置的最低价格 minPrice
- 计算当前价格与 minPrice 的差值，更新最大利润
- 时间 O(n)，空间 O(1)

**动态规划**：
- `dp[i][0]` 第 i 天不持有股票的最大利润
- `dp[i][1]` 第 i 天持有股票的最大利润
- 状态转移：不持有 = max(前一天不持有, 前一天持有今天卖出)
- 通用模板可扩展到买卖股票 II、III、IV、含冷冻期等系列题

</details>

### 6. 爬楼梯（LeetCode 70）

- **类别**: 动态规划
- **难度**: 简单
- **频率**: 高

<details>
<summary>答题要点</summary>

**思路**：
- 到第 n 阶的方法数 = 到第 n-1 阶（走 1 步）+ 到第 n-2 阶（走 2 步）
- `dp[n] = dp[n-1] + dp[n-2]`，本质是斐波那契数列
- 初始条件：dp[1] = 1, dp[2] = 2

**优化**：
- 空间压缩：只需两个变量滚动更新
- 时间 O(n)，空间 O(1)

**进阶**：最小花费爬楼梯、使用最小花费爬楼梯。

</details>

### 7. 合并两个有序链表（LeetCode 21）

- **类别**: 链表/归并
- **难度**: 简单
- **频率**: 高

<details>
<summary>答题要点</summary>

**迭代法**：
- 哑节点 dummy 作为结果链表头
- 双指针遍历两个链表，取较小值接入结果
- 其中一个链表遍历完后，直接接上另一个
- 时间 O(n+m)，空间 O(1)

**递归法**：
- `l1.val < l2.val` 时，`l1.next = merge(l1.next, l2)`，返回 l1
- 否则同理，返回 l2
- 时间 O(n+m)，空间 O(n+m)（递归栈）

</details>

### 8. 有效的括号（LeetCode 20）

- **类别**: 栈
- **难度**: 简单
- **频率**: 高

<details>
<summary>答题要点</summary>

**栈解法**：
- 遇左括号入栈，遇右括号检查栈顶是否匹配
- 用哈希表存右括号到左括号的映射
- 最后栈空则有效
- 时间 O(n)，空间 O(n)

**注意点**：
- 奇数长度直接返回 false
- 右括号开头直接返回 false
- 栈空时遇到右括号直接 false

</details>

### 9. 最大子数组和（LeetCode 53）

- **类别**: 动态规划/贪心
- **难度**: 中等
- **频率**: 高

<details>
<summary>答题要点</summary>

**动态规划 / Kadane 算法**：
- `dp[i]` 表示以 nums[i] 结尾的最大子数组和
- `dp[i] = max(nums[i], dp[i-1] + nums[i])`
- 要么从当前元素重新开始，要么接上前面的子数组
- 时间 O(n)，空间可优化为 O(1)

**分治法**：
- 最大子数组要么在左半、右半、或跨中间
- 跨中间的 = 左边最大后缀 + 右边最大前缀
- 时间 O(n log n)，空间 O(log n)

</details>

### 10. 二叉树的最大深度（LeetCode 104）

- **类别**: 树/DFS/BFS
- **难度**: 简单
- **频率**: 高

<details>
<summary>答题要点</summary>

**DFS 递归**：
- `maxDepth(root) = max(maxDepth(left), maxDepth(right)) + 1`
- 空节点深度为 0
- 时间 O(n)，空间 O(h)（递归栈，最坏 O(n)）

**BFS 层序遍历**：
- 每层遍历完深度 +1
- 时间 O(n)，空间 O(n)（队列最多存 n/2 个节点）

**相关题**：二叉树最小深度、平衡二叉树、二叉树直径。
