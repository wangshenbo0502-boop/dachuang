# 校招面试综合指南

## 一、备面时间线

| 阶段 | 时间 | 关键行动 |
|------|------|----------|
| 大三上学期 | 9-12月 | 确定求职方向、补齐核心技能、开始做项目、刷 LeetCode 简单题 |
| 大三寒假 | 1-2月 | 准备简历、系统刷 LeetCode 中等题（100道）、复习计算机基础（OS/网络/数据库） |
| 大三下学期 | 3-5月 | 投递暑期实习、参加笔试面试、总结面经、持续刷题 |
| 大三暑假 | 7-8月 | 实习积累经验、补强短板、刷 LeetCode 困难题 |
| 大四上学期 | 9-11月 | 秋招正式投递、集中面试、拿 Offer 对比、签三方 |
| 大四下学期 | 3-5月 | 春招补录、最后机会冲刺 |

## 二、典型面试流程（3-4轮）

| 轮次 | 名称 | 内容 | 时长 |
|------|------|------|------|
| 第1轮 | 笔试/在线测评 | 编程题（LeetCode 中等）+ 选择题（计算机基础） | 60-120 分钟 |
| 第2轮 | 技术一面 | 项目深挖 + 基础知识 + 手写代码（1-2道） | 45-60 分钟 |
| 第3轮 | 技术二面 | 更深入的底层原理 + 系统设计（校招简单版）+ 算法题（1-2道） | 45-60 分钟 |
| 第4轮 | HR 面 | 职业规划、薪资期望、软素质考察 | 30 分钟 |

## 三、行为面试题库

> **答题黄金法则：STAR 方法** — Situation（情境）→ Task（任务）→ Action（行动）→ Result（结果）

### 高频行为面试题

**Q1: 请做一下自我介绍**

> 控制在 1-2 分钟，按"基本信息 + 技术栈 + 1个亮点项目 + 求职动机"的结构。

**Q2: 你最大的优点和缺点分别是什么？**

> 优点说技术相关的（学习能力强/代码规范/善于调试），缺点说真实但不致命的（公开演讲经验少/需求理解有时需要多次确认）+ 改进措施。

**Q3: 你在项目中遇到的最大技术挑战是什么？如何解决的？**

> 用具体技术细节说明，体现问题分析→方案对比→落地解决的全过程。

**Q4: 如果团队中有人代码质量很差，你会怎么处理？**

> 先私下沟通了解原因→建议 Code Review→分享最佳实践→不要直接在公开场合批评。

**Q5: 你的职业规划是什么？（3-5年）**

> 短期（1-2年）：夯实技术基础，成为团队可靠成员。中期（3-5年）：在某方向深入，能独立负责模块。

**Q6: 为什么选择我们公司？**

> 提前做功课！提到公司的具体技术栈/产品/文化，表达技术方向的匹配。

**Q7: 你还有什么要问我的吗？**

> 一定要准备问题！问团队技术栈/新人培养机制/技术挑战，不要问"我表现怎么样"。

**Q8: 描述一次你和队友意见冲突的经历，怎么解决的？**

> 选一个技术决策分歧案例，重点讲你的解决方式（数据验证/技术调研/妥协与共识）。

## 四、算法笔试准备

### 推荐平台

- **LeetCode**（最核心）
- **牛客网**（国内企业真题多）
- **Codeforces**（进阶训练）

### 最低刷题目标

| 难度 | 数量 | 要求 |
|------|------|------|
| 简单 | 50 道 | 必须秒杀 |
| 中等 | 100 道 | 主流难度 |
| 困难 | 20 道 | 大厂压轴题水平 |

### 高频专题

| 专题 | 重要度 | 典型题目 |
|------|--------|----------|
| 数组与字符串 | 高 | 两数之和、最长回文子串、合并区间 |
| 链表 | 高 | 反转链表、环形链表、合并有序链表 |
| 二叉树 | 极高 | 遍历（前中后序/层序）、最近公共祖先、路径总和 |
| 动态规划 | 极高 | 爬楼梯、背包问题、最长递增子序列 |
| 栈与队列 | 高 | 有效括号、用栈实现队列、滑动窗口最大值 |
| 哈希表 | 高 | 两数之和、字母异位词分组、最长连续序列 |
| 排序与搜索 | 中 | 快排/归并排序、二分查找、搜索旋转排序数组 |
| 回溯算法 | 中 | 全排列、组合总和、N皇后 |
| 贪心算法 | 中 | 跳跃游戏、分发饼干、用最少数量的箭引爆气球 |

### 刷题策略

1. **按专题刷而非按序号刷** — 同一类型连续做 10 道才有效果
2. **不会就马上看题解** — 思考超过 20 分钟没思路就看解析，看完后独立重写一遍
3. **用白板/纸练习手写代码** — 面试时要在无提示的环境下写
4. **重视时间/空间复杂度分析** — 每次写完都要分析
5. **牛客网的 ACM 模式输入输出要提前练习** — 不同于 LeetCode 的函数模式
