# 个人博客系统

## 项目概述

搭建一个完整的个人博客网站，支持文章发布、分类标签、评论功能。这是检验前后端综合能力的经典入门项目。

## 核心功能

- 用户注册/登录（JWT认证）
- 文章发布/编辑/删除/列表（支持Markdown）
- 文章分类与标签
- 评论系统
- 搜索结果高亮
- 响应式布局

## 技术收获

- 理解前后端分离架构
- 掌握用户认证（JWT）
- 学会数据库表设计（用户-文章-评论关联）
- 体验完整开发流程（需求→设计→编码→部署）

## 适合人群

已学完一门框架 + 一门后端语言的初级学生

## 前置技能

- HTML
- CSS
- JavaScript
- SQL基础
- Vue.js 或 React 基础
