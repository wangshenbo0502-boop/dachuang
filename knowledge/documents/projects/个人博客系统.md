# 个人博客系统

## 项目概述

搭建一个完整的个人博客网站，支持文章发布、分类标签、评论功能。这是检验前后端综合能力的经典入门项目。

## 核心功能

- 用户注册/登录（JWT认证）
- 文章发布/编辑/删除/列表（支持Markdown）
- 文章分类与标签
- 评论系统
- 搜索结果高亮
- 响应式布局

## 技术收获

- 理解前后端分离架构
- 掌握用户认证（JWT）
- 学会数据库表设计（用户-文章-评论关联）
- 体验完整开发流程（需求→设计→编码→部署）

## 适合人群

已学完一门框架 + 一门后端语言的初级学生

## 前置技能

- HTML
- CSS
- JavaScript
- SQL基础
- Vue.js 或 React 基础

# 技术难点与面试展开点

博客系统是"麻雀虽小五脏俱全"的全栈练兵项目，要把**超出增删改查**的深度做出来。内容侧：Markdown 渲染（编辑器选型、代码高亮、XSS 防御——渲染富文本时白名单过滤是必考点）、文章草稿/发布状态机、目录自动生成（标题层级解析）。

**性能与 SEO**是博客场景的天然考点：文章列表分页（深分页优化）、阅读量计数（Redis 缓存 + 定时落库，防刷票）、静态资源 CDN 与图片压缩、**SSR/SSG 的 SEO 价值**（Next.js/Nuxt 或传统服务端模板——内容型网站为什么不能用纯 SPA，是前端面试的常客）。

**全栈部署链路**：域名与 HTTPS 证书（Let's Encrypt）、Nginx 反向代理与 gzip、CI/CD 自动部署（push 即上线）、数据库备份策略。这些运维细节恰是校招生稀缺的实战经验，面试中一句"我的博客跑在自己的云服务器上，HTTPS、备份、监控都是我自己配的"价值很高。

**进阶方向**：全文检索（MySQL LIKE → Elasticsearch 的升级故事）、评论系统（二级评论表设计、防灌水）、标签系统的多对多设计。面试高频：XSS 与 CSRF 防御、Markdown 渲染的安全处理、深分页优化、SSR 原理与 SEO 关系、阅读量的并发计数。

# 项目演进路线与推荐资源

**演进路线**：基础版（文章 CRUD + Markdown 渲染 + 响应式样式）→ 进阶版（SEO/SSG、评论与标签、阅读量缓存计数）→ 完整版（HTTPS + CI/CD 自动部署 + ES 全文检索，附上线后的 Lighthouse 性能评分）。

**推荐资源**：MDN（语义化 HTML 与 Web 安全）；OWASP Cheat Sheet（XSS 防御清单）；Next.js/Nuxt 官方文档（SSG 路线）；Vercel 或自有云服务器部署教程（HTTPS 与 Nginx 反代实践）。
