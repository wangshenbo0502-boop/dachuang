# 企业级权限管理系统

## 项目概述

搭建一个企业级的用户角色权限管理系统（RBAC），这是后端开发面试中最常被问到的项目类型。

## 核心功能

- 用户管理（CRUD + 分页 + 搜索）
- 角色管理（角色-权限关联）
- RBAC 动态权限控制
- 操作日志（AOP + 数据库）
- 接口限流
- Swagger 接口文档
- Docker Compose 一键部署

## 技术收获

- 深入理解 RBAC 权限模型
- Spring Security 自定义认证流程
- Redis 缓存用户权限信息
- AOP 实现操作日志
- Docker 容器化部署

## 适合人群

有 Spring Boot 基础、准备找后端工作的同学

## 前置技能

- Java
- Spring Boot
- MySQL
- Redis基础
