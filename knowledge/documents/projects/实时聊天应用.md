# 实时聊天应用

## 项目概述

实现一个支持多人实时聊天的 Web 应用。WebSocket、消息队列、在线状态等是后端面试高频考察点。

## 核心功能

- 多人聊天室（实时消息收发）
- 用户在线状态显示
- 消息历史记录
- 未读消息提醒
- @提及功能
- 消息搜索

## 技术收获

- WebSocket 协议及 Socket.io 实战
- Redis Pub/Sub 实现跨进程消息
- 实时数据同步方案
- 消息持久化策略
