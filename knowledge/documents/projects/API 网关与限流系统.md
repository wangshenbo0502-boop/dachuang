# API 网关与限流系统

## 项目概述

自建一个简易 API 网关，实现路由转发、限流、熔断功能。理解微服务基础设施的核心原理。

## 核心功能

- 动态路由配置
- 令牌桶限流算法
- IP 黑白名单
- 熔断降级
- 请求日志和统计

## 技术收获

- 令牌桶/漏桶限流算法
- 网关在微服务架构中的定位
- Redis 实现分布式限流
- 熔断器模式

## 适合人群

想深入后端基础设施的同学

## 前置技能

- Java
- Redis
- HTTP协议理解
