# 数据分析看板（Dashboard）

## 项目概述

找一个公开数据集，完成数据清洗、分析和可视化，最终呈现为一个交互式的数据分析看板。面试中展示此项目非常有说服力。

## 核心功能

- 数据清洗流程（缺失值/异常值/格式统一）
- 多维度统计指标
- 交互式图表（折线/柱状/饼图/热力图）
- 数据筛选器（按时间/类别/地区）
- 数据导出（CSV/Excel）

## 技术收获

- 真实数据的清洗经验（数据质量从来不会完美）
- Pandas 高级操作（多级索引、透视表）
- 选择合适的图表类型表达数据
- 用 API 提供分析结果给前端

## 适合人群

有 Python 基础、想往数据分析方向发展的同学

## 前置技能

- Python
- Pandas 基础
- SQL基础
