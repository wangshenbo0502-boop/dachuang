# 蔚来汽车

## 公司概况

蔚来是中国新势力造车三强之一，定位于高端智能电动车品牌。蔚来以"Blue Sky Coming"为愿景，致力于打造以用户为中心的智能电动汽车及生活方式品牌。蔚来在换电技术、自动驾驶、用户服务等领域具有显著优势，旗下ES、ET、EC系列产品覆盖SUV和轿车市场。蔚来自动驾驶团队（NIO AD）规模庞大，是公司核心竞争力之一。

- **行业**: 新能源汽车/智能驾驶
- **性质**: 民营企业（新势力造车）
- **品牌定位**: 高端智能电动车
- **核心技术**: 换电网络、NIO AD自动驾驶
- **员工规模**: 数万人（科技人员占比高）

## 主营业务

蔚来汽车业务涵盖整车制造、能源服务、自动驾驶等多个领域：

- **智能电动车**: ES系列SUV、ET系列轿车、EC系列轿跑SUV研发与生产
- **换电网络**: 全球规模最大的换电网络，NIO Power能源服务体系
- **NIO House**: 蔚来中心，用户体验与社区运营
- **自动驾驶(NIO AD)**: 自动驾驶算法研发、数据闭环、芯片适配
- **车机系统**: Banyan智能座舱系统、NOMI智能助手
- **能源服务**: 充电桩、换电站、电池租用服务(BaaS)

## 招聘岗位

蔚来汽车科技岗位需求旺盛，自动驾驶和智能座舱为核心招聘方向：

- **自动驾驶算法工程师**: 感知、决策、规划、控制算法研发
- **C++开发工程师**: 自动驾驶系统、车机系统底层开发
- **Python开发工程师**: 算法工具链、数据平台、仿真系统
- **Java开发工程师**: 后端服务、用户App、业务系统开发
- **大数据工程师**: 自动驾驶数据平台、数据处理、数据湖
- **前端开发工程师**: Web端、车机端HMI、用户界面开发
- **测试开发工程师**: 自动驾驶测试、软件测试、质量保障
- **云原生工程师**: 云平台建设、DevOps、容器化

## 校招情况

蔚来汽车校招薪资在新势力造车中具有竞争力，自动驾驶岗位薪资溢价明显。

| 项目 | 详情 |
|------|------|
| 白菜价 | 26-33K × 15薪 |
| SP薪资 | 36-46K × 15薪 |
| 总包范围 | 39-69万/年 |
| 热门岗位 | 自动驾驶算法、车机开发、大数据 |
| 工作城市 | 上海、北京、合肥、南京、深圳 |
| 学历要求 | 本科及以上，算法岗硕士优先 |

**校招特点**:
- 每年8-9月启动秋招
- 自动驾驶岗位需求量大，薪资最高
- 技术面试轮次多，算法要求高
- 实习转正比例较高
- 有造车或自动驾驶实习经历者优先

## 社招情况

蔚来汽车社招需求旺盛，自动驾驶和智能座舱是重点招聘方向。

- **招聘渠道**: 官网招聘、猎头、内部推荐、脉脉
- **经验要求**: 通常2-5年以上相关经验
- **热门岗位**: 自动驾驶算法专家、系统架构师、大数据专家
- **薪资范围**: 40-100万+/年，根据职级和能力定薪
- **特点**: 看重项目经验和技术深度，面试流程相对较快
- **股票期权**: 核心岗位有股票期权激励

## 技术栈

蔚来汽车技术栈以C++和Python为主，自动驾驶技术栈深度领先。

- **自动驾驶**: C++、Python、ROS/自研框架、深度学习(PyTorch/TensorFlow)
- **车机系统**: C++、Qt、Android、Linux
- **后端服务**: Java、Go、微服务架构
- **大数据**: Spark、Flink、Hadoop、数据湖、实时计算
- **云原生**: Kubernetes、Docker、DevOps工具链
- **AI/ML**: 计算机视觉、感知融合、决策规划、大模型
- **嵌入式**: 嵌入式Linux、MCU、AUTOSAR

## 面试特点

蔚来汽车技术面试深度较大，自动驾驶岗位算法要求高。

| 项目 | 详情 |
|------|------|
| 面试轮次 | 3-4轮技术面 + 1轮HR面 |
| 算法难度 | 中等偏高 |
| 自动驾驶岗 | 算法要求高，需掌握CV/ML基础知识 |
| 工程岗 | 看重系统设计和编码能力 |

**面试特点**:
- 每轮技术面都可能有算法题
- 自动驾驶岗考察计算机视觉、深度学习基础
- 重视项目深挖，会追问技术细节和方案选型
- 系统设计题考察工程能力和架构思维
- 整体技术难度接近互联网大厂水平
- 有自动驾驶或汽车行业经验者优势明显

## 岗位需求变化

蔚来汽车岗位需求随业务发展呈现以下趋势：

- **自动驾驶扩招**: NIO AD团队持续扩张，感知、规划算法岗位需求大
- **智能座舱增长**: 车机系统、智能座舱交互研发需求增加
- **销量带动招聘**: 2026年销量目标上调，带动各部门招聘需求
- **大模型应用**: AI大模型在车机、客服、设计等场景应用，相关岗位扩招
- **换电网络扩张**: 能源服务团队随换电站建设持续扩招
- **海外业务**: 欧洲、东南亚市场拓展，国际化人才需求增加

## 最新招聘动态

- 2026届秋招已启动，自动驾驶岗位开放数量最多
- 上海、北京为主要招聘城市，岗位占比超60%
- 算法岗竞争激烈，SP offer比例约15-20%
- 实习转正通道顺畅，建议提前申请暑期实习
- 新能源汽车行业整体招聘热度持续

## 应聘建议

- **技术准备**: 根据岗位方向深入准备，自动驾驶岗重点复习CV/ML
- **算法准备**: LeetCode中等-困难题熟练，重点练习数组、树、图、动态规划
- **项目准备**: 准备1-2个有深度的相关项目，熟悉技术细节
- **行业了解**: 了解新能源汽车行业趋势和蔚来产品特点
- **面试技巧**: 展现技术热情和学习能力，重视系统设计能力
- **投递策略**: 自动驾驶和智能座舱岗位发展空间大，建议优先考虑
