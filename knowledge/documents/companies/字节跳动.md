# 公司概况

字节跳动（ByteDance）成立于2012年，总部位于北京，是全球估值最高的未上市互联网公司之一，员工总数超过15万人（含全球业务）。公司以"激发创造、丰富生活"为使命，凭借推荐算法起家，打造了抖音、TikTok、今日头条等现象级产品，业务覆盖短视频、信息流、电商、教育、办公协作、游戏、AI等多个领域。

字节跳动是中国互联网工程师文化的代表：扁平化组织、OKR管理、快速迭代、数据驱动。2023年以来，公司将AI大模型提升为最高战略，Seed团队（原字节跳动大模型团队，支撑豆包等产品）成为国内大模型研发的第一梯队力量，豆包App长期位居国内AI助手用户量前列，2026年Seed团队推出并开源了豆包大模型系列（Doubao/Seed系列），在全球开源榜单表现领先。

对求职者而言，字节是国内招聘量最大、对院校背景相对宽容、薪资最激进的互联网大厂：2026校招研发类需求同比增加23%，产品岗Offer数量翻倍；AI方向顶尖人才薪资达到行业天花板水平。

# 主营业务与产品

**抖音集团（中国业务）**：
- **抖音**：国内最大的短视频平台，日活跃用户数亿级；抖音电商是国内增长最快的电商平台之一；本地生活服务与美团正面竞争
- **今日头条**：资讯信息流，推荐算法的发源地
- **剪映（CapCut）**：全球头部视频编辑工具，AIGC功能（智能剪辑、数字人）深度落地
- **番茄小说**：免费网文阅读头部产品
- **飞书（Lark）**：办公协作套件，AI功能（智能伙伴）是迭代重点

**TikTok**：全球最流行的短视频应用（除中国外市场），月活跃用户超15亿，是字节全球化战略的核心资产，也是跨境技术岗位的主要场景。

**AI与豆包**：
- **豆包App**：国内用户量领先的AI助手，集成对话、写作、图像生成、语音通话
- **豆包大模型**：通过火山引擎对外提供API服务，价格战的主要发起者
- **Seed团队**：大模型研发核心力量，涵盖基座模型、多模态、代码、语音等方向；2026年开源的Seed系列模型在国际榜单表现领先，直接对标全球顶尖开源模型
- **即梦AI**：图像/视频生成产品；Coze（扣子）：智能体开发平台

**火山引擎**：企业级技术服务平台（云、大模型服务、视频点播直播），是字节To B的战略入口。

**游戏与教育**：朝夕光年（收缩后聚焦）、大力教育（调整后保留部分产品）、PICO（VR，业务收缩）。

# 财务与经营状况

字节跳动未上市，财务信息主要来自媒体报道：

- **收入规模**：2024年全球收入报道口径超过1500亿美元量级，国际业务（主要是TikTok）收入占比持续提升，增速领先国内业务
- **盈利能力**：媒体报道显示公司整体保持可观盈利，抖音广告与电商是核心利润来源；AI投入（算力采购）显著增加
- **估值**：二级市场股份回购对应的隐含估值约3000亿美元量级，是全球最大的独角兽

对求职者的含义：公司现金流充沛、扩张激进，校招社招规模常年居互联网首位；同时组织调整频繁（游戏、VR等业务经历过收缩），选择业务方向时需关注战略地位（抖音、电商、Seed、火山引擎为当前核心）。

# 技术实力与核心技术

**推荐系统**：字节是全球推荐算法的标杆，抖音的推荐引擎（多目标建模、实时特征、多模态内容理解）是算法工程师最向往的练兵场；相关技术广泛输出至TikTok、番茄等产品。

**Seed大模型**：豆包/Seed系列大模型在国内处于第一梯队，涵盖语言、多模态、语音、代码方向；2026年开源模型在多项基准上对标全球头部开源模型；火山引擎提供全链路大模型服务（训练、推理、Agent平台）。

**大数据与云原生**：内部超大规模数据平台（ByteHouse、内部数仓体系）、字节在Flink/Spark社区贡献量巨大；火山引擎云原生产品线（容器、微服务治理）快速发展。

**多媒体技术**：视频编解码、点播直播、RTC、特效（智能创作）技术处于全球第一梯队——抖音/TikTok的底层能力。

**工程语言**：Go是字节后端绝对主力语言（自研微服务框架Kitex、RPC框架，主导CloudWeGo开源社区），前端React为主力，客户端双端+跨端方案齐全，Rust在基础软件中渗透加深。

# 招聘岗位

**2026届校招**：研发类需求同比增加23%，产品岗Offer数量翻倍。2027届校招及"前沿技术领域人才校招"（面向2027届及以后毕业的同学）已于2026年8月起启动。

**主要技术岗位**：
- 后端开发（Go/Java/Python）：抖音、电商、TikTok、火山引擎、飞书等全线需求
- 前端/全栈（React方向为主）、客户端（iOS/Android/鸿蒙）
- 算法：推荐、搜索、广告、大模型（Seed）、多模态、语音、计算机视觉
- 数据工程与数据分析
- 基础架构：存储、网络、编译器、数据库内核、AI Infra
- 测试开发、安全、SRE

**顶尖人才计划**：
- **Seed大模型人才校招**（seed.bytedance.com）：面向2026年9月-2027年8月毕业的本硕博，方向包括大语言模型、Code Agent算法等；2027届专项约100个名额，优秀应届生和实习生有机会获得"豆包股"激励（豆包相关期权）
- **Top Seed人才计划**：面向全球顶尖博士的研究型人才项目

**薪资标杆**：媒体报道的公开案例显示，Seed部门顶尖博士年薪总包可达200万+（如2025届北邮毕业生228万年包案例），AI顶尖人才薪酬"上不封顶"。

# 校招情况

**流程**：网申 → 测评 → 1-2轮笔试/机试（技术岗） → 3-4轮技术面试 → HR面。字节流程以"快"著称，从投递到Offer通常2-4周；全年滚动招聘（提前批-秋招-补录-春招-暑期实习）。

**院校偏好**：以985/211为主，但字节对院校的宽容度在大厂中最高——技术过硬的双非学生通过内推和实习进入的案例很多。牛客网内推是重要渠道。

**实习**：日常实习全年开放、暑期实习转正率高，"实习生招募量全国最大"是字节常态；AI方向实习（Seed、Flow）竞争激烈。

**工作地点**：北京（总部，岗位最多）、上海（游戏、电商、AI）、深圳、杭州（抖音电商）、成都、广州等。

**注意**：字节Offer发放量大但部门间差异明显；入职后Base和业务方向可能与面试部门有调整，签约前建议与HR确认清楚业务归属。

# 社招情况

社招需求常年旺盛，方向集中在：
- **AI/大模型**：Seed（基座模型、推理优化、多模态）、AI应用（豆包、扣子、即梦）、AI Infra——薪资溢价最高的方向
- **抖音电商与本地生活**：交易、履约、算法岗位（与美团、阿里竞争的业务前线）
- **TikTok与国际业务**：全球化架构、多语言算法、安全与合规
- **火山引擎**：云产品研发、解决方案

社招职级：1-1（校招起点）至1-2（高级）、2-1/2-2（资深/专家）、3-1以上（总监级）；晋升"看能力不看资历"，年轻化晋升是大厂中最快的。薪酬结构以"高现金+期权"著称，跳槽溢价空间大。

# 技术栈

**后端**：Go（主力，自研框架Kitex/Hertz，CloudWeGo开源）、Java（电商/交易）、Python（算法与服务）、Rust（基础软件渗透中）。
**前端**：React（主力）、TypeScript、Modern.js（自研框架）、Semi Design组件库。
**客户端**：Swift/Kotlin、跨端引擎、鸿蒙适配。
**数据**：Flink（核心贡献者）、Spark、ClickHouse/ByteHouse、Kafka类消息队列、Hive数据仓。
**AI**：PyTorch、自研训练框架、veRL（强化学习开源框架）、TensorRT/vLLM推理栈、Ray。
**基础设施**：Kubernetes体系、自研IDC与网络、混沌工程。

# 面试特点

| 项目 | 详情 |
|------|------|
| 面试轮次 | 3-4轮技术面 + 1轮HR面 |
| 编码考核 | 高，每轮技术面必考算法（LeetCode Medium为主，偶有Hard） |
| 项目深挖 | 高，追问到源码级别与线上指标 |
| 八股比重 | 中高，OS/网络/数据库基础必考，Go岗考语言底层（GMP调度、GC） |

**经典考察点**：
- 后端：Go GMP调度与GC、channel底层、MySQL索引与MVCC、Redis缓存一致性、Kafka消息可靠性、分布式锁与幂等
- 算法：LeetCode Hot100 + 字节高频题单（牛客"字节高频"专题）；概率题与智力题常见
- 系统设计：短链、Feed流、秒杀、消息系统
- 前端：React Fiber与Hooks原理、事件循环、性能优化指标

**面试文化**：字节面试强调"当场写代码"，手撕不过关基本一票否决；面试官喜欢追问底层原理与量化指标；整体节奏快、反馈快。

# 薪资福利

**校招薪资（技术岗，综合牛客/OfferShow等社区爆料，仅供参考）**：

| 类型 | 薪资水平 |
|------|---------|
| 实习 | 400-500元/天 |
| 普通研发Offer | 月薪约25K-40K × 15-18薪 |
| 算法/大模型Offer | 总包显著高于研发均值，SP/SSP常见 |
| Seed顶尖人才 | 年包百万级起步，公开案例达228万 |

字节是"现金为王"的薪酬结构：现金部分在大厂中最高，另有期权授予（部分岗位）；三餐、下午茶、房补（北京）、健身房、年度体检等福利齐全。

**工作强度**：大小周已取消，但整体节奏仍是大厂中最快的一档；核心业务（抖音、电商、Seed）加班强度高。

# 办公地点

- **总部**：北京（海淀区知春路、大钟寺等多个园区）
- **主要研发中心**：上海（漕河泾/杨浦，游戏/AI/电商）、深圳、杭州（抖音电商）、成都、广州、武汉、南京等
- **海外**：新加坡（TikTok）、美国、欧洲、东南亚、日本等全球120+城市办公室

北京岗位数量与技术浓度最高；上海AI与国际化岗位增长最快。

# 岗位需求变化与最新动态

- **AI人才争夺最前线**：Seed团队以"TOP级薪酬"全球争抢AI博士；"豆包股"长期激励计划（2025年Q4试点）将AI人才与豆包业务深度绑定；2027届Seed专项约100名额已启动。
- **研发需求扩张**：2026校招研发类需求+23%，产品岗Offer翻倍，是大厂中扩张最激进的。
- **开源影响力提升**：CloudWeGo、veRL、UI-TARS、Doubao/Seed开源模型等使字节成为开源社区活跃力量，开源贡献成为简历亮点。
- **业务竞争前线**：本地生活（对美团）、电商（对阿里）、AI助手（对DeepSeek/Kimi）三条战线均需大量人才。
- **国际化与合规**：TikTok在美国等市场的政策不确定性持续，相关岗位需评估风险。

# 应聘建议

**技术准备**：
- 算法是字节面试的生命线：LeetCode Hot100 + 牛客字节高频题单，做到Medium 10分钟内写出Bug-free代码
- Go后端岗准备GMP、GC、channel底层；Java岗准备JVM与并发
- 算法岗突出竞赛（ACM/Kaggle）、论文、大模型项目；关注Seed开源项目（可贡献PR作为敲门砖）
- 系统设计准备字节特色场景：Feed流、短视频推荐、直播间高并发

**投递策略**：
- 全年滚动投递，实习转正是最稳路径；提前批不影响正式批投递
- 第一志愿选择扩张业务（Seed、电商、火山引擎），通过率更高
- 多找内推（牛客/脉脉），可加速简历流转

**面试与谈薪**：字节Offer有议价空间，手握竞争Offer可争取SP；确认好业务部门、Base城市与加班强度后再签约。
