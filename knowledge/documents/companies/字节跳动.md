# 字节跳动

## 公司概况

- **行业**: 互联网/内容平台
- **规模**: 超大型（10万+人）
- **目标院校**: 985/211 为主，但技术优秀的双非也有机会

## 招聘重点

- 算法能力（LeetCode 中等-困难）
- 计算机基础扎实
- 项目经验（重深度）
- 学习能力强

## 技术栈偏好

- Go
- Python
- Rust
- React
- 自研框架

## 面试风格

| 项目 | 详情 |
|------|------|
| 面试轮次 | 3-4轮技术面 + 1轮HR |
| 编码考核比重 | 高（每轮技术面必考算法） |
| 项目深挖程度 | 高（会追问到源码级别） |

**面试特点**:
- 手写代码是核心
- 重视计算机基础（OS/网络/数据库）
- 面试官喜欢追问到底层

## 薪资范围

| 类型 | 薪资 |
|------|------|
| 实习 | 400-500元/天 |
| 应届生 | 25k-40k * 15-18薪 |

## 优缺点

### 优势
- 技术氛围极好
- 成长速度快
- 薪资有竞争力
- 内部文档完善

### 劣势
- 工作节奏快/强度大
- 组织调整频繁

## 准备建议

- LeetCode 中等题必须熟练
- 深入理解一个框架的原理
- 准备好几个有深度的项目
- 了解分布式系统基础
