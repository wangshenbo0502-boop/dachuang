# 腾讯

## 公司概况

- **行业**: 互联网/社交/游戏
- **规模**: 超大型（10万+人）
- **目标院校**: 985/211 为主

## 招聘重点

- C++/Go 能力（后台）或 前端能力
- 项目深度
- 沟通表达

## 技术栈偏好

- C++
- Go
- JavaScript/Vue/React
- 自研组件

## 面试风格

| 项目 | 详情 |
|------|------|
| 面试轮次 | 2-3轮技术面 + 1轮HR |
| 编码考核比重 | 中（常考 C++ 相关） |
| 项目深挖程度 | 高 |

**面试特点**:
- 面试体验通常较好
- 重视软素质
- 有群面环节

## 薪资范围

| 类型 | 薪资 |
|------|------|
| 实习 | 400-500元/天 |
| 应届生 | 23k-38k * 16-20薪 |

## 优缺点

### 优势
- 福利顶尖（住房/餐饮/交通）
- WLB 相对较好
- 学习资源丰富

### 劣势
- 部分业务天花板低
- 晋升速度慢于字节拼多多

## 准备建议

- 后台方向重点准备 C++/Go 和网络编程
- 前端方向重视交互体验和性能优化
- 准备一个完整的全栈项目
