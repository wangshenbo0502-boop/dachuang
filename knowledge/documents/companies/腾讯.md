# 公司概况

腾讯（Tencent，港交所股票代码 0700.HK）成立于1998年，总部位于深圳，是中国市值最高的互联网公司之一，也是全球最大的互联网综合服务提供商之一。公司使命是"用户为本，科技向善"，业务覆盖社交、游戏、金融科技、广告、云计算、人工智能等板块，员工总数超过11万人。

腾讯的两大社交基石——微信（WeChat）与QQ，构成了中国最大的社交网络。微信月活跃账户数超过13亿，围绕微信生态生长出的视频号、小程序、企业微信、微信支付，构成了腾讯最核心的商业与技术护城河。游戏业务长期位居全球游戏公司收入榜首，《王者荣耀》《和平精英》以及海外Supercell、Riot Games（英雄联盟开发商）等工作室共同构成全球化的游戏矩阵。

2024年以来，腾讯全面推进AI战略，自研混元大模型持续迭代，推出面向C端的元宝App、ima智能工作台等产品，并将AI能力深度注入微信生态（如微信搜一搜AI问答、元器智能体平台）。按照"回归一个腾讯"的组织思路，2025年腾讯将微信事业群与平台与内容事业群整合，进一步集中力量发展AI与视频号生态。

对计算机专业求职者而言，腾讯是国内校招规模最大、岗位方向最全、培养体系最成熟的互联网大厂之一，技术岗覆盖后端、前端、客户端、测试、运维、算法、安全、大数据等全链条方向。

# 主营业务与产品

腾讯的业务可以划分为六大板块：

**社交与内容**：微信、QQ、视频号、公众号、小程序生态，以及腾讯视频、腾讯新闻、腾讯音乐等数字内容产品。微信生态是腾讯技术含金量最高的业务之一，海量并发、稳定性、支付安全等工程挑战均为行业顶级。

**网络游戏**：腾讯游戏是全球收入最高的游戏业务，自研+代理双轮驱动。自研工作室群（天美、光子、魔方等）+海外控股工作室（Riot、Supercell、Digital Extremes等），技术方向涵盖游戏引擎、服务器架构、反作弊、AI NPC等。

**金融科技**：微信支付、理财通、腾讯微保等。金融科技对系统稳定性、资金安全、合规性要求极高，是后端工程师和风控算法人才的重要去向。

**广告与营销服务**：腾讯广告（腾讯智慧零售、优量汇），依托微信、视频号、小程序流量，是推荐算法、计算广告方向的核心业务场景。

**云与企业服务**：腾讯云是国内头部云厂商，提供IaaS/PaaS/SaaS全栈服务，腾讯会议、腾讯文档、企业微信等明星产品均属于该板块。云与AI基础设施（TI平台、混元大模型服务）是近年招聘扩张的重点。

**人工智能**：混元大模型（Hunyuan）系列持续迭代，覆盖文本、多模态、图像生成、视频生成（混元视频生成模型开源后在GitHub获广泛关注）、3D生成等方向；C端产品元宝App与DeepSeek、Kimi等正面竞争；游戏AI（绝悟、绝艺）长期处于行业前沿。

# 财务与经营状况

腾讯于港交所上市，按季度披露财报。近年营收结构持续优化，主要特点包括：

- **收入规模**：年度营收超过6600亿元人民币（2024年报），毛利率在高质量收入（视频号广告、搜一搜、小游戏平台服务费）带动下持续提升。
- **利润引擎**：视频号广告、微信搜一搜、金融科技服务费构成高毛利增长曲线；游戏业务保持稳定基本盘。
- **AI投入**：资本开支大幅增加，主要用于GPU采购与AI基础设施（腾讯云智算中心）建设，管理层明确"AI是未来十年最大机遇"。
- **股东回报**：持续进行大规模回购，是港股回购力度最大的公司之一。

求职者关注点：腾讯盈利能力强、现金流充沛，薪酬福利体系稳定，校招与实习招聘规模常年保持在大厂第一梯队，2026-2027届校招官网显示开放岗位300余个。

# 技术实力与核心技术

**混元大模型体系**：自研通用大模型系列，采用MoE（混合专家）架构路线，支持长上下文与多模态。混元视频生成、混元3D等开源模型在国际开源社区具有较高影响力。

**海量社交架构**：微信后端承载十亿级同时在线，是业界公认的分布式系统天花板级实践场景，涉及自研协程框架、微服务治理、存储系统（自研KV）等。

**游戏技术**：自研引擎、帧同步与状态同步技术、全球同服架构、AI NPC与AIGC内容生产管线。

**云与AI基础设施**：腾讯云星脉网络、太极智能算力平台、向量数据库等AI Infra能力，支撑自研与外部客户的大模型训练与推理。

**开源贡献**：腾讯开源了Tars、DCache、TubeMQ、混元系列模型等项目，在GitHub上维护着大量活跃仓库，参与开源贡献是校招加分项。

# 招聘岗位

腾讯2027届校招（面向2026年1月-2027年12月毕业的学生）官网显示开放岗位300余个，主要类别包括：

**技术大类（招聘量最大）**：
- 后端开发（C++/Go/Java方向）：微信、ieg游戏、金融科技、腾讯云等部门均有大量需求
- 前端开发/全栈：Web前端、小程序生态、Node.js方向
- 客户端开发：iOS/Android/PC/鸿蒙方向，微信与IEG是主力
- 技术运营/运维/SRE：云计算与基础架构方向
- 测试开发：质量效能方向
- 数据分析与数据工程：广告与金融科技业务
- 算法类：搜索、推荐、大模型、强化学习、多媒体、安全等方向（校招页面重点列出智能体、强化学习、搜索、推荐、模型等技术方向）

**产品与职能**：产品经理、产品运营、HR、财经线、法务、市场等。

**顶尖人才计划**：
- **青云计划**：腾讯面向顶尖博士/天才少年的最高级别校招通道，级别高于SP/SSP，年薪60万元起步，配备专属导师和核心项目资源。
- **T Star（腾讯星）**等技术专项计划，面向有竞赛/论文/开源成果的顶尖学生。

# 校招情况

**招聘规模与节奏**：腾讯校招分为提前批（大三暑假前后的实习生招聘及提前批）和正式批（秋招8-10月、春招3-4月）。实习转正是腾讯最重要的校招入口之一，"日常实习+暑期实习+转正"路径被广泛推荐。

**目标院校**：2026校招媒体披露的目标大学约33所，以985/211为主，但非目标院校学生通过实习和内推仍有大量机会。

**岗位方向**：2026届计算机专业学生的技术方向可覆盖后端、前端、客户端、测试、数据、运维等6个大方向。

**招聘渠道**：腾讯校招官网 join.qq.com、腾讯招聘官网 careers.tencent.com、牛客网企业主页（nowcoder.com/enterprise/138）。

**风险提示**：2026年春招期间出现过腾讯对部分26届校招生Offer毁约的情况（主要涉及部分海外院校、未签三方协议的应届生）。建议求职者拿到Offer后尽早签订三方协议保障自身权益，并保持多线求职。

# 社招情况

腾讯社招常年开放，需求集中在：

- **AI相关**：大模型训练/推理、AI应用工程、AI Infra、多模态算法——社招最热的方向，薪资溢价明显
- **微信生态**：视频号、小程序、搜一搜相关工程与算法岗位
- **游戏技术**：引擎、图形、服务器架构、反外挂
- **腾讯云**：云原生、数据库、网络、安全方向

社招职级体系：腾讯于2024年改革职级体系，专业职级简化（大致对应原T序列），从校招5级起步，6级为资深工程师，7级以上为专家/组长级别。社招进入通常要求5级以上并有相应年限经验，薪酬与职级强相关。

# 技术栈

**后端**：C++（微信/IEG大量使用）、Go（云与基础架构主力语言）、Java（广告、金融科技等业务系统）、Python（算法与工具链）；Protobuf、gRPC、自研RPC与服务治理框架。

**前端**：JavaScript/TypeScript、React、Vue、小程序框架、Node.js、跨端方案。

**客户端**：iOS（OC/Swift）、Android（Java/Kotlin）、C++跨端框架、鸿蒙ArkTS。

**数据与算法**：Hadoop/Spark/Flink大数据体系、TensorFlow/PyTorch、自研深度学习框架与推理加速、向量数据库。

**基础设施**：腾讯云TKE（Kubernetes）、Docker、自研容器与混沌工程体系、DevOps工具链（腾讯工蜂/织云等）。

# 面试特点

| 项目 | 详情 |
|------|------|
| 面试轮次 | 一般2-3轮技术面 + 1轮HR面，部分岗位有笔试/机试 |
| 编码考核 | 中高，常考数据结构与算法（LeetCode Medium为主）+ 语言底层（如C++虚函数、Go调度器） |
| 项目深挖 | 高，追问项目动机、技术选型、量化成果 |
| 八股比重 | 中，操作系统/网络/数据库基础必考 |

**面试风格**：腾讯面试体验在各大厂中口碑较好，面试官注重候选人的思考过程与软素质；部分非技术岗位设有群面环节。后端方向对C++/Go语言功底与网络编程要求较高；算法方向重视论文与竞赛经历。

**经典考察点**：
- 后端：进程线程协程、TCP/HTTP、MySQL索引与事务、Redis数据结构与缓存策略、分布式锁与一致性
- 算法：LeetCode Hot100为主，偶有Hard；概率与智力题
- 系统设计（高级岗）：短链接、秒杀、 Feed流、IM系统

| 类型 | 薪资水平 |
|------|---------|

**福利**：住房补贴（一线城市）、免费班车与餐饮/餐补、年度体检、补充商业保险、股票期权（部分级别）、30天全薪年假基础上的假期体系、学习资源（腾讯学院）。

# 办公地点

- **总部**：深圳南山腾讯滨海大厦、前海腾讯数码大厦等
- **主要研发中心**：广州（微信总部）、北京、上海、成都、武汉、西安、南京、重庆、长沙等
- **海外**：新加坡、美国、荷兰、韩国、日本等办公室（国际化业务与游戏工作室）

城市选择上，深圳与广州（微信）是技术含量与岗位数量的第一梯队；成都、武汉等新一线城市工作生活平衡更好。

# 岗位需求变化与最新动态

- **AI岗位扩张**：2026-2027届校招官网重点展示智能体、强化学习、搜索、推荐、大模型等方向，AI相关技术岗占比显著提升。
- **组织整合**：微信与平台内容事业群整合后，视频号、搜一搜、AI助手方向的用人需求集中释放。
- **资本开支转向AI基础设施**：混元大模型训练与推理平台（元宝、ima）持续扩容，AI Infra岗位（训练框架、推理优化、算力调度）需求上升。
- **游戏业务全球化**：海外工作室与全球同服架构带来国际化人才需求。
- **注意**：2026年春招出现的部分26届Offer毁约事件提示应届生注意签约节奏与三方协议保护。

# 应聘建议

**技术准备**：
- 后台方向重点准备C++/Go语言底层（内存管理、并发模型）与网络编程，配合LeetCode Hot100刷题
- 前端方向重视工程化（构建、性能优化）与框架原理（React/Vue响应式与 diff）
- 算法方向突出论文/竞赛（ACM/Kaggle），准备好数学基础（线代、概率、优化）
- 系统设计提前了解微信/视频号场景的高并发方案（Feed流、消息队列、缓存架构）

**实习路径**：大三上学期起关注日常实习，暑期实习表现优秀可获转正，是进入腾讯性价比最高的路径。

**简历与面试**：
- 项目描述量化成果（QPS、延迟、收益数据），突出与目标部门业务的匹配度
- 面试中主动展示对腾讯产品（微信生态、混元大模型、游戏）的技术理解
- 准备好反问环节（团队方向、转正机制、培养体系）

**职业发展考量**：
- 腾讯职级体系成熟、培养资源丰富，适合追求稳定成长与长期发展的候选人
- 微信、IEG、混元大模型是资源与成长速度最优的核心业务方向
- WLB相对字节、拼多多更好，但核心部门（微信）节奏同样紧张
