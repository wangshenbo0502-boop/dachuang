# 公司概况

小鹏汽车是中国领先的智能电动汽车企业，总部位于广东省广州市。公司成立于2014年，由何小鹏、夏珩、何涛等人联合创立，是中国造车新势力的代表企业之一。小鹏汽车以"未来出行的探索者"为使命，主打智能驾驶和智能网联技术，是国内最早布局全栈自研自动驾驶的车企之一。

小鹏汽车在美股（NYSE: XPEV）和港股（HK: 9868）双重上市，是国内资本实力最雄厚的新势力车企之一。公司在广州、北京、上海、深圳等地设有研发中心，在肇庆、广州、武汉等地建有智能制造基地。小鹏汽车坚持科技创新驱动，研发投入占比在国内车企中位居前列。

在智能驾驶领域，小鹏汽车的XNGP（Xpeng Navigation Guided Pilot）系统是国内最先实现城市NGP全场景落地的高阶智能驾驶系统之一，凭借全栈自研能力和快速迭代，在智能驾驶第一梯队中占据重要位置。此外，小鹏还布局了飞行汽车（小鹏汇天）和机器人（小鹏鹏行）等前沿科技领域，展现了浓厚的科技公司基因。

- **行业**: 新能源汽车/智能驾驶/出行科技
- **性质**: 民营企业（新势力造车，美股/港股上市）
- **总部**: 广州
- **研发中心**: 广州、北京、上海、深圳
- **生产基地**: 肇庆、广州、武汉
- **员工规模**: 数万人（研发人员占比高）
- **公司地位**: 中国智能驾驶第一梯队，科技属性最强的新势力车企

# 主营业务与产品

小鹏汽车围绕智能出行生态布局，产品和业务覆盖多个领域：

- **智能电动汽车**: P7系列（中大型轿车）、G9/G6系列（SUV）、X9（MPV）、MONA系列（入门级），覆盖从10万到50万价格带
- **自动驾驶（XNGP）**: 全栈自研高阶智能驾驶系统，支持城市NGP、高速NGP、自动泊车等全场景
- **智能座舱**: Xmart OS车载智能系统，全场景语音交互、AI大模型助手
- **小鹏汇天**: 飞行汽车研发制造，探索未来低空出行方式
- **小鹏鹏行**: 人形机器人研发，探索智能机器人在家庭和工业场景的应用
- **补能网络**: 超级充电站、S4/S2超充桩，覆盖全国主要城市
- **小鹏智驾**: 自动驾驶软件服务订阅，软件收入是重要增长极

小鹏汽车的核心竞争力在于智能驾驶全栈自研能力，从感知、决策到控制算法均自主研发，数据闭环体系完善。

**校招薪资**（2026届参考）：
- 自动驾驶算法岗（硕士）：25-40K × 14-16薪，年薪35-64万
- 软件开发岗（硕士）：22-32K × 14-16薪，年薪31-51万

- 北京和广州是最大的招聘城市，上海和深圳次之
- 算法岗竞争激烈，薪资溢价明显
- 暑期实习转正率约50-70%，建议尽早申请实习
- 面试注重技术深度和工程能力
- 技术氛围浓厚，适合想深耕智能驾驶领域的同学

# 社招情况

小鹏汽车社招需求大，自动驾驶和AI领域持续高薪挖人。

- **招聘渠道**: 官网招聘、猎聘、BOSS直聘、内推、猎头
- **经验要求**: 通常2-5年相关工作经验，专家岗位要求5年以上
- **薪资范围**: 中级工程师30-60万，高级工程师60-120万，技术专家120-200万+
- **热门方向**: 自动驾驶感知/规划、大模型算法、端到端智驾
- **职级体系**: P序列（专业岗）和M序列（管理岗），P5-P9为主体
- **招聘节奏**: 业务扩张期节奏快，核心岗位常年招聘
- **跳槽价值**: 小鹏自动驾驶背景在行业内认可度高，跳槽溢价明显

社招流程：简历筛选 → 技术笔试（部分岗位）→ 2-3轮技术面 → 交叉面/总监面 → HR面 → 录用。流程效率较高，通常2-3周完成。

# 面试特点

小鹏汽车技术面试注重工程能力和算法基础，自动驾驶岗难度较高。

| 项目 | 详情 |
|------|------|
| 面试轮次 | 3-4轮技术面 + 1轮HR面 |
| 算法难度 | 中等偏难（算法岗较难） |
| 工程考察 | 重工程实践和代码质量 |
| 业务理解 | 注重对智能驾驶和汽车行业的理解 |

**面试特点详解**：
- **算法考核**：每轮技术面都有算法题，自动驾驶岗难度较高，涵盖数据结构、动态规划、图论等。LeetCode中等和困难题为主
- **技术深挖**：面试官会针对简历中的项目深入追问，考察对技术细节的掌握程度
- **系统设计**：高级岗位会考察系统设计，如自动驾驶系统架构、高并发数据平台等
- **代码质量**：注重代码规范性、鲁棒性和可维护性
- **专业知识**：自动驾驶岗考察计算机视觉、深度学习、机器人学等专业知识
- **项目经历**：看重实际项目经验和解决问题的能力
- **整体风格**：技术氛围浓厚，面试官多为技术出身，沟通直接

建议候选人重点准备：C++/Python基础、算法题（LeetCode 300+）、深度学习/计算机视觉基础、自动驾驶相关知识、项目经历深度准备。

# 应聘建议

- **技术准备**:
  - 算法：LeetCode中等和困难题熟练，重点练习数组、链表、树、图、动态规划
  - C++：自动驾驶岗必须精通C++，熟悉内存管理、多线程、STL
  - 深度学习：计算机视觉、Transformer、BEV、Occupancy等前沿技术
  - 项目：准备1-2个有深度的技术项目，能讲清楚方案细节和技术难点

- **面试技巧**:
  - 算法题写之前先沟通思路，注意时间和空间复杂度分析
  - 项目经历要深入准备，能回答细节问题和技术选型考量
  - 体现对智能驾驶的热情和理解，展示学习能力
  - 提问环节可以询问团队技术方向和智驾路线规划

- **投递建议**:
  - 优先投递自动驾驶和大模型方向，发展空间大、薪资高
  - 北京自动驾驶团队规模最大，岗位最多
  - 内推效率高，通过校友或社交平台寻找小鹏员工内推
  - 暑期实习转正率高，建议尽早申请实习机会

- **适合人群**:
  - 对智能驾驶和AI有浓厚兴趣，想深耕这个领域
  - 技术驱动型人才，喜欢钻研技术难题
  - 能接受创业公司的快节奏和高成长
  - 希望在前沿科技领域快速成长
  - 看好新能源汽车和智能出行的长期发展前景
