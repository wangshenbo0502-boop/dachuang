# 公司概况

月之暗面（Moonshot AI）成立于2023年4月，是一家以长文本处理为核心差异化优势的中国人工智能大模型公司。公司创始人杨植麟，毕业于清华大学，后于卡内基梅隆大学取得博士学位，曾在谷歌大脑和OpenAI从事前沿AI研究，是大模型领域具有国际视野的顶尖科学家。总部位于北京，在杭州设有研发团队。

公司自成立以来，凭借在长上下文大模型领域的持续突破，迅速成长为中国AI大模型第一梯队的核心玩家。2026年7月发布的Kimi K3模型，以2.8万亿参数成为全球最大的开源大模型，标志着月之暗面从闭源路线全面转向开源生态，也奠定了其在全球AI开源社区的标杆地位。

月之暗面的核心定位是"让信息更高效地流动"，围绕长文本理解与生成构建技术壁垒。公司产品覆盖C端智能助手、B端开放平台API及企业级解决方案，服务互联网、金融、制造、教育、医疗等多个行业。截至2026年6月，产品已进入全球200多个国家和地区，海外付费用户增长400%。

# 主营业务与产品

月之暗面的业务布局围绕"长文本+大模型"双轮驱动，形成了C端产品、B端API和企业版三条核心产品线。

**Kimi智能助手（C端）**：面向个人用户的AI智能助手，以超长上下文处理能力为核心卖点，支持百万级Token文档阅读、长文写作、代码生成、数据分析等功能。2026年7月K3模型发布后，由于用户请求量远超预期，公司曾暂停C端新用户订阅以保障付费用户体验，后续将拆分Kimi主权益和Kimi Code权益，以更精准匹配算力资源。

**Kimi开放平台（B端API）**：面向开发者和企业客户的API服务平台，提供模型调用、微调、部署等全链路能力。API收入已占公司整体收入的70%以上，且占比持续走高，是月之暗面最核心的商业化支柱。K3模型输出定价为100元/百万tokens，与全球顶尖模型对标，体现了公司对技术能力的定价信心。

**Kimi企业版**：面向中大型企业的私有化部署和定制化解决方案，覆盖金融、制造、教育、医疗等重点行业。企业版支持本地部署、专属微调、数据安全隔离等企业级需求，帮助客户构建行业专属的AI能力。随着ARR突破3亿美元，企业客户贡献了重要的收入增量。

# 融资与估值

月之暗面的融资历程堪称AI行业的"速度奇迹"，从2025年底约43亿美元估值起步，到2026年7月冲击500亿美元目标，半年内估值暴涨超过10倍。

**关键融资节点**：
- 2025年11月：市场传言估值约40亿美元
- 2026年3月：估值3个月翻4倍至180亿美元
- 2026年5-6月：完成200亿美元估值融资交割
- 2026年6月中旬：新一轮融资启动，投前估值315亿美元
- 2026年7月：K3发布后，目标估值区间300-500亿美元
- 2026年8月（计划）：启动Pre-IPO融资谈判，目标投前500亿美元

截至2026年7月，公司累计融资超376亿元人民币。公司已启动港股IPO筹备，最快预计6个月内登陆香港资本市场。当前正在拆除红筹架构，搭建合资架构，既方便合规上市，也不影响继续引入境外美元资金。

**商业化支撑**：ARR（年度经常性收入）呈现爆炸式增长——2026年3月突破1亿美元，5月突破2亿美元，6月中旬突破3亿美元。这一收入曲线被市场机构称为"初现Anthropic早期商业化阶段的特征"。高盛和摩根士丹利的研究报告将Kimi K3视为中国模型走向定价权的新节点。

# 技术实力与核心技术

月之暗面的技术实力集中体现在长上下文处理、MoE架构和代码智能三大方向。

**Kimi K3大模型**：2026年7月17日发布，是全球首个2.8万亿参数的开源大模型。采用MoE架构（896个专家中激活16个），原生支持100万token上下文窗口和视觉理解。在Frontend Code Arena前端代码竞技场以1679分登顶，超越Claude Fable 5（1631分）和GPT-5.6 Sol（1618分），成为首个在该榜单夺冠的开源模型。

**KDA混合线性注意力机制**：Kimi Delta Attention（KDA）是月之暗面自研的核心注意力机制，配合Attention Residuals（注意力残差）技术，让信息在更长序列和更深模型中流动得更顺畅，是实现百万级上下文的关键技术底座。

**三大基础设施开源**：K3发布的同时，公司同步公开了三项关键基础设施——MoonEP（MoE训练的冗余专家负载均衡技术）、FlashKDA（注意力机制的高性能算子，prefill速度提升1.72至2.22倍）、AgentENV（大规模沙箱环境生成系统，用于Agent训练和评估）。

**成本效率优势**：K3在BrowseComp上单任务花费2.03美元（准确率91.2%），成本仅为GPT-5.6 Sol的一半；在GDPval-AA v2上成本不到Claude Fable 5的四成。通过KDA注意力机制、量化平衡算法、流水线并行等技术，整体扩展效率较K2提升约2.5倍。

# 校招情况

月之暗面2026届校园招聘呈现"规模大、门槛高、成长快"的特点。作为估值飙升的头部AI独角兽，公司对应届生的吸引力持续增强。

**校招规模与岗位**：校招技术岗占比超过80%，以算法工程师和系统工程师为主力招聘方向。长文本算法、推理优化、AI Coding是重点扩招的细分方向。非技术岗主要覆盖产品经理、解决方案和商业分析等。

**校招院校偏好**：技术岗主要面向清华、北大、中科院、上交、浙大、中科大等顶尖院校的计算机、软件、电子信息等相关专业。数学、物理等基础学科背景的候选人也受到重视，特别是有顶会论文（NeurIPS、ICML、ICLR等）发表经历的博士候选人。

**校招流程**：一般包括网申→在线笔试→技术面试（2-3轮）→HR面试→Offer发放。技术面试深度大，注重考察算法功底、模型理解和工程实践能力。面试中常涉及大模型架构理解、长上下文优化、分布式训练等前沿话题。

**培养机制**：月之暗面采用"新人直接上核心项目"的培养模式，区别于传统大厂让校招生从边缘业务过渡的做法。应届生有机会直接参与预训练、推理优化等核心攻坚任务，成长速度快但压力也较大。

社招是月之暗面人才补充的重要渠道，尤其在中高级技术专家和商业化团队建设方面。2026年社招量同比增长显著，反映了公司业务快速扩张的用人需求。

**社招重点方向**：
- 资深/专家级算法工程师：要求有大模型预训练、微调或推理优化的一线经验
- 大模型架构师：负责系统架构设计与技术选型
- 企业解决方案专家：具备行业Know-how，能主导大客户方案落地
- 商业化运营：负责API平台生态建设与开发者增长
- 技术中台负责人：支撑研发效能与工程体系升级

**社招人才来源**：主要从头部互联网公司（字节、阿里、腾讯、百度）、AI创业公司和海外科技企业引进。具有开源社区影响力或顶会论文产出的候选人尤为抢手。

**社招薪酬竞争力**：对标一线大厂P7-P9级别，核心算法岗和专家岗有显著溢价。期权是社招核心人才薪酬包的重要组成部分，考虑到公司估值的快速攀升，期权价值成为吸引高端人才的关键因素。

社招面试流程通常为3-4轮技术面+1轮HR面+1轮高管面，对技术深度和项目经验要求较高，部分核心岗位需要完成代码实操作业或系统设计题。

# 面试特点

月之暗面的面试以"技术深度大、前沿性强、节奏快"为主要特点，是AI大模型领域难度较高的面试之一。

**技术面试核心特点**：
- **算法功底要求高**：不论是算法岗还是工程岗，都要求扎实的机器学习和深度学习基础。面试常涉及Transformer架构细节、注意力机制变种、MoE原理等深度问题。
- **长上下文专题考察**：作为公司核心差异化方向，长文本处理相关问题在面试中出现频率很高，包括位置编码、注意力复杂度优化、长序列推理等。
- **代码实战比重高**：算法岗通常需要现场手写模型实现或算法题，工程岗需要完成系统设计或代码优化题目。Coding能力是重点考察项。
- **前沿技术理解**：面试会涉及最新的大模型研究进展，考察候选人的技术视野和学习能力。对开源社区的关注度和贡献度也是加分项。

**面试流程与节奏**：
- 整体流程较快，从投递到Offer通常2-4周完成
- 技术面2-4轮，由浅入深，最后一轮常由技术负责人或创始团队成员把关
- 重视项目深挖，会针对简历中的项目经历进行多轮追问，考察真实贡献和技术深度
- 部分岗位需要完成Take-home作业，如模型复现、系统设计等

**面试偏好的候选人特质**：自驱力强、对大模型技术有真正热情、能承受快速迭代的工作节奏、具备独立思考和解决复杂问题的能力。公司文化偏向工程师导向，崇尚技术实力和结果导向。
