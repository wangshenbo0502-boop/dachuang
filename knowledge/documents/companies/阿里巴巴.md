# 公司概况

阿里巴巴集团（NYSE: BABA / HKEX: 9988）创立于1999年，总部位于杭州，是全球领先的电子商务与云计算企业。使命"让天下没有难做的生意"。经过2023年"1+6+N"组织变革，形成淘天集团、阿里云智能、阿里国际数字商业（AIDC）、菜鸟、本地生活、大文娱等多业务集团并行的架构；2025年以来重新强调"用户为先、AI驱动"战略。2026年，阿里成立千问事业部，整合夸克、千问App、AI硬件等业务，目标是打造AI时代的超级应用入口。

阿里巴巴是国内计算机专业毕业生的传统顶级雇主：阿里云的技术深度、淘天的电商复杂度、通义实验室的科研水平，分别对应工程、业务、算法三类人才的顶级成长场景。2026届秋招发放7000+ Offer，规模居大厂前列。

# 主营业务与产品

**淘天集团（淘宝天猫）**：中国最大的电商平台，涵盖淘宝、天猫、闲鱼等。技术挑战包括超大规模推荐系统（手淘"猜你喜欢"）、双11交易洪峰、商品理解多模态大模型应用。

**阿里云智能**：亚太第一、全球头部云厂商，产品包括飞天云操作系统、PAI机器学习平台、百炼大模型平台、PolarDB/AnalyticDB数据库等。AI基础设施（灵骏智算集群、高性能网络）是当前投入最大的方向。

**通义实验室与千问大模型**：通义千问（Qwen）系列是全球最具影响力的开源大模型家族之一，开源模型在全球的衍生模型数量位居世界前列；千问App、夸克、通义听悟构成C端AI产品矩阵。2026年成立的千问事业部整合千问App、夸克、AI硬件、UC、智能营销、书旗等业务。

**阿里国际数字商业（AIDC）**：速卖通AliExpress、Lazada、Trendyol等，出海业务是增长最快的板块之一，技术需求集中在多语言大模型、跨境供应链、全球支付。

**菜鸟网络**：智慧物流，自动化仓储、无人配送、物流算法。

**本地生活与大文娱**：饿了么、高德、优酷、大麦等。

# 财务与经营状况

阿里在美股与港股两地上市，按季度披露财报：

- **收入结构**：淘天贡献最大收入与利润；云智能收入重回双位数增长，AI相关产品收入连续多季度三位数增长；国际数字商业增速领先。
- **AI资本开支**：2025年以来宣布未来三年3800亿元级别的资本开支计划，重点投向云和AI基础设施，直接带动AI Infra岗位需求。
- **开源生态**：Qwen开源模型衍生生态全球领先；Apache基金会顶级项目（RocketMQ、Dubbo、Paimon等）由阿里主导或深度参与，是Java与大数据工程师的"娘家"。

对求职者的含义：云+AI是明确的扩张主线，2026届校招AI相关岗位占比超六成，云智能、国际业务、千问事业部是HC最充足的板块。

# 技术实力与核心技术

**飞天操作系统**：中国自研云操作系统，调度百万级服务器；盘古存储、洛神网络、神龙计算构成长期技术壁垒。

**通义千问大模型**：Qwen系列覆盖0.5B至万亿级参数，包含闭源旗舰与Apache 2.0开源系列、Qwen-VL/Omni/Coder等衍生模型；魔搭ModelScope是国内最大的模型开源社区。

**电商技术**：世界级推荐系统（召回-粗排-精排-重排全链路）、双11交易洪峰（峰值数十万级TPS）、单元化架构与异地多活。

**中间件与大数据**：Dubbo、RocketMQ、Paimon（流式数据湖）、Flink（阿里是国内最大贡献者之一）、MaxCompute、Hologres。

**AI基础设施**：灵骏智算集群、HPN高性能网络、PAI平台、vLLM/SGLang推理优化生态。

# 招聘岗位

**2026届秋招**：2025年8月5日启动，计划发放7000+ Offer，15个业务集团同时招聘。AI相关岗位占比超60%，其中阿里云、阿里国际、钉钉的AI相关岗位占比高达80%。新增七大AI校招岗位类型，包括AI应用研发工程师、AI应用算法工程师、AI Agent优化工程师等。

**主要技术岗位**：
- 研发工程师Java（后端主力，淘天/菜鸟/本地生活为主）
- 研发工程师C++（云基础设施、存储、网络）
- 前端开发、客户端开发工程师
- 算法工程师（机器学习/NLP/CV/搜推广/大模型）
- 数据研发、数据分析、安全、测试开发、SRE
- 基础平台研发（操作系统、编译器、数据库内核）

**顶尖人才计划**：
- **阿里星（A Star）**：面向全球顶尖青年科研人才，已吸引200+顶尖青年技术人才加入，累计发布3000+论文和专利，课题覆盖基础模型、AI Infra、大模型应用、计算架构等方向（课题数超70个），薪资不设上限，公开报道有年薪百万至300万级案例。
- **C-Star**：千问事业部顶尖人才通道。

**2027届校招**：各官网已切换至27届（毕业时间2026.11-2027.10），千问事业部校招官网为 talent.quark.cn。

# 校招情况

**流程**：网申 → 在线测评/笔试 → 技术面试（2-4轮）→ 交叉面（部分）→ HR面 → Offer。算法岗通常加论文面或主管面；阿里星单独流程（答辩式评审）。

**院校偏好**：技术岗以985/211及海外名校为主，非目标院校可通过实习、竞赛（ACM/Kaggle）、开源贡献突围。浙大是阿里最大生源校。

**实习**：暑期实习转正是阿里校招主通道，日常实习全年滚动开放；千问事业部、阿里云对实习生有转正倾斜。

**注意**：阿里部分业务Offer审批周期较长，个别岗位存在调整可能，建议流程中保持多线并行，拿到书面Offer后再做决策。

# 社招情况

社招需求集中在：
- **AI方向**：大模型训练/推理、AI Agent、多模态、搜推广算法——供不应求
- **阿里云**：数据库内核、网络、存储、算力调度等基础软件方向
- **出海业务**：国际数字商业的多语言算法与跨境工程
- **即时零售竞争**：淘宝闪购带来的交易链路与本地生活岗位

职级体系：P序列（P4校招起步，P5高级，P6资深，P7专家，P8高级专家/Leader），2024年后映射为14-28级，行业仍习惯以P级沟通。社招进入一般要求P5以上，股票占比随职级上升。

# 技术栈

**后端**：Java（绝对主力：Spring/Spring Boot、Dubbo、RocketMQ）、Go（云与中间件）、C++（存储/网络/内核）、Python（算法）。
**大数据**：Flink、Spark、MaxCompute、Hologres、Paimon、StarRocks。
**数据库**：MySQL、PolarDB、OceanBase（蚂蚁系）、Lindorm、Redis、Elasticsearch。
**云原生**：Kubernetes（ACK）、Docker、Service Mesh、Serverless函数计算。
**AI**：PyTorch、PAI、DeepSpeed/Megatron、vLLM/SGLang、ModelScope魔搭、LangChain生态。

# 面试特点

| 项目 | 详情 |
|------|------|
| 面试轮次 | 3轮技术面 + 1轮交叉面 + 1轮HR面（技术岗常见配置） |
| 编码考核 | 中高，Java岗常考手写代码与算法题（LeetCode Medium为主，1-2道） |
| 项目深挖 | 极高，以"连环追问"著称，深挖到源码与线上细节 |
| 八股比重 | 高，Java岗对JVM、并发、Spring源码、MySQL底层考察深入 |

**经典考察点**：
- Java岗：JVM内存模型与GC（G1/ZGC）、synchronized与AQS、HashMap/ConcurrentHashMap源码、Spring IOC/AOP原理、MySQL索引B+树与MVCC、Redis缓存穿透/击穿/雪崩、RocketMQ消息可靠性
- 算法岗：机器学习基础、推荐系统全链路、大模型微调与推理优化、论文深挖
- 系统设计：秒杀系统、短链服务、Feed流、分布式事务

**面试文化**：重视价值观契合（"闻味"）、业务理解与Owner意识；会考察"为什么不用B方案"的技术选型Trade-off。

# 薪资福利

**校招薪资（技术岗，综合牛客/OfferShow等社区爆料，仅供参考）**：

| 类型 | 薪资水平 |
|------|---------|
| 实习 | 约350-450元/天 |
| 普通研发Offer | 月薪约22K-35K × 16薪 |
| 算法/大模型岗 | 月薪约25K-45K，总包更高 |
| 阿里星等顶尖AI人才 | 总包百万级，上不封顶 |

公开报道显示，2026届校招AI相关岗位平均月薪约4.7万起，技术岗总包普遍在55万-120万区间（含股票，顶尖算法/阿里星）；普通后端开发总包约35万-50万。

**福利**：iHome购房无息借款、康乃馨体检、补充医保、股票期权（RSU分4年归属）、15-16薪惯例、园区设施完善（杭州西溪/云谷园区）。

# 办公地点

- **总部**：杭州（西溪园区、云谷园区、Z空间）
- **主要研发中心**：北京、上海、深圳、广州、成都、南京、西安、乌兰察布（数据中心）等
- **海外**：新加坡（AIDC）、东南亚、欧洲、美国等

杭州是岗位最多、转岗空间最大的城市；北京以云与AI研发为主。

# 岗位需求变化与最新动态

- **AI岗位占比超六成**：2026届校招AI相关岗位占比超60%，云/国际/钉钉达80%，新增AI应用研发、AI应用算法、AI Agent优化工程师等七大AI岗位类型。
- **千问事业部成立（2026）**：整合千问App、夸克、AI硬件、UC等业务打造AI超级应用，校招社招同步大幅扩张。
- **Qwen开源生态扩大**：开源模型全球衍生生态带来AI工程化岗位（微调、推理、Agent）需求上涨。
- **3800亿资本开支**：三年云+AI基础设施投入直接拉动AI Infra、芯片软件、数据中心研发岗位。

# 应聘建议

**技术准备**：
- Java后端岗是校招量最大方向：吃透JVM、并发、Spring、MySQL、Redis、RocketMQ六件套，配合LeetCode刷题
- 算法岗突出论文（ACL/CVPR/NeurIPS）、竞赛与大模型项目；关注Qwen技术报告与开源项目
- 准备"阿里味"叙事：业务结果导向、Ownership、复盘意识

**投递策略**：
- 第一志愿选业务扩张方向（阿里云AI、千问事业部、AIDC），HC多且转正率高
- 暑期实习（4-6月投递）优于秋招直投
- 系统允许多事业群并行投递

**面试要点**：项目深挖时主动给出量化指标（GMV、QPS、延迟、准确率）；交叉面前复盘技术选型Trade-off；HR面准备职业规划与价值观问题。
