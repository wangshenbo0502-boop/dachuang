# 阿里巴巴

## 公司概况

- **行业**: 互联网/电商/云计算
- **规模**: 超大型（20万+人）
- **目标院校**: 985/211 为主

## 招聘重点

- Java 能力（主要技术栈）
- 系统设计思维
- 业务理解能力
- 计算机基础扎实

## 技术栈偏好

- Java
- Spring
- MySQL
- 自研中间件

## 面试风格

| 项目 | 详情 |
|------|------|
| 面试轮次 | 3轮技术面 + 1轮HR + 1轮交叉面 |
| 编码考核比重 | 中（算法题一般1-2道中等难度） |
| 项目深挖程度 | 极高（会问业务场景下的设计思路） |

**面试特点**:
- 重视业务理解
- 会问系统设计题
- 面试流程较长
- 有笔试环节

## 薪资范围

| 类型 | 薪资 |
|------|------|
| 实习 | 350-450元/天 |
| 应届生 | 22k-35k * 16薪 |

## 优缺点

### 优势
- 业务场景丰富
- 技术体系成熟
- 晋升通道清晰
- 福利完善

### 劣势
- 加班文化
- 部门间差异大

## 准备建议

- 准备一个 Java 高并发场景的项目
- 理解分布式系统设计
- 熟悉阿里常用中间件（RocketMQ/Nacos/Sentinel）
