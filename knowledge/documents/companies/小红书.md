# 公司概况

小红书（行吟信息科技（上海）有限公司）成立于2013年，总部位于上海，从海外购物攻略社区起家，成长为"生活方式社区+种草电商"平台，月活跃用户超3亿、日活跃用户过亿（2025年公开报道口径），是国内增长最快的头部内容社区。公司仍未上市，估值长期位居中国互联网独角兽前列。

小红书的社区心智是"真实分享、利他种草"：UGC笔记（图文+视频）覆盖美妆、时尚、美食、旅行、家居、职场、学习等生活方式领域，"遇事不决小红书"使其成为年轻人的搜索引擎与决策入口。商业模式以广告（信息流+搜索广告）与电商（买手电商、店播）为主，商业化仍处于高速成长期。

对求职者而言，小红书是近年最热门的"黑马雇主"之一：用户增长快、业务边界持续扩张（电商、本地生活、AI搜索）、团队年轻化（平均年龄低）、WLB在大厂中口碑偏好，技术团队规模数千人，招聘量逐年放大。

# 主营业务与产品

**社区业务**：小红书App的Feed流推荐、搜索（社区搜索是用户核心行为，搜索占比高）、内容理解与治理、创作者工具。技术挑战集中在多模态内容理解（图文/视频笔记）、搜索排序、社区生态治理（反作弊、假种草识别）。

**电商业务**：买手电商（直播+笔记带货）、店铺经营、交易链路、供应链。电商是小红书商业化第二曲线，与天猫、抖音电商差异化竞争，交易与履约岗位需求增长快。

**广告与商业化**：信息流广告、搜索广告、KOL营销平台（蒲公英）、效果广告（聚光平台）。广告技术栈对标头部大厂。

**AI方向**：小红书自研大模型与AI应用布局积极——社区C端agentic智能（AI搜索助手、笔记摘要、拍照问答）、AI创作工具（图片生成、文案辅助）、增长投放智能化等复杂业务场景的模型与AI Agent研发是校招官网明确列出的方向。

# 财务与经营状况

小红书未上市，经营信息来自公开报道：

- **用户规模**：2025年DAU突破亿级，MAU超3亿，是国内用户量第6-7大的内容平台
- **商业化增速**：广告收入快速增长（报道口径2024年广告收入超百亿量级），电商GMV持续提升
- **盈利状况**：媒体报道公司已实现盈利，现金流健康
- **估值**：一级市场估值约200亿美元量级（2024-2025年报道口径）

对求职者的含义：公司处于"用户增长兑现商业化"的黄金阶段，HC扩张、期权价值想象空间大；但业务竞争激烈（抖音、B站、淘宝都在抢"种草"心智），组织仍在快速变化中。

# 技术实力与核心技术

**多模态内容理解**：亿级图文/视频笔记的理解（封面/标题/正文/评论多模态融合）、内容标签体系、审美质量评估——多模态算法的顶级落地场景。

**搜索技术**：社区搜索是核心场景（用户搜索占比高），涵盖Query理解、召回、排序、生成式搜索（AI搜索答案生成）。

**推荐系统**：双列Feed（用户主动选择）+单列沉浸式并存的产品形态，对推荐算法提出独特要求（探索与利用、多样性）。

**信任与安全**：反作弊（虚假种草、水军识别）、内容安全、社区治理——大模型辅助治理的先行场景。

**AI Agent与AIGC**：C端agentic智能（AI搜索、智能助手）、B端经营Agent、AIGC创作工具。

**工程基础设施**：大数据（Flink/Spark）、云原生（Kubernetes）、音视频处理，规模在国内中型公司中处于一线。

# 招聘岗位

**校招（campus.xiaohongshu.com）**主要岗位方向：
- 后端开发（Java/Go）：电商交易、社区业务、广告系统
- 前端开发（React为主）：C端产品、创作工具
- 算法工程师：推荐、搜索、多模态、NLP、大模型/AI Agent（校招官网重点方向：社区C端agentic智能、增长投放智能）
- 客户端（iOS/Android）、数据工程、测试开发

**2026届春招公开岗位示例**（暨南大学就业网）：RED Finance Trainee（本科10000-15000元/月）、小红书产品经理培训生（本科10000-15000元/月）；技术岗校招薪资显著高于培训生序列。

**实习**：日常实习与暑期实习全年开放，转正机会多；上海总部为主，北京有团队。

# 校招情况

**流程**：网申 → 笔试/测评 → 2-3轮技术面试 → HR面。流程轻快、面试氛围轻松（面试官年轻）。

**院校偏好**：以985/211为主，对候选人的"社区理解与产品sense"要求高于纯八股——深度用户身份是隐性加分项。

**竞争度**：近年小红书校招热度极高（"神仙公司"口碑），报录比高于传统大厂；算法岗竞争尤其激烈。

**工作地点**：上海（总部，绝大多数岗位）、北京（部分）。介意城市者需注意。

# 社招情况

社招需求集中在：
- **AI方向**：大模型应用、AI Agent、多模态内容理解、AIGC——扩张最快
- **电商链路**：交易、履约、营销、供应链工程
- **广告技术**：投放平台、效果归因、机制设计
- **基础架构**：大数据、稳定性、音视频

社招薪酬对标头部大厂（现金+期权），电商与AI方向有溢价；从大厂（字节、阿里、腾讯）流入小红书的案例多。

# 技术栈

**后端**：Java与Go并重（电商偏Java、社区与基础组件偏Go）、Python（算法服务）。
**前端**：React主力、TypeScript、小程序、Node.js。
**数据**：Flink、Spark、ClickHouse、Hive、Kafka。
**存储**：MySQL、Redis、Elasticsearch（搜索核心）、HBase。
**AI**：PyTorch、多模态模型、大模型推理（vLLM类）、RAG与Agent框架。
**基础设施**：Kubernetes、Docker、自研中台组件。

- **总部**：上海（黄浦区/杨浦区，新总部园区）

绝大多数岗位在上海，是"绑定单一城市"最深的头部互联网公司之一。

# 岗位需求变化与最新动态

- **AI Agent方向扩招**：校招官网明确列出"社区C端 agentic 智能、增长投放智能等复杂业务场景的模型及AI Agent研发"，AI岗位占比快速上升。
- **电商闭环加速**：买手电商与店播生态建设带来交易、履约、商家技术岗位增长。
- **本地生活试水**：到店与旅行业务扩张（对抖音、美团的内容种草竞争）。
- **用户规模里程碑**：DAU破亿后，商业化（广告+电商）进入收获期，技术投入加码。

# 应聘建议

**技术准备**：
- 后端/算法岗准备主流八股+算法题（Medium为主）；算法岗重点准备推荐/搜索/多模态与大模型应用
- 前端岗重视React原理、工程化与产品交互理解
- 面试前深度体验产品：准备对社区生态、搜索体验、电商链路的观察与改进建议

**投递策略**：
- 实习转正优先；关注官网与牛客内推帖
- 简历突出"数据驱动"的项目（A/B实验、指标优化）
- 接受上海Base是前提

**面试要点**：产品讨论题展现用户同理心；项目讲解突出业务指标（点击率、留存、GMV）；HR面关注文化匹配（真实、利他、社区感）。
