# 公司概况

中国电子科技集团有限公司（简称"中国电科"，英文缩写CETC）是中央直接管理的国有重要骨干企业，是中国十大军工集团之一，总部位于北京市。中国电科成立于2002年，由原信息产业部直属的电子研究院所和高科技企业组建而成，是国家电子信息体系的核心力量。

中国电科是我国电子信息领域的主力军和国家队，在国防电子信息系统、国民经济信息化建设中发挥着不可替代的作用。集团拥有国家级研究院所数十家，上市公司多家，员工总数超过20万人，其中科技人员占比超过60%，汇聚了一大批国内顶尖的电子信息领域专家和技术人才。

中国电科的业务覆盖军民用电子信息系统全产业链，在雷达、通信、计算机、集成电路、网络安全、人工智能等领域拥有雄厚的技术实力和完整的产业体系。集团承担了大量国家重大科技专项和重点工程任务，是建设科技强国、网络强国、数字中国的重要力量。

- **行业**: 电子信息/军工/科研
- **性质**: 中央企业（副部级）
- **总部**: 北京市
- **员工规模**: 20万人以上
- **定位**: 国家电子信息体系的核心力量，十大军工集团之一

# 主营业务与产品

中国电科业务范围广泛，涵盖电子信息全产业链，主要业务板块包括：

- **军用电子信息系统**: 为军队提供各类电子信息装备和系统，包括预警探测系统、指挥控制系统、通信导航系统、电子战系统等，是国防信息化建设的核心力量。
- **雷达系统**: 研制生产各类军用和民用雷达，包括预警雷达、机载雷达、舰载雷达、气象雷达、空管雷达等，技术水平国内领先。
- **通信装备**: 研发生产各类通信设备和系统，包括战术通信、卫星通信、短波通信、数据链等，在军事通信领域占据重要地位。
- **计算机与软件**: 研制国产计算机、服务器、操作系统、数据库等基础软硬件产品，是国家信创产业的重要力量。
- **集成电路**: 设计和制造各类集成电路芯片，包括数字芯片、模拟芯片、微波芯片、功率器件等，在军工芯片领域具有核心地位。
- **网络安全**: 提供网络安全产品和服务，包括安全防护、安全检测、安全运维、密码技术等，是国家网络安全的重要保障力量。
- **人工智能**: 开展人工智能技术研究和应用，包括智能感知、智能决策、智能控制等，推动AI在国防和民用领域的应用。
- **智慧城市与数字经济**: 利用电子信息技术推动智慧城市建设和数字经济发展，提供城市大脑、智慧交通、智慧安防等解决方案。
- **民用电子**: 包括物联网、大数据、云计算、5G通信等新一代信息技术的研发和应用。

# 招聘岗位

中国电科招聘岗位以技术研发为主，覆盖电子信息多个领域，主要通过各研究所独立招聘：

- **研发工程师**: 硬件研发、软件研发、嵌入式开发、FPGA开发
- **算法工程师**: 雷达信号处理算法、通信算法、图像处理算法、AI算法
- **硬件工程师**: 电路设计、PCB设计、射频硬件、数字硬件
- **软件工程师**: C/C++开发、Java开发、Python开发、嵌入式软件
- **FPGA工程师**: FPGA设计、验证、时序优化
- **射频/微波工程师**: 射频电路设计、微波器件、天线设计
- **芯片设计工程师**: 数字IC设计、模拟IC设计、验证工程师
- **网络安全工程师**: 安全研究、渗透测试、安全开发
- **系统工程师**: 系统架构设计、系统集成、系统测试
- **测试工程师**: 硬件测试、软件测试、系统测试

主要招聘研究所包括：14所（南京，雷达）、28所（南京，指挥控制系统）、38所（合肥，雷达）、54所（石家庄，通信）、29所（成都，电子战）、36所（嘉兴，通信）、15所（北京，计算机）等。

# 校招情况

中国电科校园招聘主要由各研究所独立开展，以硕士和博士为主要招聘对象，部分岗位招收本科生。

| 项目 | 详情 |
|------|------|
| 招聘规模 | 每年招聘数千人 |
| 主要岗位 | 研发工程师、算法工程师、硬件工程师 |
| 学历要求 | 硕士及以上为主，部分本科 |
| 薪资范围 | 硕士年薪15-30万，博士25-70万+安家费 |
| 工作城市 | 北京、南京、成都、西安、合肥、石家庄、上海等 |
| 目标院校 | 985/211及重点电子信息类院校 |

**校招特点**:
- 提前批通常7月启动，正式批9-11月
- 以硕士博士为主，部分热门研究所只招硕士以上
- 芯片、雷达、通信等紧缺专业薪资上浮
- 不同研究所薪资和待遇差异较大
- 看重学校背景和专业对口度
- 提供事业编制或企业编制
- 可解决当地户口，部分城市有安家费和住房补贴
- 工作稳定，是追求稳定和职业发展的好选择

# 社招情况

中国电科社会招聘主要面向有工作经验的专业技术人才，以中高级技术人才为主。

- **招聘渠道**: 官网招聘、猎聘、内部推荐、猎头
- **热门岗位**: 高级算法工程师、芯片设计专家、系统架构师
- **经验要求**: 通常3年以上相关工作经验
- **薪资范围**: 根据职级和经验，年薪20-80万不等，高端人才可面议
- **特点**: 看重实际项目经验和专业技术能力，有军工或研究所工作经验者优先
- 部分高端人才可享受特殊人才引进政策
- 社招进入研究所也有机会获得编制

# 技术栈

中国电科技术栈以硬件和底层技术为核心，覆盖电子信息全技术链：

- **编程语言**: C/C++（主力）、Java、Python、汇编
- **硬件设计**: Verilog/VHDL、FPGA、PCB设计、电路设计
- **射频微波**: ADS、HFSS、微波电路设计、天线设计
- **芯片设计**: 数字IC设计、模拟IC设计、验证、DFT
- **信号处理**: 雷达信号处理、通信信号处理、数字信号处理（DSP）
- **嵌入式**: 嵌入式Linux、RTOS、ARM、DSP
- **操作系统**: 国产操作系统、Linux、VxWorks
- **通信技术**: 5G、卫星通信、软件无线电、数据链
- **网络安全**: 密码学、渗透测试、安全防护、可信计算
- **人工智能**: 深度学习、计算机视觉、自然语言处理、智能感知

中国电科在雷达技术、通信技术、集成电路、网络安全等领域拥有国内领先甚至国际先进的技术水平，是国家电子信息领域技术创新的主力军。

# 面试特点

中国电科面试注重专业背景和技术能力，各研究所面试流程略有差异。

| 项目 | 详情 |
|------|------|
| 面试轮次 | 2-3轮（技术面+综合面） |
| 技术考察 | 专业知识、项目经验、技术能力 |
| 综合考察 | 学校背景、专业匹配、稳定性、综合素质 |

**面试特点**:
- 通常2-3轮面试，技术面+综合面
- 看重学校背景和专业对口度，985/211院校有优势
- 技术面试考察专业基础知识和项目经验
- 算法岗会考察信号处理算法、通信算法等专业知识
- 硬件岗考察电路设计、模电数电基础
- 软件岗考察C/C++基础、数据结构、操作系统
- 综合面试关注职业稳定性和家国情怀
- 整体难度中等偏上，但竞争激烈，好的研究所门槛较高
- 部分研究所有笔试环节

# 薪资福利

中国电科薪资福利在不同研究所之间差异较大，但总体福利完善，稳定性高。

| 项目 | 详情 |
|------|------|
| 硕士年薪 | 15-30万（不同研究所差异大） |
| 博士年薪 | 25-70万 + 安家费（10-50万不等） |
| 本科年薪 | 10-20万（部分研究所） |
| 六险二金 | 五险一金 + 补充医疗保险 + 职业年金 |
| 住房补贴 | 单身公寓或住房补贴，部分所有福利房 |
| 落户 | 解决当地户口，北京/上海/南京等城市落户指标 |
| 编制 | 事业编制或企业编制 |

**其他福利**:
- 单身公寓或周转房
- 节日福利、生日福利
- 年度体检
- 带薪年假、探亲假
- 工会活动丰富
- 培训体系完善，有导师制
- 工作稳定，裁员风险低
- 子女教育资源（部分研究所）
- 科研经费和职称评定体系完善

# 办公地点

中国电科在全国多个城市设有研究院所和企业，分布广泛：

- **北京**: 总部所在地，多家研究所（15所、11所、12所等）和集团总部
- **南京**: 14所（雷达）、28所（指挥控制系统），重要的研发基地
- **成都**: 29所（电子战）、30所（通信安全），西南地区核心
- **西安**: 20所（通信导航）、39所（天线），西北地区核心
- **合肥**: 38所（雷达）、43所（微电子），中部地区重要基地
- **石家庄**: 54所（通信）、13所（半导体），华北地区重要基地
- **上海**: 32所（计算机）、51所（电子对抗）
- **嘉兴**: 36所（通信）
- **其他城市**: 广州、武汉、天津、青岛、太原等城市也有研究所或企业

# 岗位需求变化与最新动态

近年来，中国电科的岗位需求呈现以下趋势：

- **人工智能扩招**: 2026年人工智能相关岗位需求大幅增长，AI算法、智能感知、智能决策等方向持续扩招，专业技术岗占比超70%。
- **集成电路需求旺盛**: 芯片设计、验证、制造等岗位需求持续增长，国家大力支持集成电路产业发展，相关人才紧缺。
- **软件人才需求上升**: 基础软件、工业软件、嵌入式软件等方向岗位需求增加，软件人才占比持续提升。
- **网络安全持续加强**: 网络安全人才需求稳定增长，攻防对抗、密码技术、安全芯片等方向持续招聘。
- **雷达与通信**: 传统优势领域需求保持稳定，新技术方向如量子雷达、6G通信等开始布局。
- **民品业务拓展**: 智慧城市、数字经济、物联网等民品业务发展迅速，相关岗位需求增加。
- **高层次人才引进**: 各研究所加大博士和高端人才引进力度，提供优厚的待遇和科研条件。

2026年最新动态显示，中国电科继续加大科技创新力度，在人工智能、集成电路、基础软件等领域重点布局，相关专业技术人才需求持续增长。

# 应聘建议

- **专业匹配**: 中国电科非常看重专业对口，电子信息、通信、计算机、自动化、微电子等专业最对口。
- **学历提升**: 好的研究所基本只招硕士以上，建议读研读博，博士待遇和发展空间都更好。
- **技术准备**: 根据岗位方向有针对性准备。硬件岗深入学习模电数电、电路设计、FPGA；软件岗扎实掌握C/C++、数据结构、操作系统；算法岗重点学习信号处理、通信原理、机器学习。
- **项目经验**: 多参与相关的科研项目和竞赛，有电子设计竞赛、数学建模竞赛等奖项加分。
- **研究所选择**: 不同研究所差异很大，建议提前了解各所的业务方向、薪资待遇、工作强度，选择最适合自己的。
- **地域选择**: 考虑好城市选择，研究所一般在当地都有较好的社会地位和生活质量，但不同城市发展机会不同。
- **面试准备**: 准备好专业知识，复习核心课程。综合面体现稳定性和家国情怀，表达对军工电子事业的认同。
- **编制问题**: 提前了解是事业编还是企业编，不同编制在待遇和稳定性上有差异。
