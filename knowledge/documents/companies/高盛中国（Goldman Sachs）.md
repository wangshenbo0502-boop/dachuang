# 公司概况

高盛（Goldman Sachs）是全球顶级投资银行，成立于1869年，总部位于美国纽约。作为华尔街最负盛名的金融机构之一，高盛在投资银行、证券交易、资产管理、直接投资等领域均处于行业领先地位。高盛以其精英文化、高强度工作和高薪酬闻名于世，被誉为金融行业的"黄埔军校"，其校友网络遍布全球金融界和企业界。

高盛中国区总部位于上海和北京，在香港、深圳也设有办公室。高盛是最早进入中国的外资投行之一，在中国市场拥有深厚的根基和广泛的业务网络。中国区业务涵盖投资银行、股票资本市场、固定收益、资产管理、直接投资以及金融科技等多个领域。高盛工银证券（合资证券公司）是高盛在中国的重要业务平台。

近年来，高盛在金融科技和量化交易领域投入巨大，技术团队规模持续扩大，工程技术岗位在高盛中国的招聘占比逐年提升。高盛将自己定位为一家"科技公司"，全球技术人员占比超25%。

- **行业**: 投资银行/金融服务/金融科技
- **性质**: 外商独资企业（美资）
- **中国区总部**: 上海/北京
- **办公地点**: 上海、北京、香港、深圳
- **员工规模**: 中国区数千人，全球超4万人
- **公司地位**: 全球顶级投行，金融行业标杆

# 主营业务与产品

高盛业务覆盖金融全产业链，主要业务板块包括：

- **投资银行（Investment Banking）**: 企业融资、并购顾问、股票和债券承销，是全球并购业务的领导者
- **全球市场（Global Markets）**: 股票交易、固定收益交易、外汇交易、大宗商品交易，为机构客户提供做市和执行服务
- **资产管理（Asset Management）**: 面向机构和个人客户的投资管理服务，涵盖股票、债券、另类投资等
- **消费者与财富管理（Consumer & Wealth Management）**: 私人财富管理、消费金融（Marcus）、数字银行
- **直接投资（Merchant Banking）**: 私募股权投资、房地产投资、基础设施投资
- **金融科技与平台**: 数字化交易平台、数据服务、API平台、量化交易系统

在中国市场，高盛重点发展投资银行、股票资本市场、资产管理和金融科技业务。高盛工银证券在A股市场拥有全牌照经营资格。

高盛中国招聘岗位覆盖金融和技术两大方向，近年来技术岗占比持续提升：

| 岗位类别 | 主要方向 | 需求程度 |
|----------|----------|----------|
| 投资银行分析师 | M&A、ECM、DCM、行业组 | 高 |
| 量化研究员 | 量化策略、统计套利、高频交易 | 高 |
| 软件工程师 | 交易系统、风控系统、数据平台 | 极高 |

| 交易员 | 股票交易、固收交易、外汇交易 | 中 |
| 资产分析师 | 投资分析、组合管理、研究 | 中高 |

技术岗和量化岗近年来需求增长最快，高盛在中国大规模招聘金融科技人才。

# 校招情况

高盛校园招聘以精英化为特点，目标院校集中，竞争极为激烈。

| 项目 | 详情 |
|------|------|
| 招聘时间 | 每年7月中旬开启暑期实习提前批，8-9月正式秋招 |
| 学历要求 | 本科及以上，技术岗和量化岗硕士/博士优先 |
| 目标院校 | 清北复交浙 + 海外Top名校（Target School） |
| 工作地点 | 上海、北京、香港、深圳 |
| 热门部门 | 投资银行部、全球市场部、工程技术部 |

**校招薪资**（2026届参考）：
- 投资银行分析师：50-80万年包（base 30-45K × 12 + 年终奖金）
- 量化研究员：40-70万年包（base 25-45K × 12 + 绩效奖金）
- 软件工程师（技术岗）：30-50万年包（base 25-40K × 12 + 年终奖 + 股票）
- 风控/运营岗：25-40万年包
- 年终奖金占比较大，投行部奖金可达base的50-100%甚至更高

**校招特点**：
- Target School倾向明显，非目标院校难度极大
- 暑期实习是进入高盛的主要途径，转正率约60-80%
- 录取率极低，部分岗位录取率不足1%
- 面试轮次多，综合考察智商、情商和专业能力
- 英语要求极高，面试全程使用英语
- 香港办公室薪资更高，但生活成本也更高

# 社招情况

高盛社招以中高端专业人才为主，注重候选人的行业经验和专业背景。

- **招聘渠道**: 官网招聘、猎头、内部推荐、LinkedIn
- **经验要求**: 通常2-5年以上相关工作经验，高级岗位要求5-10年以上
- **薪资范围**: 中级分析师/工程师50-100万，副总裁（VP）100-300万+，执行董事（ED）300万以上
- **热门方向**: 量化交易、金融科技、中概股相关投行业务
- **职级体系**: Analyst → Associate → VP → ED → MD
- **招聘节奏**: 按需招聘，节奏相对缓慢
- **跳槽价值**: 高盛背景在金融行业含金量极高，是跳槽的黄金跳板

社招流程通常为：简历筛选 → 猎头初筛 → 3-5轮面试 → 背景调查 → 录用。流程周期较长，可能需要1-3个月。

# 技术栈

高盛虽然是金融公司，但技术体系庞大且复杂，技术栈以低延迟和高可靠性为核心：

| 领域 | 核心技术 |
|------|----------|
| 交易系统 | Java、C++、低延迟编程、FPGA加速 |
| 量化研究 | Python、R、MATLAB、机器学习、统计建模 |
| 风控系统 | Java、Python、风险模型、实时计算 |
| 大数据平台 | Spark、Hadoop、Kafka、数据湖 |
| 前端应用 | React、TypeScript、数据可视化 |
| 数据库 | Oracle、SQL Server、MongoDB、Redis |
| 云基础设施 | AWS、容器化、微服务 |
| 安全与合规 | 加密算法、身份认证、审计系统 |

高盛的交易系统对延迟要求极高，核心交易链路使用C++和FPGA开发。量化研究大量使用Python和自研的量化框架。

# 面试特点

高盛面试以多轮次、高强度和英语要求高著称，是金融行业最难的面试之一。

| 项目 | 详情 |
|------|------|
| 面试轮次 | 4-6轮面试（含Super Day终面） |
| 技术难度 | 高（技术岗）/中高（非技术岗） |
| 综合考察 | 智商测试 + 专业能力 + 行为面试 |
| 英语要求 | 极高（全程英语面试） |

**面试特点详解**：
- **多轮面试**：从电话面试到终面，通常需要经历4-6轮，终面为Super Day（一天内多轮面试）
- **Hackerrank测试**：技术岗和部分量化岗需要完成在线编程测试
- **智商/能力测试**：部分岗位有数值推理、逻辑推理等能力测试
- **技术深度**：技术岗考察算法、系统设计、编程语言深度，量化岗考察数学统计和金融知识
- **行为面试**：非常看重领导力、团队合作、抗压能力等软技能
- **案例分析**：投行岗有案例分析面试，考察商业思维和分析能力
- **Fit面**：终面会重点考察文化匹配度和职业动机
- **英语能力**：所有面试均为英语，对英语口语和听力要求极高

建议候选人重点准备：英语面试、行为面试（STAR法则）、专业知识、技术岗算法题（LeetCode中等偏难）、金融基础知识。

# 薪资福利

高盛薪资在金融行业属于顶级水平，奖金占比高，福利完善。

| 福利项目 | 详情 |
|----------|------|
| 基础薪资 | 投行/技术岗base 25K起，上不封顶 |
| 年终奖金 | 0-12个月+工资，视绩效和部门而定 |
| 股票期权 | RSU限制性股票，分多年归属 |
| 五险一金 | 全额缴纳六险一金 + 高端商业保险 |
| 带薪年假 | 15-20天/年，随职级和工龄增长 |
| 全球培训 | 丰富的全球培训项目和学习资源 |
| 健康保障 | 高端医疗保险、年度体检、心理健康服务 |
| 退休计划 | 企业年金、退休金计划 |

**薪资特点**：
- 奖金是收入的重要组成部分，投行和交易岗奖金可超过base
- 技术岗薪资接近科技公司水平，但奖金弹性更大
- 香港办公室薪资比内地高约30-50%
- 晋升后薪资涨幅显著，每升一级薪资上一个台阶
- 虽然起薪不是最高，但长期职业回报丰厚，高盛背景的跳槽溢价极高

# 办公地点

高盛在中国的主要办公地点：

- **上海**: 中国区总部之一，位于浦东新区陆家嘴金融中心。投资银行、全球市场、资产管理、工程技术等部门均有布局
- **北京**: 中国区总部之一，位于朝阳区国贸/金融街。投资银行、政府关系、部分技术团队
- **香港**: 亚太区重要枢纽，位于中环。投资银行、全球市场、资产管理等核心业务
- **深圳**: 设有办公室，主要服务华南地区客户和科技企业

各办公地点均位于城市核心金融区，办公环境高端奢华，配套设施完善。

# 岗位需求变化与最新动态

2025-2026年，高盛中国招聘需求呈现以下趋势：

| 方向 | 需求变化 | 说明 |
|------|----------|------|
| 金融科技工程师 | 快速增长 | 数字化转型和技术投入加大 |
| 量化研究/交易 | 稳步增长 | 量化业务扩张，对人才需求持续 |
| 投资银行 | 波动中增长 | 中概股回归和A股业务带动需求 |
| 财富管理 | 快速增长 | 中国财富管理市场潜力巨大 |
| 风控合规 | 稳步增长 | 监管趋严，风控合规需求稳定 |
| 传统运营岗 | 平稳 | 自动化程度提升，增量有限 |

**最新动态**：
- 高盛持续加大在金融科技领域的投入，工程师团队规模逐年扩大
- 高盛工银证券在华业务全面扩张，投行业务和经纪业务岗位增加
- 量化交易和算法交易团队持续扩招，对数学、物理、计算机背景人才需求旺盛
- 财富管理业务快速发展，私人银行和数字财富团队扩招
- AI和大模型在金融领域的应用加速，相关技术岗位需求增加
- ESG和绿色金融成为新的业务增长点，相关岗位需求上升

# 应聘建议

- **技术岗准备**:
  - 算法：LeetCode中等和困难题，重点练习数据结构和算法设计
  - 系统设计：了解分布式系统和高可用架构设计
  - 编程语言：Java/C++/Python至少精通一门
  - 金融知识：了解基本的金融概念和业务场景

- **非技术岗准备**:
  - 专业知识：扎实的金融/经济/会计基础
  - 案例分析：练习投行案例分析框架和方法
  - 行为面试：准备10个以上STAR故事，覆盖领导力、团队合作、解决问题等维度
  - 市场认知：关注金融市场动态和热点事件

- **英语准备**:
  - 英语口语必须流利，能自然表达专业观点
  - 准备英文自我介绍和常见面试问题答案
  - 多听英语财经新闻，熟悉金融英语表达
  - 建议找英语母语者模拟面试

- **投递建议**:
  - 优先申请暑期实习，转正机会远大于直接校招
  - 内推至关重要，通过校友或LinkedIn联系高盛员工内推
  - Target School学生机会更多，非目标院校需有突出经历
  - 关注高盛官网和微信公众号，及时获取招聘信息

- **适合人群**:
  - 对金融行业有浓厚兴趣和职业追求
  - 英语能力出色，能适应全英文工作环境
  - 抗压能力强，能接受高强度工作节奏
  - 有顶尖名校背景或突出的实习/项目经历
  - 追求长期职业发展和高天花板
