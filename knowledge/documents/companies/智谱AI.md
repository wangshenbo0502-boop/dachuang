# 公司概况

智谱AI（北京智谱华章科技股份有限公司，股票代码：02513.HK）是中国领先的通用大模型开发商，被誉为"全球大模型第一股"。公司脱胎于清华大学计算机系知识工程研究室（KEG），创始人唐杰教授是清华大学计算机系教授、知识工程实验室主任，在人工智能领域深耕近二十年。总部位于北京海淀中关村科学城，是海淀中关村科学城长期重点培育的硬核科技企业。

智谱的发展历程可以追溯到2006年清华大学KEG实验室发布的AMiner科研情报挖掘系统。2019年6月，AMiner团队从清华实验室拆分，智谱华章正式成立。2022年8月，公司开源千亿参数大模型GLM-130B，成为亚洲唯一入选全球30个主流大模型的中国模型。2023年8月，基于ChatGLM的C端产品"智谱清言"上线。2024年1月，新一代基座大模型GLM-4发布，达到比肩GPT-4的水平。

2026年1月8日，智谱在港交所主板正式挂牌上市，发行价116.2港元/股，全球发售募资52.3亿港元，上市首日市值578.9亿港元，成为港股首批纯AI大模型标的。上市后股价一路飙升，截至2026年6月，市值一度突破万亿港元，是当前市值最高的中国AI大模型公司。公司业务覆盖通用大模型、多模态、代码生成、数字员工等全栈AI能力，客户遍及政府、金融、制造、能源、教育等多个行业。

# 主营业务与产品

智谱AI构建了完整的"模型+平台+应用"全栈产品体系，形成了从底层基座到上层应用的全方位布局。

**GLM大模型系列**：智谱的核心技术底座，涵盖从百亿到万亿参数的全尺寸模型矩阵。GLM-5总参数量达744B，预训练数据规模28.5T，推理与代码能力已接近国际顶尖水平。2026年6月发布的GLM-5.2开源版本，在Code Arena前端开发评估中取得全球可用模型第一的成绩，上下文窗口扩展至1M（百万级Token），并全面适配国产算力平台。

**智谱清言（C端产品）**：面向个人用户的AI助手，提供通用问答、虚拟对话、代码生成、创意写作、文档处理等服务。2024年8月上线国内首个面向客户端开放的视频通话功能，实现了从语言文字、图片再到视频的模态跨越。智谱清言是国内用户量最大的AI助手产品之一。

**智谱开放平台/MaaS平台**：面向开发者和企业的API服务平台，提供GLM系列模型的调用、微调、部署等服务。商业模式正从以本地化部署为主（2025年占比约74%）向以API调用为主的云平台收入转型，2025年云端部署收入同比增长约293%。GLM Coding Plan是面向开发者的订阅制产品，是商业化的重要抓手。

**数字员工**：面向企业的AI员工解决方案，覆盖客服、研发、行政、营销等多个岗位场景。智谱提出"数字员工基础设施"的长期愿景，认为大模型公司的终局不是单纯卖模型，而是提供可替代部分人力工作的数字化劳动力。

**CodeGeeX代码模型**：专注于代码生成与编程辅助的大模型产品，支持多种编程语言，在开发者社区拥有广泛用户基础。随着GLM-5系列在Coding能力上的大幅提升，CodeGeeX正在向"理解项目、拆解任务、持续调试和最终交付"的长程编程方向演进。

**多模态产品矩阵**：包括CogView文生图模型、CogVLM多模态大模型、"清影"视频生成模型等，覆盖图像、视频、语音等多种模态的生成与理解能力。

# 技术实力与核心技术

智谱AI在大模型技术领域拥有深厚的积累和全栈的研发能力，是国产大模型的技术标杆之一。

**GLM预训练框架**：智谱自主研发的GLM（General Language Model）预训练框架，不同于GPT的自回归模式和BERT的自编码模式，采用了独特的自回归空白填充预训练目标，在中英文双语理解和生成任务上均表现出色。这一技术路线的独立性使智谱在国产大模型中具有鲜明的技术特色。

**GLM-5系列大模型**：当前旗舰模型GLM-5总参数量达744B，预训练数据规模28.5T。在SWE-bench Verified、HLE、BrowseComp等关键测试中，推理与代码能力已接近Claude、GPT-5等国际顶尖模型。输出速率达68 token/秒，每百万token成本仅3美元，性价比优势显著。GLM-5.1在长程任务上继续突破，GLM-5.2更是将上下文窗口扩展至1M。

**长程任务能力**：GLM-5.2针对1M Coding Agent训练环境进行了扩展，覆盖自动化研究、性能优化等场景，改善了传统长上下文模型在数百K后能力劣化的问题。在多个长程任务基准中表现介于Claude Opus 4.7与4.8之间，并在FrontierSWE上超过GPT-5.5和Opus 4.7。

**多模态技术**：CogView系列文生图模型、CogVLM多模态大模型、"清影"视频生成模型构成了完整的多模态技术矩阵。智谱清言上线的视频通话功能标志着其在多模态交互领域的领先地位。

**CodeGeeX代码模型**：深耕代码生成领域多年，从GLM-4.5代码基座，到GLM-4.7国产Coding模型，再到GLM-5.2面向长程任务，能力重心已从"写代码"升级为"持续完成复杂工程"。在全球百万用户参与盲测的Code Arena前端开发评估中取得全球可用模型第一。

**国产算力适配**：GLM-5.2发布首日即完成华为昇腾、平头哥、摩尔线程、寒武纪、昆仑芯、沐曦、海光、壁仞等国产算力平台推理适配，采用MIT协议开源，可自由下载、部署和商用，并支持vLLM、SGLang、transformers等主流推理框架。

**开源生态**：智谱是国内最早开源大模型的公司之一，GLM系列在开源社区拥有庞大的开发者基础。从GLM-130B到ChatGLM再到GLM-5.2，智谱的开源策略推动了中国大模型生态的繁荣发展。

# 面试特点

智谱AI的面试风格深受清华系文化影响，以"技术深度大、学术氛围浓、流程规范"为主要特点。

**技术面试核心特点**：
- **学术深度强**：面试官很多具有清华背景或博士学历，提问具有学术深度，常涉及论文级别的技术细节。对于算法岗，会深入考察对Transformer、注意力机制、预训练方法等底层原理的理解。
- **基础知识扎实**：非常看重计算机科学和数学基础，面试中常出现概率论、线性代数、优化理论等数学问题，以及操作系统、计算机网络、分布式系统等工程基础问题。
- **代码能力考察**：算法岗需要手写模型实现或算法题，难度中等偏上，不仅要求能写出来，还要求理解原理和复杂度分析。工程岗注重系统设计和代码质量。
- **项目深挖**：对简历中的项目会进行非常深入的追问，从背景、方案、实现到效果、改进，层层递进，考察候选人的真实贡献和技术思考深度。
- **长文本与多模态专题**：作为智谱的核心技术方向，长上下文处理和多模态相关问题在面试中出现频率较高。

**面试流程**：
- 技术岗：简历筛选→在线笔试→技术一面（基础）→技术二面（深度）→技术三面（负责人/交叉面）→HR面→Offer
- 产品/运营岗：简历筛选→笔试/作业→业务一面→业务二面→负责人面→HR面→Offer
- 整体周期2-4周，流程规范，反馈及时
- 部分高级别岗位有高管面或交叉面

**面试偏好的候选人特质**：
- 扎实的技术基本功和学术素养
- 对AI大模型有真正的热情和深入思考
- 良好的逻辑思维和表达能力
- 自驱力强，有持续学习的习惯
- 团队协作精神，适应相对规范的企业环境

**面试注意事项**：
- 准备好项目细节，特别是技术难点和解决方案
- 复习好机器学习和深度学习基础，GLM相关的技术论文可以重点关注
- 体现出对智谱产品和技术的了解，展现诚意
- 面试节奏适中，不必过于焦虑，面试官普遍比较专业和友善

# 薪资福利

智谱AI的薪资福利体系在AI大模型行业中处于第一梯队，对标一线互联网大厂，同时作为上市公司，股权激励更具价值和流动性。

**薪资结构**：
- **基础薪资**：
  - 校招硕士：算法岗40-70万/年，开发岗30-50万/年，产品岗25-40万/年
  - 校招博士：算法岗60-120万/年，特别优秀者面议
  - 社招P6（高级）：年薪40-70万
  - 社招P7（资深）：年薪70-120万
  - 社招P8（专家）：年薪120-200万+
  - 核心技术负责人：年薪200万以上+大量股权
- **年终奖**：14-16薪为主，绩效优秀者可达更多
- **股权激励**：作为上市公司，核心员工可获得股票期权或RSU，股权价值随公司成长增值，且流动性好于未上市公司

**福利体系**：
- 六险一金（补充医疗保险）
- 带薪年假10-20天
- 弹性工作制，部分岗位支持混合办公
- 免费三餐或餐补
- 健身房、下午茶、团建活动
- 年度体检
- 技术分享与培训机会丰富
- 员工股票期权计划

**薪资特点**：
- 整体对标一线大厂，核心算法岗有竞争力
- 股权激励价值高，但股价波动也带来不确定性
- 晋升通道相对清晰，薪资增长与职级挂钩
- 不同岗位差异较大，算法和核心技术岗溢价明显
- 地域差异：北京总部薪资最高，杭州、上海、深圳分公司基本持平

**注意事项**：智谱作为上市公司，薪资体系相对透明规范，但也意味着议价空间相对创业公司略小。股票价值与公司股价直接挂钩，波动较大。整体而言，智谱的薪资福利在行业中具有较强竞争力，且平台稳定性优于未上市的创业公司。

# 办公地点

智谱AI实行多城市布局，在北京、杭州、上海、深圳四地设有办公地点。

**北京总部**：位于北京市海淀区中关村核心区域，是公司的管理、研发和运营中心。北京团队规模最大，覆盖GLM大模型研发、产品、商业化、职能支持等所有部门。清华系的人才优势和中关村的科技创新氛围是北京总部的核心竞争力来源。AI原点社区是智谱所在的重要产业集聚地。

**杭州分公司**：设有研发和产品团队，主要负责部分工程技术、产品开发和华东区域客户服务。杭州作为互联网人才高地，为智谱提供了丰富的人才资源。

**上海分公司**：设有研发和商业化团队，覆盖金融、制造等行业的华东客户拓展与服务。上海的国际化优势和金融资源对智谱的企业业务发展具有战略意义。

**深圳分公司**：主要负责华南区域的客户拓展和技术支持，覆盖粤港澳大湾区的企业客户。深圳在硬件、制造、互联网等领域的产业资源与智谱的行业落地战略高度契合。

办公环境方面，智谱作为上市公司，办公条件良好，配备完善的基础设施和员工福利设施。核心技术团队以线下办公为主，以保障高效协作和数据安全。部分岗位支持灵活办公安排。

- **海外业务拓展**：GLM模型出海加速，海外销售、国际化运营、本地化团队需求上升。

**战略与组织动态**：

- 商业模式从项目制向token计费转型，云平台和API相关团队扩张
- 数字员工战略推进，行业解决方案团队按垂直领域细化

**行业竞争格局**：
- 智谱与DeepSeek、月之暗面、MiniMax并称中国AI"四小龙"
- 在人才市场上，与字节跳动、阿里达摩院、腾讯等大厂的AI团队存在直接竞争
- 凭借上市公司平台和股权激励，智谱在中高端人才招聘中具有独特优势
- 清华系背景对学术型人才有天然吸引力

# 应聘建议

对于希望加入智谱AI的求职者，以下建议可供参考：

**技术准备**：
- 深入理解Transformer架构和大模型核心技术，特别关注GLM系列的技术特点和论文
- 夯实机器学习、深度学习、数学（概率论、线性代数、优化理论）基础
- 算法岗需刷题准备，LeetCode Medium-Hard难度，重点关注动态规划、图论、字符串等
- 工程岗需准备系统设计，特别是分布式系统、高并发架构相关知识
- 关注最新研究进展，特别是长上下文、多模态、Agent等智谱重点方向

**简历优化**：
- 突出大模型相关的项目经历和技术成果，顶会论文、开源贡献是重要加分项
- 量化项目成果，用数据说话，如模型效果提升、推理速度优化、成本降低等
- 体现与智谱业务方向的匹配度，如多模态、代码模型、行业解决方案等
- 清华系背景或相关实验室经历可以重点突出

**面试技巧**：
- 技术面试注重原理理解，回答问题时展现思考过程和推导逻辑
- 准备好GLM相关的技术知识，体现对智谱技术路线的了解和认同
- 项目介绍采用STAR法则，清晰阐述背景、任务、行动和结果
- 面对不会的问题，坦诚说明并尝试从原理出发推导，展现思维能力
- 反问环节可以询问技术挑战、团队规划、产品路线等问题，体现深度思考

**职业发展考量**：
- 智谱作为已上市公司，平台稳定性好，适合追求相对稳定发展的求职者
- 全栈布局意味着职业选择面广，内部转岗机会多
- 清华系文化和学术氛围适合喜欢技术深耕的人
- 股权激励是重要的收益来源，但需关注股价波动风险
- 建议优先选择核心业务方向（如GLM预训练、多模态、数字员工），资源倾斜和发展空间更大
- B端和G端客户资源丰富，对想在行业解决方案方向发展的求职者是好机会
