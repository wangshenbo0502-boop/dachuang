# 公司概况

中国移动通信集团有限公司（简称"中国移动"）是中央直接管理的国有重要骨干企业，是全球最大的电信运营商，总部位于北京市。中国移动成立于2000年，前身是中国电信移动通信资产总体剥离组建的中国移动通信集团公司，2017年完成公司制改制，更名为中国移动通信集团有限公司。

中国移动是全球网络规模最大、客户数量最多的电信运营商，拥有全球最大的移动用户群体和5G网络。截至2025年底，中国移动移动用户规模超过10亿户，5G套餐用户超过7亿户，宽带用户超过3亿户。公司在香港联交所和上海证券交易所两地上市，是中国电信行业的领军企业。

近年来，中国移动积极推进"创世界一流信息服务科技创新公司"战略，加快从传统运营商向信息服务科技创新公司转型。公司大力发展5G、云计算、大数据、人工智能、物联网等新一代信息技术，数字政企业务快速增长，科技人才需求持续扩大。中国移动旗下拥有中国移动研究院、中国移动设计院、咪咕公司、中移物联网、中移（杭州）信息技术有限公司等多家专业子公司。

- **行业**: 电信运营/信息服务
- **性质**: 中央企业
- **总部**: 北京市
- **员工规模**: 40万人以上
- **定位**: 全球最大的电信运营商，创世界一流信息服务科技创新公司

# 主营业务与产品

中国移动业务涵盖基础电信服务和信息服务两大领域，主要业务和产品包括：

- **移动通信服务**: 提供2G/4G/5G移动通信服务，包括语音通话、短信彩信、移动数据流量等基础服务，是全球最大的移动网络运营商。
- **5G业务**: 建设和运营全球最大的5G网络，提供5G ToC和5G ToB服务，推动5G在工业互联网、智慧矿山、智慧医疗等领域的应用。
- **家庭宽带服务**: 提供家庭宽带接入、IPTV电视、智能家居等服务，是中国最大的固定宽带运营商之一。
- **云计算（移动云）**: 中国移动旗下的云计算品牌，提供IaaS、PaaS、SaaS全栈云服务，是政务云、企业云市场的重要参与者，发展迅速。
- **大数据业务**: 基于海量用户数据提供大数据分析和应用服务，包括位置大数据、用户画像、精准营销、智慧城市等应用。
- **物联网业务（OneNET）**: 中移物联网有限公司运营的物联网平台，提供连接管理、设备管理、应用开发等服务，是国内领先的物联网平台。
- **人工智能**: 打造"九天"人工智能平台，提供智能客服、智能网络、智慧营销等AI能力和解决方案。
- **数字政企**: 面向政府和企业客户提供数字化转型解决方案，包括智慧政务、智慧城市、工业互联网、智慧交通、智慧医疗等。
- **咪咕文化**: 中国移动旗下的数字内容公司，提供音乐、视频、阅读、游戏、动漫等数字内容服务。
- **国际业务**: 提供国际漫游、国际专线、海外云服务等，服务全球客户。

# 招聘岗位

中国移动招聘岗位类型丰富，涵盖技术、市场、运维、产品等多个方向，近年来技术岗占比持续提升：

- **云计算工程师**: 云平台开发、云原生、云运维、云安全、云解决方案
- **大数据工程师**: 大数据平台开发、数据仓库、数据分析、数据挖掘
- **AI/算法工程师**: 机器学习、深度学习、NLP、计算机视觉、推荐算法
- **网络技术工程师**: 5G网络、核心网、传输网、无线网、网络优化
- **软件开发工程师**: Java/Go/Python开发、前端开发、测试开发
- **数据通信工程师**: 路由器、交换机、SDN/NFV、IP网络
- **网络安全工程师**: 网络安全、数据安全、应用安全、安全运营
- **产品经理**: 云产品、5G产品、大数据产品、行业解决方案
- **运营专员/经理**: 市场运营、产品运营、客户运营
- **运维工程师**: 网络运维、系统运维、IT运维、动环运维

# 校招情况

中国移动校园招聘每年统一组织，规模庞大，是应届生进入央企的重要途径。

| 项目 | 详情 |
|------|------|
| 招聘规模 | 每年招聘数万人 |
| 主要岗位 | 技术岗、市场岗、运维岗、职能岗 |
| 薪资范围 | 总部和一线城市15-25万年薪，二三线10-18万 |
| 工作城市 | 全国各省均有，北京总部 |
| 学历要求 | 本科及以上 |

**校招特点**:
- 每年7月左右统一启动网申，9-11月笔试面试
- 统一笔试，各省公司和专业公司分别面试
- 云计算、5G、大数据、政企岗对留学生开放，部分免统考笔试
- 省公司之间薪资和发展差异较大，总部和发达省份待遇较好
- 技术岗主要集中在研究院、专业公司和省公司技术部门
- 六险二金，福利完善，工作稳定
- 可解决当地户口，部分城市有住房补贴
- 竞争相对激烈，热门城市和岗位报录比较高

# 社招情况

中国移动社会招聘主要面向有工作经验的专业人才，以中高级技术和管理人才为主。

- **招聘渠道**: 官网招聘、猎聘、BOSS直聘、内部推荐、猎头
- **热门岗位**: 云计算专家、大数据专家、5G专家、行业解决方案专家
- **经验要求**: 通常3年以上相关工作经验
- **薪资范围**: 根据职级和地区，年薪15-60万不等，高端人才可面议
- **特点**: 看重行业经验和专业能力，有运营商、华为、互联网公司工作经验者优先
- 社招有正式工和外包两种形式，需注意区分
- 部分岗位有编制，稳定性强

# 技术栈

中国移动技术栈覆盖通信网络、云计算、大数据、AI等多个技术领域：

- **后端语言**: Java（主力）、Go、Python、C/C++
- **云计算**: OpenStack、Kubernetes、Docker、移动云平台
- **大数据**: Hadoop、Spark、Flink、Hive、HBase、大数据平台
- **AI/ML**: TensorFlow、PyTorch、九天AI平台、NLP、CV
- **网络技术**: 5G、4G、核心网、无线网、传输网、SDN/NFV
- **数据库**: MySQL、Oracle、Redis、分布式数据库
- **中间件**: 消息队列、微服务、服务治理、API网关
- **物联网**: OneNET平台、NB-IoT、MQTT、边缘计算
- **安全技术**: 网络安全、数据安全、等保合规、密码技术
- **运维技术**: Linux、自动化运维、监控告警、DevOps

中国移动在5G网络技术、通信网络架构、运营商大数据等领域拥有深厚的技术积累，同时在云计算和AI领域快速发展。

# 面试特点

中国移动面试流程规范，各省公司和专业公司略有差异，但整体流程统一。

| 项目 | 详情 |
|------|------|
| 面试轮次 | 笔试 + 2轮面试（技术/综合 + HR） |
| 笔试内容 | 行测 + 专业知识 + 性格测试 |
| 技术考察 | 专业基础知识、岗位相关技能 |
| 综合考察 | 综合素质、沟通表达、职业规划 |

**面试特点**:
- 统一笔试是第一关，行测+专业知识+性格测试，笔试占比较高
- 面试通常2轮：一面技术/综合面，二面HR面
- 技术岗面试考察专业基础知识，难度中等
- 重视学历和学校背景，985/211院校有优势
- 综合面关注综合素质、沟通能力、稳定性
- 部分省公司有群面环节
- 整体难度中等，但竞争激烈，热门岗位报录比高
- 流程较长，从网申到offer通常需要2-3个月

# 薪资福利

中国移动薪资福利完善，不同省公司和岗位差异较大，但总体在当地处于中等偏上水平。

| 项目 | 详情 |
|------|------|
| 总部/一线城市 | 年薪15-25万（校招） |
| 二线城市 | 年薪12-18万 |
| 三线及以下 | 年薪8-15万 |
| 六险二金 | 五险一金 + 补充医疗保险 + 企业年金 |
| 住房补贴 | 部分省公司提供住房补贴或人才公寓 |
| 节日福利 | 节日礼金、购物卡、实物福利 |
| 带薪年假 | 5-15天/年 |

**其他福利**:
- 年度体检、补充医疗保险
- 工会福利、生日福利
- 餐补、交通补贴、通信补贴
- 住房公积金缴纳比例高（通常12%）
- 工作稳定，裁员风险极低
- 解决当地户口（部分城市）
- 培训体系完善，晋升通道清晰
- 子女教育资源（部分地区）
- 退休待遇优厚

# 办公地点

中国移动在全国各省市自治区均设有分公司，办公地点遍布全国。

- **北京**: 集团总部、中国移动研究院、多家专业公司，岗位级别高
- **上海**: 上海移动、研究院分院、部分专业公司
- **广东**: 广东移动（最大省公司）、深圳移动、广州移动
- **浙江**: 浙江移动、中移（杭州）信息技术有限公司
- **江苏**: 江苏移动、苏州研发中心
- **四川**: 四川移动、成都研究院
- **其他省份**: 各省会城市和主要城市均有省公司和市公司
- 专业公司分布：咪咕（厦门/北京/上海等）、中移物联网（重庆）、中移在线（洛阳等）

# 岗位需求变化与最新动态

近年来，中国移动的岗位需求呈现以下趋势：

- **数字化与信息科技岗扩招**: 2026年数字化与信息科技类一线岗位缺口涨30%，云计算、大数据、AI、网络安全等方向持续扩招。
- **5G人才需求旺盛**: 5G网络建设和应用推广带动5G相关岗位需求，5G网络优化、5G行业应用等岗位增加。
- **移动云快速发展**: 移动云业务高速增长，云计算研发、云解决方案、云销售等岗位需求大幅增加。
- **政企数字化转型**: 数字政企业务快速发展，行业解决方案、智慧城市、工业互联网等岗位需求增长。
- **AI和大数据**: AI和大数据相关岗位需求持续上升，智能客服、智能网络、数据中台等方向扩招。
- **网络运维自动化**: 网络运维向自动化、智能化转型，传统运维岗需求减少，DevOps、自动化运维岗位增加。
- **物联网业务拓展**: 物联网业务快速发展，物联网平台、行业应用等岗位需求增长。

2026年最新动态显示，中国移动加快向信息服务科技创新公司转型，科技人员占比持续提升，云计算、大数据、AI等方向的人才需求增长最快。

# 应聘建议

- **岗位选择**: 根据自己的专业和兴趣选择合适的岗位，技术岗建议优先选择研究院、专业公司或省公司技术部门，发展空间更大。
- **地区选择**: 不同省公司待遇和发展差异很大，建议优先考虑总部、研究院和经济发达省份的公司。
- **笔试准备**: 笔试是关键，提前准备行测（言语理解、数量关系、判断推理、资料分析）和专业知识。行测建议多刷真题，专业知识复习核心课程。
- **面试准备**: 技术岗复习专业基础知识，准备好项目经验。综合面试准备好自我介绍、为什么选择中国移动、职业规划等常见问题。
- **了解公司**: 了解中国移动的战略方向和业务布局，特别是5G、移动云、数字化转型等重点方向。
- **多投多面**: 中国移动招聘单位众多，可以同时投递多个省公司或专业公司，增加成功率。
- **关注提前批**: 部分单位有提前批招聘，关注官方信息，提前投递。
- **稳定性考量**: 中国移动工作稳定，适合追求稳定生活的同学，但也要考虑个人成长和职业发展。
