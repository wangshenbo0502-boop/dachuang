# 华为

## 公司概况

- **行业**: 通信/ICT/消费者
- **规模**: 超大型（20万+人）
- **目标院校**: 985/211 + 部分双非强校（目标院校名单制）

## 招聘重点

- C/C++/Java/Python 至少精通一门
- 扎实的计算机基础
- 能接受出差/外派

## 技术栈偏好

- C/C++
- Java
- Python
- 嵌入式/通信相关

## 面试风格

| 项目 | 详情 |
|------|------|
| 面试轮次 | 机考 + 2轮技术面 + 1轮主管面 |
| 编码考核比重 | 中（有机考环节，3道 LeetCode 中等题） |
| 项目深挖程度 | 中 |

**面试特点**:
- 机考是第一关（不通过直接淘汰）
- 重视学校背景和学历
- 有性格测试

## 薪资范围

| 类型 | 薪资 |
|------|------|
| 应届生 | 18k-30k * 14-16薪 + 签字费 |

## 优缺点

### 优势
- 平台大/稳定性高
- 技术积累深厚（芯片/OS/通信）
- 全球轮岗机会

### 劣势
- 加班文化（部分部门）
- 流程繁琐

## 准备建议

- 机考 600 分是硬门槛，优先刷华为机考题库
- C/C++ 基础必须扎实
- 了解通信/嵌入式基础知识（加分）
