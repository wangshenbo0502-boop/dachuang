# 公司概况

华为技术有限公司成立于1987年，总部位于深圳，是全球领先的ICT（信息与通信技术）基础设施和智能终端提供商，员工总数约20万人，业务遍及170多个国家和地区。华为是一家100%由员工持有的民营企业（工会持股），未上市。

华为的业务版图覆盖：运营商网络（5G/5.5G领导者）、企业业务（政企数字化）、终端业务（手机/PC/穿戴/鸿蒙生态）、云计算（华为云）、数字能源、智能汽车解决方案（引望）以及集成电路（海思）。在遭受多年外部制裁后，华为通过Mate/Pura系列手机回归、鸿蒙操作系统（HarmonyOS）生态扩张、昇腾AI算力体系自主化，实现了技术自立与业务复苏，2024年年报收入重回8600亿元级别。

对计算机专业求职者，华为是"体制外最稳定的巨头"：校招规模常年超万人（证券时报报道），技术方向覆盖芯片、操作系统、编译器、数据库、网络、云计算、AI全栈，是基础软件与硬件方向人才的最重要雇主。目标院校名单制下，除985/211外还覆盖部分双非强校。

# 主营业务与产品

**ICT基础设施（运营商BG + 企业BG）**：5G/5.5G无线网络、光网络、数据通信、核心网——全球份额领先；政企数字化（智慧城市、金融、能源、交通行业解决方案）。

**终端BG（消费者业务）**：Mate/Pura系列高端手机回归市场前列；HarmonyOS（鸿蒙）已成为中国市场份额领先的移动操作系统（纯血鸿蒙HarmonyOS NEXT已商用），PC（搭载鸿蒙系统的MateBook/鸿蒙电脑）、平板、穿戴、智慧屏构成全场景生态。

**海思芯片**：麒麟（SoC）、昇腾（AI训练/推理）、鲲鹏（服务器CPU）、巴龙（基带）等芯片设计能力是国内自主可控的代表。

**华为云**：中国前二、全球五大的云厂商，盘古大模型（行业大模型路线的代表）、ModelArts AI开发平台、GaussDB数据库、云原生产品线。

**计算产品线**：鲲鹏服务器生态 + 昇腾AI算力（Atlas系列、CANN异构计算架构、MindSpore框架）——国产AI算力底座的核心力量，在全国建设多个智算中心。

**数字能源与智能汽车解决方案**：光伏逆变器、数据中心能源；引望（车BU）为车企提供智能驾驶（ADS）、智能座舱方案，是增长最快的新业务之一。

# 财务与经营状况

华为未上市，按年报披露经营数据：

- **收入复苏**：2024年全球销售收入8621亿元人民币，同比增长22%，重回历史高位；净利润626亿元
- **研发投入**：2024年研发费用1797亿元，占收入20.8%，近十年累计研发投入超1.2万亿元——研发强度全球科技企业前列
- **生态扩张**：鸿蒙生态设备数超10亿；昇腾AI算力集群（CloudMatrix等）在国产大模型训练中广泛部署

对求职者的含义：研发预算充沛、招聘稳定、涉足"卡脖子"技术攻关（芯片、EDA、操作系统、大模型），基础研究方向岗位数量与质量在国内无出其右。

# 技术实力与核心技术

**昇腾AI算力体系**：Atlas服务器/集群 + CANN异构计算架构 + MindSpore深度学习框架（开源）+ 昇腾芯片，构成国产替代的完整AI基础设施；2026年发布的新一代昇腾芯片与超节点集群（CloudMatrix 384等）支撑国内大模型训练主力。

**鸿蒙操作系统**：微内核设计、分布式软总线、一次开发多端部署（ArkTS/ArkUI）；HarmonyOS NEXT去除AOSP兼容层，原生应用生态快速扩张，鸿蒙开发人才供不应求。

**5G与光通信**：无线技术全球专利份额第一；光传输、光交换处于行业顶尖。

**高斯数据库（GaussDB）**：国产数据库代表，金融、政企核心系统落地案例多。

**盘古大模型**：面向行业的"AI for Industry"路线（气象、矿山、药物、电力等），与通用大模型差异化。

**编译器与语言**：方舟编译器、仓颉编程语言（面向全场景应用开发的新语言）——基础软件自研的代表。

# 招聘岗位

**校招规模**：华为校园招聘规模超万人（证券时报报道），2027届应届生招聘已启动（面向2027年1月1日-12月31日毕业的国内本硕，2026年1月1日-2027年12月31日毕业的国内博士与海外本硕博）。

**主要技术岗位方向**：
- 软件开发（C/C++/Java/Python/Go）：通信软件、终端应用、云服务、车控软件
- 鸿蒙开发（ArkTS/ArkUI）：终端生态应用开发，需求爆发
- 昇腾/AI方向：AI框架、算子开发、大模型训练与推理优化（MindSpore/CANN）
- 芯片与硬件：数字IC设计、验证、EDA算法（海思）
- 算法：无线算法、媒体算法、自动驾驶（引望ADS）
- 测试、网络安全、解决方案、技术支持（海外常驻机会多）

**天才少年计划**：华为顶尖技术人才培养计划，面向全球吸引优秀博士，年薪分三档（公开报道最高档曾达201万元），已有代表性成果如大幅提升AI大模型在昇腾算力底座上的训练推理性能（普林斯顿ECE博士案例）。华为云设有独立的天才少年招聘（面向云、计算、AI领域）。官网通道：career.huawei.com 天才少年专区。

# 校招情况

**流程**：网申 → 机考（3道编程题，600分为通过线） → 性格测试 → 2轮技术面试 → 主管面 → Offer审批。华为流程周期较长（审批环节多），建议早投递。

**机考特点**：3道题，难度约LeetCode Easy-Medium，总分600（AK线）；机考不通过直接淘汰，刷华为机考题库（牛客"华为OD/校招机试"专题）是必备功课。

**院校偏好**：目标院校名单制，985/211全覆盖+双非强校（邮电、电子类等）；博士与顶尖人才有单独通道。

**性格测试**：华为校招特色环节，测试职业性格与价值观匹配；不过关会有复测机会。

**风险与注意**：华为Offer分批发放、审批周期长；部分岗位入职后可能分配至海外研究所或客户现场，签约前与HR确认工作地点与业务方向。

# 社招情况

社招需求集中在：
- **AI算力生态**：昇腾算子、推理优化、大模型训练框架（对接国产芯片的迁移适配）——当前最热
- **鸿蒙生态**： ArkTS应用开发、鸿蒙底层（图形、内核）
- **车BU（引望）**：智能驾驶、智能座舱全栈方向
- **华为云**：云原生、数据库、大模型服务化
- **海思**：芯片设计、EDA、先进封装

社招职级：13-22级（13-14级校招起步，15-16资深，17+专家/管理者），薪酬 = 月薪×(12-16) + 奖金 + TUP/ESOP分红。OD（外包渠道，人力外包"精英"计划）与正式员工在薪酬与股票上有明显差异，投递时注意区分招聘性质。

# 技术栈

**语言**：C/C++（系统软件、通信、终端底层主力）、Java（云与政企服务）、Python（算法/AI）、Go（云原生）、ArkTS（鸿蒙应用）、仓颉（新业务探索）。
**AI栈**：MindSpore、CANN、昇腾NPU工具链、盘古大模型、ModelArts。
**操作系统与数据库**：鸿蒙/OpenHarmony、欧拉openEuler、GaussDB。
**嵌入式与通信**：RTOS、DSP、5G协议栈。
**工具链**：自研IDE（DevEco）、方舟编译器、毕昇编译器。

# 面试特点

| 项目 | 详情 |
|------|------|
| 面试轮次 | 机考 + 2轮技术面 + 1轮主管面 |
| 编码考核 | 中，机考3道LeetCode中等题（600分门槛），面试手撕较少但机考是硬关 |
| 项目深挖 | 中，重视项目完整度与工程规范 |
| 八股比重 | 中，C/C++语言特性、OS、网络基础常考；通信岗考通信原理 |

**经典考察点**：
- 通用：数据结构（链表/树/图）、排序与查找、动态规划基础题
- C++岗：内存管理、虚函数与多态、智能指针、STL容器实现
- 嵌入式/终端岗：进程线程调度、中断、Linux驱动基础
- AI岗：深度学习基础、算子优化、CUDA/异构计算（昇腾方向加分）
- 性格测试与主管面：价值观（艰苦奋斗）、抗压、地点意愿

**面试文化**：务实、重基础、流程规范；主管面关注稳定性（能否接受出差/外派/加班）与长期意愿。

# 岗位需求变化与最新动态

- **校招规模超万人**：与腾讯等大厂并列大规模校控行列（证券时报），2027届招聘与宣讲会已于2026年8月启动。
- **昇腾AI生态扩军**：国产算力集群（CloudMatrix超节点）部署带动算子开发、推理优化、训练框架岗位激增；天才少年代表案例即"AI大模型在昇腾算力底座上的性能提升"。
- **鸿蒙原生开发人才荒**：HarmonyOS NEXT生态扩张使ArkTS开发者供不应求，校招社招同步放量。
- **车BU（引望）独立化**：智能驾驶方案商业化（问界等车型热销）带动ADS算法与车控软件需求。
- **实习生招聘**：2026年5月11日华为2027届实习生招聘启动，实习转正是重要入口。

# 应聘建议

**技术准备**：
- 机考是第一关：刷透牛客华为机考题库，确保3题拿到600分通过线
- C/C++基础必须扎实（内存、多态、智能指针、STL）；目标终端岗需学ArkTS与鸿蒙应用开发
- 昇腾/AI方向了解MindSpore、异构计算基础；算法岗复习深度学习与模型部署
- 准备好"为什么选华为/能否接受外派"类稳定性问题

**投递策略**：
- 早投递（流程长、分批发Offer）；同时投递多个BU（终端、云、计算、车BU）
- 博士与顶尖成果者直接走天才少年通道（官网单独入口）
- 注意区分正式校招与OD招聘渠道

**谈薪与选择**：华为Offer级别谈判空间有限（按面试评级定级），但TUP长期分红可观；若目标长期发展（尤其芯片、OS、AI Infra方向），华为是国内最深的积累平台。
