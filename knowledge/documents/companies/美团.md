# 公司概况

美团（HKEX: 3690）成立于2010年，总部位于北京，是中国最大的生活服务电子商务平台，创始人为王兴。公司使命"帮大家吃得更好，生活更好"，业务覆盖外卖、即时零售（美团闪购）、到店餐饮与综合服务、酒店旅游、交通出行（美团打车）、共享单车等，并孵化了无人机配送、自动配送车等前沿科技业务。海外外卖平台Keeta已在香港、沙特等市场快速扩张。

美团拥有超过千万级的日活跃用户和数百万骑手构成的即时配送网络，是"线上+线下"复杂度最高的互联网业务之一：毫秒级订单调度系统（超脑系统）、LBS技术、大规模推荐与搜索、供应链SaaS构成其技术画像。

对计算机专业求职者，美团是"技术味最浓的Java大厂"：后端以Java技术栈为核心（自研中间件众多），校招培养体系成熟（"新人训练营"机制），2026届校招招募6000人、技术岗占比超三分之一，2026年春招再补招6000人，招聘规模居大厂前列。

# 主营业务与产品

**核心本地商业**：
- **外卖**：日订单量峰值超亿级，是全球规模最大的外卖平台；配送调度（ ETA 预估、路径规划、运力调度）是算法与工程的顶级场景
- **美团闪购（即时零售）**：万物到家的30分钟配送网络，与淘宝闪购、京东秒送正面竞争，是当前投入最大的战场
- **到店与酒旅**：到店餐饮、休闲娱乐、酒店预订、机票火车票，利润奶牛业务

**新业务**：
- **美团优选/小象超市**：社区团购与线上超市（优选业务规模收缩调整中）
- **Keeta**：海外外卖业务，2023年起进入香港，2024年起进入沙特等中东市场，是国际化战略核心
- **无人机与自动配送车**：城市低空配送网络与L4自动驾驶配送车已在多个城市落地常态化运营

**AI与科技**：
- **LongCAT龙门大模型**：2025-2026年发布的自研大模型（语言/多模态/编程方向），编程模型在开源榜单表现领先
- **AI助手"问小白"与商家端AI工具**：覆盖C端问答与B端经营提效
- 2026届校招新增AI产品经理、AI Agent开发工程师等岗位，并首次引入AI胜任力考察模块

# 财务与经营状况

美团在港交所上市，按季度披露财报：

- **收入规模**：2024年度营收超3300亿元人民币，核心本地商业贡献主要收入与利润
- **利润拐点**：2024年起实现经调整净利润大幅转正，经营现金流健康；即时零售竞争（外卖大战）带来补贴投入压力
- **AI与自动化投入**：无人机、自动配送车、大模型研发投入持续加大；资本开支向AI基础设施倾斜

对求职者的含义：主业盈利、现金流强，招聘规模稳定且逐年扩大；即时零售与外卖竞争（对淘宝闪购、京东）使交易、履约、算法岗位需求处于高位。

# 技术实力与核心技术

**配送"超脑"系统**：全球最大规模的即时配送调度系统，运筹优化（订单指派、路径规划、ETA预估）与机器学习深度结合，发表多篇顶会论文。

**Java技术体系**：后端以Java为核心，自研了大批基础设施——服务治理（OCTO）、消息队列（基于Kafka/RocketMQ的封装）、分库分套件（Zebra）、监控（CAT同类体系）等，是国内Java工程师成长体系最完善的公司之一。

**大数据与算法**：Spark/Flink大数据平台、大规模特征平台、搜索推荐广告全链路；LBS相关技术（地图、定位、路径）积累深厚。

**无人机与自动驾驶**：城市低空物流网络（FP400系列无人机）与L4级自动配送车，涉及飞控、感知、规划、车路协同，硬件+软件复合人才需求旺盛。

**LongCAT大模型**：自研大模型家族，编程方向模型（LongCAT-Code）在SWE-bench等代码基准上表现领先，2026年开源后在开发者社区反响积极。

# 招聘岗位

**2026届校园招聘**：全球启动，计划招募6000人，覆盖技术、产品、商业分析、运营、金融、零售、职能等10大类、100余种岗位，技术岗位占比超三分之一，工作地点涉及北京、上海、香港、迪拜等全球几十个城市（新华网2025年7月报道）。

**2026年春季校招**：补招6000名2026届毕业生，同时为2027届毕业生开放超过3000个转正实习岗位（中新经纬2026年3月报道）。

**主要技术岗位**：
- 后端开发（Java主力方向：外卖、闪购、到店、金融）
- 算法工程师（配送调度、搜索推荐、大模型、计算机视觉）
- 前端/客户端开发、数据开发、测试开发、运维/SRE
- 无人机/自动配送车方向（嵌入式、感知规划、飞控）

**特色项目**：
- **北斗计划**：面向前沿技术研究、对AI充满热情的顶尖人才专项（zhaopin.meituan.com/web/beidouprogram）
- **AI产品经理提前批**、AI Agent开发工程师等新增AI岗位

# 校招情况

**流程**：网申 → 笔试（技术岗：编程题+基础选择题） → 2-3轮技术面试 → HR面。美团流程以快著称，面试反馈周期短。

**院校偏好**：以985/211为主，双非技术强校（如邮电类、电子类院校）机会较多；美团是"双非友好度"较高的大厂之一。

**实习**：日常实习与暑期实习全年滚动，转正机制透明（实习生评级转正）；2027届3000+转正实习岗位规模大，是进入美团的黄金通道。

**培养**：新人有体系化培训（技术训练营+导师制），内部转岗与晋升通道清晰，"练级"体验在大厂中口碑好。

# 社招情况

社招需求集中在：
- **即时零售战场**：交易、履约、营销、供应链方向的后端与算法（竞争带来的HC高地）
- **AI方向**：大模型研发与应用（LongCAT）、AI Agent、搜索推荐
- **国际化（Keeta）**：海外业务的全栈工程师与算法，常驻/出差中东、香港
- **无人机/自动配送**：稀缺的 robotics 全栈方向

社招职级：校招起点约L7-L8（对应工程师序列），资深L9-L10，专家及以上对应更高；晋升需答辩。Java后端社招量长期居大厂前列。

# 技术栈

**后端**：Java（Spring Boot/Spring Cloud、自研RPC OCTO、Zebra分库分表）、Go（新业务与基础组件）、Python（算法）。
**数据**：Kafka、Flink、Spark、ClickHouse、Hive、自研特征平台。
**存储**：MySQL、Redis、MongoDB、Elasticsearch、TiDB（部分场景）。
**前端**：React为主、小程序生态、Node.js BFF。
**AI**：PyTorch、LongCAT自研模型、vLLM推理、RAG与Agent平台。
**基础设施**：Kubernetes、Docker、自研发布系统（Juno类）、全链路压测体系。

# 面试特点

| 项目 | 详情 |
|------|------|
| 面试轮次 | 2-3轮技术面 + 1轮HR面 |
| 编码考核 | 中高，Java相关题目多（集合、并发、JVM）+ 算法题（LeetCode Medium为主） |
| 项目深挖 | 高，重视实际编码与业务落地能力 |
| 八股比重 | 中高，MySQL/Redis/网络/OS基础必考 |

**经典考察点**：
- Java岗：HashMap/ConcurrentHashMap、线程池参数与执行流程、JVM分区与GC、Spring事务与AOP、MySQL索引与执行计划、Redis缓存一致性
- 算法岗：机器学习基础、运筹优化（配送调度场景题）、大模型RAG/微调
- 系统设计：外卖订单系统、优惠券系统、库存扣减、骑手调度
- 场景题特色：美团爱出业务场景题（秒杀、红包、拼单），考察工程直觉

**面试文化**：务实、节奏快、反馈快；面试官多为一线工程 Leader，问题贴近业务实战；2026届校招起部分岗位加入AI胜任力考察。

# 办公地点

- **总部**：北京（望京、恒电大厦等多园区；2025年起逐步迁往新总部）
- **主要研发中心**：上海、成都、厦门（点评系）、深圳、广州等
- **海外**：香港、沙特利雅得等（Keeta业务）

北京岗位最多；成都、厦门研发中心工作生活平衡较好。

# 岗位需求变化与最新动态

- **招聘规模扩大**：2026届校招6000人+春招补招6000人+2027届3000转正实习，总招聘量在大厂中名列前茅。
- **AI岗位密集新增**：AI产品经理、AI Agent开发工程师等新岗位首次进入校招；校招新增AI胜任力考察模块。
- **即时零售大战**：外卖与闪购竞争（对淘宝闪购、京东秒送）使交易/履约/算法方向持续缺人。
- **自研大模型落地**：LongCAT模型开源与内部全面接入，带动大模型工程化岗位。
- **Keeta国际化**：中东与东南亚扩张带来外派与全球化技术岗位。

# 应聘建议

**技术准备**：
- Java后端是校招主力：扎实准备Java集合/并发/JVM、MySQL、Redis、消息队列，配合业务场景题演练（秒杀、优惠券）
- 算法岗复习机器学习与运筹优化基础，了解配送调度、ETA预估等美团特色问题
- 大模型方向关注LongCAT技术报告与RAG/Agent工程实践
- 刷题以LeetCode Medium为主，注意手写代码规范

**投递策略**：
- 暑期实习转正优先（2027届转正实习3000+名额）；北斗计划适合顶尖AI人才
- 投递时注意选择业务方向：闪购/外卖/到店核心业务资源与成长最优
- 面试反馈快，可并行多部门推进

**面试要点**：场景题回答体现工程Trade-off思维；项目讲解突出量化结果（订单量、延迟、收益）；HR面准备对美团业务（即时零售竞争、AI战略）的理解。
