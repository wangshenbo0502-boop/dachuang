# 公司概况

理想汽车是中国新能源汽车新势力的领军企业之一，总部位于北京。公司成立于2015年，由李想创立，以"创造移动的家，创造幸福的家"为使命，专注于家庭智能电动车市场。理想汽车以精准的产品定位和高效的运营能力著称，旗下L系列SUV持续蝉联30万以上新能源SUV销量榜首，是中国新势力造车中销量最高的品牌之一。

理想汽车在港股（HK: 2015）上市，是国内盈利能力最强的新势力车企。公司在北京、上海、常州、重庆、杭州等地设有研发中心和生产基地。理想汽车坚持产品驱动，以用户需求为核心，在增程电动技术、智能座舱、自动驾驶（理想AD）等领域积累深厚。企业文化强调理性、务实和结果导向，技术团队规模庞大且成长迅速。

在智能驾驶领域，理想汽车的AD Max系统采用全栈自研路线，城市NOA功能已覆盖全国主要城市。理想汽车在大模型和端到端智驾方面投入巨大，致力于打造行业领先的智能驾驶体验。同时，理想的智能座舱以家庭用户为中心，多模态交互和后排娱乐系统体验出色。

- **行业**: 新能源汽车/智能驾驶/出行科技
- **性质**: 民营企业（新势力造车，港股上市）
- **总部**: 北京
- **研发中心**: 北京、上海、杭州、深圳
- **生产基地**: 常州、重庆
- **员工规模**: 数万人（科技人员占比高）
- **公司地位**: 中国新势力造车销量冠军，家庭智能电动车领导者

# 主营业务与产品

理想汽车业务聚焦家庭用户，产品和技术围绕"移动的家"展开：

- **理想L系列SUV**: L9、L8、L7、L6，覆盖全尺寸到紧凑型SUV，主打家庭用户
- **理想MEGA**: 纯电MPV，家庭出行新选择，搭载800V高压平台和5C超充
- **自动驾驶（理想AD）**: 全栈自研自动驾驶系统，支持城市NOA、高速NOA、自动泊车
- **智能座舱**: 全车交互系统、后排娱乐、家庭场景功能、理想同学语音助手
- **增程电动技术**: 增程器、电池、电驱系统自研，解决里程焦虑
- **超充网络**: 5C超充站建设，覆盖全国主要城市和高速路网
- **软件服务**: 自动驾驶软件订阅、车内娱乐服务等软件收入

理想汽车的核心优势在于产品定义能力和用户洞察，能够精准把握家庭用户需求并快速落地。

理想汽车科技岗位需求旺盛，自动驾驶和智能座舱为核心招聘方向：

| 岗位类别 | 主要方向 | 需求程度 |
|----------|----------|----------|
| 自动驾驶算法工程师 | 感知、预测、规划、控制 | 极高 |
| C++开发工程师 | 自动驾驶系统、车机系统、嵌入式 | 高 |
| 大模型算法工程师 | NLP、多模态、端侧大模型应用 | 极高（扩招中） |
| 智能座舱开发 | 车机应用、语音交互、HMI设计开发 | 高 |
| 大数据工程师 | 数据平台、数据仓库、智驾数据闭环 | 高 |
| 后端开发工程师 | Java/Go后端服务、业务系统开发 | 中高 |

| 测试开发工程师 | 软件测试、自动化测试、质量保障 | 中 |

自动驾驶和大模型相关岗位占技术岗招聘的50%以上，是理想汽车人才战略的核心方向。

理想汽车校招薪资在新势力造车中具有竞争力，自动驾驶算法岗薪资最高。

| 项目 | 详情 |
|------|------|
| 招聘时间 | 每年8-9月秋招，3-4月春招补录 |
| 学历要求 | 本科及以上，算法岗硕士优先 |
| 目标院校 | 985/211及海外名校，双非优秀生源也有机会 |
| 工作地点 | 北京、上海、常州、重庆、杭州 |
| 热门部门 | 智能驾驶、智能座舱、大模型团队 |

**校招薪资**（2026届参考）：
- 白菜价（研发硕士）：26-33K × 15薪，年薪39-50万
- SP薪资：36-46K × 15薪，年薪54-69万
- 算法岗（硕士）：28-42K × 15薪，年薪42-63万
- 大模型岗（硕士）：32-48K × 15薪，年薪48-72万
- 博士另议，顶尖人才可走SSP通道，年薪80万+
- 本科薪资比硕士低约15-20%

**校招特点**：
- 自动驾驶和算法岗位薪资溢价明显
- 技术面试轮次多，重视工程能力和产品思维
- 实习转正比例较高，暑期实习竞争激烈
- 北京岗位最多，杭州和上海次之
- 产品思维和业务理解能力受重视
- 技术氛围好，成长速度快

# 社招情况

理想汽车社招需求大，自动驾驶、大模型、智能座舱为重点方向。

- **招聘渠道**: 官网招聘、猎聘、BOSS直聘、内推、脉脉、领英
- **经验要求**: 通常2-5年以上相关经验，专家岗位要求5-10年
- **薪资范围**: 中级工程师30-60万，高级工程师60-120万，技术专家120-200万+
- **热门方向**: 自动驾驶端到端、大模型算法、系统架构师
- **职级体系**: P序列（专业技术）和M序列（管理）双通道
- **招聘节奏**: 业务驱动，核心岗位常年开放
- **股票激励**: 核心岗位有RSU股票激励，长期收益潜力大

社招流程：简历筛选 → 技术笔试（部分岗位）→ 2-3轮技术面 → 总监面 → HR面 → 录用。整体流程较快，通常2-3周完成全流程。

理想汽车技术体系完整，自动驾驶和智能座舱技术深度在行业内处于第一梯队，大模型应用场景丰富。

# 面试特点

理想汽车技术面试注重工程能力和业务理解，算法难度中等偏上。

| 项目 | 详情 |
|------|------|
| 面试轮次 | 3-4轮技术面 + 1轮HR面 |
| 算法难度 | 中等偏难 |
| 工程考察 | 重工程能力和系统设计 |
| 业务理解 | 看重产品思维和业务sense |

**面试特点详解**：
- **技术面考察深度**：面试官会追问项目细节，考察对技术原理的理解深度
- **算法题**：以LeetCode中等题为主，注重解题思路和代码质量，部分困难题
- **系统设计**：高级岗位考察架构设计能力和工程思维
- **产品理解**：重视候选人的产品思维和对用户需求的理解
- **价值观匹配**：理想很看重候选人是否认同公司文化和价值观
- **自动驾驶岗**：考察算法基础、代码质量和对自动驾驶的理解
- **整体风格**：务实高效，关注解决实际问题的能力和结果导向

建议候选人重点准备：算法题（LeetCode 300+）、C++/Python基础、项目经历深度准备、对理想产品的了解、自动驾驶相关知识。

# 办公地点

理想汽车在全国多个城市设有研发和办公基地：

- **北京**: 总部所在地，位于顺义区/朝阳区。自动驾驶、智能座舱核心研发，总部职能部门
- **上海**: 研发中心，位于浦东新区。造型设计、智能网联、部分研发团队
- **常州**: 制造基地，位于武进区。生产制造和部分研发岗位
- **重庆**: 生产基地和研发中心，智能制造和部分研发
- **杭州**: 研发中心，位于余杭区。智能座舱、算法研发中心

# 岗位需求变化与最新动态

2025-2026年，理想汽车岗位需求随业务快速发展呈现以下趋势：

| 方向 | 需求变化 | 说明 |
|------|----------|------|
| 端到端智驾 | 大幅增长 | 端到端技术路线转型，算法团队扩招 |
| 大模型/AI | 快速增长 | 大模型在车机、语音、智驾等场景全面应用 |
| 智能座舱 | 稳步增长 | 多模态交互、理想同学升级带动座舱研发需求 |
| 自动驾驶数据 | 快速增长 | 数据闭环体系建设，数据团队扩招 |
| 整车研发 | 平稳增长 | 新车型持续推出，需求稳定 |
| 出海业务 | 快速增长 | 海外市场布局，国际化人才需求增加 |
| 制造工艺 | 平稳 | 产能扩张带动，但自动化程度提升 |

**最新动态**：
- 2026年理想汽车销量持续增长，新车型和改款车型密集推出
- 城市NOA全国覆盖加速推进，自动驾驶团队持续扩招
- 大模型在智能驾驶和智能座舱全面落地，AI算法岗需求激增
- 端到端自动驾驶技术路线投入加大，相关人才争夺激烈
- MEGA和纯电车型发展，三电和高压平台岗位需求增加
- 海外市场战略启动，国际化和本地化人才需求上升
- 整体技术团队规模持续扩大，是新能源汽车行业招聘热度最高的企业之一

# 应聘建议

- **技术准备**:
  - 算法：LeetCode中等题熟练，注重代码质量和解题思路，准备300+题量
  - C++/Python：至少精通一门，熟悉语言特性和常用库
  - 自动驾驶岗：复习计算机视觉、深度学习、路径规划等专业知识
  - 系统设计：了解分布式系统和高可用架构（中高级岗位）

- **面试技巧**:
  - 准备有深度的项目，能讲清楚技术方案和业务价值
  - 算法题先沟通思路再写代码，注意边界条件
  - 展现务实态度，强调结果导向和学习能力
  - 了解理想产品特点和用户定位，体现产品思考
  - 准备几个有质量的问题问面试官，展示思考深度

- **投递建议**:
  - 自动驾驶、大模型方向发展空间大，建议优先考虑
  - 北京岗位最多，杭州智能座舱团队也很强
  - 内推效率高，通过校友或社交平台寻找理想员工内推
  - 暑期实习转正比例高，建议尽早申请实习

- **适合人群**:
  - 对智能电动汽车和AI有浓厚兴趣
  - 产品思维强，关注用户体验
  - 追求快速成长，能接受创业公司节奏
  - 务实肯干，结果导向
  - 看好新能源汽车和智能出行的长期发展
