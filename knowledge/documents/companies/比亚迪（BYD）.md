# 公司概况

比亚迪股份有限公司（BYD）是全球新能源汽车领导者，总部位于广东省深圳市。公司成立于1995年，最初以二次充电电池业务起步，经过三十余年发展，已成为横跨汽车、轨道交通、新能源和电子四大产业的综合性高新技术企业。比亚迪是全球唯一同时掌握电池、电机、电控及整车制造等新能源汽车全产业链核心技术的企业，凭借垂直整合能力和规模效应，在新能源汽车市场占据领先地位。

比亚迪在A股和H股两地上市，市值位居全球汽车企业前列。公司在全球拥有数十个生产基地和研发中心，员工总数超百万人，是中国制造业的标杆企业。2022年比亚迪超越特斯拉成为全球新能源汽车销量冠军，并持续保持领先优势。

在技术创新方面，比亚迪拥有刀片电池、DM-i超级混动、e平台3.0、CTB电池车身一体化等核心技术，构建了强大的技术护城河。近年来，比亚迪加速智能化转型，在智能驾驶、智能座舱等领域加大投入，从"电动化领导者"向"智能化引领者"迈进。

- **行业**: 新能源汽车/动力电池/汽车制造
- **性质**: 民营企业（A股/H股上市）
- **总部**: 深圳
- **生产基地**: 深圳、西安、常州、合肥、长沙、郑州等全国数十个城市
- **员工规模**: 超70万人（全球）
- **公司地位**: 全球新能源汽车销量冠军，中国汽车工业领军企业

# 主营业务与产品

比亚迪业务版图庞大，形成了以新能源汽车为核心的多元化产业布局：

- **新能源汽车**: 王朝系列（汉、唐、宋、秦、元）、海洋系列（海豹、海豚、海鸥）、腾势（高端品牌）、仰望（百万级高端品牌），覆盖从入门到豪华的全价格带
- **动力电池**: 刀片电池（磷酸铁锂）、三元锂电池，外供特斯拉、丰田等多家车企
- **电子业务**: 手机部件及组装、笔记本电脑、汽车电子，客户包括苹果、华为等全球知名品牌
- **光伏与储能**: 太阳能电池及组件、储能系统、新能源整体解决方案
- **轨道交通**: 云轨（跨座式单轨）、云巴（胶轮有轨电车），城市轨道交通解决方案
- **半导体**: 车规级IGBT、MCU、功率半导体，自研自用+对外供应

比亚迪是全球少有的具备从电池到整车完全垂直整合能力的企业，这种模式使其在成本控制和供应链安全方面具备显著优势。

比亚迪招聘岗位种类繁多，覆盖研发、制造、质量、供应链等全链条：

| 岗位类别 | 主要方向 | 需求程度 |
|----------|----------|----------|

# 校招情况

比亚迪是中国最大的校招雇主之一，每年招聘规模庞大，是理工科学生的重要就业选择。

| 项目 | 详情 |
|------|------|
| 招聘时间 | 每年9-10月秋招，3-4月春招补录 |
| 学历要求 | 本科及以上，研发岗硕士优先，博士另有通道 |
| 目标院校 | 985/211/双一流及重点理工科院校 |
| 工作地点 | 深圳（总部）、西安、上海、常州、合肥等全国多地 |
| 热门部门 | 汽车工程研究院、中央研究院、弗迪电池、规划院 |

**校招薪资**（2026届参考）：
- 研发岗（硕士）：18-30万 × 13-16薪，年薪23-48万
- 研发岗（博士）：35-60万 × 13薪 + 安家费，年薪45-80万+
- 研发岗（本科）：12-20万 × 13-16薪，年薪16-32万
- 工艺/质量岗（硕士）：15-22万年薪
- 智能驾驶/算法岗薪资较高，可达30-45万年薪（硕士）

**校招特点**：
- 招聘规模极大，每年校招人数超万人
- 岗位种类丰富，从研发到制造全覆盖
- 深圳总部研发岗竞争激烈，基地岗位相对容易
- 博士有专门的引进计划，薪资待遇优厚，有安家费和科研启动资金
- 面试流程相对简洁，效率较高
- 提供住宿或住房补贴，生活成本相对较低

# 社招情况

比亚迪社招需求旺盛，尤其在智能化和高端研发领域持续扩招。

- **招聘渠道**: 官网招聘、猎聘、BOSS直聘、内推、猎头
- **经验要求**: 通常1-5年相关工作经验，专家岗位要求5-10年以上
- **薪资范围**: 中级工程师20-40万，高级工程师40-80万，专家/总监80-200万+
- **热门方向**: 智能驾驶算法、智能座舱、芯片设计、三电系统
- **职级体系**: 技术序列和管理序列双通道，职级从F级到A级
- **招聘节奏**: 全年持续招聘，业务扩张期节奏加快
- **跳槽价值**: 比亚迪背景在新能源汽车行业认可度高

社招流程：简历筛选 → 技术面试 → 综合面试 → HR谈薪 → 录用。整体流程较快，通常1-2周完成。

# 面试特点

比亚迪面试风格务实，注重专业能力和综合素质，整体难度中等。

| 项目 | 详情 |
|------|------|
| 面试轮次 | 2-3轮面试（技术面 + 综合面 + HR面） |
| 技术难度 | 中等（研发岗偏难） |
| 考察重点 | 专业基础、项目经验、学习能力 |
| 英语要求 | 较低（大部分岗位不要求） |

**面试特点详解**：
- **技术面试**：考察专业基础知识和项目经验，会问具体的技术问题和实现细节
- **算法考核**：软件和算法岗有算法题，难度中等，以LeetCode简单和中等题为主
- **项目深挖**：会深入了解候选人做过的项目，考察解决问题的思路和能力
- **综合面试**：由部门领导面试，考察综合素质、职业规划、价值观匹配
- **HR面试**：谈薪资、了解求职动机、确认入职时间
- **面试节奏**：流程较快，通常一天内完成所有面试
- **风格特点**：面试官大多务实，注重实际能力和动手能力，不太看重花架子

建议候选人重点准备：专业基础知识（汽车/电子/软件）、项目经历（准备2-3个深度项目）、对应岗位的技术栈、对比亚迪和行业的了解。

# 薪资福利

比亚迪薪资在汽车行业中处于中高水平，研发和智能化岗位薪资竞争力强。

| 福利项目 | 详情 |
|----------|------|
| 基础薪资 | 按岗位和学历定薪，研发岗薪资较高 |
| 年终奖金 | 1-3个月工资，部分部门更多（13-16薪） |
| 五险一金 | 全额缴纳五险一金 |
| 住房补贴 | 提供员工宿舍或住房补贴（各基地不同） |
| 员工购车 | 员工购车优惠政策，折扣力度大 |
| 带薪年假 | 5-15天/年，按国家规定执行 |
| 餐饮福利 | 员工食堂，餐补或低价餐饮 |
| 学历提升 | 在职深造支持、内部培训体系 |

**薪资特点**：
- 研发岗薪资显著高于制造和职能岗
- 智能驾驶和算法岗薪资向互联网看齐，溢价明显
- 博士薪资待遇优厚，有安家费和科研启动资金
- 深圳总部薪资最高，各基地薪资略有差异
- 整体薪资低于造车新势力，但工作稳定性和规模优势突出
- 晋升通道清晰，技术和管理双通道发展

# 岗位需求变化与最新动态

2025-2026年，比亚迪岗位需求随业务快速发展呈现以下趋势：

| 方向 | 需求变化 | 说明 |
|------|----------|------|
| 智能驾驶 | 大幅增长 | 智能化转型核心方向，天神之眼团队扩招 |
| 智能座舱 | 快速增长 | 车机系统升级，DiLink团队持续扩张 |
| 三电研发 | 稳步增长 | 技术迭代和产能扩张带动需求 |
| 芯片/半导体 | 快速增长 | 车规芯片自研，半导体事业部扩招 |
| 整车研发 | 平稳增长 | 新车型持续推出，需求稳定 |
| 制造工艺 | 平稳 | 产能扩张带动，但自动化程度提升 |
| 海外业务 | 快速增长 | 出口和海外建厂加速，国际化人才需求增加 |

**最新动态**：
- 2026年比亚迪新能源汽车年销量持续增长，全球市场份额进一步提升
- 智能化战略加速推进，智能驾驶和智能座舱团队大规模扩招
- 天神之眼高阶智驾系统发布后，算法和软件开发岗位需求激增
- 海外市场快速扩张，欧洲、东南亚、拉美等地建厂，国际化人才需求增加
- 高端品牌仰望和腾势持续发展，高端研发和设计岗位增加
- 半导体业务分拆上市进程推进，芯片设计和工艺岗位扩招
- 整体招聘规模持续扩大，是新能源行业最大的雇主之一

# 应聘建议

- **技术准备**:
  - 专业基础：扎实的汽车工程、电子工程或计算机基础
  - 嵌入式：C/C++编程、MCU开发、AUTOSAR知识（车载软件岗）
  - 算法岗：数据结构和算法基础，LeetCode中等题熟练
  - 智能驾驶：计算机视觉、深度学习、ROS、自动驾驶基础

- **面试技巧**:
  - 项目经历准备充分，能讲清楚技术方案和遇到的问题及解决方法
  - 体现学习能力和动手能力，比亚迪很看重实干精神
  - 了解比亚迪的企业文化和发展战略，表达对比亚迪的认可
  - 面试中保持务实态度，不要过度包装，展示真实能力

- **投递建议**:
  - 优先投递智能驾驶、智能座舱等智能化方向，发展空间大
  - 深圳总部研发岗薪资高但竞争激烈，可考虑上海/常州研发中心
  - 内推效率更高，可通过校友或社交平台寻找比亚迪员工内推
  - 博士走人才引进通道，待遇和发展空间更好

- **适合人群**:
  - 对新能源汽车行业有热情，愿意在制造业深耕
  - 追求稳定发展，看重企业规模和行业地位
  - 专业背景匹配（车辆工程、自动化、电子信息、计算机等）
  - 能接受制造业的工作节奏和环境
  - 希望在大型平台积累经验，长期发展
