# 公司概况

国家电网有限公司（简称"国家电网"）是中央直接管理的国有独资公司，是全球最大的公用事业企业，总部位于北京市。国家电网成立于2002年，是在原国家电力公司部分企事业单位基础上组建的特大型国有企业，关系国家能源安全和国民经济命脉。

国家电网以投资建设运营电网为核心业务，承担着保障安全、经济、清洁、可持续电力供应的基本使命。公司经营区域覆盖全国26个省、自治区、直辖市，覆盖国土面积的88%以上，供电服务人口超过11亿人。国家电网连续多年位列《财富》世界500强前列，是全球最大的电力企业。

近年来，国家电网大力推进电网数字化转型和新能源发展，在特高压、智能电网、新能源消纳、能源互联网等领域取得了举世瞩目的成就。公司积极推进"一体四翼"发展布局，加快建设具有中国特色国际领先的能源互联网企业。在技术创新方面，国家电网在特高压输电、大电网控制、新能源并网等领域拥有世界领先的技术水平。

- **行业**: 电力/能源/公用事业
- **性质**: 中央企业（国有独资）
- **总部**: 北京市
- **员工规模**: 150万人以上
- **定位**: 全球最大的公用事业企业，能源互联网建设的引领者

# 主营业务与产品

国家电网以电网运营为核心，业务涵盖电力全产业链：

- **电网运营**: 建设和运营全国性电网，包括输电、变电、配电、售电等环节，为社会提供安全可靠的电力供应。
- **特高压输电**: 建设和运营特高压交流和直流输电工程，实现远距离、大容量、低损耗输电，是全球特高压技术的领导者。
- **智能电网**: 推进智能电网建设，实现电网的信息化、自动化、互动化，提高电网运行效率和可靠性。
- **新能源消纳**: 大力推动新能源并网和消纳，支持风电、光伏等新能源发展，促进能源转型和碳达峰碳中和。
- **电力调度**: 负责全国电力调度和电网安全稳定运行，保障电力系统安全可靠供电。
- **配电业务**: 建设和运营配电网，为终端用户提供电力配送服务，推进配电网智能化升级。
- **售电业务**: 在电力市场化改革背景下，开展售电业务，为用户提供多元化的电力服务。
- **电力装备制造**: 通过下属企业生产变压器、开关、线缆等电力设备，是国内重要的电力装备制造商。
- **数字化与信息服务**: 推进电网数字化转型，发展电力大数据、人工智能、工业互联网等业务。
- **国际业务**: 在海外投资建设和运营电网项目，业务遍布多个国家和地区。

# 招聘岗位

国家电网招聘岗位类型多样，涵盖电工、计算机、通信、财会等多个专业类别：

- **电工类岗位**: 电网运行维护、变电检修、输电运检、配电运检、电力调度
- **计算机类岗位**: 软件开发、数据分析、网络安全、信息化建设、系统运维
- **通信类岗位**: 通信网络运维、通信工程建设、通信设备维护
- **财会类岗位**: 财务会计、审计、税务、财务管理
- **其他工学类岗位**: 土木工程、机械工程、自动化、环境工程
- **管理类岗位**: 人力资源、行政管理、企业管理、市场营销
- **法学类岗位**: 法律事务、合规管理、合同管理
- **经济类岗位**: 经济分析、电力市场、投资管理

主要招聘单位包括：国家电网总部、各区域分部、各省电力公司、中国电力科学研究院、国网经济技术研究院、国网信息通信产业集团、许继集团、平高集团、南瑞集团等。

# 校招情况

国家电网校园招聘是每年规模最大的央企校招之一，分为一批和两批次招聘。

| 项目 | 详情 |
|------|------|
| 招聘规模 | 每年招聘数万人 |
| 主要岗位 | 电工类、计算机类、通信类、财会类等 |
| 薪资范围 | 一线城市15-25万年薪，二三线10-18万 |
| 工作城市 | 全国各省市均有 |
| 学历要求 | 本科及以上，部分岗位专科可报 |

**校招特点**:
- 提前批7月初-中旬线下宣讲启动，正式批分两批（12月和次年3月）
- 电工类、计算机类、财会类是紧缺专业，优先招聘
- 各省公司分开招聘，独立组织考试和面试
- 统一笔试，笔试占比高，是进入面试的关键
- 以电工类专业为主，计算机和通信类需求逐年增长
- 工作稳定，福利完善，是很多同学的首选
- 可解决当地户口，部分城市有安家费
- 不同省公司和市县公司差异较大

# 社招情况

国家电网社会招聘相对较少，主要面向有经验的专业技术人才和管理人才。

- **招聘渠道**: 官网招聘、内部推荐、猎头
- **热门岗位**: 高级工程师、专家人才、管理岗位
- **经验要求**: 通常5年以上相关工作经验
- **薪资范围**: 根据职级和地区，年薪15-50万不等
- **特点**: 社招名额较少，门槛较高，看重行业经验和专业资质
- 有注册电气工程师、注册会计师等证书者优先
- 社招通常也是正式编制，稳定性强

# 技术栈

国家电网技术体系以电力技术为核心，融合信息技术和通信技术：

- **电力技术**: 电力系统分析、继电保护、高电压技术、电力电子技术
- **自动化技术**: 变电站自动化、配电自动化、调度自动化
- **信息技术**: Java、Python、C/C++、大数据、云计算
- **通信技术**: 电力通信、光纤通信、无线通信、5G
- **特高压技术**: 特高压交流、特高压直流、换流技术
- **智能电网**: 智能变电站、智能电表、配电自动化
- **新能源技术**: 风电并网、光伏并网、储能技术、微电网
- **数据库**: Oracle、MySQL、Redis、时序数据库
- **工业互联网**: 电力物联网、边缘计算、数字孪生
- **安全技术**: 网络安全、工控安全、密码技术

国家电网在特高压输电、大电网安全稳定控制、新能源大规模并网等领域拥有世界领先的技术水平。

# 面试特点

国家电网面试以笔试为基础，面试流程规范，各省略有差异。

| 项目 | 详情 |
|------|------|
| 面试轮次 | 统一笔试 + 1-2轮面试 |
| 笔试内容 | 综合能力 + 专业知识 |
| 笔试占比 | 较高（通常60%左右） |
| 面试考察 | 专业知识、综合素质、沟通表达 |

**面试特点**:
- 统一笔试是关键，笔试成绩占比高，决定能否进入面试
- 笔试内容包括综合能力（行测+电力能源战略）和专业知识
- 面试通常1-2轮，半结构化面试为主
- 电工类岗位重点考察电力系统、继电保护等专业知识
- 计算机类岗位考察编程基础、数据库、计算机网络等
- 重视学校背景和专业对口度
- 综合面关注综合素质、稳定性、家国情怀
- 整体难度中等，但笔试竞争激烈
- 体检和政审严格，是央企招聘的标准流程

# 薪资福利

国家电网薪资福利完善，不同地区和岗位差异较大，但总体在当地处于中上水平。

| 项目 | 详情 |
|------|------|
| 一线城市 | 年薪15-25万（校招） |
| 二线城市 | 年薪12-18万 |
| 三线及以下 | 年薪8-15万 |
| 六险二金 | 五险一金 + 补充医疗保险 + 企业年金 |
| 住房补贴 | 部分单位提供住房补贴或周转房 |
| 节日福利 | 节日礼金、购物卡、实物福利 |
| 带薪年假 | 5-15天/年 |

**其他福利**:
- 年度体检、补充医疗保险
- 高温补贴、取暖补贴
- 餐补、交通补贴
- 住房公积金缴纳比例高（通常12%）
- 工作非常稳定，几乎没有裁员风险
- 解决当地户口
- 培训体系完善，有师徒制
- 工会福利丰富
- 退休待遇优厚
- 子女教育资源（部分地区）

# 办公地点

国家电网在全国各省市均设有分公司和供电企业，办公地点遍布全国。

- **北京**: 集团总部、国网研究院、南瑞集团北京分部等
- **上海**: 上海电力公司、华东分部
- **江苏**: 江苏电力公司（最大省公司之一）、南京供电公司
- **浙江**: 浙江电力公司、杭州供电公司
- **广东**: 广东电网（属南方电网，非国家电网）
- **四川**: 四川电力公司、成都供电公司
- **山东**: 山东电力公司、济南供电公司
- **湖北**: 湖北电力公司、武汉供电公司
- 全国26个省、自治区、直辖市均有国家电网公司
- 各市县均有供电公司，岗位覆盖基层到总部

注：广东、广西、云南、贵州、海南五省区属南方电网，非国家电网经营区域。

# 岗位需求变化与最新动态

近年来，国家电网的岗位需求呈现以下趋势：

- **电网数字化岗位需求大幅增长**: 电网数字化转型加速，计算机、大数据、AI、网络安全等数字化岗位需求同比大幅增长。
- **新能源电站运维岗扩招**: 新能源快速发展，风电、光伏电站运维和新能源并网岗位需求增加。
- **特高压建设持续推进**: 特高压工程持续建设，相关技术和工程岗位需求稳定。
- **智能电网升级**: 智能电网建设和升级改造，带动智能化、自动化相关岗位需求。
- **电力市场改革**: 电力市场化改革推进，电力交易、市场分析等岗位需求增加。
- **储能和综合能源**: 储能技术和综合能源服务快速发展，相关岗位需求上升。
- **电工类仍是主力**: 电工类岗位仍然是招聘的主力，但计算机和通信类占比持续提升。

2026年最新动态显示，国家电网加快推进新型电力系统建设，新能源、数字化、智能化相关的人才需求增长最快，计算机类岗位招聘人数逐年增加。

# 应聘建议

- **专业匹配**: 国家电网最看重专业对口，电工类专业机会最多，计算机、通信、财会等专业也有较多岗位。
- **笔试准备**: 笔试是关键，笔试占比高，一定要认真准备。综合能力部分多练行测，专业知识部分复习核心课程。
- **地区选择**: 不同省公司待遇和发展差异很大，建议根据自己的情况选择合适的地区。省会城市和发达地区待遇好但竞争激烈，基层单位竞争小但发展空间有限。
- **提前批机会**: 提前批7月就开始了，主要面向985/211和电力院校的优秀学生，有机会免笔试或优先录取，一定要抓住。
- **证书加分**: 英语四六级、计算机二级、注册电气工程师等证书在网申和面试中都有加分作用。
- **面试准备**: 复习好专业基础知识，准备好自我介绍和常见问题。体现稳定性和对电力行业的认同。
- **多手准备**: 国家电网竞争激烈，建议同时准备南方电网和其他电力企业，增加成功机会。
- **基层锻炼**: 新入职员工通常需要在基层锻炼一段时间，要有心理准备，基层经验对职业发展很重要。
