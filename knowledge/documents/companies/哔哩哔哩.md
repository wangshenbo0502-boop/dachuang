# 公司概况

哔哩哔哩（Bilibili，NASDAQ: BILI / HKEX: 9626）成立于2009年，总部位于上海，是中国年轻世代高度聚集的文化社区和视频平台，被用户亲切称为"B站"。公司以弹幕视频起家，构建了PUGV（专业用户创作视频）+OGV（专业机构创作内容：纪录片、国创动画、综艺）+直播+Story Mode（竖屏短视频）的综合视频生态，并延伸出游戏、电商（会员购）、广告等商业化业务。

B站社区以Z世代为核心（用户平均年龄约20余岁），独特的弹幕文化与"一键三连"社区互动构成强用户粘性。董事长兼CEO陈睿，创始人徐逸。公司已在美股与港股双重上市，2024年起实现单季度盈利，进入"增毛利、控成本、促增长"的健康经营阶段。

对计算机专业求职者，B站是"热爱驱动的技术雇主"：业务涵盖视频（转码、推荐、播放体验）、直播（低延迟推流）、游戏（自研+发行）、AI（AIGC辅助创作、AI搜索）等方向；团队规模数千人，社招开放职位约500+个，技术氛围年轻开放，面试体验口碑好。

# 主营业务与产品

**社区与视频**：主App的Feed推荐、搜索、播放器技术（自研播放内核）、弹幕系统（实时消息洪峰）、Story Mode竖屏流。技术挑战包括亿级视频的存储/转码/分发（PCDN生态）、推荐与搜索的社区特色（兴趣圈层、知识区内容）。

**直播**：虚拟主播（VTuber）生态是国内最大，直播推流、低延迟互动、连麦技术。

**OGV内容**：纪录片、国创（动画）自制内容的技术制作管线与版权管理。

**游戏**：独家代理《FGO》《碧蓝航线》长期贡献稳定流水；自研与发行并行，二次元品类是基本盘。游戏技术服务于发行运营与自研项目。

**电商与会员购**：手办、周边等二次元消费电商。

**AI与AIGC**：AI搜索助手（搜索结果AI摘要）、AIGC创作工具（智能剪辑、AI字幕、封面生成）、必剪App的AI功能；开源Index-1.9B等轻量模型与index-tts语音模型在开源社区有影响力。

# 财务与经营状况

B站在美股与港股上市，按季度披露财报：

- **盈利拐点**：2024年第三季度首次实现单季度盈利（调整后），2025-2026年保持盈利态势，广告与游戏成为增长引擎
- **收入结构**：增值服务（大会员/直播）+广告+游戏+电商四轮驱动；广告收入增速领先（效果广告放量）
- **成本优化**：带宽与内容成本占比下降，经营效率持续改善

对求职者的含义：公司从"烧钱换增长"转向健康盈利，招聘更聚焦核心业务（广告、游戏、AI、视频技术）， HC质量重于数量。

# 技术实力与核心技术

**视频技术**：自研播放器内核与转码管线、窄带高清（画质增强+码率优化）技术处于行业前列，直接服务于带宽成本优化；PCDN分享技术降低分发成本。

**弹幕与实时互动**：亿级弹幕的存储、过滤、实时分发是特色技术场景。

**推荐与搜索**：多目标排序（三连、完播、评论）、兴趣圈层建模（知识区/游戏区/生活区差异化）。

**AI开源**：Index系列开源模型（Index-1.9B对话模型、IndexTTS语音合成）在GitHub获得广泛Star，是国内中型公司中开源活跃度代表。

**基础设施**：Go语言生态（B站开源了Kratos微服务框架——国内最流行的Go微服务框架之一）、Kubernetes云原生体系、大数据平台（Flink/Spark）。

# 招聘岗位

**校招（jobs.bilibili.com/campus）**：2027届秋招面向毕业时间2026年9月1日-2027年8月31日的应届毕业生。主要方向：
- 后端开发（Go/Java/Python）：社区、直播、电商、游戏服务
- 前端/客户端（Vue/React、iOS/Android）：播放器、创作工具
- 算法：推荐、搜索、多媒体（视频理解/画质）、AIGC
- 数据工程、测试开发、SRE、安全

**B-UP顶尖技术人才项目**（jobs.bilibili.com/campus/bup）：面向海内外本硕博毕业生的顶尖技术人才专项招聘，可提前实习入职——对标大厂SP/SSP的争夺通道。

**社招**：开放职位约519个（2026年9月官网口径），涵盖直播产品、内容消费、流量策略、商业化（广告）、游戏、AI等方向。

**校园大使**：面向2027届及以后在校生的品牌项目，是接触公司的窗口。

# 校招情况

**流程**：网申 → 测评/笔试 → 2-3轮技术面 → HR面。流程规范、反馈速度中等。

**院校偏好**：以985/211及上海本地强校为主，对"B站深度用户"身份有隐性偏好——熟悉社区文化（分区、UP主生态、弹幕礼仪）是面试加分项。

**实习**：日常实习与暑期实习开放，转正机制成熟；上海总部为主。

**竞争度**：技术岗竞争低于字节/腾讯（报录比相对友好），但对社区理解要求更高。

# 社招情况

社招需求集中在：
- **商业化（广告）**：效果广告、投放平台、归因算法——盈利引擎带来的持续需求
- **AI方向**：AIGC工具、AI搜索、内容理解
- **直播与实时技术**：低延迟、音视频传输
- **游戏**：自研项目与发行运营技术

社招薪酬对标上海互联网市场（略低于头部大厂，但WLB与氛围占优）；Kratos开源社区与音视频人才是特色来源。

# 技术栈

**后端**：Go（主力，开源Kratos框架）、Java（部分业务）、Python（算法与工具）。
**前端**：Vue（B站前端Vue生态浓厚）与React并存、TypeScript。
**客户端**：Android/iOS、跨端方案、播放器内核（C++）。
**音视频**：FFmpeg、自研编解码与转码、WebRTC（直播连麦）。
**数据**：Flink、Spark、ClickHouse、Kafka。
**基础设施**：Kubernetes、微服务治理（Kratos生态）、CDN/PCDN。

# 面试特点

| 项目 | 详情 |
|------|------|
| 面试轮次 | 2-3轮技术面 + 1轮HR面 |
| 编码考核 | 中，算法题（LeetCode Easy-Medium为主）+ 语言基础（Go岗考runtime与GC） |
| 项目深挖 | 高，重视技术热情与社区理解 |
| 八股比重 | 中，OS/网络/数据库基础 + 音视频方向特色题 |

**特色考察**：
- Go岗：goroutine调度、channel、GC、Kratos框架理解（加分）
- 音视频岗：编解码基础、FFmpeg使用、直播推流原理
- 社区理解题：如何优化某分区的推荐体验、如何看待弹幕生态治理
- 对B站产品（播放器、直播、创作中心）的体验与建议

**面试文化**：面试官年轻、氛围友好；"用爱发电"的技术热情在面试中是被欣赏的特质。

# 岗位需求变化与最新动态

- **2027届秋招启动**：面向2026年9月-2027年8月毕业的应届生（官网已开放投递）。
- **AI投入加码**：AIGC创作工具、AI搜索、Index系列开源模型迭代带动算法与工程需求。
- **广告商业化**：效果广告与智能投放平台是社招需求最大的方向（约519个社招职位中占比高）。
- **盈利后的组织健康**：控本增效背景下，HC向核心盈利业务（广告、游戏、视频技术）集中。

# 应聘建议

**技术准备**：
- Go后端岗：深入GMP调度、channel、GC，了解Kratos框架源码（开源可读）
- 音视频方向：FFmpeg、编解码、直播推流基础
- 算法岗：推荐/搜索基础 + 多模态内容理解（B站场景特色）
- 前端岗：Vue生态（B站传统）+React，重视播放器与创作工具场景

**投递与面试**：
- 提前深度使用产品：准备对播放体验、推荐流、创作工具的具体观察与改进建议
- B-UP计划适合有竞赛/论文/开源成果的顶尖学生
- 简历突出技术热情（开源项目、技术博客、社区贡献）

**职业考量**：适合热爱二次元/社区文化、看重WLB与氛围的候选人；追求最高现金薪资或最大业务规模者可对比字节/腾讯。
