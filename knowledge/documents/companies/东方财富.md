# 公司概况

东方财富信息股份有限公司（简称"东方财富"）是中国领先的互联网财经信息服务平台，A股上市公司（股票代码：300059），总部位于上海市。公司前身为2004年创立的东方财富网，经过二十余年的发展，已成为集财经资讯、金融数据、证券交易、基金销售于一体的综合性互联网金融服务集团。

东方财富以"让投资更简单"为使命，致力于为广大投资者提供专业、及时、全面的金融信息服务。公司旗下拥有东方财富网、天天基金网、股吧、东方财富证券、Choice金融终端等多个知名品牌，覆盖了从资讯获取、行情分析到交易执行的完整投资链条。东方财富证券是国内首家获得证券全牌照的互联网券商，天天基金网是中国最大的第三方基金销售平台之一。

在技术领域，东方财富拥有强大的研发团队，自主开发了高性能行情系统、大数据分析平台、智能投顾系统等核心技术产品。公司持续加大研发投入，在金融大数据、人工智能、量化交易等领域不断突破，技术实力在金融信息服务行业处于领先地位。

- **行业**: 金融科技/互联网财经信息服务
- **性质**: 民营企业（A股上市公司）
- **股票代码**: 300059.SZ
- **总部**: 上海市
- **员工规模**: 约1-2万人
- **定位**: 中国领先的互联网财经信息服务平台

# 主营业务与产品

东方财富业务布局覆盖金融信息服务全产业链，主要产品和服务包括：

- **东方财富网**: 中国访问量最大、影响力最大的财经证券门户网站之一，提供7×24小时财经资讯、股票行情、基金数据、理财服务等内容。
- **天天基金网**: 国内最大的第三方基金销售平台之一，提供基金净值查询、基金定投、基金组合、基金研究等服务，基金销售规模位居行业前列。
- **股吧**: 中国最大的投资者社区平台，股民可以在这里交流投资心得、分享市场观点、讨论个股行情，具有极高的用户粘性。
- **东方财富证券**: 东方财富旗下的全牌照证券公司，提供证券经纪、融资融券、股票期权、投资顾问等服务，依托互联网优势快速发展。
- **Choice金融终端**: 面向机构投资者和专业投资者的金融数据终端，提供海量金融数据、研究报告、量化工具等，是Wind金融终端的主要竞争对手。
- **东方财富APP**: 移动端综合理财平台，集行情、资讯、交易、理财于一体，用户量位居财经类APP前列。
- **优优私募**: 私募基金服务平台，提供私募产品展示、业绩评价、投资咨询等服务。
- **东方财富期货**: 期货经纪业务，提供期货行情、交易、研究等服务。

# 招聘岗位

东方财富招聘岗位以技术岗和金融岗为主，兼顾产品、运营、市场等职能岗位：

- **后端开发工程师**: Java/Go为主，负责行情系统、交易系统、数据平台等核心系统开发
- **前端开发工程师**: Web前端、移动端H5、小程序开发
- **算法工程师**: 量化算法、推荐算法、NLP、金融数据分析
- **数据开发工程师**: 大数据平台、数据仓库、ETL开发、实时计算
- **测试开发工程师**: 自动化测试、性能测试、测试平台建设
- **产品经理**: 金融产品、数据产品、工具产品、C端/B端产品
- **运营专员/经理**: 用户运营、内容运营、活动运营、社区运营
- **金融研究员**: 行业研究、宏观研究、量化研究、基金研究
- **证券分析师**: 股票分析、行业分析、投资顾问
- **运维工程师**: 系统运维、数据库运维、网络运维

东方财富校园招聘每年定期举办，技术岗和金融岗是校招的主要方向。

- 技术岗和金融研究岗竞争较激烈
- 看重金融知识和数据处理能力
- 有金融相关专业背景或实习经历者优先

- 工作强度略低于互联网大厂，性价比较高

# 社招情况

东方财富社会招聘持续进行，主要招聘有经验的技术人才和金融专业人才。

- **招聘渠道**: 官网招聘、BOSS直聘、猎聘、内部推荐
- **热门岗位**: Java高级开发、大数据开发、量化工程师、金融分析师
- **经验要求**: 通常2-5年相关工作经验
- **薪资范围**: 中级开发20-35K×14薪，高级开发35-55K×14薪
- **特点**: 看重金融行业经验和数据处理能力，有券商、基金公司工作经验者优先
- 面试流程相对高效，通常2-3轮面试即可出结果

# 技术栈

东方财富技术栈以Java和大数据为核心，围绕金融数据处理和交易系统构建技术体系。

- **后端语言**: Java（主力）、Go、Python
- **前端技术**: Vue、React、TypeScript
- **数据库**: MySQL、Oracle、Redis、MongoDB、时序数据库
- **大数据**: Hadoop、Spark、Flink、Hive、HBase、Kafka
- **金融数据**: 行情数据处理、高频数据存储、金融数据建模
- **AI/ML**: 量化策略、推荐算法、NLP（资讯分类/摘要）、智能投顾
- **交易系统**: 低延迟交易系统、撮合引擎、风控系统
- **中间件**: 消息队列、缓存、服务治理、分布式调度
- **运维**: Linux、Docker、Kubernetes、监控告警系统
- **移动端**: iOS、Android、小程序、H5

东方财富在金融数据处理、低延迟行情系统、量化交易平台等领域有较强的技术积累，自研的Choice金融终端在机构市场具有较强竞争力。

- 算法题难度适中，以LeetCode中等题为主
- 注重数据结构和SQL能力
- 产品和运营岗会考察对金融行业的理解和用户思维

# 办公地点

东方财富在全国多个城市设有办公地点，上海是绝对的核心。

- **上海**: 总部所在地，徐汇区和浦东新区均有办公区，岗位最多，覆盖所有业务线
- **北京**: 朝阳区，主要是技术研发和市场团队
- **深圳**: 南山区，华南区域技术和业务团队
- **广州**: 天河区，区域业务和运营团队
- **成都**: 高新区，研发中心和客服中心
- **其他城市**: 南京、武汉、杭州、西安等城市也有少量岗位

# 岗位需求变化与最新动态

近年来，东方财富的岗位需求呈现以下趋势：

- **金融科技持续投入**: 东方财富持续加大金融科技研发投入，技术人员占比稳步提升，研发费用逐年增长。
- **大数据和AI需求增长**: 量化投资、智能投顾、智能风控等业务发展迅速，算法工程师和数据开发工程师需求持续增长。
- **证券业务扩张**: 东方财富证券经纪业务份额持续提升，证券相关的IT系统开发和维护岗位需求稳定。
- **基金销售强劲**: 天天基金网交易规模屡创新高，基金相关的产品和技术岗位需求增加。
- **Choice终端发展**: Choice金融终端机构客户增长迅速，金融数据产品和技术岗位扩招。
- **国际化探索**: 东方财富开始探索国际化业务，港股、美股相关产品和技术岗位逐步增加。

2026年最新动态显示，东方财富在AI大模型应用方面积极布局，智能资讯、智能选股、智能客服等方向的研发投入加大，相关岗位需求有所增长。

# 应聘建议

- **技术准备**: 扎实掌握Java基础、JVM、并发编程、MySQL数据库原理。大数据岗位需深入学习Hadoop、Spark、Flink等技术栈。
- **金融知识**: 学习基本的金融知识，了解股票、基金、证券等基本概念和业务流程，这是东方财富面试的加分项。
- **数据处理能力**: 金融数据处理是核心能力，熟悉SQL优化、数据仓库建模、ETL开发会很有帮助。
- **算法准备**: LeetCode刷题量建议200+，重点练习数组、链表、树、动态规划，中等题要熟练。
- **项目准备**: 准备1-2个相关项目，有金融数据处理、量化交易、推荐系统等项目经验加分。
- **简历优化**: 突出金融相关经验和数据处理能力，有证券从业资格、基金从业资格证书加分。
- **面试技巧**: 表达清晰，体现对金融科技行业的兴趣和理解。准备好回答"为什么选择东方财富"这类问题。
- **投递策略**: 关注东方财富招聘官网，上海岗位最多，机会最大。内推可以提高简历通过率。
