## 文档规范

每篇市场报告遵循以下结构：

1. **Front Matter**：标题、分类、标签、来源、更新时间
2. **数据来源声明 + 免责声明**
3. **6-8 个核心章节**：含行业规模、薪资分析、人才结构、地域分布、趋势建议等
4. **丰富的数据表格**：便于检索和对比
5. **参考来源**：不少于 3 个，标注发布时间和访问时间
