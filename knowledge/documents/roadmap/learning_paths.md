# 技术学习路线总览

本文档汇总了各主要技术岗位从初级到专家的完整职业成长路径和核心技能要求。

---

## 前端开发

> 前端开发是 Web 用户界面的构建者，职业路径清晰，从页面切图到全栈架构师。

### 初级前端工程师（0-1年）— P4/P5 | 薪资范围：12k-22k

**核心能力：**
- 熟练使用 HTML/CSS/JavaScript
- 掌握 Vue 或 React 框架开发
- 能独立完成页面还原和简单交互
- 会使用 Git 和基本的 npm 包管理
- 了解 HTTP 协议和浏览器基础

**日常工作：** 根据设计稿完成页面开发、修复简单 Bug、写组件

**升阶建议：** 深入 JS 核心原理（闭包/原型/异步），开始做全栈项目

### 中级前端工程师（1-3年）— P6 | 薪资范围：22k-35k

**核心能力：**
- 深入理解 JavaScript 核心机制
- 能独立设计复杂组件和前端架构
- 掌握 TypeScript 和工程化工具链
- 有性能优化实战经验
- 了解 Node.js 服务端开发
- 能指导初级工程师

**日常工作：** 负责核心业务模块开发、技术方案设计、Code Review、带新人

**升阶建议：** 深入前端工程化、接触 DevOps、学习系统设计

### 高级前端工程师（3-5年）— P7 | 薪资范围：35k-55k

**核心能力：**
- 精通前端架构设计（微前端/组件库/脚手架）
- 深入理解 Node.js 和 BFF 层设计
- 有跨团队技术方案落地经验
- 能推动技术栈升级和工程化改造
- 对性能/稳定性/安全有体系化认知

**日常工作：** 技术选型与架构规划、跨团队技术方案评审、团队技术氛围建设

**升阶建议：** 从业务视角思考技术价值，扩展后端和系统设计能力

### 前端负责人（5-8年）— P8+ | 薪资范围：55k-80k+

**核心能力：**
- 制定部门前端技术战略
- 跨端方案决策（Web/小程序/跨端框架/SSR）
- 团队管理和人才梯队建设
- 业务架构能力（不只是前端）

**替代路径：** 转全栈工程师（前后端兼顾） | 转前端基础设施/工具链工程师 | 转技术管理

## Java后端开发

> Java 后端是就业面最广、岗位最多的方向。从业务开发到中间件再到架构师，成长曲线长且稳定。

### 初级Java工程师（0-1年）— P4/P5 | 薪资范围：12k-22k

**核心能力：**
- 熟练 Java 基础和 Spring Boot 开发
- 能写 CRUD 接口 + 简单的 SQL
- 了解 MySQL 和 Redis 基础使用
- 会用 Git / Maven / Linux 基础命令

**日常工作：** 实现业务接口、修 Bug、写单元测试

**升阶建议：** 深入 JVM/多线程/MySQL索引，掌握分布式基础

### 中级Java工程师（1-3年）— P6 | 薪资范围：22k-38k

**核心能力：**
- 深入 JVM 原理（GC/内存模型）
- 精通 MySQL 索引优化和分库分表
- 熟练使用 Redis/MQ 等中间件
- 能独立设计中等复杂度的系统
- 有性能调优和线上故障排查能力

**日常工作：** 负责核心功能模块、技术方案设计、线上问题排查、指导新人

**升阶建议：** 深入分布式理论，学习领域驱动设计(DDD)

### 高级Java工程师（3-5年）— P7 | 薪资范围：38k-55k

**核心能力：**
- 掌握分布式系统设计(CAP/一致性/分片)
- 深入微服务架构和治理
- 有大规模系统重构经验
- 能预判技术风险和瓶颈
- 技术方案影响力覆盖多条业务线

**日常工作：** 架构设计评审、核心技术攻坚、疑难问题排查、技术roadmap

### 架构师/技术总监（5-10年）— P8+ | 薪资范围：55k-100k+

**核心能力：**
- 制定公司级技术战略
- 全局架构决策（技术选型/演进路线）
- 多团队技术管理和协调
- 成本/性能/可用性的全局平衡

**替代路径：** 转大数据开发（Spark/Flink） | 转中间件/基础架构开发 | 转技术管理/CTO

## Python数据分析

> 数据分析是企业决策的数据支撑角色，近年需求持续增长。对技术广度要求高于深度。

### 初级数据分析师（0-1年） | 薪资范围：10k-18k

**核心能力：**
- 熟练 SQL + Excel 取数和分析
- Python/Pandas 进行数据处理
- 制作数据看板和常规报表
- 基本的统计分析能力

**日常工作：** 取数跑报表、制作数据看板、配合业务方做简单的数据分析

**升阶建议：** 深入学习统计学 + A/B测试，开始用 Python 做更复杂的分析

### 中级数据分析师（1-3年） | 薪资范围：18k-30k

**核心能力：**
- 独立完成复杂分析课题
- 设计 A/B 测试并解读结果
- 掌握统计学（假设检验/回归/聚类）
- 能产出可落地的业务建议
- 数据可视化讲好故事

**日常工作：** 独立负责一条业务线的分析、设计实验、产出分析报告、推动业务优化

### 高级/专家（3-5年） | 薪资范围：30k-50k

**核心能力：**
- 掌握机器学习建模能力
- 能设计指标体系并推动落地
- 跨部门协作和数据驱动决策
- 有行业深度分析能力

**替代路径：** 转数据工程师（数据仓库/ETL） | 转数据产品经理 | 转机器学习工程师

## AI算法工程师

> AI 算法是薪资天花板最高的方向，但门槛也最高。通常要求硕士起步，博士更有竞争力。

### 初级算法工程师（0-2年） | 薪资范围：25k-40k

**核心能力：**
- 深入理解机器学习和深度学习原理
- 熟练 PyTorch/TensorFlow
- 能独立完成模型训练和调优
- 有论文阅读和复现能力
- Python 和 CUDA 编程基础

**日常工作：** 复现论文模型、在具体数据集上训练和调优、撰写技术报告

**升阶建议：** 深入某个细分方向（CV/NLP/推荐），积累项目经验

### 中级算法工程师（2-4年） | 薪资范围：40k-60k

**核心能力：**
- 在某个细分方向有深度积累
- 能独立设计改进方案并提升指标
- 有模型部署和工程化经验
- 有论文或竞赛成绩

**日常工作：** 算法方案设计、模型优化、跨团队技术对接

### 高级/专家（4-8年） | 薪资范围：60k-100k+

**核心能力：**
- 在学术/工业界有影响力
- 能定义技术方向和路线
- 从0到1搭建技术体系
- 顶级论文/开源项目贡献

**替代路径：** 转 AI 产品经理 | 转 AI Infra 工程师（模型训练加速/推理优化） | 转研究型科学家

## 全栈开发工程师

> 全栈工程师能独立完成前后端开发，在创业公司和中小团队中极受欢迎。大厂中也有全栈角色。

### 初级全栈工程师（0-2年） | 薪资范围：15k-25k

**核心能力：**
- 前端：Vue/React 熟练
- 后端：Node.js/Java/Python 一门熟练
- 数据库：MySQL + 至少一种 NoSQL
- DevOps：Docker + Git + Linux基本操作

**日常工作：** 独立完成中小型需求的前后端开发

**升阶建议：** 深入系统设计，学习云原生和 CI/CD

### 高级全栈工程师（2-5年） | 薪资范围：25k-45k

**核心能力：**
- 前后端都达到中级以上水平
- 能独立设计中等系统的架构
- 掌握云服务(AWS/阿里云)和 CI/CD
- TypeScript 全栈经验

**替代路径：** 转技术负责人/CTO（小公司） | 深耕某一端转专家 | 创业

## 通用建议

- **首份工作选择：** 第一份工作优先选平台（大厂）> 岗位（核心业务）> 薪资
- **跳槽节奏：** 校招入职后建议至少待 2 年再跳
- **技术保鲜：** 技术的半衰期约 3-5 年，保持学习习惯比任何单一技能都重要
- **软技能：** 3年后决定天花板的是沟通、项目管理和业务理解能力，而非纯技术
