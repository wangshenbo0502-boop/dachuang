# 计算机专业大学四年完整规划

> 从大一开始系统规划，四年磨一剑，毕业时手握大厂 offer。本文档按学年拆解每个阶段的核心任务，帮你少走弯路。

---

## 大一：打基础

> 大一最重要的是建立对计算机的兴趣和基本编程能力，不要急于学框架，把基础打牢比什么都重要。

### 上学期（9月-1月）

- **核心课程**：C/C++ 语言入门（指针/内存管理）、计算机导论、高等数学/线性代数
- **课外任务**：加入 ACM 队或编程社团、英语四级（大一上搞定）、PTA/洛谷刷 50+ 入门题
- **关键产出**：能独立写出 200 行以上的 C 语言程序

### 下学期（2月-7月）

- **核心课程**：数据结构（链表/栈/队列/树/图/排序）、离散数学
- **自学任务**：Java 或 Python 第二语言、Git 和 GitHub 基础、Linux 基本命令、LeetCode 简单题 50 道
- **关键产出**：数据结构课程设计拿高分，GitHub 有第一个仓库

### 暑假（7月-8月）

- Python 进阶：面向对象、文件处理、常用库（requests/bs4/numpy）
- 做第一个小项目：个人博客网站 / 爬虫小工具 / 命令行小游戏
- 参加暑期学校或线上夏令营（清北复交等高校常有免费计算机夏令营）
- 阅读经典书籍：《编码》《计算机是怎样跑起来的》

---

## 大二：定方向

> 大二是关键的分水岭。基础课集中，要确定自己的技术方向，开始做有质量的项目。

### 上学期（9月-1月）

- **核心课程**：操作系统（进程/内存/文件系统）、计算机网络（TCP/IP/HTTP/Socket）、数据库系统（SQL/事务/索引）、算法设计与分析
- **课外任务**：LeetCode 中等题 100+ 道（按题型分类刷）、参加校内编程比赛、深入学习一门语言的标准库
- **关键产出**：LeetCode 150 题 + 算法课设拿优

### 下学期（2月-7月）

- **确定方向**（五选一）：
  - **后端开发**：Spring Boot / Django / Go
  - **前端开发**：Vue / React + TypeScript
  - **算法竞赛**：ACM 区域赛 / 蓝桥杯国赛
  - **网络安全**：CTF 入门、渗透测试基础
  - **人工智能**：机器学习入门、PyTorch 基础
- **项目实战**：做一个完整项目（前后端都有）、写技术博客、参与开源项目
- **关键产出**：1 个完整的 GitHub 项目 + 5 篇以上技术博客

### 暑假（7月-8月）

- **优先选择**（按推荐顺序）：① 找第一份实习（小公司也行）② 参加竞赛（蓝桥杯/ACM/数学建模）③ 准备秋招实习的项目和简历
- **暑假学习清单**：系统学习目标方向主流框架、做 1-2 个有亮点的项目、开始看八股文基础题

---

## 大三：冲实习

> 大三是最关键的一年。能不能拿到大厂 offer，基本取决于大三的积累。

### 上学期（9月-1月）

- **深度方向学习**：后端学分布式/微服务/中间件；前端学工程化/性能优化/Node.js；算法深入细分方向；安全学 Web/二进制/云安全
- **刷题**：LeetCode 累计 200+ 道，Hot 100 全部刷完
- **项目**：做 2-3 个有亮点的项目（有技术深度、有数据支撑）
- **简历**：10 月份开始写第一版简历，找学长学姐帮忙改
- **关键产出**：简历 v1.0 + 3 个拿得出手的项目

### 下学期（2月-7月）

- **春招找暑期实习**（大厂优先）：2-3 月投简历笔试面试、目标 BATJ/字节/华为、投 30+ 家面 10+ 家拿 3+ offer
- **系统复习八股文**：操作系统（进程/内存）、计算机网络（TCP/HTTP/DNS）、数据库（索引/事务/锁）、语言基础高频题
- **面试复盘**：每次面试后记录问题，建立自己的面经库
- **关键产出**：大厂暑期实习 offer

### 暑假（7月-8月）

- **大厂实习**：认真完成项目争取有产出亮点、多和 mentor 沟通积极主动、争取转正 offer（转正率通常 50%-70%）
- **补齐短板**：实习中发现缺什么补什么、准备秋招笔试面试、每周 5-10 道 LeetCode 保持手感

---

## 大四：拿 offer

> 大四是收获的季节。秋招是主战场，春招是补漏，毕业设计水到渠成。

### 上学期（9月-1月）— 秋招冲刺

- **金九银十**：9 月提前批+正式批网申（投 50+ 家）、10 月笔试面试密集期、11 月收 offer 谈薪资签三方
- **多拿 offer 对比**：至少拿 3 个再决定，对比维度（薪资/平台/业务/城市/WLB），第一份工作平台 > 业务 > 薪资
- **签三方注意**：了解违约金条款、确认落户政策、不要拖到最后一刻

### 下学期（2月-6月）— 收尾阶段

- **春招补录**（3-5 月）：秋招没满意 offer 的抓住最后机会，春招岗位少但竞争也小
- **毕业设计**：12 月-1 月选题，3 月开题，5 月答辩，尽量和实习或项目结合
- **毕业旅行 + 入职准备**：6 月答辩后毕业旅行、提前了解公司技术栈、租房搬家安排

## 关键时间节点

| 时间 | 大一 | 大二 | 大三 | 大四 |
|------|------|------|------|------|
| 9月 | 开学/四级备考 | 操作系统/网络 | 深度方向学习 | 秋招提前批 |
| 10月 | 加入社团 | 确定方向 | 写简历 | 秋招正式批 |
| 12月 | 四级考试 | 期末项目 | 投寒假实习 | 收offer/选offer |
| 1-2月 | 寒假自学 | 寒假项目 | 春招实习准备 | 毕设选题 |
| 3-4月 | 大一下开学 | 项目实战 | 春招实习笔试面试 | 春招补录 |
| 5-6月 | 期末复习 | 竞赛/找实习 | 暑期实习入职 | 毕业设计答辩 |
| 7-8月 | 暑假项目 | 实习/竞赛 | 大厂实习+转正 | 毕业旅行/入职 |

## 各方向技能地图

### 后端开发路线
- **大一**：C/C++ 基础 + 数据结构 + Java/Python
- **大二**：操作系统 + 网络 + 数据库 + Spring Boot
- **大三**：分布式 + 中间件 + 微服务 + 项目实战
- **大四**：系统设计 + 源码阅读 + 架构思维

### 前端开发路线
- **大一**：HTML/CSS/JS 基础 + Git
- **大二**：Vue/React + TypeScript + Node.js
- **大三**：工程化 + 性能优化 + 跨端 + 组件库
- **大四**：前端架构 + 全栈能力 + 工程化体系

### 算法/AI 路线
- **大一**：高数 + 线代 + 概率论 + C++/Python
- **大二**：数据结构 + 算法 + 机器学习 + PyTorch
- **大三**：细分方向（CV/NLP/推荐）+ 论文复现 + 竞赛
- **大四**：顶会论文 / 大厂算法实习 + 博士申请

### 网络安全路线
- **大一**：C/Python + 网络基础 + Linux
- **大二**：CTF 入门 + Web 安全 + 渗透测试
- **大三**：二进制安全 / 云安全 / 红蓝对抗
- **大四**：护网行动 + 安全研究员 / 甲方安全岗

## 避坑指南

### 不要只上课不做项目
- 大学课程和工业界严重脱节，光靠上课学的东西找工作远远不够
- 从大一下开始就要动手做项目，哪怕很小；项目经验 > 绩点（但也不能挂科）

### 不要等到大三才找实习
- 第一份实习最难找，越早开始越好
- 大二暑假能找到实习就已经赢了一半；小公司实习也比没有强

### 不要忽视英语
- 大厂面试很多有英文自我介绍或英文技术面
- 好的技术文档和论文都是英文的；六级尽量刷高分

### 不要盲目跟风 + 不要只刷题不做项目
- 别人学什么你就学什么，最后什么都不精；大二下确定方向后就深耕
- LeetCode 是敲门砖但项目才是区分度；面试官更关心你做过什么、解决过什么问题
- 刷题和项目的时间分配建议 3:7
