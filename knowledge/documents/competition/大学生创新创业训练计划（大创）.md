## 竞赛简介

大学生创新创业训练计划（简称"大创"）是教育部为深化高等教育教学改革、强化创新创业能力训练、增强高校学生创新能力和创业能力而实施的重要举措。大创计划由国家级、省级、校级三级项目体系构成，是大学生接触科研、开展创新实践的重要平台。

大创计划面向全体本科生，鼓励学生在导师指导下自主选题、自主设计、自主实施，培养科学思维和创新实践能力。项目周期通常为1-2年，涵盖自然科学、工程技术、人文社科等各个学科领域。

## 竞赛价值

- **科研入门首选**：本科生接触科研、参与学术研究的最佳入门途径
- **保研综测加分**：国家级/省级大创项目在保研和综合测评中均有加分
- **经费支持**：国家级项目资助1-2万元/项，省级项目资助0.5-1万元/项，校级项目资助0.2-0.5万元/项
- **导师资源**：获得专业导师的系统性指导，建立学术联系
- **成果产出**：可产出论文、专利、软著、产品原型等实质性成果
- **竞赛衔接**：大创成果可进一步打磨后参加挑战杯、互联网+等高级别赛事

## 参赛要求

1. **申报主体**：全日制普通本科在校生，以团队形式申报
2. **团队规模**：3-5名学生组成项目团队，设负责人1名
3. **指导教师**：每个项目必须配备1名指导教师，部分高校可配2名
4. **项目类型**：
   - **创新训练项目**：本科生个人或团队在导师指导下，自主完成创新性研究项目设计、研究条件准备和项目实施
   - **创业训练项目**：本科生团队在导师指导下，团队中每个学生在项目实施过程中扮演一个或多个具体角色
   - **创业实践项目**：本科生团队在学校导师和企业导师共同指导下，采用前期创新训练项目的成果，提出一项具有市场前景的创新性产品或服务
5. **立项条件**：选题明确、方案可行、团队合理、经费预算合理

## 赛制说明

大创计划采用**申报→评审→立项→中期检查→结题验收**的项目管理模式：

| 阶段 | 时间 | 说明 |
|------|------|------|
| 项目申报 | 每年3-4月 | 学生组队选题，提交立项申请书 |
| 校级评审 | 4-5月 | 学校组织专家评审，确定校级立项 |
| 省级/国家级推荐 | 5-6月 | 学校择优推荐省级和国家级项目 |
| 立项公布 | 6-7月 | 教育部门公布各级立项名单 |
| 中期检查 | 次年3-4月 | 提交中期报告，检查项目进展 |
| 结题验收 | 次年10-12月 | 提交结题材料，组织验收评审 |

项目周期一般为1-2年，国家级项目周期通常为2年。

## 含金量评级

- **难度系数**：⭐⭐⭐（立项门槛适中，重在过程和产出质量）
- **社会认可度**：💎💎💎（高校内部认可度高，企业研发岗有一定参考价值）
- **保研加分**：★★★☆（国家级项目加分较高，省级/校级递减）
- **科研训练价值**：★★★★★（本科生科研入门的最佳途径）

## 参赛全流程

### 1. 选题组队阶段（1-2月）
- 结合专业兴趣和导师研究方向确定选题
- 组建3-5人团队，成员专业互补
- 联系指导教师，确定项目方向和研究方案

### 2. 立项申报阶段（3-4月）
- 撰写立项申请书（5000-8000字）
- 内容包括：研究背景、研究内容、技术路线、创新点、进度安排、经费预算
- 准备答辩PPT，参加校內立项评审

### 3. 项目实施阶段（立项后-中期检查前）
- 按照计划开展研究工作
- 定期与导师沟通进展，及时调整方案
- 积累实验数据，形成阶段性成果
- 撰写中期检查报告

### 4. 结题验收阶段（中期后-结题前）
- 完成研究内容，整理研究成果
- 产出论文、专利、软著、产品原型等
- 撰写结题报告，准备结题答辩
- 参加结题验收评审

## 评审标准

### 立项评审标准
| 评审维度 | 考察要点 |
|----------|----------|
| 选题价值 | 选题的创新性、科学性、应用价值 |
| 方案可行性 | 技术路线、研究方法、进度安排是否合理 |
| 团队实力 | 团队成员专业背景、知识储备、分工合理性 |
| 创新程度 | 项目的创新点和特色 |
| 经费预算 | 预算编制的合理性、规范性 |

### 结题验收标准
| 评审维度 | 考察要点 |
|----------|----------|
| 完成情况 | 项目计划完成度、目标达成情况 |
| 成果质量 | 论文、专利、软著、产品等成果的数量和质量 |
| 创新水平 | 研究成果的创新性和学术/应用价值 |
| 学生收获 | 团队成员的能力提升和成长情况 |
| 经费使用 | 经费使用的规范性和合理性 |

## 获奖策略

1. **选题紧扣热点**：选择学科前沿或国家战略相关方向，容易获得评审青睐
2. **导师资源用好**：选择有研究基础、愿意指导的导师，争取加入导师课题组
3. **团队分工明确**：成员各有专长，分工清晰，避免挂名混经历
4. **成果意识要强**：从立项初期就规划好成果产出（论文、专利、软著等）
5. **过程管理到位**：定期组会汇报，及时记录实验数据，做好文档管理
6. **申请书质量高**：立项申请书逻辑清晰、论证充分、格式规范
7. **早启动早准备**：提前了解导师研究方向，寒假期间就开始准备立项材料

## 对就业/创业的帮助

### 就业方面
- **考研复试加分**：有大创经历在考研复试中是重要加分项，体现科研潜力
- **研发岗优势**：应聘企业研发岗时，大创项目经历可证明动手能力和研究能力
- **技术岗面试**：大创项目是技术面试中的优质谈资，可深入讨论技术细节
- **学术深造**：国家级大创+论文产出，对申请保研和海外高校有帮助

### 创业方面
- **创业预演**：创业训练/实践项目是低成本的创业试水机会
- **资源积累**：通过大创积累技术成果、团队伙伴和行业认知
- **赛事跳板**：大创成果可进一步打磨后参加互联网+、挑战杯等创业赛事
- **创业资助**：优秀创业实践项目可获得额外的创业扶持资金和孵化资源

## 典型获奖案例

1. **"基于深度学习的图像去噪算法研究"（国家级创新训练）**：项目产出2篇SCI论文，团队3人全部保送985高校研究生
2. **"校园智能快递柜系统"（创业实践项目）**：从大创起步，逐步发展为校园创业项目，获得天使投资
3. **"新型锂电池正极材料研究"（国家级创新训练）**：获结题优秀，申请发明专利2项，团队成员入职头部新能源企业
4. **"乡村振兴背景下的数字农业调研"（省级创新训练）**：产出高质量调研报告，获省级优秀大创项目，成员考取选调生
