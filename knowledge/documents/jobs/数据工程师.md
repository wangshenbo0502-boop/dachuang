# 简介

数据工程师（Data Engineer）是负责数据基础设施建设、数据管道开发、数据仓库构建和数据平台维护的专业技术岗位。与数据分析师侧重业务洞察、数据科学家侧重算法建模不同，数据工程师的核心职责是构建稳定、高效、可扩展的数据系统，确保数据从采集、存储、处理到服务的全链路畅通。数据工程师是大数据时代的"管道工"和"建筑师"，为上层数据分析、BI报表、机器学习、AI应用提供可靠的数据底座。主要技术方向包括离线大数据开发（Hadoop/Spark/Hive）、实时计算（Flink/Kafka/Spark Streaming）、数据仓库建模、数据中台建设等。

# 最新数据

- **招聘需求稳定增长**：猎聘《2025年大数据人才招聘报告》显示，数据工程师/大数据开发岗位全年招聘量同比增长22%，在技术类岗位中保持稳健增长。
- **实时计算方向热度最高**：Flink岗位需求增速最快，2025年同比增长超50%，实时数仓和流批一体成为企业建设重点。
- **数据中台建设降温但未停**：经历2021-2023年的"数据中台热"后，企业对数据中台的投入更趋理性，从"大而全"转向"小而美"的数据治理和数据资产化。
- **Lakehouse架构兴起**：数据湖仓一体（Data Lakehouse）成为2025-2026年最热门的数据架构趋势，Iceberg/Hudi/Delta Lake三大表格式快速普及。
- **AI驱动数据工程升级**：大模型训练数据管道、向量数据库、特征平台（Feature Store）等AI相关数据工程岗位快速增长。
- **云原生大数据成主流**：企业上云加速，EMR、Databricks、MaxCompute等云原生大数据服务替代传统自建Hadoop集群成为趋势。

# 当前就业趋势

1. **实时计算是最大增长点**：Flink已成为实时计算的事实标准，掌握Flink SQL和Flink DataStream的数据工程师薪资溢价明显。
2. **流批一体架构普及**：以Flink为核心的流批一体架构替代传统的Lambda架构，减少运维复杂度和数据冗余。
3. **SQL能力越来越重要**：大数据开发从写MapReduce/Spark代码向写SQL演进，Hive SQL/Spark SQL/Flink SQL是日常工作的核心。
4. **数据治理受重视**：数据质量、数据血缘、元数据管理、数据安全等数据治理能力成为高级数据工程师的必备技能。
5. **云原生替代自建Hadoop**：传统Hadoop运维岗位缩减，基于云服务（阿里云EMR/MaxCompute、AWS EMR/Athena）的数据开发岗位增加。
6. **数据工程师向数据平台工程师演进**：纯ETL开发岗位价值下降，能建设数据平台、提升研发效能的数据平台工程师更受青睐。
7. **AI数据工程新赛道**：为大模型准备训练数据、构建特征平台、维护向量数据库成为新兴高薪方向。
8. **一线城市集中度高**：北京、上海、深圳、杭州集中了约70%的大数据岗位，新一线城市以成都、武汉、西安为主。

# 核心技能

## 初级数据工程师（0-2年）
- 编程语言：Java/Scala（主流）或Python，SQL必须熟练
- Hadoop生态：HDFS、YARN、MapReduce原理理解
- Hive数据仓库：Hive SQL、分区/分桶、UDF开发、数据倾斜处理
- Spark基础：Spark Core、Spark SQL、DataFrame/Dataset API
- 数据采集：Sqoop/DataX离线采集、Flume/Logstash日志采集
- 消息队列：Kafka基本使用（Topic/Partition/Producer/Consumer）
- Linux基础：Shell脚本编写、常用命令、集群基础运维
- 数据库：MySQL基础、Redis基础使用
- 数据仓库理论：维度建模基础（星型模型、雪花模型）、事实表/维度表概念

## 中级数据工程师（2-5年）
- Spark进阶：Spark调优（内存管理、Shuffle优化、数据倾斜处理）、Spark Streaming
- Flink实时计算：Flink DataStream API、Flink SQL、窗口函数、Watermark、状态管理、Checkpoint
- 数据仓库建模：Kimball维度建模方法论、分层架构（ODS/DWD/DWS/ADS）、缓慢变化维处理
- 实时数仓：基于Kafka + Flink + HBase/Doris/ClickHouse构建实时数仓
- OLAP引擎：ClickHouse/Doris/StarRocks/Presto/Trino至少一种深度使用
- 数据集成与调度：Airflow/DolphinScheduler/Azkaban任务调度，DataX/Flink CDC数据同步
- 数据湖：Iceberg/Hudi/Delta Lake至少一种，理解湖仓一体架构
- 数据治理：数据质量监控（Great Expectations/Apache Griffin）、元数据管理（Atlas）
- 性能调优：SQL优化、任务调优、存储优化（列式存储、压缩格式Parquet/ORC）

## 高级数据工程师/架构师（5年+）
- 大数据架构设计：
  - 流批一体架构设计与落地
  - 湖仓一体架构（Iceberg/Hudi + Spark/Flink + OLAP引擎）
  - 企业级数据中台架构规划
  - 万亿级数据量下的系统设计
- 平台建设：数据平台/数据资产平台/数据服务平台（OneService）设计与建设
- 实时计算深度：Flink内核优化、CEP复杂事件处理、Flink CDC实时入湖
- 云原生大数据：Kubernetes上运行大数据（Spark on K8s/Flink on K8s）、存算分离架构
- AI数据工程：特征平台（Feast）、向量数据库（Milvus/Pinecone）、大模型训练数据管道
- 数据治理体系：数据标准、数据质量、数据安全（脱敏/权限/审计）、数据血缘
- 团队管理：数据团队建设、技术规范制定、跨部门协作
- 技术选型与成本优化：云资源成本管控、存储计算成本优化

# 企业要求

- **学历要求**：本科及以上为基本门槛，大数据/数据平台核心岗位偏好计算机相关专业本科以上；大厂架构师岗位普遍要求985/211或硕士学历。
- **编程能力**：Java/Scala是大数据开发的主流语言，Flink和Spark生态以Java/Scala为主；Python在数据科学和AI数据工程方向使用较多。
- **SQL能力**：SQL是数据工程师的核心工具，面试中SQL编写和优化是必考点（窗口函数、复杂聚合、执行计划分析）。
- **项目经验**：中高级岗位要求有完整的数据仓库建设或实时计算项目经验，能描述数据流向、架构设计、技术选型和遇到的挑战。
- **业务理解**：需要理解业务逻辑才能进行合理的数据建模，优秀的数据工程师既懂技术又懂业务。
- **数据量门槛**：高级岗位普遍要求处理过TB/PB级数据量的经验，小数据量背景在面试中缺乏竞争力。

# 学习建议

1. **先学好SQL和Linux**：SQL是数据工程师最核心的技能，Linux是大数据运行的基础环境，这两项不扎实后面寸步难行。
2. **从Hadoop生态入手**：学习HDFS、YARN、Hive、HBase，理解分布式存储和计算的基本原理，搭建本地伪分布式集群练手。
3. **重点掌握Spark和Flink**：Spark是离线计算标配，Flink是实时计算标配，这两个框架是面试的重中之重。
4. **深入数据仓库建模**：学习Kimball维度建模理论，理解数仓分层设计（ODS/DWD/DWS/ADS），实践中积累建模经验。推荐《数据仓库工具箱》。
5. **动手做完整项目**：搭建一个从数据采集（Flume/DataX）-> 消息队列（Kafka）-> 实时处理（Flink）-> 存储（HBase/ClickHouse）-> 可视化的完整数据管道。
6. **学习OLAP引擎**：ClickHouse和Apache Doris/StarRocks是当前最热门的OLAP引擎，至少掌握一种。
7. **关注湖仓一体趋势**：学习Apache Iceberg或Hudi，理解Lakehouse架构如何解决传统数仓和数据湖的痛点。
8. **了解云原生大数据**：学习Spark/Flink on Kubernetes，了解主流云厂商的大数据产品（阿里云EMR/MaxCompute、AWS EMR/Athena）。
9. **了解AI数据工程**：学习向量数据库（如Milvus）和特征工程平台的基本概念，AI+数据是未来重要方向。
10. **刷题准备面试**：LeetCode中等难度算法题、SQL题（窗口函数、TopN、连续登录等经典题型）必须熟练。

# AI总结

数据工程师是数据领域中技术栈最重、工程要求最高的方向，也是大数据和AI时代的基础性岗位。2025-2026年，数据工程师就业市场呈现"稳中有变"的格局：传统离线Hadoop/Spark开发岗位竞争激烈，但实时计算（Flink）、数据平台建设、湖仓一体架构、AI数据工程等方向人才稀缺、薪资看涨。薪资方面，应届12-20K，1-3年15-28K，3-5年25-40K，资深大数据架构师可达50-80K+。与数据分析师相比，数据工程师更侧重技术实现而非业务洞察，技术门槛更高、薪资天花板也更高。值得注意的趋势是：SQL能力取代手写代码成为日常核心，云原生大数据服务替代传统自建集群，实时流处理取代纯离线批处理成为标配。对于求职者，建议以"Java/Scala + SQL + Spark + Flink + 数仓建模"为核心技能栈，重点攻克实时计算方向，同时关注湖仓一体和AI数据工程的新机会。
