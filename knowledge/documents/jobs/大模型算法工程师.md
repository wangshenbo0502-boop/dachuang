# 简介

大模型算法工程师（LLM Algorithm Engineer）是当前AI行业最核心、薪资最高的岗位方向之一，负责大语言模型（Large Language Model）的预训练、指令微调（SFT）、人类反馈强化学习对齐（RLHF/DPO）、多模态扩展以及推理优化等核心算法工作。与大模型应用工程师侧重API集成和应用开发不同，大模型算法工程师深入模型内部，直接参与基座模型的训练与迭代。

该岗位是DeepSeek、字节跳动（Seed/豆包）、阿里（通义千问）、腾讯（混元）、百度（文心一言）、MiniMax、月之暗面（Kimi）、智谱AI等头部AI公司的核心招聘方向，也是2025-2026年竞争最激烈、技术门槛最高的技术岗位之一。

# 最新数据

根据猎聘2026年7月最新招聘数据，大模型算法工程师岗位在杭州、北京、上海、深圳等地需求旺盛。字节跳动LLM大模型算法工程师开出30K-60K·15薪的待遇；某头部AI公司资深大模型算法工程师/算法负责人月薪可达100K-150K·13薪；大模型Posttrain（后训练）算法工程师岗位薪资达55K-85K。脉脉高聘数据显示，2025年1-2月大模型算法工程师平均月薪达68,051元，位居AI岗位薪资榜首。

CSDN《2025大模型求职报告》指出，2026届大厂AI算法工程师校招年薪普遍在35万-45万，顶尖候选人（有大模型训练经验、顶会论文）总包可突破50万-80万，相比2025届涨幅约15%-20%。大模型算法岗是AI领域校招薪资天花板，字节跳动大模型算法岗校招SSP级别可达34K×15≈51万，加上签字费和股票总包可超70万；腾讯混元大模型语音算法岗社招开出100K-200K·16薪的高薪。

# 当前就业趋势

**头部企业抢人激烈**：DeepSeek（杭州）大模型算法工程师年薪60-120万；MiniMax（上海）算法研究员月薪5-8万·14薪；月之暗面/Kimi（北京）大模型训练工程师年薪80-150万；阿里云通义算法专家P7-P8级别年薪70-200万。第一梯队企业（阿里、字节、科大讯飞）和第二梯队新锐（DeepSeek、智谱AI、MiniMax、月之暗面）均在大规模扩招。

**岗位细分专业化**：大模型算法岗位已细分为预训练工程师（Pre-training）、后训练/对齐工程师（SFT/RLHF/DPO）、推理优化工程师（Inference Optimization）、多模态大模型工程师等方向，每个方向的技术栈和能力要求差异显著。

**学历门槛最高**：大模型算法岗是AI领域学历要求最高的方向，头部公司校招基本要求硕士及以上，核心预训练岗位优先博士。但同时，有实际大模型训练经验（如开源项目贡献、百亿级模型训练经验）的候选人学历可适当放宽。

**推理优化方向需求爆发**：随着大模型从训练走向部署，推理优化工程师（CUDA编程、TensorRT/vLLM、模型量化压缩、KV Cache优化）需求激增，年薪50-100万，高性能计算工程师出现7个岗位抢1个人的局面。

**城市集中度高**：北京、上海、深圳、杭州是大模型算法岗位最集中的城市，杭州因DeepSeek、阿里等公司成为新增大模型岗位的重要城市。

# 核心技能

## 理论基础

- **深度学习核心**：精通Transformer架构原理（Self-Attention、Multi-Head Attention、位置编码、LayerNorm），理解GPT/BERT/Llama/Qwen/DeepSeek等主流模型架构差异
- **预训练理论**：掌握因果语言建模（CLM）、掩码语言建模（MLM）、预训练数据配比、学习率调度（Cosine/Warmup）、混合精度训练（FP16/BF16）
- **后训练与对齐**：精通SFT（监督微调）、RLHF（PPO算法）、DPO/ORPO/KTO等对齐算法原理，理解RLAIF、Constitutional AI等前沿对齐方法
- **分布式训练**：理解数据并行（DP/DDP）、张量并行（TP）、流水线并行（PP）、ZeRO优化策略、序列并行（SP）
- **推理优化理论**：理解KV Cache、PagedAttention、投机解码（Speculative Decoding）、模型量化（GPTQ/AWQ/GGUF）、Flash Attention等

## 技术栈

- **编程语言**：精通Python，熟悉C++/CUDA编程（推理优化方向必备）
- **深度学习框架**：精通PyTorch，了解JAX/Flax
- **分布式训练框架**：熟练使用DeepSpeed、Megatron-LM、FSDP、Colossal-AI
- **推理框架**：熟悉vLLM、TensorRT-LLM、TGI（Text Generation Inference）、llama.cpp、SGLang
- **开源模型**：熟悉Hugging Face Transformers/PEFT/Accelerate生态，有Llama/Qwen/DeepSeek等开源模型微调经验
- **数据处理**：熟悉大规模数据清洗、去重、质量过滤、数据配比策略

## 工程能力

- **训练工程**：能处理千卡/万卡集群训练中的故障排查、梯度累积、Checkpoint保存与恢复、OOM问题定位
- **微调能力**：熟练使用LoRA/QLoRA/全参微调，能设计SFT数据构造方案、训练策略
- **评测能力**：掌握大模型评测方法（MMLU/C-Eval/GSM8K/HumanEval/MT-Bench），能构建领域评测集
- **论文复现**：具备快速复现arXiv前沿论文并应用到实际模型训练中的能力

# 企业要求

## 学历要求

- 硕士及以上学历，计算机科学、人工智能、数学、电子信息等相关专业
- 预训练/核心算法岗博士优先，有顶会论文（NeurIPS/ICML/ICLR/ACL/EMNLP等）者大幅加分
- 推理优化方向对C++/CUDA工程能力要求极高，硕士+扎实工程能力即可

## 经验要求

- **校招/应届生**：有大模型相关研究经历（实验室项目）、开源贡献（Hugging Face/LLaMA Factory等）、竞赛获奖或顶会论文
- **1-3年**：有百亿/千亿参数模型训练或微调经验，能独立负责SFT/DPO数据构建与训练
- **3-5年**：能主导大模型训练或对齐方案设计，有从0到1训练大模型或参与基座模型训练的核心经验
- **5年以上**：大模型算法专家/负责人，能制定模型技术路线，带领团队攻克预训练/对齐技术难题

## 典型JD要求

1. 计算机/AI相关专业硕士及以上学历，扎实的深度学习和自然语言处理基础
2. 精通Transformer架构，深入理解大模型预训练、SFT、RLHF/DPO等技术原理
3. 熟练使用PyTorch和DeepSpeed/Megatron等分布式训练框架，有大规模模型训练经验
4. 熟悉大模型推理优化技术（vLLM/TensorRT-LLM/量化/Flash Attention），有推理优化经验者优先
5. 有Llama/Qwen/DeepSeek等开源模型微调或二次开发经验
6. 在NeurIPS/ICML/ICLR/ACL等顶会发表过论文，或在GitHub有高质量开源项目贡献者优先
7. 具备优秀的英文论文阅读能力，紧跟大模型前沿进展

# 学习建议

## 阶段一：深度学习与Transformer基础（2-3个月）

1. **深度学习巩固**：复习神经网络、反向传播、优化器、正则化等核心知识
2. **Transformer精读**：精读《Attention Is All You Need》论文，理解Self-Attention、Multi-Head Attention、位置编码细节
3. **PyTorch进阶**：熟练掌握PyTorch自定义算子、分布式训练基础、混合精度训练
4. **Hugging Face实战**：使用Transformers库加载预训练模型，完成文本生成、分类等任务

## 阶段二：大模型核心技术（3-5个月）

1. **预训练学习**：学习GPT系列、LLaMA系列论文，理解预训练数据处理、训练策略；使用Megatron-DeepSpeed在小规模数据上训练小模型（如1B参数）
2. **微调实践**：学习LoRA/QLoRA原理，使用LLaMA Factory/PEFT完成SFT微调实践；理解DPO/PPO算法，尝试DPO对齐实验
3. **推理优化**：学习vLLM源码（PagedAttention）、Flash Attention原理、GPTQ/AWQ量化方法，使用vLLM部署开源模型
4. **评测体系**：学习MMLU/C-Eval/GSM8K等评测基准，使用OpenCompass/lm-evaluation-harness进行模型评测
5. **项目一**：完成一个完整的大模型微调+部署项目（如：垂直领域对话模型、代码助手模型）

## 阶段三：进阶与求职准备（3-4个月）

1. **源码精读**：精读DeepSpeed/Megatron核心代码，理解分布式训练实现细节
2. **CUDA编程**：学习CUDA基础编程，理解GPU架构和Kernel优化，为推理优化方向打基础
3. **论文追踪**：定期阅读arXiv（cs.CL/cs.LG），复现关键论文，写论文笔记/技术博客
4. **开源贡献**：给LLaMA Factory/vLLM/Transformers等开源项目提交PR，积累开源影响力
5. **实习/竞赛**：争取大模型团队实习机会，或参与大模型相关竞赛/黑客松
6. **面试准备**：准备Transformer细节、分布式训练原理、RLHF/DPO算法推导、手撕Attention/CUDA Kernel等面试高频题

## 推荐学习资源

- **课程**：李沐《动手学深度学习》d2l.ai、斯坦福CS224N/CS230/CS336（大模型专题）、Hugging Face NLP Course
- **书籍**：《深度学习》（花书）、《自然语言处理：基于预训练模型的方法》、《Build a Large Language Model From Scratch》
- **论文必读**：Attention Is All You Need、GPT-1/2/3、LLaMA/LLaMA 2/3、InstructGPT、Training language models to follow instructions with human feedback（RLHF）、DPO、LoRA、Flash Attention
- **开源项目**：Hugging Face Transformers/PEFT、LLaMA Factory、DeepSpeed、Megatron-LM、vLLM、SGLang
- **社区**：arXiv、GitHub Trending、HuggingFace Papers、机器之心、量子位、Semantic Scholar

# AI总结

大模型算法工程师是2025-2026年AI行业薪资最高、技术门槛最高的岗位方向，应届硕士起薪30K-50K，3-5年经验可达50K-80K，资深专家年薪可达200万以上。DeepSeek、字节、阿里、MiniMax、月之暗面等头部企业争抢人才，但岗位要求也极为严苛——扎实的Transformer理论功底、大规模分布式训练经验、深度学习框架源码理解能力是核心要求。该岗位学历门槛较高，头部公司普遍要求硕士及以上，预训练核心岗优先博士，但推理优化等工程方向更看重实际CUDA编程和工程能力。对于有志于进入该领域的学生，建议从Transformer论文精读入手，系统学习预训练-微调-对齐全流程，通过开源贡献和实际模型训练经验积累竞争力，顶会论文和高质量开源项目是进入头部公司的最佳敲门砖。
