# 简介

计算机视觉算法工程师（Computer Vision Algorithm Engineer）是人工智能领域的核心岗位之一，负责研究和开发让计算机"看懂"图像和视频的算法与系统。CV技术广泛应用于自动驾驶、安防监控、人脸识别、工业质检、医疗影像、OCR文字识别、图像搜索、AIGC图像生成、增强现实等场景。

在大模型和多模态时代，CV领域正在经历两大变革：一是传统CV任务（检测/分割/分类）与Transformer架构（ViT/DETR/SAM）深度融合，二是AIGC图像生成（Stable Diffusion/ControlNet/FLUX）和多模态大模型（GPT-4V/LLaVA/Qwen-VL）开辟了全新的应用方向。CV工程师的技术栈需要从传统CNN方法扩展到Transformer、Diffusion Model和多模态大模型。

# 最新数据

根据猎聘2026年7月数据，计算机视觉算法工程师岗位需求保持稳定，自动驾驶和AIGC方向薪资突出。字节跳动CV算法工程师校招开出28K-45K·15薪；华为自动驾驶CV算法岗（车BU）社招薪资40K-70K·14-16薪；商汤科技/旷视科技资深CV算法专家月薪可达50K-80K；AIGC方向（图像/视频生成）算法工程师在AI独角兽公司薪资可达35K-65K。

BOSS直聘数据显示，2026年上半年CV岗位招聘中，多模态和AIGC方向同比增长约35%，自动驾驶CV方向增长约15%，而传统安防/人脸方向需求相对平稳。CVPR 2025会议收录论文中，多模态、3D视觉、AIGC和自动驾驶相关论文占比超过60%，反映了学术界和工业界的研究热点。OpenMMLab生态持续发展，成为CV工程师必备的开源工具链。

# 当前就业趋势

**CV+多模态+AIGC是热门方向**：Stable Diffusion、ControlNet、Sora、可灵等文生图/文生视频模型引爆AIGC应用，多模态大模型（VLM）打通视觉与语言的壁垒。具备Diffusion Model微调和多模态大模型开发能力的CV工程师薪资溢价显著。

**自动驾驶CV方向持续火热**：特斯拉、华为、小鹏、理想、蔚来、百度Apollo、Momenta、文远知行等公司持续招聘自动驾驶感知算法工程师，3D目标检测、BEV感知、Occupancy Network等方向需求旺盛，薪资普遍高于传统CV岗位20%-30%。

**传统CV检测岗需求稳定**：目标检测、图像分割、OCR、人脸识别等传统CV任务在工业质检、安防、金融、零售等行业仍有大量落地需求，YOLO/RT-DETR等轻量高效模型在工业界广泛使用。

**医疗影像CV方向壁垒高**：医学影像分析（CT/MRI/病理切片分析）是CV的重要垂直领域，对专业知识要求高，岗位竞争相对较小但门槛高。

**3D视觉与具身智能兴起**：3D重建、NeRF/3D Gaussian Splatting、机器人视觉感知、具身智能（Embodied AI）等前沿方向受到关注，被视为下一代AI的重要方向。

**端侧部署需求增长**：随着AI应用向移动端和边缘设备延伸，具备模型压缩、量化、端侧部署（NCNN/TNN/MNN/TensorRT）能力的CV工程师需求增加。

# 核心技能

## 理论基础

- **CV基础任务**：精通图像分类、目标检测、图像分割（语义分割/实例分割/全景分割）、人脸识别、OCR、图像检索等经典CV任务
- **传统CV方法**：理解图像处理基础（滤波/边缘检测/特征提取/SIFT/HOG）、经典分类网络（LeNet/AlexNet/VGG/ResNet/EfficientNet）
- **目标检测**：精通YOLO系列（v3/v5/v8/v11）、Faster R-CNN、SSD、DETR/RT-DETR、DINO等检测算法
- **图像分割**：精通FCN/U-Net/Mask R-CNN/DeepLab系列/SAM（Segment Anything Model）等分割算法
- **Transformer在CV中的应用**：理解ViT（Vision Transformer）、Swin Transformer、DETR系列等视觉Transformer架构
- **AIGC图像生成**：理解GAN/VAE/Diffusion Model（DDPM/Stable Diffusion/ControlNet/FLUX）原理，掌握文生图/图生图/ControlNet控制
- **多模态大模型**：理解CLIP/BLIP/LLaVA/Qwen-VL等视觉语言模型（VLM）架构，掌握多模态对齐原理
- **3D视觉**：了解点云处理（PointNet/PointPillars）、BEV感知、NeRF/3D Gaussian Splatting等3D视觉技术

## 技术栈

- **编程语言**：精通Python，熟悉C++（工业部署必备）
- **深度学习框架**：精通PyTorch，熟悉TensorFlow
- **CV开源框架**：熟练使用OpenMMLab（MMDetection/MMSegmentation/MMDeploy）、Detectron2、Ultralytics YOLO
- **图像处理库**：熟练使用OpenCV、PIL/Pillow
- **推理部署**：熟悉TensorRT、ONNX Runtime、NCNN/MNN/TNN等推理框架，掌握模型导出和优化
- **AIGC工具**：熟悉Diffusers、ComfyUI、Stable Diffusion WebUI等AIGC工具链
- **多模态工具**：熟悉Hugging Face Transformers中的多模态模型（CLIP/LLaVA等）

## 工程能力

- **模型训练**：能独立完成CV模型的数据准备、训练、调参、评估全流程
- **数据标注与增强**：掌握数据标注规范、数据增强策略（Mosaic/Mixup/CutMix/AugMix等）
- **模型部署**：能将训练好的模型部署到服务器/端侧/边缘设备，处理性能优化和延迟控制
- **评测分析**：掌握CV任务评测指标（mAP/IoU/Precision/Recall/F1/PSNR/SSIM等），能进行错误分析

# 企业要求

## 学历要求

- 硕士及以上学历，计算机科学、人工智能、电子信息、自动化、数学等相关专业
- 头部大厂和自动驾驶公司核心算法岗博士优先，有CVPR/ICCV/ECCV/NeurIPS/ICML等顶会论文者大幅加分
- 有CV竞赛获奖经历（如COCO/Kaggle/天池/ Kaggle CV竞赛）或高质量开源项目贡献者优先

## 经验要求

- **校招/应届生**：有CV相关研究或项目经历，熟悉经典CNN和Transformer模型，有竞赛或实习经历
- **1-3年**：能独立完成CV任务建模和上线，有目标检测/分割/OCR/AIGC等方向实战经验
- **3-5年**：能主导CV算法方案设计，有大规模CV系统落地经验，对特定垂直领域（自动驾驶/医疗/AIGC）有深入理解
- **5年以上**：CV算法专家/架构师，能制定技术路线，带领团队攻克视觉技术难题

## 典型JD要求

1. 计算机/AI/电子信息相关专业硕士及以上学历，扎实的计算机视觉和深度学习基础
2. 精通目标检测/图像分割/图像分类等经典CV任务，熟练掌握YOLO/DETR/Transformer等算法
3. 熟练使用PyTorch和OpenMMLab/Detectron2等开源框架，有CV项目落地经验
4. 熟悉Diffusion Model和AIGC图像生成，有多模态大模型（VLM）经验者优先
5. 具备C++编程能力和TensorRT/ONNX模型部署经验
6. 在CVPR/ICCV/ECCV等顶会发表过论文，或有知名CV竞赛获奖经历者优先
7. 有自动驾驶/医疗影像/工业质检/OCR等行业落地经验者优先

# 学习建议

## 阶段一：CV与深度学习基础（2-3个月）

1. **深度学习基础**：系统复习CNN原理、反向传播、优化器、正则化等核心知识
2. **图像处理基础**：学习OpenCV基本操作，理解图像滤波、边缘检测、形态学处理、特征提取
3. **经典CV网络**：学习LeNet/AlexNet/VGG/ResNet/EfficientNet等分类网络演进
4. **PyTorch实战**：使用PyTorch完成图像分类任务，掌握数据加载、训练、评估全流程

## 阶段二：CV核心任务与Transformer（3-5个月）

1. **目标检测**：系统学习YOLO系列、Faster R-CNN、DETR/RT-DETR等检测算法，使用MMDetection/Ultralytics完成检测项目
2. **图像分割**：学习U-Net/Mask R-CNN/DeepLab/SAM等分割算法，完成语义分割/实例分割项目
3. **视觉Transformer**：精读ViT、Swin Transformer论文，理解Self-Attention在视觉任务中的应用
4. **OCR/人脸识别**：了解OCR（DBNet/CRNN/SVTR）和人脸识别（ArcFace）技术方案
5. **项目一**：完成一个完整的CV应用项目（如：工业缺陷检测、交通标志识别、人像分割）

## 阶段三：前沿方向与求职准备（3-4个月）

1. **AIGC图像生成**：学习Diffusion Model原理（DDPM/Stable Diffusion/ControlNet），使用Diffusers/ComfyUI完成文生图/图生图微调项目
2. **多模态大模型**：学习CLIP/BLIP/LLaVA等VLM模型，理解视觉-语言对齐原理，尝试多模态应用开发
3. **3D视觉/自动驾驶**：了解BEV感知、3D目标检测、NeRF/3DGS等3D视觉技术（自动驾驶方向重点）
4. **模型部署**：学习TensorRT/ONNX模型导出和量化，掌握NCNN/MNN端侧部署
5. **开源贡献**：给OpenMMLab/Ultralytics等CV开源项目提交PR
6. **竞赛/论文**：参加Kaggle/天池CV竞赛，或尝试复现CVPR/ICCV前沿论文
7. **面试准备**：准备CNN/Transformer原理、目标检测算法对比、手撕代码、CV系统设计、模型部署等高频面试题

# AI总结

计算机视觉算法工程师是AI领域历史最悠久、应用最广泛的岗位方向之一，2025-2026年正处于多模态和AIGC技术带来的新一轮变革期。应届硕士起薪25K-45K，3-5年经验可达40K-70K，自动驾驶和AIGC方向薪资更高。传统CV检测/分割/OCR方向需求稳定，而CV+多模态+AIGC成为增长最快的热门方向，自动驾驶感知方向薪资最具竞争力。对于求职者，建议在扎实掌握CV基础（分类/检测/分割）的前提下，重点拓展三个方向：一是AIGC图像生成（Diffusion Model/ControlNet），二是多模态大模型（VLM），三是模型部署能力（TensorRT/端侧部署）。自动驾驶方向的同学还需深入3D视觉和BEV感知技术。OpenMMLab生态是CV工程师必须掌握的开源工具链，顶会论文和竞赛经历是进入头部公司的核心竞争力。
