# graph/ — 知识图谱模块

## 目录职责
构建和维护技能-岗位-企业的领域知识图谱，支持图检索增强生成（Graph RAG）。

## 当前状态
【预留】当前关闭。仅保留接口框架。

## 未来用途
- 构建技能依赖图（学 A 之前需要先掌握 B）
- 构建岗位-技能映射图
- 发现隐藏的学习路径
- 支持 Graph RAG（结合传统检索和图谱推理）

## 技术选型（未来）
| 组件 | 选项 |
|------|------|
| 图存储 | Neo4j（生产）/ NetworkX（开发） |
| 图查询 | Cypher |
| 方法论 | Microsoft Graph RAG |
