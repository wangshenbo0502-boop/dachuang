AI就业竞争力分析助手
Backend API Interface Specification
后端接口设计规范文档 V1.0
1. 文档说明
1.1 项目名称
AI就业竞争力分析助手
英文名称：
AI Job Competitiveness Analyzer
1.2 文档目的
本文档用于规定系统后端 API 接口标准，是前后端开发、AI辅助编码、系统测试以及后期维护的唯一接口依据。
所有前端页面、后端服务、大模型调用模块以及第三方服务接入，均需要遵循本文档定义。
1.3 技术架构
系统采用前后端分离架构：
                用户浏览器

                    |
                    |
              Vue3 + TypeScript
                    |
                    |
              REST API接口
                    |
                    |
              FastAPI Backend

        ---------------------------
        |            |            |

     MySQL       Knowledge      AI Engine

     数据库       RAG知识库     DeepSeek
2. 接口设计原则
2.1 RESTful规范
接口采用 REST 风格设计：
操作	HTTP方法
查询数据	GET
新增数据	POST
修改数据	PUT
删除数据	DELETE


例如：
查询用户：
GET

/api/v1/users/profile
创建技能：
POST

/api/v1/users/skills
3. 基础接口规范
3.1 服务地址
开发环境：
http://localhost:8000
统一接口前缀：
/api/v1
完整接口：
http://localhost:8000/api/v1/users/profile
3.2 数据格式
所有普通接口：
请求：
Content-Type: application/json
返回：
{
    "code":200,
    "message":"success",
    "data":{}
}
3.3 统一响应结构
成功响应
{
    "code":200,

    "message":"success",

    "data":{
        
    }
}
字段说明：
字段	类型	说明
code	int	状态码
message	string	提示信息
data	object	业务数据


失败响应
{
    "code":4001,

    "message":"参数错误",

    "data":null
}

AI生成代码规则
1. 禁止直接在 API 层写业务逻辑
错误：
@app.post()
def match():
    查询数据库
    算匹配度
正确：
API

↓

Service

↓

Repository

2. DeepSeek调用必须统一：
app/ai/deepseek_client.py
3. 所有接口必须：
   - 有请求Schema
   - 有响应Schema
   - 有异常处理
   - 有接口注释
